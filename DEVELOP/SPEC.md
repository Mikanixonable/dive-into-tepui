## 1. 基本ゲームシステム

- 舞台: 実寸・実時間の地球低軌道(ECI 座標系、Y 軸 = 北極、単位 m / m/s)。
- 視点: 自機中心の三人称チェイスカメラ(上 = 動径方向、前 = 速度方向に緩やかに追従)。
- 操作:
  - 並進(フレーム基準): W/S = プログレード/レトログレード、A/D = ノーマル/アンチノーマル、Q/E = ラジアルイン/アウト。
  - [F] でターゲット基準フレームに切替(視線方向=接近/離脱、左右、上下)。
  - 回転: I/K = ピッチ、J/L = ヨー、U/O = ロール。角速度に上限はなく、RCS を吹き続けるほど加速し続ける。[T] で RCS 回転制動 ON/OFF。[V] で微調整モード(角加速度を約 3% に絞る)。
  - 姿勢制御ノズルは機首側4隅に2基ずつの計8基で、いずれも機体外向きに固定されている。噴射して見えるのは、そのノズルが生む
    トルクが指令トルクと同じ側を向くものだけ — どのキーを押しても4基が噴き、押しているキーと噴いているノズルは常に対応する。
  - エンジン出力 3 段階([1]/[2]/[3]、5.0 / 20.0 / 100.0 m/s²)。
  - 並進6キー(W/S/A/D/Q/E)は単押しなら押している間だけ噴射する。0.3 秒以内に同じキーを2回押すと、
    押しっぱなし相当で噴射し続ける「ラッチ」状態になる。解除は同じキーをもう一度2回押すか、逆方向の
    キーを押す(押している間ずっと解除され、離すと復活はしない)か、艦を操作対象から外す/格納する
    ことによる。タイムワープ×4を超える間は連打してもラッチが立たず、押下自体もカウントされない
    (ワープを下げた瞬間に不意打ちの噴射が始まることはない)。
  - [9]/[0] で右/左ラジエーターの展開・収納を切り替える(ステータスウィンドウのボタンと同じ操作)。
  - [,]/[.] でタイムワープ(×1〜×131072)。推進・射撃はワープ×4以下でのみ可能。
  - 画面上部中央のグローバルステータスバーは絶対日時(`yyyymmddhhmmss`、UTC、2030-01-01T00:00:00Z 起点)と経過時間(T+)、時間加速倍率、NODE WARP(次のノードまでの残り sim 時間、対象なしは `—`)を横に並べて表示する。自動ワープ中は時間加速倍率の右に残り実時間の見積もり(`(残り HH:MM:SS)`)を表示する。停止中は時間加速の表示が `PAUSE` になる。自機の有無・戦闘/マップビューによらず常に表示される。
  - [Space] / 左クリックで機関砲発射。連射開始時に 0.3 秒の起動遅延音、連射間隔 0.112 秒。
  - 右クリックで敵に照準を合わせて当てると、第一/第二ターゲットの設定・解除メニューが開く(自動選定はない)。
    第二ターゲットは軌道線・マーカー・敵一覧の色分け(シアン)のみに関与し、射撃・照準補助には影響しない。
  - カメラ操作: 左ドラッグ/矢印キーでヨー・ピッチ、テンキー 0/1 で視線軸まわりのロール、ホイール/2本指
    ピンチでズーム。[Z] 長押しで機首方向の照準ズーム(FOV 55°→6°)。
  - [P] 一時停止、[H] ヘルプ、[R] 再出撃(終了後 — **同じステージで**出撃し直す。選択画面へは戻らない)。
- 勝敗: 敵の残存機が居なくなれば勝利。撃破だけでなく自然損耗(再突入・交戦圏離脱)で消えた機も
  残存機から除かれるので、最後の1機が勝手に落ちた場合もそこで決着する。自機喪失で敗北(原因は複数、§5参照)。
  一度勝敗が確定した後は、その後の被弾・再突入などで追加の喪失判定が起きても結果画面は上書きされない
  (例: 最後の敵を倒した直後に自機が大破しても勝利のまま)。
- 弾丸衝突判定はサブステップ間の線分 vs 球判定でトンネリングを防止。
- **弾の消滅は距離基準**: 自機から 30 km(交戦圏と同じ)以上離れた弾は消える。寿命(240 sim 秒)は
  「自機とほぼ同じ軌道に乗って離れない弾」を片付けるための保険。弾は1発ずつ独立した描画対象なので、
  生存数がそのまま描画コストになる — 距離で消すことで、連射しても生存数が交戦圏内に収まる。
- 薬莢・撃破デブリは軌道力学に従って物理的に正確に漂う。
- **弾薬の補給**: マガジン残数が減ると自機の軌道上に補給が投入され、接近すると自動で取り込む。
  位置は ▣ AMMO マーカー(距離ラベル付き)で示す。補給が画面外にあるあいだは実位置を指せないので、
  代わりに画面端の円周上へ塗り抜きの △ を方位マーカーとして出す — 敵の画面外方位マーカー ▲ と
  同じ仕組み・同じ置き方で、記号の塗りだけで区別する。どちらに飛べば拾えるかが常に分かる。
  **自動投入が働くのは等倍のときだけで、×4 以上の時間加速中は止まる** — 補給は接近して回収する
  ものなので、回収操作が成立しない倍率で投入だけが進むと拾えない補給が軌道上に溜まる。加速を
  戻せば次のフレームで投入判定が走り、止まっていた分が待ち時間として持ち越されることはない。
  既に軌道上にある補給の回収と遠方消滅は、倍率によらず常に働く。
- **画面表示の重なり順**: 上位から ①システムウィンドウ(ゲーム進行を扱いゲーム内世界とは無関係な
  もの。ESC メニューを最上位、終了画面とヘルプを中位とする) → ②ゲームウィンドウ(戦闘ビューの
  SHIP STATUS / ORBIT / TARGET / CONTACTS などの常設パネルと、マップモードの操作パネル。この中では
  一時表示のモーダル的な案内 — トースト・ヒント — が常設パネルより上) → ③ゲーム内世界 UI
  (LEAD・軌道方向・弾薬・敵位置などのスクリーン投影マーカーとその引き出し線)。タッチ操作の
  仮想パッドはゲーム内世界を操作する UI なので②③と同じくシステムウィンドウより下。
  実装は `hud/dom.ts` の STYLE に z-index を一元定義する(0〜4 の 5 段)。

## 2. 軌道マニューバの強化

- **エンジン出力 3 段階切替**([1]/[2]/[3] キー): 弱 5.0 / 中 20.0(既定) / 強 100.0 m/s²。
- **姿勢微調整モード**([V] キー): 角加速度を通常の半分に絞り、精密な照準合わせを可能にする。角速度自体に上限はない。
- **照準ズーム**([Z] 長押し): 機首固定・FOV 6° のガンサイト視点。自機モデルは非表示になり、画面中心が照準先になる。マズルフラッシュはズーム中は最大不透明度を 1/10 に減光(完全には消さない)。
- **軌道要素表示は常に現在の軌道を表す**: ORBIT パネルの遠地点/近地点高度・傾斜角・周期、TARGET パネルの
  同項目、軌道線、AN/DN マーカーはいずれも毎フレームの状態ベクトルから算出した値であり、噴射・摂動で
  軌道が変われば即座に追従する。
- **軌道要素・軌道線の中心天体は状態から自動的に決まる**: その瞬間に最も強く重力を及ぼしている天体
  (地球・月・木星・太陽のいずれか)を中心として算出し、プレイヤーが選ぶ操作は無い。地球を周回する艦は
  地球を中心とする楕円が、月を周回する艦は月を中心とする楕円が自動的に表示される(月への遷移軌道の
  途中で支配天体が切り替われば、楕円の中心もその場で切り替わる)。ORBIT/TARGET パネルの軌道要素、
  自機・ターゲット・敵背景の軌道線、近地点・遠地点(Pe/Ap)アイコンすべてに共通する。
- **ターゲット軌道要素表示**: TARGET パネルに距離・接近速度・相対速度・装甲・遠地点/近地点高度・傾斜角・周期・自機軌道面との相対傾斜角を表示。
- **装甲**: 機体の機械的な損傷度を総合的に示す指標(自機は最大 1,000)。被弾と高速接触で減少し、毎秒 1 ずつ自然回復する。0 で機体喪失。自然回復が及ぶのは機内の部品だけで、外装の放熱板・太陽電池パドルと、全損した部品は基地ドックでしか直せない。
- **部品と損傷の配分**: 艦は本体・コックピット・スラスター・RCSタンク・放熱板(左右2枚)・太陽電池パドル(左右2枚)・武装・装甲の各部品でできており、**装甲値は全部品の残 HP の合計**。被弾・高速接触のダメージは装甲部品の軽減率を掛けたうえで、健全な部品のどれか1つに入る(展開中の放熱板に当たった場合だけは、その放熱板の部品に固定で入り、ダメージも軽い)。本体かコックピットを失うと、他の部品が無事でも即座に機体喪失となる。
- **部品の性能反映**: 推力・トルク・燃料容量・放熱能力・発電量・発射レート・砲口初速・1発あたりの威力は、いずれも搭載している部品の値の集計。ドックで部品を換装すればそのまま挙動が変わる。スロットル段の表示値(5 / 20 / 100 / 400 m/s²、4段目は3段目の4倍)は既定部品の艦での実加速度と一致する。部品の重量は現状まだ機体質量に反映していないため、重い部品を積む不利は生じない。
- **放熱板の損耗**: 展開中の放熱板への被弾でのみ損耗し、飛行中に自然回復はしない。回復手段は基地ドックでの修理のみ。全損した側は放熱面積を失い、機体メッシュからも消える。
- **デバッグステージ**: タイトル右下の小さな「debug stage」リンク(または `[D]` / `?stage=debug`)から入る。敵集団が 1 つだけ配置され、戦闘ビュー上部のステータスウィンドウ左部に出るトグルスイッチで敵の射撃を実行中に ON/OFF できる。勝敗判定が起きないため検証を中断されず、クリア回数にも記録されない。
- **高速接触ダメージ**: 自機と敵機が接触したとき、接触速度 50 m/s で 0、500 m/s で装甲の最大値ぶんを失う線形のダメージを双方が受ける。タイムワープ ×4 を超えると剛体接触の解決自体が行われないため発生しない。
- **軌道昇降点(AN/DN)マーカー**: マップ上で右クリックし「航法ターゲットに設定」を選んだ対象(生存中の
  自機・敵船、月、ラグランジュ点)の軌道面と自機軌道の交線を自機軌道上に投影し、▲AN(昇交点)/▽DN(降交点)
  として表示。面変更(ノーマル/アンチノーマル)burn を行うべき位置が一目で分かる。アイコンを右クリック
  すると、その通過時刻まで時間加速する / その時刻にノードを追加する / フォーカスを移すメニューが開く。
- **近地点・遠地点(Pe/Ap)アイコン**: 軌道計画モードで、最後のバーン後に乗る軌道の近地点・遠地点を
  ◇アイコンと高度ラベルで表示。**実際に描かれている計画軌道の積分折れ線を走査して求める**(軌道要素
  から解析的には求めない)ため、アイコンは常に画面上の線の上に乗り、Δv=0 のノードを置いても
  (評価するエポックが自機の現在時刻から未来のノード時刻へ切り替わるだけなので)アイコンは動かない。
  折れ線の半径変動から見た離心率相当値が円軌道に近い(`APSIS_MIN_ECC` 未満)と方向が定まらないため
  両方隠れ、双曲線軌道では遠地点側の極値が折れ線上に存在しないため自然に隠れる。右クリックでその
  通過時刻(= 見つかった点自身の時刻)にノードを追加する / フォーカスを移すメニューが開く。
- **赤道交点(EqAN/EqDN)アイコン**: マップビューで、操作艦(軌道計画があれば最後のバーン後に乗る軌道、
  無ければ現在の軌道)・航法ターゲット・戦闘ターゲット・生存中の全基地(選択の有無に関わらず常に対象)
  のうち今フレーム存在するものそれぞれについて、
  その軌道と中心天体の赤道面との交点を△EqAN(昇交点)/▽EqDN(降交点)アイコンと通過時刻ラベルで表示。
  **操作艦だけは計画軌道の積分折れ線を走査して求める**(計画軌道は積分折れ線として描かれるため、
  Pe/Ap アイコンと同じ理由でノードの有無に関わらずアイコンが線の上から動かない)。それ以外
  (航法ターゲット・戦闘ターゲット・基地)は従来どおり軌道要素から解析的に求める(それらの軌道は
  解析楕円として描かれるため)。同じ艦・敵・基地が複数の役割を兼ねてもアイコンは重複しない。実際に
  自転軸をモデル化している中心天体(地球・月)のときだけ出る — 太陽・木星中心のときは自転軸が無いため
  出ない。軌道面が赤道面とほぼ一致するときはその対象の分だけ隠れる。戦闘ビューでは出ない。右クリックで
  その通過時刻まで時間加速する / ノードを追加する / フォーカスを移すメニューが開く。

## 3. 射撃・エフェクト強化

- **機関砲起動音**: 発射開始時、レールが機械的に動き出すサウトゥース波の摩擦音(0.3 秒)+ ノイズバースト。連射間隔は 0.112 秒(旧比 ×0.8 相当に短縮)。
- **発砲音**: 低域寄りのノイズバースト + 65Hz 矩形波トーンで重い印象に変更。
- **マズルフラッシュ・命中フラッシュの位置**: 各フラッシュは発生位置と発生源速度に加えて「その位置がどの時刻のものか」を持ち、毎フレームその時刻から現在時刻まで移流する。発生源の軌道速度(LEO で約 7.7 km/s)がどれだけ大きくても、またタイムワープ中でも、フラッシュが発生源から取り残されて軌道後方に離れることはない。
- **薬莢**: 直径・長さを従来比 2 倍に拡大した上で全長を 2/3 に短縮。射出方向は右舷偏向をやめ、機体側方向へのランダム散布に変更(タンブリング角速度は従来通り激しい)。
- **標的面通過マーカー(✦)**: ターゲット位置に「自機の方を向いた仮想的な標的板」があるとみなし、発射弾がその面を自機側から通過した点を検出する。ターゲットの軌道面との交差ではなく、視線方向を法線とする平面との交差判定に変更。通過点はターゲット相対オフセットで記録し、ターゲットに追従する光点として描画。的の半径 4,000 m を超える通過は無視。表示は 2.5 秒でフェードアウト(`BOARD_MARK_LIFETIME`)。

## 4. 軌道表示・視覚品質

- **軌道線の高解像度化**: 楕円のサンプル点数を 220 → 2,048 点に増加。LEO(周長 ~42,000 km)で 1 セグメント約 20 km、弦の矢高は数 m まで低下し、軌道上から見ても折れ線に見えない。
- **予測・計画・履歴軌道線のエルミート細分**: サンプル点列から描く軌道線(予測軌道・計画軌道・履歴)は、隣接サンプル間を両端の速度を接線とする3次エルミート補間で細分して描くため、サンプル間隔が粗い長期表示(28日など)でも多角形に見えない。LEO・28日表示(サンプル間隔 約1,210秒)ではサジッタが約1,517 kmから約6.2 kmまで下がる。細分の粗さは画面上のサジッタ(≈0.5px)を目標に画面スケールから決まるので、マップビューでズームしても折れ線と実際の軌道のずれが画面上で拡大しない(camDist=4.5e7〜1e5 のどこでも同程度)。
- **地球のリアル調化**: ローポリ Icosahedron(面単位色+フラットシェーディング)から、1024×768 分割の `SphereGeometry` + 頂点単位の滑らかな色 + スムーズシェーディングへ変更。バイオーム(深海→浅海→砂浜→草原/森林→砂漠/ツンドラ→岩肌→冠雪)は smoothstep で連続的に混合し、閾値の段差をなくした。
- **雲**: 別シェルにすると水平線付近で地表と z-fighting するため、頂点色に焼き込む方式を維持。2 スケールのノイズを合成し縁を柔らかく。
- **雲の影**: 頂点色計算時に東方向へオフセットした位置の雲量で地表を減光。地球固定座標への焼き込みのため太陽方向には追従しない近似。
- **薄明のグラデーション・連続な濃度の大気**: 大気は幾何形状ではなく解析的なシェーダー効果として描く(高度 400 km 未満に不透明な物体を複数置くと、near=2m・24bit 非対数深度バッファでは視線が浅い角度のときに z-fighting が避けられないため)。地表付近の近接ヘイズは Beer-Lambert 則(`haze = 1 - exp(-τ₀/cosθ)`)、地平線の縁の発光(リムライト)は高度 20〜340 km(`ATMO_RIM_MIN_H`〜`ATMO_RIM_MAX_H`、スケール高 90 km)にわたる指数減衰を、地球本体との解析的な光線-球交差判定で地球に隠れる分を遮蔽しながら、いずれも1ピクセルごとに計算する。太陽光の入射角に応じて明暗が付くため、昼夜境界(ターミネーター)をまたぐ薄明が自然に生じる。リムの上限高度(340 km)は通常飛行高度(420 km)より低く抑え、カメラが発光域に入らないようにしている。
- **オーロラ**: 磁気(近似的に地理)極を囲む緯度 ±67° の波打つカーテンメッシュ。下端は緑、上端は紫→黒(加算合成につき透明)へフェード。自転に固定し、`Earth.tick` でゆっくり明滅する疑似アニメーションを付加。
- **地球の影**: 自機位置が地球本体の影円柱内にあるかを判定(縁 60 km のぼかし付き)し、太陽光を最大 4%、環境光を最大 35% まで減光。夜側では機体・敵機・薬莢などが暗く見える。
- **天球グリッド**: 赤道面・黄道面それぞれの基準円・30°間隔の緯経線・両極マーカーを、面/極/グリッドの計6トグルで独立に出し分けられる(実装は `render/celestial-grid.ts`)。現状はトグルを操作する UI が無く6トグルとも既定で false のため、プレイ中は何も描かれない(navball ウィンドウ実装時にそちらへ操作を移す想定)。

## 5. 大気抵抗・空力加熱・オーバーヒート

- **大気密度モデル**(`src/physics/atmosphere.ts`): Vallado 準拠の区分指数モデル(高度 0〜1000 km、28 区間)。
- **抗力**: 地球と共回転する大気に対する対気速度から `a = -½ρ|v_rel|·(Cd·A/m)·v_rel` を計算し、RK4 の追加加速度として全エンティティ(自機・敵機・弾丸・薬莢/破片)に適用。弾道係数はエンティティ種別ごとに設定。
- **空力加熱**: よどみ点熱流束を Sutton–Graves 近似(`q̇ = k·√(ρ/Rn)·v³`)で計算し、機体外殻の熱容量に蓄積。
- **射撃発熱**: 発砲 1 発ごとに 0.55 MJ を外殻の熱収支へ投入する(約 1.6 K/発)。
- **被弾発熱**: 自機が被弾すると 1 発ごとに 0.3 MJ を外殻の熱収支へ投入する(約 0.9 K/発)。射撃発熱と同じ経路(投入熱量を持ち越して次の熱計算で一度だけ温度へ変換)を通る。
- **放射冷却**: ステファン・ボルツマンの法則で外殻から宇宙空間へ放熱。
- **ラジエーター(放熱板)**: 機体側面、太陽電池パネルの直下(`x=±2.62, y=0.30, z=-2.20`)に 1 枚ずつ個別に展開できる(「右」=+X 側、「左」=-X 側)。**収納時は機体幅と同じ 2.3 × 2.3 m の正方形**で、パネル面は機体側面と同じ向き(その側の外向き、±X)を向く。展開すると**蛇腹が左右方向(X)にまっすぐ伸びて**約 9.2 m に達し、蛇腹の折り畳みが解消される(放熱面とは逆位相の蛇腹が骨格として入る)。全開したパネル面は太陽電池パネルの法線(+Y)と垂直な前後方向(±Z)を向き、機首/機尾側から見て面積が最大に見える。展開度に応じて放熱面積が 1 枚あたり最大 42 m² 加わる(ハル自体の 70 m² に対し、左右全開で約 2.2 倍)。展開・収納には 3 秒かかる。
  - **昼夜で効率が変わる**: 地球の影に入っていれば太陽入射がなく最大効率。日照中はパネル面法線と太陽方向の余弦に比例した太陽光(1,361 W/m² の 15%)を受け取るため、**太陽方向に対して垂直に構えるほど効率が上がる**。
  - **被弾で損耗する**: 被弾位置の機体座標 X 符号で左右どちらのパネルかを判定し、その側の放熱板部品へダメージが入る(装甲軽減後で 1 発あたり 0.2、全損まで約 250 発)。薄く大きい構造物なので船体への直撃より 1 発のダメージは軽い。損耗は自然回復せず、基地ドックでの修理でのみ戻る。展開度 15% 未満のパネルには当たらないため、畳んでおけば損耗を避けられる。全損したパネルは蛇腹のメッシュが消え、その場で破片エフェクトを撒く。
  - **展開すると被弾しやすくなる**: 自機の被弾判定半径が 5 m から蛇腹先端の実距離(約 12.1 m)まで展開度に比例して広がる。
  - **操作**: 戦闘ビュー上部のステータスウィンドウ右部の「ラジエーター右 [9]」「ラジエーター左 [0]」ボタンをクリック、または `[9]`/`[0]` キーで個別に展開/収納する。ボタンの着色部(fill)の幅は損耗度に応じて減っていき、色は展開中はアクセント色、損耗度 50% を超えると警告色になる。ボタンには展開状態と損耗度(%)も文字で表示する。
- **太陽電池(発電)**: 機体固定(可動部なし)の太陽電池パネル(合計 7.2 m²、変換効率 25%)が、太陽方向とパネル法線の余弦に応じて発電し、最大 1.5 MJ まで蓄電する(初期蓄電量は満充電の 75%)。裏面は発電しない。戦闘ビュー上部のステータスウィンドウ中央部に「電力」ゲージとして表示し、値は kJ/MJ 単位(%ではない)で示す。
- **ゲームオーバー条件の追加**:
  - 機体温度が 1,300 K を超えると機体喪失。原因は動圧の有無で出し分ける — 大気中なら「断熱圧縮による加熱で熱防御が飽和」、軌道上(射撃発熱による過熱)なら「排熱が追いつかず機能不全」。ステータスウィンドウの温度ゲージには機能停止するこの上限値(1,300 K)を併記する。
  - **再突入の燃焼エフェクト**: 動圧 200 Pa で出始め、20 kPa で最大になるプラズマ状の輝きが対気速度方向の前方に出る。強度は動圧に対して連続的に変化する。
  - 動圧が 35 kPa を超えると「空力的破壊」で機体喪失。
  - 危険域(温度 70% または動圧 50%)で警告ヒントと警告音。
  - ORBIT パネルに「動圧 Q」「機体温度」を常時表示(危険時は赤色)。
  - 戦闘ビュー上部のステータスウィンドウに「装甲」「エンジン出力」「温度」をバーで常時表示(温度は 70% 超で赤色)。
- 敵機は簡易的に高度 80 km 未満で消滅する従来ロジックを維持しつつ、自機はより厳密な熱・動圧モデルで判定する。

## 6. Navball(姿勢儀)

- 画面左上に SVG ベースの Navball ウィンドウを実装(`src/game/navball/navball.ts` + `navball-panel.ts`)。戦闘ビュー・マップビューの両方で常に表示される。

- **基準モード**(パネルのボタンで切替、排他選択):
  - **自機**(既定): 自機の軌道要素そのものが基準(pro=自機プログレード等)。
  - **TGT+**: 第一ターゲットのプログレードを基準の pro に取る(ターゲットへの接近方向)。
  - **TGT-**: 同じ基準を反転(pro/radOut の符号を反転、nrm は共通)、ターゲットからの離脱方向。
  - ターゲットが居ないあいだ TGT+/TGT- ボタンは無効化される。TGT+/TGT- を選んだままターゲットを外すと、自動的に「自機」へ戻る。
- **マーカー**: PRO ⊙ / RET ⊗(緑系、プログレード/レトログレード)、NRM ▲ / ANM ▽(紫系、ノーマル/アンチノーマル)、OUT ◎ / IN ◉(シアン系、ラジアルアウト/イン)。裏半球にあるマーカーは減光して表示する(隠しはしない)。
- 自機が死亡している間、またはターゲット系モードでターゲットの基準が組めない間はボールを空にする(グリッド・マーカーとも非表示)。
- 姿勢儀が読む自機・ターゲットの状態は常に**現在時刻**のもので、マップの未来ゴーストスライダーには連動しない。
- **天球グリッドの6トグル**(黄道面/黄道極/黄道グリッド/赤道面/赤道極/赤道グリッド)は、この Navball ウィンドウ内に置かれたトグルスイッチで独立に ON/OFF できる(実装は `render/celestial-grid.ts`、可視状態の正本は `Navball`)。既定はすべて OFF。ON にすると、自機/カメラに追従する固定半径の殻として、赤道面・黄道面それぞれの基準円・30°間隔の緯経線・両極マーカーが描かれる。

## 9. 潮汐力・J2 摂動・第三体摂動

- **天体の2次重力場**(`degree2Accel`): 帯状項 J2(極方向の扁平)と、非軸対称なら帯状外項 C22(赤道断面の楕円性)を、任意の自転軸方向に対して評価する。どの天体が2次重力場を持つかは天体定義側が宣言し、全エンティティの積分に常時適用される。係数はいずれも非正規化。
  - **地球**: J2 = 1.08262668×10⁻³、極軸 = Y(ECI の定義そのもの)、基準半径 = 赤道半径。赤道断面の楕円性 C22 は J2 の約 1/690 しかないため軸対称として扱う。
    - 検証値: 高度 420 km・傾斜 51.6° の軌道で昇交点歳差 −4.98°/日(理論値 −4.97°/日と一致)。
  - **月**: J2 = 203.3×10⁻⁶、C22 = 22.4×10⁻⁶(GRAIL による測定値)、基準半径 = 1738.0 km。**基準半径は月の表面半径 1737.4 km とは別の量**として保持する。
    - 月では J2 に対する C22 の比が約 1/9 と大きく、地球のように軸対称近似が成り立たないため、C22 を一組として扱う。3次以上の項とマスコン(質量集中)は実装しないので、**現実の低月軌道が持つ不安定性は再現されない** — このゲームの月周回軌道は現実より安定に振る舞う。
    - 自転軸はカッシーニの法則で決める。月の赤道は黄道に対し 1.543° 傾き、自転軸・白道面法線・黄道極は常に同一平面上で、自転軸は黄道極を挟んで白道面法線の反対側にある。結果として自転軸と白道面法線は 6.688° 離れ、両者とも 18.6 年周期で共に歳差する。**白道面法線を自転軸に流用すると摂動の向きが 6.688° ずれる**(大きさは変わらないので値の検査では捕まらない)。
    - C22 が基準とする長軸(本初子午線)は**平均黄経**方向で取る。同期回転する天体は一様に自転するため本初子午線は平均黄経を追い、地球方向(真黄経)とは中心差ぶん最大 6.3° ずれる。物理秤動(振幅 0.03° 程度)は扱わない。
    - 検証値: 高度 100 km の低月軌道で J2 摂動加速度 3.96×10⁻⁴ m/s²(中心重力 1.45 m/s² に対する比 2.7×10⁻⁴)。低軌道における地球 J2 の比 1.4×10⁻³ の約 1/5 で、数日スケールの昇交点歳差として観測できる。同高度で地球の第三体摂動(2.6×10⁻⁵ m/s²)より 15 倍強く、両者が拮抗するのは高度およそ 1,430 km。
  - **太陽・木星**: 2次重力場を持たず質点として扱う。

- **太陽輻射圧**(`srpAccel`): 物体を反射率一定の球とみなすキャノンボールモデル。太陽からの距離の2乗に反比例し、向きは太陽 - 物体を結ぶ直線方向。姿勢には依存しない。
  - 係数は輻射圧係数と断面積質量比の積 `C_R·A/m` [m²/kg] としてエンティティ種別ごとに持つ(機体 1.56e-2、薬莢・破片・弾薬 4.7e-3、弾丸は寿命が数秒で影響が無視できるため 0)。
  - 地球の影に入っている間は働かない。日照率は大気抵抗・放熱板・発電と同じ `sunlitFactor`(地球を円柱とみなす影)を共有するので、「日照しているか」の答えがモジュール間で食い違わない。月の影による日食は考慮しない。
  - 大きさは自機で約 7.1×10⁻⁸ m/s²。高度 420 km の大気抵抗(2.6×10⁻⁷ m/s²)の約 1/4 でしかないが、**大気抵抗は高度とともに消えるのにこちらは消えない。** ラグランジュ点・月遷移軌道の領域では、物体に働く唯一の非重力摂動になる。
- **月・木星・太陽の重力**(`attractor.ts` の `attractorAccel` を天体ぶん合算): 1 天体あたり、直接引力から「ECI 原点(地球)自身がその天体から受ける引力」を差し引く(ECI が非慣性系であることの補正)。式そのものが標準的な差分潮汐加速度式 `a = μ[(ρ/|ρ|³) − (r_b/|r_b|³)]` で、天体暦から得た太陽・月・木星の位置に対して適用される。
  - 月は白道傾斜 5.145° + 昇交点が 18.61 年周期で逆行歳差する簡易月理論(永年項 + 出差・二均差・年差・視差不等などの周期項)。検証で月の赤道(ゲーム座標系)傾斜角が理論どおり 18.3°〜28.6° を掃くことを確認。これが LEO 軌道傾斜角の長期的な変動(潮汐力による摂動)の物理的な源になる。
  - 月の位置角はすべて**黄経**(黄道上の固定方向からの角)で組み立て、最後に軌道面内の緯度引数へ落とす。平均黄経は恒星月ちょうどで 1 周し、昇交点・近地点の歳差は公転そのものを遅速させない(平均黄経を昇交点基準の角として扱うと年 19° 級で位置がずれる)。
  - 太陽・木星の位置は、地球-月重心の日心ケプラー軌道(惑星間摂動由来の要素永年変化つき)に対する地球本体の重心オフセット(月との質量比 1:81 ぶん、振幅 4,673 km)を差し引いた地球日心位置と、木星自身の日心ケプラー軌道から求める。惑星本体ではなく**惑星-衛星系の共通重心**がケプラー軌道を描くのは、地球が月に対して重心オフセットを無視できるほど軽くはないため。
  - 地球周回艦にとっての摂動の大きさは高度 420 km で太陽 ~4.8×10⁻⁷ m/s²、月 ~7.9×10⁻⁷ m/s² と、現実のオーダーに一致。
  - 抗力・2次重力場・全天体重力を合成した加速度(`dynamics.ts` の `stepDynamics`)は敵機・弾丸・薬莢・破片を含む全エンティティに適用(各 entity 自身の `stepActual`)。高ワープ中もサブステップごとに天体位置を再評価。月・木星・太陽を周回する艦も同じ合成加速度で積分される — どの天体が支配的かは常に全天体分の合算から決まり、積分そのものに「中心天体」の選択は存在しない。

## 10. 太陽・月の実体

- **太陽**: 黄道面(赤道に対し 23.44° 傾斜)を 1 恒星年で公転する天体暦(`src/physics/ephemeris.ts`)に、毎フレーム DirectionalLight とビルボードを追従させる。地球の影・薄明もこの方向に連動。DirectionalLight は地心方向、ビルボードは**カメラから見た太陽の方向**(実 ECI 位置 − カメラ位置)に一定の表示距離で置く — 広範囲視点ではカメラが地球から最大 4.5×10⁹ m 離れるため、地心方向のままだと視差ぶん(最大 1.7°)実位置からずれ、実位置に置かれる太陽ラベルと像が合わなくなる。
- **月**: 白道傾斜 5.145° + 18.61 年周期の逆行昇交点歳差 + 離心率 0.0549(近地点は 8.85 年周期で順行)の楕円軌道に、太陽摂動の周期項(出差・二均差・年差・視差不等)を加算した簡易月理論。低ポリメッシュ(`createMoon`)を実方向・実距離から換算した角直径で表示し、太陽の平行光で照らされるため月相(満ち欠け)が自然に生じる。広範囲視点では実 ECI 位置・実スケールで置く。
- **木星**: 太陽まわりの楕円軌道(周期 11.86 年)。テクスチャなしの単色球(`createJupiterMesh`)で、月と同じ表示距離圧縮を共有する。
- 初期位相は月のみゲームごとにランダム化。

## 11. 軌道計画モード([M] キー)

- **SHIP STATUS はマップビューでは畳む**: 操作艦固有の RCS制動/並進出力/微調整/進行方向ホールド/
  視点のRCS追従/弾薬は戦闘ビューだけの情報として常設パネルから消える(装甲・温度・電力・弾薬・
  軌道要素は右クリックのプロパティウィンドウで参照する)。TARGET パネルはマップビューでも従来どおり
  表示され続ける。ORBIT パネルはマップビューでは画面右側の折り畳み式パネル群(MANEUVER PLAN・
  軌道オブジェクトウィンドウなどと同じ列)へ移動し、その開閉トグルで一緒に畳める。戦闘ビューでは
  従来どおり画面左下に表示される。軌道オブジェクトウィンドウ(画面右側、種別ごとの区画にタブ見出しで
  開閉する一覧。行クリックでその対象へフォーカス移動)はマップビューである間は常設で表示され、
  開閉のトグル操作はない。
- **マップビュー**: [M] キーで戦闘中の物理を一時停止し、地球中心の 3D ビューに切替。専用カメラ(near=1×10⁴ m, far=6×10⁸ m)を使用し、左ドラッグで回転、ホイールでズーム(9,000 km 〜 260,000 km)、中ドラッグで注視点のパン。中ボタンはその場で押して離したときだけ視点リセットになり、パンした後に離しても発動しない。
- **軌道比較**: 操作対象の自機の軌道線は、数値積分で伸ばしている予測軌道をそのまま実線の折れ線として表示する
  (マップビュー・戦闘ビューの両方に出る)。予測軌道が表示されているあいだ、同じ自機の軌道要素から解析的に
  引く軌道楕円は表示しない。艦を配置した直後や `MAX_PHYS_SIM_SPEED` を超えるタイムワープ中など予測軌道が
  まだ短い/空のあいだだけ、代わりに軌道楕円が表示される。自機が月を基準天体として周回しているときも
  予測軌道は月の引力を含めて積分されるため、月遷移軌道のように解析楕円では正しく表せない形もそのまま
  表示される。全生存敵の軌道はグレーの軌道楕円で同時表示し、比較しやすくする。第一ターゲットはオレンジ、
  第二ターゲットはシアンで個別に強調され、通常のグレー表示からは除外される。
- **軌道オブジェクトの選択**: マップ上で自機(自分の艦)または基地のマーカーをクリックすると選択される — 自機なら操作対象に切り替わり(右クリックの「操作対象にする」と同じ)、基地なら選択状態になる(この時点ではドックビューへは遷移しない。遷移するには右クリックの「ドックビューを開く」か、右上のビュー切替を使う)。この選択はノード配置より優先され、当たらなかった場合だけ次のノード配置・選択解除に進む。
- **軌道オブジェクトのフォーカス移動**: マップ上の被選択物(天体・自機・敵船・基地・弾薬・近地点/遠地点アイコン・相対 AN/DN の全種別)をダブルクリックすると、その対象へマップ視点のフォーカスが移る。プロパティウィンドウの「フォーカスを移動」項目と同じ操作を素早く行える。
- **天体に遮蔽された軌道要素・オブジェクトはマップビューで隠れて選べなくなる**: 近地点/遠地点(◇)・相対 AN/DN(▲/▽)・赤道交点(△/▽)の各アイコンは、カメラから見て地球・月などの天体の裏側にあるあいだ表示されない。同じ判定で、右クリックのピック候補・軌道折れ線上のノード配置クリックからも除外される — 画面上見えているものだけが選べ、見えていないものは選べない。この遮蔽判定はマップビューでのみ働き、戦闘ビューの表示・操作には影響しない。
- **ノード配置・編集**: マニューバ計画にノードを1つも置いていない間、計画軌道の折れ線は描かれない
  (自機が実際に乗っている軌道と一致し、計画として示す追加情報を持たないため)。最初のノードは、
  近地点・遠地点(◇)アイコンや赤道交点(△▽)アイコンを右クリックして「ここにノードを追加」で置くか、
  実線で描かれている予測軌道をクリックして置く(ノードの無い計画軌道は自機の実軌道とほぼ重なるため)。
  クリックした位置(真近点角)にノードを仮配置してそれを選択し、既存ノードに近い位置をクリックすれば
  そちらを選択、ノードにも折れ線にも当たらない場所をクリックすると選択を解除する。
  - Δv 調整: W/S = プログレード成分、A/D = ノーマル成分、E/Q = ラジアル成分([V] で微調整モード)、または
    MANEUVER PLAN パネルの6方向長押しボタン。キー/ボタンは押し続けるほど加算レートが約2秒かけて
    指数的に大きくなる(タップは微調整、長押しは粗い調整)。ノード上の Δv アームは短いドラッグでは
    そのままの変位量を加算するが、基点から一定距離(約60px)を超えてドラッグするとラッチし、
    その後はポインタを止めていても超過距離に応じたレートで加算が続く(ドラッグをやめると解除)。
  - 計画軌道はリアルタイムに再描画される破線で、バーン前の区間は薄い橙、バーン後の区間は中間の橙、
    末尾区間は濃い橙と、色の濃さだけで区間を描き分ける(不透明度はどの区間も同じ)。破線1本の長さと
    間隔は、マップの倍率を変えても画面上では常に同じ大きさに見える。自機と同じ弾道係数で大気抵抗を
    受けながら数値積分されるため、7日/28日など長期間の予測では低軌道区間の高度が徐々に下がっていく
    様子が見え、天体表面に達した時点で軌道線が途切れる。
  - 左下パネルに Δv 各成分・合計・ノードまでの飛行時間(ケプラー方程式による厳密計算)・計画軌道の遠地点/近地点高度・傾斜角・周期を表示。近地点が大気圏内(120 km 未満)になる場合は警告。この Δv は、画面に描かれている計画軌道と同じ積分結果から求められる。
  - 計画軌道を描く長さは [PREDICT] パネルで選んだ表示期間に従う。ノードを1つ以上置いている間、
    各区間は次のノードの実行時刻で終わり、最後のノードから先は選んだ表示期間ぶん描く。既定の
    「1周」を選んでいる間は解析軌道のちょうど1周期ぶんで、折れ線が自分自身と重ならない。周期を
    持たない軌道(双曲線・放物線)は1日ぶんを代用する。7日/28日/1年など1周を超える期間を選ぶと、
    折れ線は複数周を重ねて描く。
  - 折れ線が自分自身と重なっている区間をクリック/ドラッグで指すと、まず画面上もっとも近い点が
    属する区間(バーン前かバーン後か)が選ばれ、その区間の中でだけ数ピクセルの許容差にある候補を
    比べる。新規ノードの配置(クリック)は、その中でもっとも早い時刻(=「その位置へ最初に
    到達する時刻」)が選ばれる。狙った1点にサブピクセル差で複数周ぶんの候補が重なっていても、
    選ばれる周回は毎回同じになる。
  - ノードをドラッグすると実行時刻が動く。動かせる範囲は**直前の状態(1つ前のノード、最初のノードなら
    計画の起点)を起点に描かれている区間の折れ線が尽きるところまで**——すなわち上と同じ表示期間ぶん
    ——で、ポインタをそれより先へ持っていってもその範囲内の最寄り点に留まる。折れ線が自分自身と
    重なっている区間でドラッグする場合は、そのノードの現在時刻にもっとも近い候補が選ばれる
    (新規配置と違って最早時刻ではない)ため、遠い未来の周回にあるノードを掴んでも周回0へ
    飛ばされない。ノードが移動しても、そのノードに割り当てられた Δv の成分は保ったまま新しい
    時刻の計画軌道へ焼き直す。
  - **末尾区間には積分ステップ数の上限があり、非常に長い表示期間を選んでも描かれる範囲には現実的な
    上限がある**(1区間あたり周回数にして約200周相当)。420 km 低軌道(周期約1.55時間)では
    28日/1年のどちらを選んでも約12.9日ぶんで折れ線が途切れる(遷移後の長楕円軌道で周期約3.59時間
    なら約30日ぶんまで届く)。ステップ幅を無理に粗くして最後まで描き切らせることはしていない
    ——粗すぎる刻みでは数値積分が発散し、実際には起きない軌道を描いてしまうため、正確だが
    途中で途切れる表示を選んでいる。
  - ノードを1つ編集(時刻移動・Δv 調整・削除)すると、それより後ろのノードはすべて消える。後ろの
    ノードは編集前の軌道上で凍結された絶対状態なので、上流が変われば繋がらなくなるため。
  - [X] キーでノード削除。
  - マップを閉じると、末尾から Δv が実質ゼロのノードだけが間引かれる(有意な Δv のノードに
    当たった時点で打ち切るので、その手前のノードは残る)。
- **計画軌道は戦闘ビューでも見える**: ノードを1つ以上置いた計画は、マップを閉じて戦闘ビューへ
  戻ってからも破線の折れ線として描かれ続ける(操作しながら実際に機体を動かすのは戦闘ビューのため)。
  ノードハンドル・Δv アーム・TRAJECTORY パネルといった操作 UI はマップモード中だけ現れる。
  ノードが1つも無い計画は自機の現在軌道と一致するので、その間は表示されない。
  ⬡ ゴーストマーカーはノードを1つ以上置いて初めて現れ(ノード無しの計画は自機の現在軌道の
  追従コピーでしかなく、実軌道とのズレを示す意味を持たないため)、以降は未来位置スライダーが
  0(現在時刻)でも表示され、計画どおりに飛べているかを目で確認できる。ラベルは現在時刻以前
  なら「計画位置 高度 …」、未来なら「T+…h…m 高度 …」。
- **プロパティウィンドウ**: 天体・自機・敵船・基地・弾薬・近地点/遠地点アイコン・相対 AN/DN を
  右クリックすると、その対象の名前・状態(装甲・温度・電力・弾薬・距離・接近速度・軌道要素など、
  種別ごとに異なる)と操作項目(フォーカス移動・航法ターゲット設定・複製・削除など、従来の
  右クリックメニューと同じ内容)をまとめて表示するウィンドウが開く。装甲・距離・接近速度・
  高度・速度など主要な状態行は常に表示され、軌道要素(基準天体・遠地点・近地点・傾斜角・周期)・
  相対傾斜角・操作対象か・計画追従などの副次的な行は末尾の「▼ 詳細を表示」で開閉する折り畳みに
  まとめられる。ヘッダをドラッグして
  好きな位置へ動かせる。値も操作項目(操作対象の有無で「削除」の出現が変わる、など)も毎フレーム
  最新化される。ウィンドウ隅の 📌 ボタンでクリップすると、複数のウィンドウを並べたまま比較し
  続けられる(既定は非クリップで、この場合は他のウィンドウを開く・外側をクリックする・操作項目を
  選ぶ・マップビューを離れるのいずれかで自動的に閉じる — クリップ済みは ✕ ボタン・対象の削除・
  対象の消滅・マップビューを離れる、のいずれでのみ閉じる)。非クリップのウィンドウは常に高々1枚で、
  クリップすると次に開いた(または既存の非クリップウィンドウのクリップを外した)ウィンドウへ
  その座を譲る。項目のキーボードショートカット([F]フォーカス移動・[T]航法ターゲット・
  [W]時間を加速・[N]ノードを追加・[ESC]キャンセルなど、`従来の右クリックメニュー`と同じキー)は
  非クリップのウィンドウでのみ効く(高々1枚なのでどのウィンドウ宛か曖昧にならない)。
  自機・基地はタイトル横の ✎ ボタンで改名できる(それ以外の種別には出ない)。押すとタイトルが
  入力欄になり、Enter または欄外クリックで確定、Escape で取り消す。空欄のまま確定した場合は
  変更しない。自機の表示名は重複を許し、変更は自機マーカー(▲)のラベルにも即座に反映される。
  1つの対象につきウィンドウは常に高々1枚で、既に開いている対象を再度右クリックしても新規には
  開かず、そのウィンドウをクリック位置へ動かして最前面に出すだけ。撃破・回収・削除などで対象が
  消えると、開いていたウィンドウも自動的に閉じる(未来位置スライダーを先の時刻にした・
  `MAX_PHYS_SIM_SPEED` を超えてワープしたなどで生存中の対象の位置が一時的に求まらないだけの
  フレームでは閉じない)。空域(何にも当たらない場所)の右クリックだけは従来どおりのメニュー
  (設定メニューを開く・クリエイティブモードではオブジェクト配置)のままで、プロパティウィンドウは
  開かない。
- **操作パネル**: マップモード中だけ現れる 3 枚のパネルに分かれる(画面左上に縦積み)。パネルは
  それぞれ担当モジュールの状態だけを操作し、互いの設定に干渉しない。
  - **MAP VIEW**: カメラを固定する座標系(登録されている全天体ぶんの慣性系 — 地球中心慣性系 /
    月中心慣性系 / 太陽中心慣性系 / 木星中心慣性系 — と、公転している全天体ぶんの回転系 —
    太陽-地球回転系 / 地球-月回転系 / 太陽-木星回転系)、視点リセット。フォーカス先の切替は
    軌道オブジェクトウィンドウの行クリック・被選択物のダブルクリック・プロパティウィンドウの
    「フォーカスを移動」項目で行う。
  - **PREDICT**: 未来位置スライダーが指せる期間および計画軌道の末尾区間の長さ・ノードを置ける
    範囲(90分 / 1日 / 7日 / 28日 / 手動。手動は時/日/週/年の単位で任意の値を指定でき、
    範囲は1時間〜1年 — 範囲外の入力はその場でクランプされ、入力欄の表示値もクランプ後の値へ
    書き換わる。単位を切り替えると入力欄の min/max もその単位の値へ追従する)。「1周」は自機の
    現在軌道の周期をそのまま使うため、選んでいる間は自機が周回するにつれ値が連続的に変わる。
    スライダー下に目盛り(各点の T+ 経過時間を表示)。目盛りは期間の等分ではなく、10分/30分/
    1時間/3時間/6時間/12時間/1日/2日/5日/10日/30日/90日/1年 の候補から、本数が6本を超えない
    最小の間隔を選び、その倍数の位置に置く。表記の単位も選ばれた間隔で決まる(1時間未満なら
    分、1日未満なら時間、30日未満なら日、それ以上は月)。以下、未来位置スライダー
    (期間内の任意時刻へゴースト ⬡ を表示。0 で非表示、そのときは操作案内を表示。スライダーが
    立っている間はパネル側には絶対日時 + 経過時間(T+ 表記)を表示し、高度など自機の予定位置に
    依存する詳細はゴースト ⬡ 自身のラベルが表示する)、「現在に戻す」ボタン(スライダーを原点へ
    ワンクリックで戻す)、T+時刻への直接ジャンプ入力(値+単位。現在の表示期間に対する相対時刻を
    入力すると、期間でクランプしたうえでスライダー位置へ逆算する)。期間を切り替えると、その場で
    スライダーは原点(0 = 現在時刻)へ戻る。スライダーの段階数は表示期間に応じて可変(粒度の目標は
    約10秒刻み、200〜4000段階の範囲でクランプ)で、短い期間ほど滑らかに、長い期間でも粗くなり
    すぎないようにしている。

  - **TRAJECTORY**: 計画軌道を描く座標系(慣性系 / 太陽回転系 / 月回転系)。
  - 計画軌道の座標系とカメラの座標系は**独立に選べる**。両方を回転系にすると回転系での軌道形状が
    静止して見え、カメラだけ慣性系にすると同じ形状が基準天体とともにゆっくり回って見える。
  - **回転系はどちらも基準天体の方向を厳密に固定する。** 太陽-地球回転系の回転軸は黄道法線(赤道面に対し
    23.44° 傾く)で、太陽は常に同じ方向に静止する。地球-月回転系の回転軸は白道法線で、白道は黄道に対し
    さらに 5.145° 傾き、その昇交点は 18.61 年周期で歳差する。地球-月回転系では月が常に同じ方向に静止
    (離心率ぶんの遠近だけが残る)して見え、低軌道からの月遷移軌道の形が読み取れる。太陽-木星回転系は
    木星の公転面法線を軸に固定し、木星が常に同じ方向に静止して見える。
- **未来ゴーストスライダーは自機の計画上のゴースト⬡だけでなく、敵・補給・自機本体もその時刻の
  軌道上の位置へ動かす**(機体メッシュ・敵マーカー・補給マーカー・自機マーカーがすべて連動。
  自機本体の推進炎/RCS 噴射/再突入プラズマの各エフェクトも同じ未来位置に付いてくる)。
- **マップビューでは自機・敵・基地・補給の各マーカーが三角形になり、頂点が進行方向(ECI 速度の
  投影)を向く**(円軌道は静止画からでは回転方向が読み取れないための対策)。速度が視線方向とほぼ
  平行で投影上の向きが定まらない場合は回転させず出す。敵マーカーは残 HP を辺の切り欠きではなく
  三角形内部の塗り高さで示す(戦闘ビューの切り欠き表示は姿勢を示さず従来どおり)。戦闘ビューでは
  機体メッシュ自体が姿勢を示すため、マーカーは回転しない。
  自機・敵・補給(弾・薬莢・破片は予測しない)は [PREDICT] パネルで選んだ表示期間(既定1周、最大1年)
  だけ先まで予測されており、スライダーはその期間を超える時刻を指せない。表示期間を短い方へ
  切り替えた、またはマップを閉じて戦闘ビューへ戻った直後はスライダーが原点(現在時刻)へ戻る。
  この予測はマップモードの機能ではなく常時裏で進んでおり、スライダーはあくまで「その時刻を覗き見る」
  だけなので、マップを閉じて再度開いても連続的に動き続けて見える。自機が噴射すると、その瞬間に
  未来予測は破棄され、次のフレームから新しい軌道で伸び直す(数フレーム以内に追従)。タイムワープが
  物理演算の上限(×4)を超えている間は既存の予測を新たに伸ばすのを止める(実状態が1フレームで
  追い越してしまうため)が、実状態との乖離判定は止めないので、乖離した古い予測がそのまま
  居座ることはない。スライダーが指す時刻がサンプル間に落ちる場合は、前後のサンプルから
  エルミート補間した位置にゴーストが立つ。表示期間を長くするほど積分の刻み幅・保持サンプル
  間隔は粗くなり(頭打ちの上限がある)、ゴーストの位置精度が落ちる。28日で数十km、それ以上では
  軌道の形そのものが崩れ、途中で途切れることがある。
- **ポーズ中の [M]**: ポーズメニュー(⚙ / [Esc])を開いている間は [M] を受け付けない。既に開いている
  マップを強制的に閉じることはしないので、マップを開いたままポーズ→解除すると元の状態に戻る。
  決着後(勝敗確定)は従来どおりマップを強制的に閉じる。
- **確定と実行**: 再度 [M] を押すとノードを実行計画として凍結し、戦闘ビューへ復帰。
  - ◆NODE マーカー: ノード実行位置とカウントダウン(T-/T+ 表示)。
  - ⬢BURN ガイド: 現在速度と計画速度の差分ベクトルの方向・大きさ(残り Δv)、目標軌道速度を表示。
  - [N] キー: ノード到達時刻に向けてタイムワープ段数を自動調整する自動ワープ。ノード実行時刻の20秒前
    (実行の窓)に入ると自動的に ×1 へ解除される。
  - **実行の窓**: ノード実行時刻の20秒前に入ると、自動ワープの有無に関わらず「マニューバ実行点に
    接近」を通知する(ノードごとに一度)。
  - **達成判定**: 実行の窓に入った後、実軌道の要素(長半径・離心率・軌道面)が計画軌道に十分近づいた
    時点(長半径相対誤差 2%、離心率差 0.02、軌道面角度差 2° 以内)で、最後のノードなら「マニューバ
    達成」、それ以外なら「ノード達成」を通知する(ノードごとに一度)。J2・第三体摂動の影響で厳密な
    速度一致は現実的でないため、軌道要素の近さで判定する設計。
  - **ノードの消化**: 実行時刻を60秒過ぎたノードは、達成判定に関わらず計画から自動的に落ちる
    (噴射に多少遅れても実行できる猶予)。そのノードで終わる区間の計画折れ線も同時に消える。

## 13. ステージ00(無限耐久サバイバル)の波状攻撃

常時選択可能。弾薬を確保すると波状攻撃が始まり、自機が破壊されるまで無限に続く(撃破数では終わらない)。

- **波の間隔**: `STAGE00_SPAWN_INTERVAL` = 30 秒。ただし交戦中のグループが 0 になった場合のみ、
  最短 2 秒まで短縮する(全滅後に手持ち無沙汰にならないための下限)。
- **同時展開数**: 波数が進むほど上限が上がる(1 → 2 → 3 グループ)。
- **1 波の機数**: 5 機から始まり波ごとに +2 機、上限 30 機。
- **出現位置**: 自機と同じ高度の水平方向(全方位)にランダムな距離 10〜14 km。ただし第1波だけは必ず後方(逆行方向)。
- **フライパス速度**: 自機に対する相対速度は 200 m/s から始まり波ごとに +10 m/s、**上限 400 m/s**。
- **敵の軌道の保証**: 出現時の高度は必ず 90 km 以上、かつ**軌道の近地点高度が必ず 120 km 以上**になる。
  後者は「フライパス速度を、近地点が安全高度を割らない大きさまで縮める」ことで保証している
  (自機の軌道速度は約 7.7 km/s なので、数百 m/s の Δv は近地点を数百 km 引き下げるだけの効果がある)。
  したがって**実際の相対速度は方向によって上限 400 m/s より小さくなる** — とくに逆行方向のフライパスは
  100 m/s 前後まで抑えられる。順行・法線方向・動径方向のフライパスは軌道を壊しにくいため速いままになる。
- **デスポーン**: 自機から 30 km 以上離れた敵は交戦圏外として消える(「交戦圏を離脱」)。
  高度 80 km を割った敵は再突入で消える(「再突入により喪失」)。

## 17. クリエイティブモード

タイトル画面のタブ(ステージモード/クリエイティブモード)、または `?mode=creative` で起動する。勝敗判定・クリア回数の記録は行わず、艦艇を自由に配置して軌道を眺めるためのモード。

- **開始**: マップビューから始まる(戦闘ビューへ切り替える艦がまだ無いため)。艦を1隻も操作対象にしていない間は `[M]` が無効化され、戦闘ビューへは切り替えられない。
- **艦艇配置パネル**(マップモード中のみ表示): 「軌道要素」「ラグランジュ点」の2方式から選ぶ。
  - **軌道要素方式**: 基準天体(公転している全天体 — 地球/月/木星。ただし種類が「基地」のときは月のみ)を選び、サイズ/形の指定を「近地点+遠地点高度」「半長軸+離心率」「周期+離心率」の排他な3方式から1つ選択(残り2方式の入力欄は隠れる)。向きは傾斜角・昇交点赤経・近点引数、位相は真近点角で指定する。地球以外を基準にした場合、その天体中心の軌道要素で組んでから天体自身の位置・速度を足して地球中心座標(ECI)へ変換する。
  - **スライダー**: サイズ/形(近地点/遠地点高度・半長軸・周期・離心率)と向き/位相(傾斜角・昇交点赤経・近点引数・真近点角)のすべての数値入力に、下にスライダーが付き双方向に同期する。角度は 0〜180°(傾斜角)/ 0〜360°(残り)の線形で 45° ごとに目盛が出る。離心率は 0〜0.99 の線形で 0/0.25/0.5/0.75/0.99 に目盛が出る。近地点/遠地点高度・半長軸・周期は上限が無いため相対スケールで、操作を始めた時点の値を 100% としてつまみが中央に来る(目盛は 0/50/100/200/400%)。中央より左は等倍、右は2倍指数(右端で4倍)で、操作を終えるたびにその値を新しい基準に取り直してつまみが中央へ戻るので、繰り返し操作でいくらでも高い/長い軌道へ伸ばせる。
  - **プリセット**: サイズ/形の直前に、選んでいる基準天体に応じた代表的な軌道のボタンが並ぶ。地球なら低軌道(高度400km)・静止軌道(恒星日周期の高度、傾斜角0°)・太陽同期軌道(高度700km、J2 歳差が地球の公転角速度に一致する傾斜角 約98.2°)、月なら低軌道(高度100km)。押すと近地点/遠地点高度(円軌道として両方同値)と、指定があれば傾斜角を書き換え、サイズ/形は「近地点+遠地点高度」表示に揃う。基準天体を切り替えるとボタンの並びも切り替わる(組み合わせが無い天体では非表示)。
  - **基地の設置先**: 地球近傍は敵の射程となるため、種類が「基地」のときは月基準の軌道要素方式か、ラグランジュ点方式でしか設置できない。
  - **入力のリアルタイム検証**: パネルを開いている間、フォームの現在値を毎フレーム検証し、問題のある入力欄を枠線でハイライトしつつ、メッセージをパネル下部にまとめて表示する(離心率0以上1未満・近地点が基準天体表面より上・振幅が正数、など)。確定ボタンを押したときの検証は従来通り独立して働き、問題があれば配置を中止してヒントを5秒間表示する(パネルを経由しない配置経路もあり得るため、リアルタイム表示は確定時検証の代わりにはならない)。
  - **ラグランジュ点方式**: 系(地球-月/太陽-地球/太陽-木星)・点(L1/L2)・軌道種別(ハロー/リサジュー)・面内振幅/面外振幅を指定する。初期状態は制限三体問題の線形近似解(Richardson の三次振幅拘束は実装していない)で、ゲームの積分器は制限三体問題そのものではない(地球・月・木星・太陽の重力 + J2 + 抗力を積分する多体モデル)ため、**配置後は実際にはこの軌道を維持せずドリフトしていく**。
  - **配置プレビュー**(軌道要素方式のみ): パネルを開いている間、フォームの現在値がそのまま乗る軌道を白い楕円で、その時点の艦の位置を ▷ PREVIEW マーカーでマップに重ねる。配置は「いまの時刻」を基準に組むので、プレビューは時間の経過(ワープ中も)に追従して動き続ける。入力値を解釈できない間は消え、値が有効に戻れば再び出る。
  - 確定すると1隻配置される。配置数の上限は8隻(`CREATIVE_MAX_SHIPS`)で、上限に達している間は配置できずヒントが出る。
- **LOGISTICS パネル**(マップモード中のみ表示): 「補給の自動投入」トグル1つ。切ると残弾が減っても補給が投入されなくなる(既に軌道上にある補給の回収・遠方消滅はそのまま働く)。軌道を眺めるモードなので、補給が湧き続けるのを止められる。§1 のワープによる停止(×4 以上)とは独立で、両方が満たされたときだけ投入される。
- **艦の右クリックプロパティウィンドウの操作項目**: 「操作対象にする」(以後その艦を操作・視点の対象にする — カメラ・軌道計画パネルの編集対象・戦闘ターゲットのロック状態が新しい艦のものへ切り替わる)、「軌道計画への自動追従 ON/OFF」、「フォーカスを移動」、「航法ターゲットに設定/解除」、「複製」、「削除」。操作対象の艦には「操作対象にする」と「削除」が出ない(すでに操作対象であり、削除すると自機が居なくなるため)。
- **複製**: 艦(自機・敵機)・弾薬・基地の右クリックプロパティウィンドウの操作項目から選べる。艦艇配置パネルが、その対象の現在の軌道要素(基準天体・近地点+遠地点高度・傾斜角・Ω・ω・ν)をそのまま引き継いだ状態で開く — 種類もその対象と同じものに固定される。真近点角も複製されるので、確定すると元の対象とまったく同じ位置に重なって配置される(位置をずらしてから確定するかは操作する側の判断)。軌道要素に変換できない対象(双曲線・放物線軌道)や、変換できても基地の基準天体制約(月基準の軌道要素かラグランジュ点のみ)に反する対象(地球が支配的な基地など)は、軌道要素を引き継がず種類だけを引き継いだ通常の新規配置として開く(理由をヒントで通知する)。
- **軌道計画への自動追従**: ON にした艦は、自身のマニューバ計画のノード時刻に達するたびに、瞬間的にその艦の状態をノードの(バーン後)絶対状態へ置き換える(有限時間のバーンは模擬しない — ノード自体が既にバーン後の絶対状態のため、瞬間置換だけで計画軌道と厳密に一致する)。ノードが複数あれば時刻を跨いだぶんだけ連続して消費する。
- 各艦は自分自身のマニューバ計画([M] を開いて編集)を持つ。操作対象を切り替えると、軌道計画パネルの編集対象もその艦のものへ切り替わる。
- **艦の喪失**: 勝敗判定を行わないモードなので、艦(操作対象を含む)を熱防御飽和・動圧超過・大気突入高度不足・高速接触などで喪失しても結果画面は出ない。喪失理由はヒントとして通知されるだけ。喪失した艦はマップの被選択物一覧に出なくなるため、以後右クリックでは選べない。操作対象の艦が1隻も居なくなると、自機基準の距離を出す ▣ 補給マーカーとステータス表示は消える(補給そのものは軌道上に残る)。
- **基地本体**: 他の軌道オブジェクトと同じく実軌道を持つ実体で、専用の低ポリモデル(中央ハブ・放射トラス4本・ドッキングモジュール4基・太陽電池パドル2枚)がマップビューだけでなく戦闘ビューでも描画される。マップビューでは軌道楕円も描かれる(戦闘ビューでは出ない)。左クリックで選択するか、右クリックのプロパティウィンドウから「ドックビューを開く」を選ぶとその基地がアクティブになり、以後は右上のビュー切替からも直接遷移できる(アクティブでない基地は選択肢に出ない。左クリックの選択だけではビューは切り替わらない)。
  - **画面マーカー**: マップ・戦闘のどちらでも ● のポイントマーカーが常設される。戦闘ビューで画面外に出ると、AMMO ピックアップと同じ方式で画面端に方位矢印が出る。
  - **航法ターゲット**: 基地は他の艦・月・ラグランジュ点と同じく航法ターゲットに設定できる(軌道要素を持つため軌道面が定まる)。マップの右クリックプロパティウィンドウに加え、戦闘ビューでも基地アイコンを右クリックすると同じ設定/解除項目を持つメニューが開く。基地は武装を持たないので戦闘ターゲット(第一/第二ターゲット・射撃照準)の対象にはならない。
- **ドックビュー**: アクティブな基地があるとき、右上のビュー切替(または基地の右クリックメニュー)から遷移できる全画面ビュー。表示中は時間が止まり、3D は描画されない。
  - **格納艦**: 収容中の艦の一覧。発進・詳細表示ができる。「新造」ボタンで既定パーツ一式の艦を1隻、即座に建造して格納艦へ加えられる(35,000 Cr、クリエイティブモードでは無料)。建造した艦はランデブーで収容した艦と同じ扱いで、実際に軌道上へ現れるのは発進した瞬間。
  - **部品**: 左に搭載部品、右に基地の倉庫を並べる。搭載部品は修理・同種在庫との換装ができ、倉庫の在庫は売却できる(売値は購入価格の 50%)。RCS タンクは搭載中・在庫を問わずその場で燃料補給できる(1 kg あたり 2 Cr)。倉庫は基地の持ち物なので、格納艦が居なくても表示される。
  - **ショップ**: 部品を購入して倉庫へ入れる。クリエイティブモードでは修理・補給・購入すべて無料。
- **戦闘ビュー上部のステータスウィンドウ**: 他ステージと同じく表示される(装甲・エンジン出力・動圧・温度・電力のゲージ、太陽光パドル/放熱板の展開ボタン、撃墜数)。ステージ固有の補助メッセージ欄だけは無い。
