# INVARIANTS — 全分野に掛かる不変条件

分野を問わず常に成り立っていなければならないこと。**破られたらバグである。**

**この文書は目指す振舞いを書いたもので、実装状況ではない。未実装の記述が混じっているのは正常。**

本書に定める不変条件は、すべての分野・機能に対して原則として適用される。**分野別の仕様書は、これらが当てはまることを
個別に記載しない。** 記載するのは、一般則から外れる例外事項のみとする(書き方の詳細は [README.md](README.md)
「一般則と事例」を参照)。

## 1. 連続性

**原因が連続に変わるものは、連続に見える。** 詳細度の段階・優先順位の入れ替わり・表示の切り替え・
近似の精度が、明滅・ちらつき・跳躍・段差として画面に出てはならない。作り方の都合が絵に現れる
場所は、それ自体が違反である。

離散に切り替わってよいのは、**切り替えの理由そのものが離散のとき**だけ(天体の親子関係・フォーカス
対象・トグルの状態)。そのときも、境目で往復してはならない — いったん切り替わったものは、
切り替える理由が十分に解消するまで戻らない。

**対象を毎フレーム解決するものは、一時的に解決できないだけの間は直前の結果を保ち、失われたと
確定して初めて手放す。** 視点のフォーカス・座標系の基準・ターゲットのいずれも、答えが一瞬得られ
なかったことを喪失として扱わない。

## 2. 決定性

**同じ時刻・同じ状態から見えるものは、いつ見ても同じである。** フレームレート・時間加速倍率・
一時停止・セーブと読み込みは、見た目にも物理の答えにも現れない。

時間加速倍率が変えるのは時計の速さだけである。**倍率を上げたことが、軌道の変化としても、
出来事の起こる順序としても、判定の答えとしても見えてはならない。**

## 3. 表示は世界を変えない

**「どう見るか」の選択は、物理の答えにも HUD の読みにも影響しない。** 座標系・表示期間・表示スタイル・
描画品質・カメラの位置・表示のオンオフは、そのどれを選んでも、物体が実際に辿る軌道と、
画面に出る数値を動かさない。

逆に、世界の側が表示の都合で変わることもない。**表示のためだけに持っている量**(見た目の揺らぎ・
演出・近似した表示形状)は、軌道・接触・命中の判定に入らない。

## 4. 見えるものと触れるものは一致する

**画面に出ていないものは選べない。** 隠れている・間引かれている・トグルで消しているものは、
その間クリック・選択・配置の対象にならない。

**押せる形で出ているものが、押してから拒否されることはない。** 選べない選択肢は、無効として
並べるのではなく、そもそも出さない。

## 5. 同じ問いに答えは1つ

**同じ問いに、機能ごとに別の答えを持たない。** 日照しているか・当たったか・いまどこにいるか・
どの天体が基準かは、どの機能から辿っても同じ答えを返す。

同じ量を2つの経路で別々に求めることはしない。求め方が1つであることが、**答えが食い違わないことの
保証そのもの**になる。

## 6. 選んだことは残る

**遊ぶ人が選んだ状態は保存され、次に来ても同じ状態から始まる。** ページを読み込み直しても、
直前の状態で開く。

**そのゲームの空間と時間に依拠する選択は、そのゲームのセーブに残る。** 特定の物体・天体・空間上の
位置を指す選択と、そのゲームの時間の尺度や時刻を指す選択(表示期間・未来ゴーストスライダーの位置)が
これにあたる。セーブを切り替える・手動セーブを読み込むとそのセーブの選択になり、新しく始めたゲームでは
既定から始まる。

描画品質・表示スタイル・配色・音量・画面全体に掛かる表示のオンオフ(天球グリッドなど)・パネルの
畳みとタブのように、どのゲームにも共通させる選択は**ブラウザに残り**、セーブを切り替えても新しい
ゲームを始めても引き継がれる。

残らないものだけを、その場に例外として書く。

## この文書に足す条件

**2つ以上の分野で共通する条件のみ**を本仕様書に集約する。1つの分野内でのみ完結する規則は、
その分野の仕様ファイルの該当節冒頭に記述する。**分野別ファイルから追い出した記述の退避先ではない** —
本書に収録するのは、全領域で普遍的に成り立つ不変条件のみとする。

## 未確定の案

**決定事項ではない。** 「どの拡張性を残すべきか」を判断するための材料。
