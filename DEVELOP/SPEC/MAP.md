# MAP — マップビュー

マップビューの表示・選択・座標系の仕様。ノードの配置・編集・Δv・未来予測パネルなど軌道計画そのものの
仕様は [PLAN.md](PLAN.md)、視点カメラ(フォーカス・回転の固定先・ズーム)は [CAMERA.md](CAMERA.md)
を参照。

## 1. マップビューへの切替

**ビューを切り替える条件そのものは GAME.md が持つ。** ここではマップ側の事情だけを定める。

- マップは地球中心の3D俯瞰ビューで、照準表示だけが戦闘ビュー専用である。それ以外の操作は
  マップを開いていても同じく効く。
- 一時停止メニューを開いている間はビューの切り替えを受け付けない。既に開いているマップを一時停止が
  強制的に閉じることはないので、マップを開いたまま一時停止→解除すると元の状態に戻る。
- ステージの勝敗が決着すると、マップは強制的に閉じられる。

## 2. 座標系パネル

カメラが固定する座標系と、計画軌道の折れ線を描く座標系を、それぞれ独立に
「何に固定/追随するか(基準)」×「何の回転に合わせて回すか(回転)」の2段で選ぶパネル。
マップビューにのみ現れる。**カメラ(視点)** と **軌道計画(描画基準)** の2区画に分かれ、
どちらも「基準」ゾーンと「回転」ゾーンの2ゾーンを持つ。

**各ゾーンが何を選ばせるかは、この文書の担当ではない。** カメラ区画が選ばせるもの(注視対象と
視点の回転の固定先)は [CAMERA.md](CAMERA.md)、軌道計画区画が選ばせるもの(計画軌道の描画基準)は
[PLAN.md](PLAN.md)。ここではパネルという UI 部品の構成だけを定める。

- **基準ゾーン**(両区画)は中心の選択。天体とは限らない(機体も役割も選べる)ので、見出しは
  「基準」であって「基準天体」ではない。
  - 上段は登録天体・自艦・敵・基地・弾薬まで含む全候補から、絞り込み入力つきのポップアップ
    (グループ分けした多列グリッド)で選ぶ。先頭のグループには **役割** ——「操作対象の船」と
    「ターゲット」—— が並ぶ。役割の解決の規則は CAMERA.md。
  - 下段は**いまカメラがいる系**(CAMERA.md)の天体だけに絞ったクイックボタンで、候補に無い天体は
    出さない(押せてから拒否されることはない)。
  - **カメラ区画**の基準ゾーンの先頭には「固定を解除」があり、選ぶと注視点はその瞬間のECI位置を
    **恒星中心の慣性系**(恒星の無いレジストリでは原点天体の慣性系)へそのまま焼き込んだ固定点になる
    ——元の天体を追いかけ続けるのをやめる操作で、たとえば地球を見ていた注視点を解除すると、その場に
    静止したまま地球の公転から取り残されて見える(地球からは相対的に離れていく)。
  - **軌道計画区画**の基準ゾーンには解除が無い——計画折れ線は常にどこかの座標系に焼き込んで描くしか
    なく、「どこにも固定しない」状態自体が無い。太陽系空間そのものへの固定は、プルダウンで恒星を
    選ぶことに当たる。
- **回転ゾーン**(両区画)は回転の選択。先頭は慣性系(回転させない)で、これは他の選択の否定では
  なく並列な選択肢の1つなので「解除」とは書かない。
  - **カメラ区画**の選択肢はフォーカス対象から導かれる(CAMERA.md)。
  - **軌道計画区画**の選択肢はいまカメラがいる系から導かれる(PLAN.md)。
- 基準ゾーン(両区画)と軌道計画区画の回転ゾーンの選択肢はカメラ位置という連続量から導かれるが、
  区切り方自体は天体の親子関係という離散的な単位なので、ズーム操作の途中で選択肢が明滅する
  ことはない。カメラ区画の回転ゾーンはフォーカスという離散量から導かれる。
- **条件で消えうる選択肢は、押せてから拒否されることがない。** その代わり、選んでいる最中に条件が
  崩れたら慣性系へ落ち、選択表示も慣性系へ戻る。
- パネル末尾に、いま選ばれている2つの座標系を1行で述べるサマリを出す
  (例: 「カメラ: 地球・慣性系 / 計画: 地球・月回転系」)。4ゾーンが答えているのは別々の問いなので、
  合わせて何を選んでいるのかを読み直さずに把握できるようにする。**ここに使う綴りは短縮形**で、
  ボタンに使う正式名とは別(CAMERA.md「画面に出す名前」)。
- カメラの座標系と計画軌道の座標系は独立に選べる。両方を回転系にすると回転系での軌道形状が静止して
  見え、カメラだけ慣性系にすると同じ形状が回転対象とともにゆっくり回って見える。
- **同じ画面に出るものは、同じ座標系・同じ時刻で描かれる。** 計画軌道の座標系に回転系を選んでも、
  計画の折れ線・予測の折れ線・ノード/バーン点マーカー・赤道交点・相対昇交点/降交点はすべて同じ
  座標系に載る。表示時刻を未来へ送ったときも、天体・機体のメッシュと軌道線・各マーカーは同じ時刻の
  位置に揃う(線とマーカーだけが現在時刻に取り残されることはない)。
- **公転回転系はどちらも回転対象の方向を厳密に固定する。** 太陽-地球回転系の回転軸は黄道法線(赤道面に
  対し 23.44° 傾く)で、太陽は常に同じ方向に静止する。地球-月回転系の回転軸は白道法線で、白道は黄道に
  対しさらに 5.145° 傾き、その昇交点は 18.61 年周期で歳差する。地球-月回転系では月が常に同じ方向に
  静止(離心率ぶんの遠近だけが残る)して見え、低軌道からの月遷移軌道の形が読み取れる。太陽-木星回転系・
  太陽-土星回転系はそれぞれの公転面法線を軸に固定し、木星・土星が常に同じ方向に静止して見える。
  この静止は未来ゴーストスライダーで表示時刻をずらしても保たれる(スライダーを動かした瞬間に回転対象
  だけ画面上を流れ始めることはない)。
- **自転回転系は回転対象の地表を厳密に固定する。** 回転軸は自転軸そのもので、地表の1点が画面上に
  静止する。自転軸自体もゆっくり動く(歳差)が、その速さは自転の 10⁻⁷ 倍未満なので、座標系の
  角速度としては無視する(基底の取り方と逆行自転の扱いは
  [CELESTIAL.md](CELESTIAL.md)「座標系と参照フレーム」)。

## 3. 表示するオブジェクトの選択(可視性の規則)

マップに何を出すかは、「表示」パネルの天体クラス別トグルと自艦・敵・弾薬・基地の種別トグルで決まる。
ラベル(位置の点+名前表示)・軌道線をON/OFFでき、いずれかがONの対象だけが表示・選択
(クリック・右クリック・ダブルクリック・一覧への掲載)の対象になる——**見えないものは選べない**。

- 対象クラスは 惑星/衛星/準惑星/小天体/ラグランジュ点 の5行(恒星はトグルを持たず常時表示)と、
  自艦/敵/弾薬/基地 の4行。
- 惑星・衛星・準惑星・小天体・自艦・敵・弾薬・基地の各行は、ラベル・軌道線の2つを独立にON/OFFできる。
  既定はラベルが全クラス/全種別でON、軌道線は惑星・衛星・自艦・敵・弾薬・基地はON(準惑星・小天体は
  OFF)。ラベルをOFFにすると位置の点(マーカー)ごと消える——「点だけ残して名前だけ消す」
  「名前だけ残して点を消す」という中間状態は無い。
- 衛星の軌道線トグルは、ON にしても即座に全衛星の軌道楕円が出るわけではなく、カメラ/フォーカスが
  その衛星の属する惑星系にあるときだけ実際に表示される(全衛星の軌道楕円を同時に描くと内惑星系が
  埋もれるため、トグルと系の判定の両方がONのときだけ表示される)。ただし地球の月だけは常時例外的に
  表示される。
- ラグランジュ点の行はラベルのみを持つ(軌道という概念自体が無いため軌道線は無い)。
- 各行の見出しは、ラベル・軌道線をまとめてクラスごと表示/非表示にする**クラス全体トグル**を
  兼ねる。ラベル・軌道線のうち少なくとも1つがONならクラス全体トグルは自動的にONになり、
  行が持つそれらが全てOFFになれば自動的にOFFになる(手動で個別に合わせる必要は無い)。
  クラス全体トグルを直接ONにすると、その行のラベル・軌道線を全てONにする。直接OFFにすると
  全てOFFにする。ラベル・軌道線はクラス全体トグルの状態に関わらず常に個別にON/OFFできる
  ——クラス全体がOFFの間にラベル・軌道線を個別に触っても操作は無効にならない。
- クラス全体トグルは表示可否の最終的なゲートであり続ける。OFFの間は、そのクラスの天体は
  (常時表示の例外を除き)ラベル・軌道線とも表示されない。
- **常時表示される対象**: 恒星、いまカメラがいる系の天体、フォーカス中の天体の親・子・
  (同じ惑星系内の)兄弟は、ラベルトグルを介さず強制的に表示・選択可能になる。ただし、そのクラス
  自体のラベルがOFFになっている場合はこの例外の対象にならず、表示されない(トグルで丸ごと消した
  クラスを、常時表示の例外がよみがえらせることはない)。
- **操作中の自艦**は、自艦クラスのラベルをOFFにしていても位置の点は常に表示される(自分の位置を
  見失わないため、艦名だけは出ない)。軌道線は通常どおりトグルに従う。
- **どの系がラグランジュ点を持ち、そのうちどの点が出るか**は CELESTIAL.md が定める。マップは
  そこで出ると決まった点だけをラベルとして扱う。
- 「距離が近づいたら見える」といった連続量による表示切替は無い(ズーム中に表示がちらつくのを避ける
  ため)。表示・非表示は上記の離散的な規則だけで決まる。「いまカメラがいる系」の決まり方と、
  勢力圏の境界で明滅してはならないという要求は CAMERA.md。

## 4. 表示パネル

マップビューでのみ表示される(戦闘ビューでは「表示」パネル自体が畳まれる)。パネルは
**対象 / ガイド / 軌道ガイド** の3つのタブに分かれ、上部のタブボタンで切り替える。表示されるのは
選んだタブの内容だけで、タブは常にどれか1つが選ばれている。選んでいるタブは保存され、ページを
再読み込みしても直前のタブが開く。

- **対象**タブ: マップに出す対象クラスの選択(3節)。
- **ガイド**タブ: 天球グリッド・空間グリッド(4.1節)とゼロ速度曲線(4.3節)。
- **軌道ガイド**タブ: 参照として描く軌道のガイド線(4.2節)。

画面全体の見せ方(写実/模式図)は表示パネルではなく、左ドックの独立した「スタイル」パネルが
持つ — マップビュー限定の選択ではないため(RENDERING.md「表示スタイル」)。

### 4.1 ガイドタブ(天球グリッド・空間グリッド)

- 黄道・赤道・月軌道・月赤道の4つを行、面/極/網/縮尺の4つを列とする1つの表にまとめる。
  月軌道・月赤道は面/極/網を持たず縮尺のみを持つ(該当セルはトグル自体を置かない空欄になる)。
- 黄道・赤道の行は、面/極/網の3列トグルと、それらをまとめる**行見出しトグル**を持つ
  (縮尺列はこの行見出しの管理下に入らない独立トグル)。3列トグルのうち少なくとも1つが
  ONなら行見出しは自動的にONになり、3つ全てがOFFになれば自動的にOFFになる。行見出しを
  直接ONにすると面・極・網を全てONにし、直接OFFにすると全てOFFにする。面・極・網は行見出し
  の状態に関わらず常に個別にON/OFFでき、行見出しは表示可否の最終的なゲートであり続ける
  (行見出しがOFFの間は面・極・網を個別にONにしても表示は再開しない)。
- 月軌道・月赤道の行は縮尺列しか持たないため、行見出しトグル自体がその行の縮尺グリッドの
  ON/OFFを兼ねる。
- 既定は4行とも、行見出し・全列トグルがすべてOFF。
- 面をONにすると、自機/カメラに追従する固定半径の殻として、その面の基準円・30°間隔の緯経線・
  両極マーカーが描かれる(極トグルは面と独立に極マーカーの表示可否だけを切り替える)。
  網(グリッド)をONにすると、同じ殻の上に緯経線の格子を重ねる。
- 縮尺列は、自機/カメラの位置を通る縮尺グリッド(基準円は持たず、目盛りの交点だけを十字で示す
  平面)を面とは独立にON/OFFする。月軌道は月の軌道法線を、月赤道は月の自転軸(潮汐ロックして
  いても軌道面法線とは一致しない)をそれぞれ面の向きとして使い、時刻の経過とともに向きが
  追従する。黄道・赤道・月軌道・月赤道の4種は互いに独立した色で描かれ、同時に何枚でも重ねて
  表示できる。
- トグルの状態は保存され、ページを再読み込みしても直前の設定が復元される。

### 4.2 軌道ガイドタブ

参照として描く軌道のガイド線を、軌道の種類ごとに選ぶ。種類は次の群に分かれ、**群は横並びの
タブとして切り替える**(常に1群だけを開く。複数群を同時に開いたままにはできない)。

| 群 | 含まれる種類 |
| --- | --- |
| 基本 | 静止軌道 / 太陽同期準回帰軌道 / ドーンダスク軌道 / モルニヤ軌道 / ツンドラ軌道 |
| 共線点 | 平面リヤプノフ軌道 / 垂直リヤプノフ軌道 / ハロー軌道(北・南)/ 軸方向軌道 / 蝶形軌道(北・南)/ トンボ形軌道(北・南)/ リサジュー軌道 |
| 三角点 | 短周期軌道 / 長周期軌道 / 垂直軌道 / 軸方向軌道 |
| 副天体周回 | 遠距離逆行軌道 / 遠距離順行軌道 / 低高度順行軌道(東・西) |
| 共鳴 | 1:2 / 2:1 / 3:1 / 2:3 / 4:3 / 3:4 共鳴軌道 |

画面に出す種類名は、日本語訳に英語を添えた形にする(例:「軸方向軌道(axial)」)——定訳の
無い語が多く、文献と照らし合わせられるようにするため。**共鳴の6種類だけは例外**で、見出しに
「共鳴軌道」を付けず比率(例:「1:2」)だけを表示する——比率どうしの見分けが本質で、6つ並ぶ
ボタンを素早く押し分けられることを優先し、見出しのボタン自体も他の種類よりひとまわり大きく
表示する。

- 各種類の見出しはその種類の表示トグルを兼ね、それが表示可否の最終的なゲートになる。
  既定は静止軌道だけがONで、他はすべてOFF。
- **表示がOFFの間、その種類の設定は現れない**(見出しの1行だけになる)。種類が数十あるため、
  出しているものだけを詳しく見せる。
- **系のトグルはタブ上部に1組だけ**持ち、すべての群に共通して効く(群ごとに個別選択は
  しない)。系は地球-月・太陽-地球・太陽-火星・木星-エウロパ・土星-タイタン・
  土星-エンケラドス・火星-フォボスの7つで、折りたたみは設けずすべて並べて出す。
  **「基本」群(静止軌道・太陽同期準回帰軌道・ドーンダスク軌道・モルニヤ軌道・ツンドラ軌道)は
  CR3BP の軌道ではなく、いずれも地球専用の軌道なので系の軸を持たない。**
- ある系に存在しない種類は、その系を選んでいる間は選択肢に出ない。

#### 小題(点/南北/東西/区間をまとめて選ぶ種類)

共線点のリヤプノフ・垂直・軸方向・ハロー、三角点の短周期・長周期・垂直・軸方向、副天体周回の
DPO・LPOは、ラグランジュ点・南北・東西・区間のうちその種類が持つ軸を、種類ごとに独立した見出し
ではなく、**軸1つずつのボタンにまとめた小題**として並べる。蝶形軌道・トンボ形軌道・共鳴軌道・
DROはこの対象外で、今までどおり種類ごとに独立した見出しを持つ。

- 軸のボタンは表示ON/OFFの複数選択トグルで、**押した軸値すべての積を満たす族**が表示される
  (例: ハロー小題で「L1」「L2」「北」を押すと、ハロー L1 北・ハロー L2 北の2本が表示される)。
- **点・南北・東西の軸は、他の軸を1つでも押していれば、自分が空でも「その軸の全部」を対象に
  補って表示する**(例: ハロー小題で「L1」だけ押すと、北・南の両方が表示される。「北」だけ
  押すと、南北を持つ全ての点が表示される)。ただし全軸とも1つも押していなければ何も表示しない。
- **区間の軸だけはこの自動補完の対象にしない。** 区間は同じ点・向きでも物理的に別系統の族なので、
  区間を持つ小題(軸方向・DPO)では区間を明示的に押さない限り何も表示しない(他の軸を押しても
  区間は補われない)。
- 押した組み合わせが実在しない(例: 軸方向の L2 に区間2 を掛けたもの)ときは、その組み合わせ
  だけが静かに表示されない——他の組み合わせの表示や、ボタン自体の押下は妨げない。
- 「種類・小題ごとの表示設定」(次項)は小題1つにつき1組だけ持ち、押している組み合わせすべてに
  同じ設定が適用される(異なる組み合わせへ別々の色や本数を割り当てることはできない)。設定
  パネルは、組み合わせが1つも表示されていない間は隠れる。
- **1本に繋がらない族を区間ごとに分けた種類**(「ガイド線の正確さ」参照)のうち、小題に含まれる
  もの(軸方向・DPO)は区間も軸ボタンの1つとして扱う。小題に含まれない種類(蝶形・トンボ形・
  共鳴・DRO)は、元の種類のすぐ後ろに区間の番号順で並ぶ独立した見出しのまま、表示・色・族の
  範囲を区間ごとに独立して設定する。

#### 種類・小題ごとの表示設定

| 設定 | 内容 | 既定 |
| --- | --- | --- |
| 本数 | 族から何本描くか。1 なら族ではなく範囲の下限にあたる1本 | 1 |
| 族の範囲 | 族に沿った位置の下限と上限(0〜1)。**0 が最も小さい軌道、1 が族の末端** | 0.15〜0.60 |
| 色(始・終) | 族の下限側・上限側の色。既定は群ごとの色相を、種類ごとに明度を変えて割り当てる | 群の色 |
| 反転 | 始と終の色を入れ替える | OFF |
| 透明度 | 線の不透明度 | 0.4 |
| 進行方向 | 表示しない / 1周に1つ / 多数 | 表示しない |
| アニメーション | 進行方向マーカーを動かすか | OFF |
| 安定度を示す | 安定な軌道を目立たせるか | OFF |
| 色をリセット | 既定色へ戻す | — |

- **本数が1のとき、族範囲の上限・色(終)・反転は意味を持たない**ため、その行は現れない。
- **本数を増やして複数本描くとき、線の間隔は画面上で均等に見えなければならない。** 族に沿った
  位置の値(0〜1)そのものが、焼き込み元データの並び順に対して均等である必要はない。
- **選んだ軌道の実際の値**(周期・ヤコビ定数・安定性指数)を、族の範囲の近くに読み取り専用で
  添える。族の位置という抽象的な指定が、どの軌道を指しているのかを読み取れるようにする。
- 進行方向マーカーは、頂点が進行方向を向いた小さな三角形で、その軌道と同じ色で描く。
  画面上の大きさはズームによらず一定に保つ。
- アニメーションは**実際の軌道速度に比例**して進む。近点で速く、遠点で遅く動く。
- 安定度を示すと、その族のうち**線形安定な軌道**が他と見分けられるようになる。族内の位置を
  示す色のグラデーションは保たれ、安定度は色とは別の見え方で重なる。
- **リサジュー軌道だけは族の概念を持たない。** 本数・族の範囲の代わりに、面内振幅・面外振幅・
  それぞれの位相・周回数を指定する。閉じない軌道なので、指定した周回数ぶんの軌跡として描かれる。
  安定度も持たない(周期軌道ではないため)。
- 同時に描く線が多くなりすぎたときは、パネルにその旨を示す。**ただし指定した本数を勝手に
  減らすことはしない。**

#### 基本群の新規4種類(太陽同期準回帰軌道・ドーンダスク軌道・モルニヤ軌道・ツンドラ軌道)

いずれも CR3BP の族を持たない単一の地球周回軌道なので、本数・族の範囲・安定度を示す設定は
持たない(リサジュー軌道と同様)。色・透明度・進行方向・アニメーションは他の種類と共通に持つ。

- **太陽同期準回帰軌道**: 回帰日数(地表軌道が同じ経路を繰り返すまでの日数)と、その日数の間に
  周回する回数をそれぞれ整数のスライダーで指定する。円軌道とし、この2値から、地球の自転に対して
  指定どおりに地表軌道が回帰し、かつ昇交点が太陽と同じ向き・同じ角速度で歳差する(=軌道面と
  太陽の関係が季節を通して変わらない)高度・傾斜角を一意に求めて描く。指定の組み合わせによっては
  そのような軌道が存在しない(必要な傾斜角が実数解を持たない、解の高度が地表を下回るなど)ことが
  あり、そのときは軌道を描かず、パネルにその旨を示す。回帰日数・周回数のスライダーは、可動範囲
  自体は動かさないまま、もう一方の現在値に対して軌道が存在する範囲をトラックの色を変えて示す。
- **ドーンダスク軌道**: 太陽同期準回帰軌道と同じく回帰日数・周回数を指定する太陽同期軌道だが、
  昇交点の地方太陽時を朝(6時)・夕(18時)のどちらに置くかをあわせて選ぶ。地方時が異なると
  軌道面の向きが変わるだけで、高度・傾斜角の求め方は太陽同期準回帰軌道と同じ。
- **モルニヤ軌道**: 近地点高度と昇交点赤経をスライダーで指定する。傾斜角は近地点引数の摂動が
  止まる臨界値(63.4°)、近地点引数は遠地点が北半球高緯度に来る270°に固定し、周期は半恒星日
  (1日に2周)に固定する。離心率は周期・近地点高度から一意に決まる。
- **ツンドラ軌道**: モルニヤ軌道と同じパラメータ(近地点高度・昇交点赤経)・傾斜角・近地点引数を
  使うが、周期は1恒星日(1日に1周)に固定する。

#### ガイド線の正確さ

- **ガイド線は予め計算しておいた軌道を補間して描く。** 実行中に軌道を解き直すことはしない。
- 近似であっても、次が正しく見えなければならない: 軌道は主星-副星回転座標系で閉じた線に見え、
  ハロー軌道の北側と南側は互いに鏡像で、族に沿って形が連続に変わる。**振幅を大きくしたときに、
  天体の近くを曲がらずに突き抜けるような、力学的に成り立たない形が出てはならない。**
- ガイド線はその瞬間の実際の天体位置・公転面から組み立てた回転座標系に載せて描かれ、
  慣性系のカメラからは天体の公転とともに回って見える。
- CR3BP は天体を質点として扱うため、周期軌道として数学的には成り立つが主星・副星いずれかの
  実際の半径より近点距離が小さい(=実際にはその天体に衝突する)メンバーが族に含まれることが
  ある。**そうしたメンバーは族から除外する。** 族は振幅について連続な列なので、除外は族の端から
  連続して行い、族の途中に穴を開けない。
- **1本の連続した列にならない族は、連続する区間ごとに別の種類として分ける。** 元データの族が
  互いに繋がらない枝に分かれていることがあり、また衝突するメンバーを除いた結果が族の途中で
  途切れることもある。どちらの場合も、**連続した区間のそれぞれを独立した種類として扱う** —
  1つの種類の中に飛びを残さない。**分けた結果生じた短すぎる断片**(軌道が数本しか取れない
  もの)は出さない。**分ける必要が無かった種類は、軌道が少なくてもそのまま出す** — 元から
  軌道が数本しか取れない種類はあり、それを断片と同じ扱いで消さない。
- **分けた種類の名前には区間の番号を添える**(例:「軸方向軌道(axial) L1 区間2」)。番号は
  族に沿った順に1から振る。**分ける必要が無かった種類の名前は変わらない** — 大半の種類は
  1本に繋がるので、番号は分かれたものにだけ付く。
- ゲーム本体のシミュレーションは制限三体問題ではないため(ORBIT.md)、ガイド線はあくまで
  参照であり、その上に置いた艦が留まり続けることは保証しない。
- タブ内の全設定は保存され、ページを再読み込みしても直前の設定が復元される。

### 4.3 ゼロ速度曲線(ガイドタブ)

ガイドタブに、指定したエネルギー水準(ヤコビ定数)で到達できる領域の境界を描く節を置く。

- **断面**は4つで、2つの系それぞれについて、両天体を含む面と、それに垂直な面を取る。
  「月軌道面」「地球と月を通る垂直な断面」「地球公転面」「太陽と地球を通る垂直な断面」。
  それぞれ独立にON/OFFできる。既定はすべてOFF。
- **表示方式**は「1本」と「多数」から選ぶ。1本は指定したヤコビ定数の曲線だけを、多数は
  指定した範囲を等分した値それぞれの曲線を描く。
- ヤコビ定数はスライダーと数値入力の両方で指定できる。**各ラグランジュ点の値へ一発で合わせる
  ボタン**を添える——ネックが開く瞬間を見るのがこの表示の主な使い道であるため。
- 断面の描画範囲は**その系のスケールに固定**する。ズームしても格子の粗さが変わらず、表示が
  ちらつかない。
- 曲線だけを描き、到達できない側を塗ることはしない。

## 5. 軌道線の表示

- 生存中の全敵の軌道は解析軌道楕円(グレー)で常時表示され、比較しやすい。戦闘ロック中のターゲットは
  第二アクセントカラーで個別に強調され、通常のグレー表示からは除外される。
- **操作艦の軌道線**は表示ビューによって描き方が変わる。
  - 戦闘ビュー: 現在の状態ベクトルから求めた解析軌道楕円として表示する(敵・基地の軌道楕円と同じ
    仕組みで、専用の色・不透明度を持つ)。楕円はその瞬間の状態ベクトルだけから描かれるので、
    噴射中も摂動で軌道要素が動いている間も、常に自機の現在位置を通る。
  - マップビュー: 数値積分で伸ばしている予測軌道のうち現在時刻から先を実線の折れ線として表示する。
    線の先頭は常に現在の実位置に載る——実際の飛行がこの線をそのまま辿るため、先頭が実位置から
    離れることはない(ORBIT.md)。噴射中も途切れず伸び続ける。予測が表示期間の終端まで届いて
    いない間(艦を配置した直後・噴射で予測を捨てた直後・タイムワープが予測の伸長を追い越して
    いるときなど)は、届いている先端から中心天体まわりの二体軌道とみなしたケプラー外挿で表示
    期間の終端まで線を継ぎ、途切れずに1本の折れ線として見える。
    外挿が成り立たない軌道の先端と、天体の地表へ到達して打ち切られて以後伸びない予測は外挿せず、
    届いている区間で線が止まる。自機が月を基準天体として周回している
    ときも予測軌道は月の引力を含めて積分されるため、月遷移軌道のように解析楕円では正しく表せない
    形もそのまま表示される。
  - 自機の軌道は常に1本の線で表示され、解析楕円と積分線が同時に並んで見えることはない。
- マップビューで自艦が複数存在するときは、**現在操作している艦だけ**が上記の予測線・過去線
  (アクセントカラー)で描かれる。操作対象でない自艦は、敵・基地と同じ解析軌道楕円(白)で表示される。
- 過去へ遡って描く軌跡(履歴)はどちらのビューでも変わらず、自機が既に通ってきた実軌道を積分の履歴
  からそのまま描く。
- 自艦・敵・基地は、プロパティウィンドウ(11節)から個体ごとに軌道線の表示方式を解析軌道楕円⇔
  予測線・過去線の組に切り替えられる。既定は操作対象の自艦以外すべて解析軌道楕円。切り替えて
  数値積分側を選んだ対象は、操作対象の自艦と同じ規則(先頭が現在位置に載る・ケプラー外挿で
  途切れず継ぐ・過去は積分の履歴から描く)で予測線・過去線が描かれるが、色は操作対象の自艦の
  アクセントカラーとは別に、対象の既定色(敵は個体ごとの識別色、基地・自艦は既定色)を保つ。
- マニューバ計画に1つ以上ノードを置いている間は、これとは別に破線の計画軌道線が重ねて表示される
  (バーン前後で色分けされ、戦闘ビューでも見える)。詳細は [PLAN.md](PLAN.md) を参照。

## 6. マーカー

### 6.1 記号の体系

画面に出る記号は、読み手が最初に判断する「それは物か、向きか、軌道上の点か」に対応して3つの族に
分かれる。

- **塗りつぶし = 実体**: 艦 ▲ / 天体 ● / 計画上の自機ゴースト ⬢ / 配置プレビュー ▷。
  天体のうち恒星は二重丸 ⊚、衛星は中抜きの丸 ○ で他の分類と見分けられるようにし、
  惑星・準惑星・小天体は共通の ● のままにする。
- **矢 = 方向**: プログレード ⊙・レトログレード ⊗、ノーマル ⇧・アンチノーマル ⇩、
  ラジアルアウト ◎・ラジアルイン ◉、ターゲット ⇨・反ターゲット ⇦、画面外の対象を指す方位矢印 ↑、
  天球グリッドの極 ⇕。
- **中空 = 軌道上の点**: 近地点/遠地点 ◇ / 昇交点 △・降交点 ▽ / 再接近点 ✧ / マニューバノード ◈ /
  バーン点 ⬡ / 衝突点 ✕。

進行方向/逆行(プログレード/レトログレード)・法線方向(ノーマル/アンチノーマル)・動径方向
(ラジアルアウト/イン)の6方向マーカーだけは色を持つ例外で、進行方向=青・法線=緑・動径方向=赤
(逆向きは記号形状だけで区別し、色は同じ軸のペアで共有する)。それ以外のマーカーはモノトーン基調で、
注意を引く対象(リード照準・ノード/バーン点)は基調のアクセント色(オレンジ系)で強調される。
弾薬はモノトーン基調のまま強調しない。
**操作対象の船のマーカーは基調のアクセント色、ターゲットのマーカーは第二アクセント色**で強調され、
両者は異なる色で区別される([UI-DESIGN.md](UI-DESIGN.md) 参照)。船が同時に操作対象かつターゲットで
あることはあり得るが、その場合はターゲットの色を優先する。UIの縦方向の折りたたみ矢印
(▾ = 開いている / ▸ = 閉じている)は上記のいずれの族とも重ねない(折りたたみと方向マーカーが
読み違えられないようにするため)。

### 6.2 天体ラベル

- 登録天体それぞれに1つの位置ラベルが付き、力学的に意味を持つラグランジュ点(3節参照)には
  さらに専用のラベルが付く。ラグランジュ点のラベルは「L1」を「地球」の上に2段で表示するなど、点自体を
  主役に、天体名を補足として示す。
- 画面上でラベルが密集した場合、優先度(惑星/恒星 > 準惑星 > 衛星/小天体 > ラグランジュ点)に従って
  近接するラベルの名前を間引く。名前の間引きが起きる近接度と、位置の点(マーカー)自体が間引かれる
  近接度は別の閾値であり、点の間引きは名前よりも顕著に近接した場合にのみ起こる(名前だけが消えて
  点は残る距離帯が存在する)。ただしカメラからの距離が著しく離れている対象同士が重なった場合は、
  優先度に関わらずカメラから遠い側を間引く(手前の対象が奥の対象の陰に隠れて見えなくなることを
  防ぐ)。この遠い側を間引く判定も、名前用と点用でそれぞれ独立した近接度で働く(点は名前より近接
  しないと間引かれない)。**周期の短い衛星どうしが画面上で重なっても、高いタイムワープ中に
  ラベルが明滅してはならない** — いったん間引かれたものは、間引く理由が十分に解消するまで
  間引かれたままにする。
  この「カメラからの距離が著しく離れている対象同士は遠い側を間引く」規則は天体ラベル同士に限らず、
  自艦・敵・基地・ターゲット・ノード類など画面上で近接するマーカー全般に働く(6.3 参照)——手前の
  低優先度マーカーが、奥にあるだけの高優先度マーカー(天体ラベルを含む)に隠され続けることはない。
- 天体の裏に隠れているラベルや、上記の混雑で名前または点が間引かれているラベルは、その間クリック・
  右クリック・ダブルクリックいずれの対象にもならない(表示が復活すれば選択候補にも戻る)。この
  遮蔽・混雑の判定はマップビュー限定で、戦闘ビューの表示・操作には影響しない。

### 6.3 自艦・敵・弾薬・基地マーカー

- マップビューでは自艦・敵・基地・弾薬のマーカーいずれも進行方向(ECI速度の投影)へ回転する
  (円軌道は静止画からでは回転方向が読み取れないための対策)。速度が視線方向とほぼ平行で投影上の
  向きが定まらない場合は回転させず、直前の向きを保持する。戦闘ビューでは機体メッシュ自体が姿勢を
  示すため、マーカーは回転しない。
- 実際に向きが見た目へ現れるのは形が非対称な自艦・敵の鏃形マーカーだけで、基地(正七角形)・弾薬
  (▣)は形が対称なため回転していても見た目は変わらない。
- 自艦・敵マーカーの残HPは、マップビューでは鏃形内部の塗り高さで、戦闘ビューでは辺の切り欠きで示す。
  基地・弾薬にHPの概念は無く、塗り高さ表示も無い。
- **自艦の艦名ラベルは1隻につき1つだけ出る**。操作対象の艦は基調のアクセント色(オレンジ系)の
  自艦マーカーに艦名が付き、それ以外の自艦(複数隻を操作できるステージ)は既定色のマーカー側にだけ
  艦名が付く。艦名ラベルには距離などの副情報を添えない。ターゲットになっている船はターゲット色
  (6.1 参照)を優先する。
- 弾薬(補給ピックアップ)のマーカーはマップビューでは距離を添えない(軌道上の位置で見つけるもので、
  縮んでいく数字を追いかけるものではないため)。基地のマーカーは戦闘ビュー・マップビュー双方で距離を
  添える。
- 自艦・敵・弾薬・基地のマーカーは、未来位置スライダーがその対象の予測が届いていない時刻を指している
  間は非表示になる(下記「未来ゴーストスライダー」参照)。

#### 近接時のまとめ表示

- 自艦・敵・基地・弾薬のマーカーは、画面上で一定距離より近接した2隻以上を1つの代表マーカーへ
  まとめる。まとめる/まとめないの判断は対象の種別・操作対象かどうか・ターゲットかどうかに関わらず、
  画面上の近さだけで決まる——操作対象の艦、ターゲットの船も他の船と同様にまとめの対象になる。
- 2隻が近接した場合、代表マーカーの下に両者の正式名称を2行で表示する。各行は該当する船自身の色
  (7.1 の色分けに従う)で表示され、代表側の色に統一されることはない。
- 3隻以上が近接した場合は正式名称を省略し、"×N" の件数表示にまとめる。
- まとめられて代表に吸収された側のラベルは消えるが、マーカー本体(アイコン)は消えず、各自の色で
  その場に残り続ける。
- 代表の選出は優先度(ターゲット > 基地 > 自艦 > 敵)で決まる——操作対象かどうかはこの優先度に
  影響しない。

#### 天体ラベル下の省略表示

- 天体のラベル(7.2)に画面上で近接した船(操作対象の艦・僚艦・敵・基地・弾薬すべてを含む)は、
  個別のラベルの代わりに、所属する天体のラベル直下へサブ行としてまとめて表示される。所属天体は
  各船に最も強く重力を及ぼす天体で、その天体自身にラベルが出ていなければ、ラベルの出ている
  親天体へ繰り上げる。この折りたたみ自体も 7.2 の「遠い側を間引く」規則に従い、船がカメラに
  著しく近く天体が著しく遠い場合は折りたたまず、船自身のラベルを残す。
- カメラから所属天体までの距離が 500万 km 未満の間は、優先度順に最大3隻まで「グリフ 正式名称」を
  1行ずつ縦に並べ、4隻目以降は「+N 隻」の1行にまとめる。繰り上げが起きた船の行には、元の所属天体名
  (例:「月: 」)を接頭辞として添える。
- カメラから所属天体までの距離が 500万 km 以上になると、正式名称を出さず、種別ごとの記号と
  隻数だけの1行(敵 △N・自艦 ▲N・基地 ⬡N・弾薬 ▣N)に切り替わる。同じ天体の衛星系に属する船も
  まとめて数える。
- このサブ行は天体ラベルと同じ控えめな単色(目立たない灰色)で表示され、7.1 の色分け
  (操作対象・ターゲットの強調色)は適用されない。

### 6.4 未来ゴーストスライダーとの連動

- 未来ゴーストスライダーは自機の計画上のゴースト ⬢ だけでなく、敵・弾薬・自艦本体もその時刻の
  軌道上の位置へ動かす(機体メッシュ・敵マーカー・弾薬マーカー・自艦マーカーがすべて連動する)。
  自艦本体の推進炎・RCS噴射・再突入プラズマの各エフェクトも同じ未来位置に付いてくる。
- 自艦・敵・弾薬(弾・薬莢・破片は予測しない)は、選んだ表示期間(既定1周、最大1年)だけ先まで
  予測されており、スライダーはその期間を超える時刻を指せない。表示期間を短い方へ切り替えた、または
  マップを閉じて戦闘ビューへ戻った直後はスライダーが原点(現在時刻)へ戻る。
- **スライダーをどの時刻へ動かしても、ゴーストはその時刻に物体が実際にいる位置に立つ。**
  表示期間の長さによって位置がずれることはない。

## 7. ターゲットと相対昇交点・降交点

**ターゲットが何であり、どう設定・解除するかは COMBAT.md が持つ。** ここではマップに現れる
ターゲット由来のマーカーを定める。

- 対象の軌道面が求まらない、または自艦の軌道面とほぼ一致する場合は、右クリックの
  「ターゲットに設定」項目自体が出ない。
- ターゲットを設定すると、自艦の軌道がターゲットの軌道面と交わる位置に相対昇交点(△)・
  降交点(▽)アイコンが立ち、毎フレーム自艦の現在軌道要素から再計算される。
- **自艦とターゲットが同じ中心天体を周回しているあいだ、両者の相対距離が今から1日先までの
  範囲で最初に極小になる位置に再接近点(◎)アイコンが立つ**。軌道面が求まらない・ほぼ一致する
  場合でも(相対昇交点・降交点とは独立に)表示される。まだ近づいている途中、または範囲内に
  極小が見つからない(既に最接近を過ぎた)場合は表示されない。
- これらのアイコンは右クリックのプロパティウィンドウから「ここへワープ」(自動タイムワープ開始)・
  「ここにノードを追加」ができる。
- 天体の裏に隠れているあいだは非表示・選択不可になる(マップビュー限定)。
- PREDICT パネルの「軌道要素の時刻を表示」がONの間は、ラベルに通過時刻を併記する(PLAN.md 9節)。

## 8. 赤道交点マーカー

- 自艦・敵・基地など軌道を持つ対象は、その軌道が基準天体の赤道面を横切る点(昇交点△・降交点▽)を
  表示できる。基準天体に赤道モデルが無い場合(太陽・木星など)や、軌道面が赤道面にほぼ一致する場合は
  表示されない。
- 常時表示される対象: 生存中の全基地(接近・ドッキングそのものが軌道面合わせのマニューバであるため)。
- 選択に応じて表示される対象: 操作中の自艦、戦闘ターゲット(ロックした敵/自艦)、航法ターゲット
  (天体・ラグランジュ点を除く軌道を持つ対象)。
- **交点マーカーは、その対象について画面に出ている線に合わせて置く。** 位置はその線と同じ座標系・
  同じ表示時刻の規則で求めるので、表示座標系に回転系を選んでも表示時刻を未来へ送っても、マーカーは
  線に乗ったまま動く。
- 交点そのものを探す先も、出ている線に合わせる。マニューバ計画の折れ線が出ている対象は、表示中の
  区間すべての折れ線が対象で、どの区間の中にある交点でも拾う。解析軌道楕円が出ている対象は楕円上の
  交点を使う。計画を出していない自艦も後者で、積分との差ぶん交点はおおよその位置になる。
- マップビューでのみ、天体の裏に隠れた交点マーカーは非表示・選択不可になる。
- PREDICT パネルの「軌道要素の時刻を表示」がONの間は、ラベルに通過時刻を併記する(PLAN.md 9節)。

## 9. 軌道物体一覧パネル

- マップビューである間は画面右側に常設で表示され、閉じる操作は無い(見出しの開閉ボタンで一覧全体を
  畳めるだけ)。
- 天体/自艦/敵/弾薬/RCS燃料/基地の6区画に分かれる(近地点/遠地点・相対昇交点/降交点/再接近点・
  赤道交点・空域はマーカーであって物体ではないため一覧に含まれない)。区画見出しをクリックすると
  その区画だけ開閉できる。6区画は既定で開いており、開閉状態はビューごとに保存され次回も引き継がれる。
- 各行に添える形態記号は、自艦・敵・基地についてはマップ実マーカーと同一形状のアイコン(6.3参照)を
  使い、天体・弾薬は7.1の文字グリフをそのまま使う。同じ種別を指す記号がパネルとマップで別の形に
  見えることはない。
- 天体区画の中では天体の階層構造(太陽 > 惑星 > 衛星、ラグランジュ点はその天体の直下)がそのまま
  入れ子のツリーとして示される。ある天体の衛星・自身のラグランジュ点は、その天体の行の下に折りたたみ
  可能な子リストとしてぶら下がり、衛星自身のラグランジュ点はさらにもう1段深く入れ子になる。これらの
  子リストは既定で畳まれている(候補数が多く、常に見る必要は薄いため)。
- 天体区画の見出しには、区画そのものの開閉トグルとは別に「全展開」「全折りたたむ」の2つのボタンを
  持つ。押すと天体区画内の全ての入れ子(衛星・ラグランジュ点の子リスト)を一括で展開/折りたたむ
  ——個々の子リストを1つずつ開閉する手間を避けるためで、結果は通常の手動開閉と同じ状態として扱う
  (絞り込みによる自動展開のような一時的なものではない)。他の4区画は入れ子を持たないため、この
  2つのボタンは天体区画にだけ現れる。
- 検索欄は名前・補助表示文字列に部分一致する。フィルタボタン(惑星/衛星/準惑星/小天体/
  ラグランジュ点/人工物/敵)は排他選択で、選択中のボタンをもう一度押すと解除して全種別に戻る。
  「人工物」フィルタはフォーカス中の天体系に属する自艦・弾薬・RCS燃料・基地だけに絞り、「敵」フィルタは
  同じ条件で敵だけに絞る——どちらも天体は対象にしない。ただし太陽を直接周回中でどの惑星系にも
  属さない対象は、フォーカスに関わらず常に含める。「ラグランジュ点」フィルタは全系のラグランジュ点
  だけに絞る。衛星フィルタを選ぶと各衛星の親惑星をクラスタ見出しとして自動で添える。クラスタ見出し
  行はフィルタを通っていない対象であることが見た目(淡色化)で分かるが、クリック・ダブルクリック・
  右クリックの挙動は通常行と変わらない。
- 検索語を入力する、またはクラスフィルタを選ぶと、絞り込みに一致した行を含む区画・クラスタ見出し・
  子リストはその瞬間だけ自動的に開く(一致行が畳みの中に隠れることはない)。この自動展開は絞り込みが
  変化したその回だけ働き、以後はプレイヤーが手で畳んでも毎フレーム開き直されない。検索語を消しクラス
  フィルタも解除して絞り込みが完全に無くなると、自動展開ぶんだけ元々の畳み状態へ戻る。
- フォーカスが切り替わった瞬間、そこへ至る経路(祖先の天体・衛星)を自動的に展開し、対象の行が
  一覧のスクロール領域内に見えるようスクロールする(既に見えていれば動かさない)。この自動展開は
  フォーカスが変化したその回だけ働き、以後はプレイヤーが手で畳んでも毎フレーム開き直されない
  (検索語・クラスフィルタの自動展開と同じ考え方)。
- 検索語・クラスフィルタのどちらか(または両方)により一覧全体の一致件数が0件になった場合、5区画の
  代わりに「該当する物体がありません」を一覧本体の位置に1つ表示する。
- 並び順は太陽系順(太陽(恒星)からの距離が近い順、同着は名前順、既定)・近さ順(自機からの
  距離が近い順、同着は名前順)・名前順から選べる。恒星の無いレジストリでは太陽系順は近さ順と
  同じ並びになる。
- 一覧の候補は「4. 表示するオブジェクトの選択」の可視性の規則に一致する対象に限られる(見えない
  ものは一覧にも出ない)。
- 行クリックは何もしない(選択状態は持たない)。ダブルクリックはその対象へマップ視点のフォーカスを
  移す(対象が自艦なら操作対象にもなる)。右クリックはその対象のプロパティウィンドウを開く(マップ上の
  マーカーを直接右クリックするのと同じ)。
- 行はキーボードからも到達でき、フォーカスのある行で F はダブルクリックと同じフォーカス移動を、
  T はその対象のナビ対象の設定/解除を行う。Enter / Space はその行の子リストを開閉する(子を持た
  ない行では何も起きない)。行の上でのこれらの打鍵は機体操作のキー割り当てへ渡らない。
- マップ上のマーカーは他のラベルとの表示衝突で隠れることがあり、隠れたマーカーはマップ上では
  ピックできない。一覧の行はこの衝突の影響を受けず、隠れている対象でも一覧からは操作できる
  (一覧は表示の重なりとは別の入口であるため)。

## 10. クリックとピック

- **ピックは「マーカー」と「本体」の2段で当てる。** まず対象のマーカーへ、画面上の一定の
  ピクセル半径で当てる。外れたら、**画面に描かれている本体**——天体の円盤、艦・基地の
  3Dモデル——へ視線を通し、最初に当たった対象を選ぶ。**本体を持たない対象**(近地点/遠地点・
  相対昇交点/降交点/再接近点・赤道交点・ラグランジュ点)はマーカー段だけで当たる。
  遠くて点にしか見えない対象はマーカー段で、拡大して画面を覆う対象は本体段で掴める。
- **単クリックは取り消せない操作をしない。** 操作艦の切替や基地パネルの展開は、明示的な項目
  (プロパティウィンドウの操作項目)かダブルクリックからのみ行える。
- **左クリック**: まず自艦または基地のマーカーに当たるかを調べる。当たれば、自艦なら
  プロパティウィンドウが開き、基地なら選択状態になる——このどちらの
  場合も、単クリックだけでは操作艦もビューも変わらない。当たらなければマニューバ計画のノード配置・
  選択に進む(既存ノードに近ければ選択、実線で描かれた自艦の予測軌道上ならそこにノードを仮配置、
  どちらにも当たらなければ選択を解除する)。
- **右クリック**: まず被選択物(天体ラベル・自艦・敵・基地・弾薬・近地点/遠地点アイコン・
  相対昇交点/降交点/再接近点・赤道交点アイコン)に画面上もっとも近いものを一定のピクセル半径内で探し、
  当たればその対象のプロパティウィンドウを開く。当たらなければマニューバ計画のノードハンドル(ドラッグ・
  削除メニュー)を探す。それも外れれば、画面に描かれている軌道線(公転軌道・船の軌道・軌道ガイド線)
  への当たり判定を最後の候補として試み、一定のピクセル距離内にもっとも近い軌道線があれば軌道の
  プロパティウィンドウを開く(11節)。それも外れれば空域として扱い、単純なコンテキストメニュー
  (「軌道物体ウィンドウを表示」「設定メニューを開く」、オブジェクトを配置できるステージでは
  「オブジェクトを配置」も)を開く。
- **ダブルクリック**: 選択可能な物すべて(天体・自艦・敵・基地・弾薬・近地点/遠地点・相対昇交点/降交点/
  再接近点アイコン)を対象に、マップ視点のフォーカスをその対象へ移す。対象が自艦なら同時に操作対象にもなる
  (操作艦を切り替える最速の手段)。
- 天体の裏に隠れているもの、表示トグルで消しているもの、フォーカス中の惑星系に属さないものは、
  その間クリック・右クリック・ダブルクリックいずれの対象にもならない。**線が見えていない区間に
  ノードを置ける、ということも起こらない。** この遮蔽判定はマップビュー限定で、戦闘ビューの
  表示・操作には影響しない。
- ラベルの混雑で名前が一時的に間引かれている対象は、その間**マーカー段では当たらない**。
  本体が描かれていれば本体段では当たる——円盤が画面に見えているのに掴めない、ということは
  起こらない。

## 11. プロパティウィンドウ

- 天体・自艦・敵・基地・弾薬・近地点/遠地点アイコン・相対昇交点/降交点/再接近点・赤道交点アイコンを
  右クリックすると開く。空域(何にも当たらない場所)の右クリックは開かず、単純なコンテキスト
  メニューになる。
- 内容はタイトル(名前)と、種別ごとに異なる状態行、および操作項目。装甲・距離・接近速度・高度・
  速度など主要な状態行は常に表示され、軌道要素(基準天体・遠地点・近地点・傾斜角・周期)・相対傾斜角・
  操作対象かどうか・計画追従などの副次的な行は末尾の「▸ 詳細を表示」の折り畳みにまとめられる。
  対象が存在しない値に依存する行はそもそも出さない(「—」表示にしない)。
- 種別ごとの状態行の例: 自艦(装甲・温度・電力・弾薬)、敵(距離・接近速度・相対速度・軌道要素・
  相対傾斜角)、基地(所持金・ドック中の艦数・距離・軌道要素)、弾薬(距離・軌道要素)、天体(表示名・
  種別・重力定数・半径・距離・軌道要素)、近地点/遠地点アイコン(高度・交差までの時間)、
  相対昇交点/降交点/再接近点アイコン(対象・交差までの時間)。
- 値も操作項目も毎フレーム最新化される。ヘッダをドラッグして好きな位置へ動かせる。
- クリップ(📌)の有無で閉じ方が変わる(共通の規約は UI-DESIGN.md)。非クリップはマップビューを
  離れるだけでも閉じ、クリップ済みは ✕ ボタン・対象の削除・対象の消滅・マップビューを離れる、の
  いずれかでのみ閉じる。
- 項目のキーボードショートカット(`[F]` フォーカス移動・`[T]` ターゲット・`[W]` 時間を加速・
  `[N]` ノードを追加・`[Esc]` キャンセルなど)は非クリップのウィンドウでのみ効く(高々1枚なので
  どのウィンドウ宛か曖昧にならない)。
- 1つの対象につきウィンドウは常に高々1枚。既に開いている対象を再度右クリックしても新規には開かず、
  そのウィンドウをクリック位置へ動かして最前面に出すだけ。撃破・回収・削除などで対象が消えると、
  開いていたウィンドウも自動的に閉じる(未来位置スライダーを先の時刻にした、タイムワープの上限を
  超えたなどで生存中の対象の位置が一時的に求まらないだけのフレームでは閉じない)。
- 操作項目は種別ごとに異なる。共通で「フォーカスを移動」。自艦・敵・天体は条件が揃えば「航法
  ターゲットに設定/解除」。近地点/遠地点・相対昇交点/降交点/再接近点・赤道交点アイコンは「ここにノードを
  追加」、相対昇交点/降交点/再接近点はさらに「ここへワープ」。自艦はドック対象の基地選択・軌道計画の実行
  モード切替(オブジェクトを配置できるステージのみ)・操作対象にする/解除・削除(操作中の自艦では
  出ない)。オブジェクトを配置できるステージ(CREATIVEなど)では自艦・敵・弾薬・基地に「複製」項目も
  追加される(複製が何を引き継ぐかは GAME.md)。
- 自艦・敵・基地には「軌道線の表示」トグルスイッチがある(5節)。ONで解析軌道楕円の代わりに
  予測線・過去線の組を表示する。操作対象の自艦には出ない(常に予測線・過去線側で固定のため)。
  状態は対象ごとに保存され、対象が消えるまで(セーブデータをまたいでも)保たれる。
- 自艦・基地はタイトル横の ✎ ボタンで改名できる(それ以外の種別には出ない)。押すとタイトルが入力欄
  になり、`[Enter]` または欄外クリックで確定、`[Escape]` で取り消す。空欄のまま確定した場合は
  変更しない。自艦の表示名は重複を許し、変更は自艦マーカーのラベルにも即座に反映される。
- 操作対象の自艦のプロパティウィンドウでは、搭載部品の一覧を状態行より上に表示する。部品行の
  右クリックで部品のプロパティウィンドウを開き、元の自艦ウィンドウは閉じない。部品ウィンドウには
  部品名・取り付け先の艦名・損耗度を表示し、展開可能な部品には「展開」「収納」ボタンを表示する。

### 11.1 軌道のプロパティウィンドウ

- 10節の当たり判定で軌道線(公転軌道・船の軌道・軌道ガイド線)を右クリックすると、その軌道の
  プロパティウィンドウが開く。タイトルは軌道の種類(公転軌道/船の軌道/軌道ガイド)。
- 状態行に「計算方法」(解析軌道/予測軌道/軌道ガイド)と「所属」を表示する。
  - 公転軌道・船の軌道の所属は1件(公転軌道はその軌道を周回している天体、船の軌道はその船自身)。
  - 軌道ガイドの所属はラグランジュ点・主星・副星の3件。
  - 所属欄の各項目は右クリックでその対象のプロパティウィンドウを新規に開く(元の軌道のプロパティ
    ウィンドウは閉じない。部品ウィンドウと同じ規則)。
- 操作項目は無い(フォーカス移動などの共通操作も持たない。軌道自体はフォーカスできる実体ではない
  ため)。
- 1つの軌道につきウィンドウは常に高々1枚(既存の対象と同じ規則)。軌道線自体が表示されなくなった
  場合(表示方式の切り替え・対象の消滅など)、開いていたウィンドウも自動的に閉じる。

## 12. スケールバー

- マップビュー中、カメラが現在フォーカスしている対象の深さにおける画面1ピクセルあたりの距離から、
  1/2/5 のいずれかの倍数に丸めた区切りの良い距離と、それに対応する画面上の長さを表示する
  (画面中央ではなくフォーカス深度を基準にするため、フォーカスが同じ天体のままズームせずにパンする
  限り、表示は変わらない)。
- ズームすればバーの示す距離・長さもそれに応じて伸び縮みする。太陽系規模までズームアウトすると
  Gm(ギガメートル)・Tm(テラメートル)単位で表示される。
