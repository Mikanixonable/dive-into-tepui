# MAP — マップビュー

マップビューの表示・選択・座標系の仕様。軌道計画そのものは [PLAN.md](PLAN.md)、画面に出る記号と
ラベルは [MARKERS.md](MARKERS.md)、右クリックで開くウィンドウは [UI-DESIGN.md](UI-DESIGN.md)。

**この文書は目指す振舞いを書いたもので、実装状況ではない。未実装の記述が混じっているのは正常。**

## マップビューへの切替

**ビューを切り替える条件そのものは GAME.md が持つ。** ここではマップ側の事情だけを定める。

- マップは地球中心の3D俯瞰ビューで、照準表示だけが戦闘ビュー専用である。それ以外の操作は
  マップを開いていても同じく効く。
- ESC メニューを開いている間はビューの切り替えを受け付けない。既に開いているマップを一時停止が
  強制的に閉じることはないので、マップを開いたまま一時停止→解除すると元の状態に戻る。
- ステージの勝敗が決着すると、マップは強制的に閉じられる。

## 座標系パネル

カメラが固定する座標系と、計画軌道の折れ線を描く座標系を、それぞれ独立に
「何に固定/追随するか(中心)」×「何の回転に合わせて回すか(回転)」の2段で選ぶパネル。
**カメラ(視点)** と **軌道計画(描画基準)** の2区画に分かれ、どちらも「基準」ゾーンと
回転ゾーン(カメラ側は「視点を一緒に回す」、計画側は「線を一緒に回す」)の2ゾーンを持つ。

**座標系そのものの定義**——中心に何を選べるか、公転・自転の基底をどう取るか、役割がどう解決
されるか——は [CELESTIAL.md](CELESTIAL.md)「座標系と参照フレーム」が持つ。ここではパネルが
何を選択肢として並べるかだけを定める。

- **基準ゾーン**(両区画)は中心の選択。天体とは限らない(機体も役割も選べる)ので、見出しは
  「基準」であって「基準天体」ではない。
  - 登録天体・自艦・敵・基地・弾薬まで含む全候補と **役割**(「操作対象の船」「ターゲット」)から、
    絞り込み入力つきのポップアップで選ぶ。
  - いまカメラがいる系(カメラ位置から最も強く重力を及ぼす天体を起点に、その祖先を主星まで
    遡った系列と、系列上の各天体の子をあわせたもの)だけに絞ったクイックボタンも持つ。
  - **カメラ区画**の中心ゾーンには「固定を解除」があり、選ぶと注視点はその瞬間のECI位置を
    **恒星中心の慣性系**(恒星の無いレジストリでは原点天体の慣性系)へそのまま焼き込んだ固定点になる
    ——元の天体を追いかけ続けるのをやめる操作で、たとえば地球を見ていた注視点を解除すると、その場に
    静止したまま地球の公転から取り残されて見える(地球からは相対的に離れていく)。
  - **軌道計画区画**の中心ゾーンには解除が無い——計画折れ線は常にどこかの座標系に焼き込んで描くしか
    なく、「どこにも固定しない」状態自体が無い。太陽系空間そのものへの固定は、プルダウンで恒星を
    選ぶことに当たる。
- **回転ゾーン**(両区画)は回転の選択。「解除」を選ぶと回転させない慣性系になる。
  - **カメラ区画**の選択肢は**フォーカス対象から導かれる**([CAMERA.md](CAMERA.md)
    「基準フレーム」)。
  - **計画区画**の選択肢は次の3種を並べたクイックボタン。
    - **公転** — いまカメラがいる系の各天体のうち恒星でないものを「〈主星〉-〈天体〉回転座標系」として。
      地球を回る低軌道からなら 地球-月回転座標系 / 太陽-地球回転座標系 の2つ。
    - **自転** — 同じ天体のうち自転モデルを持つものを「〈天体〉自転座標系」として。選ぶとその天体の
      地表の1点が画面上で静止する。低軌道からなら 地球自転座標系 / 月自転座標系 の2つ。
    - **役割の公転** — 「操作対象の船の公転」と「ターゲットの公転」(現れる条件は CELESTIAL.md)。
- 基準ゾーン(両区画)と計画区画の回転ゾーンの選択肢はカメラ位置から導かれるが、区切り方自体は
  天体の親子関係という離散的な単位である。カメラ区画の回転ゾーンはフォーカスから導かれる。
- **カメラの基準に追随**トグル(軌道計画区画)は、フォーカス移動が計画軌道の中心まで動かすかどうかの
  選択。既定は有効。無効にすると、視点をどこへ移しても計画折れ線の描画基準は動かない(見る場所を
  変えただけで線の形まで変わることを避けたいときの選択肢)。この連動は一方向で、計画側の中心を
  切り替えてもカメラのフォーカスが動くことはない。
- パネル末尾に、いま選ばれている2つの座標系を1行で述べるサマリを出す
  (例: 「カメラ: 地球・慣性系 / 計画: 地球・月回転系」)。4ゾーンが答えているのは別々の問いなので、
  合わせて何を選んでいるのかを読み直さずに把握できるようにする。
- カメラの座標系と計画軌道の座標系は独立に選べる。両方を回転系にすると回転系での軌道形状が静止して
  見え、カメラだけ慣性系にすると同じ形状が回転対象とともにゆっくり回って見える。
- **計画軌道の座標系に載るのは、折れ線だけではない。** ノード/バーン点マーカー・赤道交点・
  相対昇交点/降交点など、その軌道の上にある印はすべて同じ座標系に載る。
- **回転系を選んだとき、対象は厳密に静止して見えなければならない。** 公転回転系ではその天体が
  常に同じ方向に(離心率ぶんの遠近だけを残して)、自転回転系ではその天体の地表の1点が。
  地球-月回転系を選べば、低軌道からの月遷移軌道の形がそのまま読み取れる。

## 表示するオブジェクトの選択(可視性の規則)

マップに重ねる記号と線を、「表示」パネルの天体クラス別トグルと自艦・敵・弾薬・RCS燃料・基地の
種別トグルで選ぶ。ラベル(位置の点+名前表示)・軌道線を独立に ON/OFF できる。

**選択経路は、実体に重ねるマーカー/線と、画面に描かれた3D本体の2つである。** 表示トグルを閉じると
そのマーカーや線からは選べなくなるが、天体の球や艦艇・基地の3Dモデル自体が画面に描かれているなら、
本体からの選択は残る。3D本体の表示条件は RENDERING.md が持つ(「クリックとピック」)。

- 対象クラスは 惑星/衛星/準惑星/小天体/ラグランジュ点 の5行(恒星はトグルを持たず常時表示)と、
  自艦/敵/弾薬/RCS燃料/基地/軌道標識 の6行。
- 惑星・衛星・準惑星・小天体・自艦・敵・弾薬・RCS燃料・基地・軌道標識の各行は、ラベル・軌道線の2つを独立にON/OFFできる。
  既定はラベルが全クラス/全種別でON、軌道線は惑星・衛星・自艦・敵・弾薬・RCS燃料・基地・軌道標識はON(準惑星・小天体は
  OFF)。ラベルをOFFにすると位置の点(マーカー)ごと消える——「点だけ残して名前だけ消す」
  「名前だけ残して点を消す」という中間状態は無い。
- 衛星の軌道線トグルは、ON にしても即座に全衛星の軌道楕円が出るわけではなく、カメラ/フォーカスが
  その衛星の属する惑星系にあるときだけ実際に表示される——全衛星の軌道楕円を同時に描くと内惑星系が
  埋もれるため。
- ラグランジュ点の行はラベルのみを持つ(軌道という概念自体が無いため軌道線は無い)。
- **1つの対象クラスは、名前を書いた1つのチップで示す。** チップには押し所が2つあり、名前の部分が
  ラベル、右端の軌道の図が軌道線の ON/OFF である(軌道線を持たないラグランジュ点のチップは名前の
  部分だけ)。どちらも押した1回で狙った状態になり、状態を巡回させない。チップの見た目だけで、
  そのクラスのラベルと軌道線がそれぞれ出ているかが読める。操作の仕方を説明する文や、行の番号は置かない。
- チップは内容の幅で並べて折り返し、名前を途中で切らない。天体と機体・設備の2群に分けて並べる。
- **なぞって揃える**: チップの名前の部分を押したままほかのチップの名前の部分へなぞると、通った
  チップのラベルが最初に押したチップと同じ状態に揃う。軌道の図どうしをなぞれば軌道線だけが揃う。
- **常時表示される対象**: 恒星、いまカメラがいる系の天体、フォーカス中の天体の親・子・
  (同じ惑星系内の)兄弟は、ラベルトグルを介さず強制的に表示・選択可能になる。ただし、そのクラス
  自体のラベルがOFFになっている場合はこの例外の対象にならず、表示されない(トグルで丸ごと消した
  クラスを、常時表示の例外がよみがえらせることはない)。
- **操作中の自艦**は、自艦クラスのラベルをOFFにしていても位置の点は常に表示される(自分の位置を
  見失わないため、艦名だけは出ない)。軌道線は通常どおりトグルに従う。
- **どの系がラグランジュ点を持ち、そのうちどの点が出るか**は CELESTIAL.md が定める。マップは
  そこで出ると決まった点だけをラベルとして扱う。
- **未解放の天体**(GAME.md「天体の解放」)は、一覧・記号・ラベル・軌道線・選択のいずれにも現れない。3D の球は描かれるが、選べない。常時表示の例外も、未解放の天体には及ばない。
- ラグランジュ点は、その系の両方の天体が解放されているときだけ現れる。
- 「距離が近づいたら見える」といった連続量による表示切替は無い。表示・非表示は上記の離散的な規則
  だけで決まる。
- 「いまカメラがいる系」は、カメラ位置に対して最も強く重力を及ぼす天体から決まる。系が切り替わるのは、
  新しい系が明確に優勢になったときだけである。

## 表示パネル

マップビューでのみ表示される(戦闘ビューでは「表示」パネル自体が畳まれる)。パネルは
**対象 / ガイド / 軌道ガイド** の3つのタブに分かれる。表示されるのは
選んだタブの内容だけで、タブは常にどれか1つが選ばれている。

- **対象**タブ: マップに出す対象クラスの選択(「表示するオブジェクトの選択」)。
- **ガイド**タブ: 天球グリッド・空間グリッドとゼロ速度曲線。
- **軌道ガイド**タブ: 参照として描く軌道のガイド線。

### ガイドタブ(天球グリッド・空間グリッド)

- 黄道・赤道・月軌道・月赤道の4つを行、面/極/網/縮尺の4つを列とする1つの表にまとめる。
  月軌道・月赤道は面/極/網を持たず縮尺のみを持つ(該当セルはトグル自体を置かない空欄になる)。
- 黄道・赤道の行は、面/極/網の3列トグルと、それらをまとめる**行見出しトグル**を持つ
  (まとめトグルの規約は UI-DESIGN.md。縮尺列はこの行見出しの管理下に入らない独立トグル)。
- 月軌道・月赤道の行は縮尺列しか持たないため、行見出しトグル自体がその行の縮尺グリッドの
  ON/OFFを兼ねる。
- 面をONにすると、自機/カメラに追従する固定半径の殻として、その面の基準円・30°間隔の緯経線・
  両極マーカーが描かれる(極トグルは面と独立に極マーカーの表示可否だけを切り替える)。
  網(グリッド)をONにすると、同じ殻の上に緯経線の格子を重ねる。
- **目盛りはその面の標準的な天球座標そのもので、読んだ値がそのまま通用する。** 赤道面は赤経・赤緯、
  黄道面は黄経・黄緯を刻み、交点に添える `経度°/緯度°` のラベルはその方向の座標として読める
  (座標の定義は CELESTIAL.md)。
- 縮尺列は、自機/カメラの位置を通る縮尺グリッド(基準円は持たず、目盛りの交点だけを十字で示す
  平面)を面とは独立にON/OFFする。月軌道は月の軌道法線を、月赤道は月の自転軸(潮汐ロックして
  いても軌道面法線とは一致しない)をそれぞれ面の向きとして使い、時刻の経過とともに向きが
  追従する。黄道・赤道・月軌道・月赤道の4種は互いに独立した色で描かれ、同時に何枚でも重ねて
  表示できる。

### 軌道ガイドタブ

参照として描く軌道のガイド線を、軌道の種類ごとに選ぶ。種類は次の群に分かれ、**群は横並びの
タブとして切り替える**(常に1群だけを開く。複数群を同時に開いたままにはできない)。

| 群 | 含まれる種類 |
| --- | --- |
| 基本 | 静止軌道 / 太陽同期準回帰軌道 / ドーンダスク軌道 / モルニヤ軌道 / ツンドラ軌道 |
| 共線点 | 平面リヤプノフ軌道 / 垂直リヤプノフ軌道 / ハロー軌道(北・南)/ 軸方向軌道 / 蝶形軌道(北・南)/ トンボ形軌道(北・南)/ リサジュー軌道 |
| 三角点 | 短周期軌道 / 長周期軌道 / 垂直軌道 / 軸方向軌道 |
| 副天体周回 | 遠距離逆行軌道 / 遠距離順行軌道 / 低高度順行軌道(東・西) |
| 共鳴 | 1:2 / 2:1 / 3:1 / 2:3 / 4:3 / 3:4 共鳴軌道 |

画面に出す種類名は、日本語訳に英語を添えた形にする(例:「軸方向軌道(axial)」)——定訳の
無い語が多く、文献と照らし合わせられるようにするため。**共鳴の6種類だけは例外**で、見出しに
「共鳴軌道」を付けず比率(例:「1:2」)だけを表示する——比率どうしの見分けが本質で、6つ並ぶ
ボタンを素早く押し分けられることを優先する。

- 各種類の見出しはその種類の表示トグルを兼ね、それが表示可否の最終的なゲートになる。
- **表示がOFFの間、その種類の設定は現れない**(見出しの1行だけになる)。種類が数十あるため、
  出しているものだけを詳しく見せる。
- **系のトグルはタブ上部に1組だけ**持ち、すべての群に共通して効く(群ごとに個別選択は
  しない)。系は地球-月・太陽-地球・太陽-火星・木星-エウロパ・土星-タイタン・
  土星-エンケラドス・火星-フォボスの7つで、折りたたみは設けずすべて並べて出す。
  **「基本」群(静止軌道・太陽同期準回帰軌道・ドーンダスク軌道・モルニヤ軌道・ツンドラ軌道)は
  CR3BP の軌道ではないため系の軸を持たない。必要な物理量を持つ基準天体について同じ種類を定義できる。**

#### 小題(点/南北/東西/区間をまとめて選ぶ種類)

共線点のリヤプノフ・垂直・軸方向・ハロー、三角点の短周期・長周期・垂直・軸方向、副天体周回の
DPO・LPOは、ラグランジュ点・南北・東西・区間のうちその種類が持つ軸を、種類ごとに独立した見出し
ではなく、**軸1つずつのボタンにまとめた小題**として並べる。蝶形軌道・トンボ形軌道・共鳴軌道・
DROはこの対象外で、種類ごとに独立した見出しを持つ。

- 軸のボタンは表示ON/OFFの複数選択トグルで、**押した軸値すべての積を満たす族**が表示される
  (例: ハロー小題で「L1」「L2」「北」を押すと、ハロー L1 北・ハロー L2 北の2本が表示される)。
- **点・南北・東西の軸は、他の軸を1つでも押していれば、自分が空でも「その軸の全部」を対象に
  補って表示する**(例: ハロー小題で「L1」だけ押すと、北・南の両方が表示される。「北」だけ
  押すと、南北を持つ全ての点が表示される)。ただし全軸とも1つも押していなければ何も表示しない。
- **区間の軸だけはこの自動補完の対象にしない。** 区間は同じ点・向きでも物理的に別系統の族なので、
  区間を持つ小題(軸方向・DPO)では区間を明示的に押さない限り何も表示しない(他の軸を押しても
  区間は補われない)。
- 押した組み合わせが実在しない(例: 軸方向の L2 に区間2 を掛けたもの)ときは、その組み合わせ
  だけが静かに表示されない——他の組み合わせの表示や、ボタン自体の押下は妨げない。
- 「種類・小題ごとの表示設定」(次項)は小題1つにつき1組だけ持ち、押している組み合わせすべてに
  同じ設定が適用される(異なる組み合わせへ別々の色や本数を割り当てることはできない)。設定
  パネルは、組み合わせが1つも表示されていない間は隠れる。
- **1本に繋がらない族を区間ごとに分けた種類**(「ガイド線の正確さ」参照)のうち、小題に含まれる
  もの(軸方向・DPO)は区間も軸ボタンの1つとして扱う。小題に含まれない種類(蝶形・トンボ形・
  共鳴・DRO)は、元の種類のすぐ後ろに区間の番号順で並ぶ独立した見出しのまま、表示・色・族の
  範囲を区間ごとに独立して設定する。

#### 種類・小題ごとの表示設定

**族は1本ではなく、族として読める。** 族に沿った範囲と本数を選んで何本かを同時に描き、族内の
どこにいるかを色のグラデーションで示す。線の色・透明度は選び直せる。

- **複数本描くとき、線の間隔は画面上で均等に見えなければならない。** 族に沿った位置の値そのものが、
  焼き込み元データの並び順に対して均等である必要はない。
- **選んだ軌道の実際の値**(周期・ヤコビ定数・安定性指数)を、族の範囲の近くに読み取り専用で
  添える。族の位置という抽象的な指定が、どの軌道を指しているのかを読み取れるようにする。
- 進行方向を示すマーカーを重ねられる。頂点が進行方向を向いた小さな三角形で、その軌道と同じ色で
  描き、画面上の大きさはズームによらず一定に保つ。動かす場合は**実際の軌道速度に比例**して
  進み、近点で速く、遠点で遅い。
- 族のうち**線形安定な軌道**を見分けられるようにできる。族内の位置を示す色のグラデーションは
  保たれ、安定度は色とは別の見え方で重なる。
- **意味を持たない設定は現れない。** 1本だけ描いているときの族の上限側の色、族を持たない種類の
  族の範囲など。
- **リサジュー軌道だけは族の概念を持たない。** 面内振幅・面外振幅・それぞれの位相・周回数を
  指定する。閉じない軌道なので、指定した周回数ぶんの軌跡として描かれる。安定度も持たない
  (周期軌道ではないため)。
- 同時に描く線が多くなりすぎたときは、パネルにその旨を示す。**ただし指定した本数を勝手に
  減らすことはしない。**

#### 基本群の4種類(太陽同期準回帰軌道・ドーンダスク軌道・モルニヤ軌道・ツンドラ軌道)

いずれも CR3BP の族を持たない単一の基準天体周回軌道なので、本数・族の範囲・安定度を示す設定は
持たない(リサジュー軌道と同様)。色・透明度・進行方向・アニメーションは他の種類と共通に持つ。

- **太陽同期準回帰軌道**: 回帰日数(地表軌道が同じ経路を繰り返すまでの日数)と、その日数の間に
  周回する回数をそれぞれ整数のスライダーで指定する。円軌道とし、この2値から、地球の自転に対して
  指定どおりに地表軌道が回帰し、かつ昇交点が太陽と同じ向き・同じ角速度で歳差する(=軌道面と
  太陽の関係が季節を通して変わらない)高度・傾斜角を一意に求めて描く。指定の組み合わせによっては
  そのような軌道が存在しない(必要な傾斜角が実数解を持たない、解の高度が地表を下回るなど)ことが
  あり、そのときは軌道を描かず、パネルにその旨を示す。回帰日数・周回数のスライダーは、可動範囲
  自体は動かさないまま、もう一方の現在値に対して軌道が存在する範囲をトラックの色を変えて示す。
- **ドーンダスク軌道**: 太陽同期準回帰軌道と同じく回帰日数・周回数を指定する太陽同期軌道だが、
  昇交点の地方太陽時を朝(6時)・夕(18時)のどちらに置くかをあわせて選ぶ。地方時が異なると
  軌道面の向きが変わるだけで、高度・傾斜角の求め方は太陽同期準回帰軌道と同じ。
- **モルニヤ軌道**: 近地点高度と昇交点赤経をスライダーで指定する。傾斜角は近地点引数の摂動が
  止まる臨界値(63.4°)、近地点引数は遠地点が北半球高緯度に来る270°に固定し、周期は半恒星日
  (1日に2周)に固定する。離心率は周期・近地点高度から一意に決まる。
- **ツンドラ軌道**: モルニヤ軌道と同じパラメータ(近地点高度・昇交点赤経)・傾斜角・近地点引数を
  使うが、周期は1恒星日(1日に1周)に固定する。**近地点高度の既定はモルニヤ軌道と別に持つ**
  (24,000 km)——1恒星日の周期にモルニヤ軌道の低い近地点を当てると離心率が大きくなりすぎ、
  ツンドラ軌道の特徴である8の字の地表軌跡にならないため。

#### ガイド線の正確さ

- **ガイド線は近似でよい。** ただし次が正しく見えなければならない: 軌道は主星-副星回転座標系で閉じた線に見え、
  ハロー軌道の北側と南側は互いに鏡像で、族に沿って形が連続に変わる。**振幅を大きくしたときに、
  天体の近くを曲がらずに突き抜けるような、力学的に成り立たない形が出てはならない。**
- ガイド線はその瞬間の実際の天体位置・公転面から組み立てた回転座標系に載せて描かれ、
  慣性系のカメラからは天体の公転とともに回って見える。
- CR3BP は天体を質点として扱うため、周期軌道として数学的には成り立つが主星・副星いずれかの
  実際の半径より近点距離が小さい(=実際にはその天体に衝突する)メンバーが族に含まれることが
  ある。**そうしたメンバーは族から除外する。** 族は振幅について連続な列なので、除外は族の端から
  連続して行い、族の途中に穴を開けない。
- **1本の連続した列にならない族は、連続する区間ごとに別の種類として分ける。** 元データの族が
  互いに繋がらない枝に分かれていることがあり、また衝突するメンバーを除いた結果が族の途中で
  途切れることもある。どちらの場合も、**連続した区間のそれぞれを独立した種類として扱う** —
  1つの種類の中に飛びを残さない。**分けた結果生じた短すぎる断片**(軌道が数本しか取れない
  もの)は出さない。**分ける必要が無かった種類は、軌道が少なくてもそのまま出す** — 元から
  軌道が数本しか取れない種類はあり、それを断片と同じ扱いで消さない。
- **分けた種類の名前には区間の番号を添える**(例:「軸方向軌道(axial) L1 区間2」)。番号は
  族に沿った順に1から振る。**分ける必要が無かった種類の名前は変わらない** — 大半の種類は
  1本に繋がるので、番号は分かれたものにだけ付く。
- ガイド線はあくまで参照であり、その上に置いた艦が留まり続けることは保証しない(ORBIT.md)。

### ゼロ速度曲線(ガイドタブ)

ガイドタブに、指定したエネルギー水準(ヤコビ定数)で到達できる領域の境界を描く節を置く。

- **断面**は8つで、太陽-地球・地球-月・太陽-木星・太陽-土星の4系それぞれについて、両天体を含む面と
  それに垂直な面を取る。それぞれ独立にON/OFFできる。既定はすべてOFF。
- **表示方式**は「1本」と「多数」から選ぶ。1本は指定したヤコビ定数の曲線だけを、多数は
  指定した範囲を等分した値それぞれの曲線を描く。
- ヤコビ定数はスライダーと数値入力の両方で指定できる。**各ラグランジュ点の値へ一発で合わせる
  ボタン**を添える——ネックが開く瞬間を見るのがこの表示の主な使い道であるため。
- 断面の描画範囲は**その系のスケールに固定**する。
- 曲線だけを描き、到達できない側を塗ることはしない。

## 軌道線の表示

- 生存中の全敵の軌道は解析軌道楕円(グレー)で常時表示され、比較しやすい。戦闘ロック中のターゲットは
  第二アクセントカラーで個別に強調され、通常のグレー表示からは除外される。
- **操作艦の軌道線**は表示ビューによって描き方が変わる。
  - 戦闘ビュー: 現在の状態ベクトルから求めた解析軌道楕円として表示する(敵・基地の軌道楕円と同じ
    仕組みで、専用の色・不透明度を持つ)。
  - マップビュー: 数値積分で伸ばしている予測軌道のうち現在時刻から先を実線の折れ線として表示する
    (予測がどこまで伸び、どこで外挿され、どこで途切れるかは ORBIT.md「未来予測(予測軌道)」)。
  - 自機の軌道は常に1本の線で表示され、解析楕円と積分線が同時に並んで見えることはない。
- マップビューで自艦が複数存在するときは、**現在操作している艦だけ**が上記の予測線・過去線
  (アクセントカラー)で描かれる。操作対象でない自艦は、敵・基地と同じ解析軌道楕円(白)で表示される。
- 過去へ遡って描く軌跡(履歴)はどちらのビューでも変わらず、自機が既に通ってきた実軌道を積分の履歴
  からそのまま描く。
- 自艦・敵・基地は、プロパティウィンドウ(UI-DESIGN.md)から個体ごとに軌道線の表示方式を解析軌道楕円⇔
  予測線・過去線の組に切り替えられる。既定は操作対象の自艦以外すべて解析軌道楕円。切り替えて
  数値積分側を選んだ対象は操作対象の自艦と同じ規則で描かれるが、色は対象の既定色(敵は個体ごとの
  識別色、基地・自艦は既定色)を保つ。
- **軌道標識の軌道線**は、自艦・敵・基地とは別の色の細い実線で、解析的な楕円(ラグランジュ点
  まわりの標識は閉曲線)として描く。実体の線(艦・敵・基地)よりも細く、参照であることが
  見た目で分かる。標識の位相点の位置には専用の記号(⌾、MARKERS.md)が立つ。
- マニューバ計画に1つ以上ノードを置いている間は、これとは別に破線の計画軌道線が重ねて表示される
  (バーン前後で色分けされ、戦闘ビューでも見える)。詳細は [PLAN.md](PLAN.md) を参照。
- **航行指令を持つ艦の計画軌道**も、航行一覧で選んだ(または全部の)艦について破線で重ねられる
  — 操作対象の艦の計画でなくても、指令が書き込んだ計画は読める。

## 勢力の占有域

敵・味方がどの空域を占有しているかを、軌道線とは別の「域」として示す。域は占有の目安であって、
構成員個々の軌道線(形の比較)は従来どおり別に出る。

- **域の定義** — 勢力ごと・中心天体ごとに、その天体を周回する構成員の軌道の近点距離の最小〜
  遠点距離の最大を結んだ帯。閉じた軌道を持つ構成員だけを数え、どの天体にも捕まっていない
  (遷移・離脱中の)ものはどの域にも属さない。ターゲット中の敵も構成員に含む。
- **勢力の分け** — 敵は敵勢力として、自艦(操作対象・非操作対象を問わず)・基地・補給艇は
  味方勢力として数える。弾薬は含まない。
- **色** — 敵は暖色系・味方は寒色系の半透明で、既存の色分け(アクセント・signal・基地・
  敵の個体識別色)と重ならない色を使う。
- **見せ方** — 帯の実幅が画面上で読める縮尺では、中心天体の赤道面上の環(近点距離〜遠点距離)
  として実寸で示す。潰れて読めない縮尺では、天体を囲う記号的なリング(画面上の太さは実寸と
  無関係)として示す。2表現はズームに応じて連続的に切り替わる。
- **ラグランジュ点** — 点から一定距離(系の主星・副星間距離に対する比率)以内に構成員がいる
  勢力があるとき、その点の背後に勢力色の小さなパッドを出す。いなければ出ない。
- **表示条件** — 対応するクラスの軌道線表示が ON のときだけ出る(敵域は敵の軌道線トグル、
  味方域は自艦・基地の軌道線トグルに連動)。域自体の独立したトグルは持たない。

## 軌道標識

プレイヤーが配置する、質量も当たり判定も持たない**参照軌道**。運動モデル(時刻の関数としての
位置・速度の求め方)は ORBIT.md「軌道標識」が持ち、ここでは配置・表示・選択を定める。

- **構成**: 基準天体・軌道の形と向き・その上を進む1つの**位相点**を持つ。ラグランジュ点まわりの
  周期軌道(ハロー・NRHO・リヤプノフ・DRO など)を標識にすることもでき、その場合は基準天体の
  代わりに系(主星・副星)と族の1メンバーを持つ。
- **配置**: 空域の右クリック「軌道標識を配置」から物体配置パネル(GAME.md 9.1)のフォームで
  作る(軌道要素方式・ラグランジュ点方式・プリセット・入力の検証・配置プレビューは艦の配置と
  同じ)。艦・敵・基地・天体の公転線・軌道ガイド線の右クリック「この軌道から軌道標識を作る」
  からは、その瞬間の接触軌道要素またはガイドの族メンバーを写し、位相を対象の現在位相に揃えて
  作る。名前を付けられる(空欄なら既定名が自動で付く)。
- **表示**: 軌道線は上記「軌道線の表示」のとおり。位相点の位置に ⌾ の記号が立ち、ラベルには
  名前を表示する。
- **選択**: 軌道物体パネルの図・検索、またはマップ上の軌道線・位相点の右クリックで
  プロパティウィンドウが開く。操作項目は、ターゲットに設定/解除・ここへ向かわせる…・名前の
  変更・削除・フォーカスの移動。
- **ターゲット**: 軌道標識はターゲットに設定できる(射撃・照準補助の基準にはならない — 
  COMBAT.md「ターゲット指定」の航法基準のみの対象と同じ扱い)。標識がターゲットのあいだ、
  相対昇交点・降交点と再接近点(標識の位相点との最接近)が自艦の軌道上に立つ。
- **標識は実体ではない**: 物体どうしの接触・剛体接触・弾の衝突には参加せず、積分される
  物体でもない(位置は時刻の関数として決まる)。

## ターゲットと相対昇交点・降交点

**ターゲットが何であり、どう設定・解除するかは COMBAT.md が持つ。** ここではマップに現れる
ターゲット由来のマーカーが、どこに、どんな条件で立つかを定める(記号そのものは MARKERS.md)。

- 対象の軌道面が求まらない、または自艦の軌道面とほぼ一致する場合は、右クリックの
  「ターゲットに設定」項目自体が出ない。
- ターゲットを設定すると、自艦の軌道がターゲットの軌道面と交わる位置に相対昇交点(△)・
  降交点(▽)アイコンが立ち、毎フレーム自艦の現在軌道要素から再計算される。
- **自艦とターゲットが同じ中心天体を周回しているあいだ、両者の相対距離が今から1日先までの
  範囲で最初に極小になる位置に再接近点(✧)アイコンが立つ**。軌道面が求まらない・ほぼ一致する
  場合でも(相対昇交点・降交点とは独立に)表示される。まだ近づいている途中、または範囲内に
  極小が見つからない(既に最接近を過ぎた)場合は表示されない。
- これらのアイコンは右クリックのプロパティウィンドウから「ここへワープ」(自動タイムワープ開始)・
  「ここにノードを追加」ができる。

## 赤道交点マーカー

- 自艦・敵・基地など軌道を持つ対象は、その軌道が基準天体の赤道面を横切る点(昇交点△・降交点▽)を
  表示できる。基準天体に赤道モデルが無い場合(太陽・木星など)や、軌道面が赤道面にほぼ一致する場合は
  表示されない。
- 常時表示される対象: 生存中の全基地。
- 選択に応じて表示される対象: 操作中の自艦と、ターゲット(軌道を持つ対象であるとき)。
- **交点マーカーは、その対象について画面に出ている線に合わせて置く。** 交点そのものを探す先も、
  出ている線に合わせる。マニューバ計画の折れ線が出ている対象は、表示中の
  区間すべての折れ線が対象で、どの区間の中にある交点でも拾う。解析軌道楕円が出ている対象は楕円上の
  交点を使う。計画を出していない自艦も後者で、積分との差ぶん交点はおおよその位置になる。

## 軌道物体パネル

マップビューの右レールに常設し、「いまどこに何があり、どれを見るか」に答える。物体を行の一覧では
なく天体の系を図案化した図で示し、読まずに押すだけで視点を移せるようにする。

- マップビューである間は常設で、閉じる操作は無い(見出しの開閉ボタンで本文を畳めるだけ)。畳んで
  いる間も、接近中の敵がいることの注意(△)は見出しに残る。
- 載るのは「表示するオブジェクトの選択」の規則に一致する対象だけである。近地点/遠地点・
  相対昇交点/降交点/再接近点・赤道交点・空域はマーカーであって物体ではないので載らない。
- **路線図** — 主星と、主星を直接周回する惑星を、主星を起点とする1本の線の上の駅として等間隔に
  並べる。間隔は距離を表さない。恒星を持たない星系では、原点の天体とそれを直接周回する天体を同じ
  形で並べる。準惑星・小天体は駅にせず、主星の系の軌道図に載る。
  - 主星から、いま軌道図に出している系の駅までの区間が強調され、どの系を見ているかの経路として読める。
  - 各駅には、その系(衛星の系を含む)にいる艦の数を添える。接近中の敵がいる系には注意の記号(△)を添える。
- **軌道図** — 1つの系を、中心天体と同心円で図案化して示す。
  - **出す系はフォーカスに追従する。** フォーカス対象を周回する物体があればその対象の系、なければ
    フォーカス対象が周回している天体の系。フォーカスが無いときは主星の系。
  - 系に載るのは、中心天体を主天体とする天体と、中心天体から最も強く重力を受ける天体以外の物体
    (艦・基地・弾薬・RCS燃料・軌道標識・ラグランジュ点)である。
  - **円の大きさは中心からの距離の順を保つが、縮尺は持たない。** 外側ほど遠く、同じくらいの距離の
    ものは同じ円に載る。距離の比は読めない。
  - 物体は、中心天体から見た方向を黄道の北から見下ろした角度の位置に置く。時間が進めば図の上でも回る。
  - 記号はマップと同じ体系(MARKERS.md「記号の体系」)で、色は HUD の意味の割り当て(UI-DESIGN.md)に従う。
    フォーカス対象は自分の色の輪で囲む。接近中の敵には注意の記号と距離を添える。
  - **図の上で重なり合う物体は「記号 ×件数」の1つの束にまとめる。** 束を押すと、中身が札に並び、
    そこから1つを選べる。名前が重なるときは、フォーカス対象・操作対象・ターゲット・天体の名前を残して
    他を間引く。
  - 図に出す種類(天体・艦・補給・標識・ラグランジュ点)を選べる。マップの表示の選択とは独立で、
    図の見え方だけを変える。
- **札** — 図の下に、いまのフォーカス対象の記号・名前・系の経路・状態の1行と、その対象にできる操作
  (ターゲットの設定/解除、プロパティウィンドウを開く、操作対象でない自艦なら操作対象にする)を置く。
  航行一覧(UI-DESIGN.md)への入口もここに持つ。
- **操作** — 駅・図の物体・札に並んだ束の中身のどれを押しても、その対象へマップ視点のフォーカスを
  移す。長押し・右クリックはその対象のプロパティウィンドウを開く(マップ上のマーカーの右クリックと
  同じ)。**押しただけでは操作対象は切り替わらない**(「クリックとピック」)— 切り替えは札の操作か
  ダブルクリックで行う。
- **検索** — 見出しの検索ボタンで、図の代わりに検索欄と、一致した物体の一覧を出す。名前・補助表示
  文字列に部分一致する。行を押すとフォーカスを移して図へ戻る。**束・種類の選択・表示の重なりで図や
  マップに出ていない対象も、ここからは操作できる。**
- キーボードでも、駅・図の物体・束・検索の行を辿れる。当たっている対象で F はフォーカスの移動、
  T はターゲットの設定/解除で、これらの打鍵は機体操作のキー割り当てへ渡らない。当たっている対象は、
  マップ視点のフォーカスとは別の見え方で示す。
- 図に載る物体が無いときは、中心天体だけを描き、その系に何もいないと読めるようにする。検索で一致が
  0 件のときは「該当する物体がありません」を出す。

## クリックとピック

- **ピックは「マーカー」と「本体」の2段で当てる。** まず対象のマーカーへ、画面上の一定の
  ピクセル半径で当てる。外れたら、**画面に描かれている本体**——天体の円盤、艦・基地の
  3Dモデル——へ視線を通し、最初に当たった対象を選ぶ。**本体を持たない対象**(近地点/遠地点・
  相対昇交点/降交点/再接近点・赤道交点・ラグランジュ点)はマーカー段だけで当たる。
  遠くて点にしか見えない対象はマーカー段で、拡大して画面を覆う対象は本体段で掴める。
- **単クリックは取り消せない操作をしない。** 操作艦の切替は、明示的な項目(プロパティウィンドウの
  操作項目)かダブルクリックからのみ行える。
- **左クリック**: まず自艦のマーカーに当たるかを調べる。当たればプロパティウィンドウが開く——
  単クリックだけでは操作艦もビューも変わらない。当たらなければマニューバ計画のノード配置・
  選択に進む(既存ノードに近ければ選択、実線で描かれた自艦の予測軌道上ならそこにノードを仮配置、
  どちらにも当たらなければ選択を解除する)。
- **右クリック**: まず被選択物(天体ラベル・自艦・敵・基地・弾薬・軌道標識の位相点・近地点/遠地点アイコン・
  相対昇交点/降交点/再接近点・赤道交点アイコン)に画面上もっとも近いものを一定のピクセル半径内で探し、
  当たればその対象のプロパティウィンドウを開く。当たらなければマニューバ計画のノードハンドル(ドラッグ・
  削除メニュー)を探す。それも外れれば、画面に描かれている軌道線(公転軌道・船の軌道・軌道ガイド線・
  軌道標識の軌道線)
  への当たり判定を最後の候補として試み、一定のピクセル距離内にもっとも近い軌道線があれば軌道の
  プロパティウィンドウ(UI-DESIGN.md)を開く。それも外れれば空域として扱い、単純なコンテキストメニュー
  (「軌道物体パネルを表示」「設定メニューを開く」、オブジェクトを配置できるステージでは
  「オブジェクトを配置」「軌道標識を配置」も)を開く。
- **ダブルクリック**: 選択可能な物すべて(天体・自艦・敵・基地・弾薬・近地点/遠地点・相対昇交点/降交点/
  再接近点アイコン)を対象に、マップ視点のフォーカスをその対象へ移す。対象が自艦なら同時に操作対象にもなる
  (操作艦を切り替える最速の手段)。
- 天体の裏に隠れているもの、フォーカス中の惑星系に属さないものは、その間クリック・右クリック・
  ダブルクリックいずれの対象にもならない。**線が見えていない区間にノードを置ける、ということも
  起こらない。** この遮蔽判定はマップビュー限定で、戦闘ビューの表示・操作には影響しない。
- **マーカーが出ていない対象は、その間マーカー段では当たらない。** 表示トグルで記号を消している
  対象も、ラベルの混雑で名前が一時的に間引かれている対象も同じ扱いで、どちらも本体が描かれて
  いれば本体段では当たる——未解放の天体を除き、円盤が画面に見えているのに掴めない、ということは起こらない。

## スケールバー

- マップビュー中、カメラが現在フォーカスしている対象の深さにおける画面1ピクセルあたりの距離から、
  1/2/5 のいずれかの倍数に丸めた区切りの良い距離と、それに対応する画面上の長さを表示する
  (画面中央ではなくフォーカス深度を基準にするため、フォーカスが同じ天体のままズームせずにパンする
  限り、表示は変わらない)。
- ズームすればバーの示す距離・長さもそれに応じて伸び縮みする。太陽系規模までズームアウトすると
  Gm(ギガメートル)・Tm(テラメートル)単位で表示される。

## 未確定の案

**決定事項ではない。** 「どの拡張性を残すべきか」を判断するための材料。

- 不変多様体(安定・不安定マニフォールド)とポアンカレ断面の表示。軌道ガイドから軌道要素を
  読めるようにすること。
- 軌道上の目盛の時刻を、絶対時刻と現在からの相対時刻で切り替えられるようにすること。
- 既に通過した軌道を、指定した時間範囲だけ遡って表示すること。
- 敵の集団の平均的な軌道を、個々の軌道より薄く太い1本として表示すること。
