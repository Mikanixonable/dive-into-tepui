# SAVE — セーブとスナップショット

セーブデータについての仕様。

## 全体構造

セーブは3階層で構成される: **セーブデータ(歴史線)⊃ ステージ履歴 ⊃ スナップショット**。

- セーブデータ: プレイヤーが作成する歴史線の単位(いわゆるセーブスロット)。名前を持ち、複数
  作成できる。
- ステージ履歴: 1つのセーブデータの中で、あるステージを遊んだ記録のまとまり。
- スナップショット: ある瞬間のゲーム状態そのものの記録。手動でクリップしたものと、自動保存された
  ものの2種類がある。

## スナップショットの記録

- **手動クリップ**([F5]): 現在の瞬間を、名前を付けた手動スナップショットとして記録する。クリップ
  したスナップショットは自動では消えない。
- **自動保存**: 実時間で60秒ごとに、直前の瞬間を無名のスナップショットとして自動的に記録する。
  時間加速の倍率によって早まったり遅くなったりしない。
- 自動保存されたスナップショットは自動で消えていく対象で、同じステージ履歴の中で古いものから順に
  破棄される(同じステージ履歴の中で最大12件まで保持)。
- クリップしたスナップショットは自動で消えることはない。ただし記録できる件数には上限があり(同じ
  ステージ履歴の中で最大30件)、上限を超えてクリップしようとすると拒否される(何かを自動的に消して
  空きを作ることはしない)。
- ステージの勝敗が確定したあとは、手動クリップも自動保存も行えない(拒否のヒントが表示され、何も
  記録されない)。決着後の状態を保存してしまうと、結果画面へ二度と辿り着けない中途半端な状態を
  残してしまうため。

## 読み込み

- セーブデータ/スナップショット画面でスナップショットのカードをダブルクリックすると読み込まれる
  (専用の読み込みボタンはない)。
- 読み込めるのは、いま画面に表示しているセーブデータが、現在実際にプレイしているものと同じ場合
  だけ。別の歴史線のスナップショットはその場では読み込めない。
- 読み込みは、いま進行中のゲームをいったん終了し、読み込んだ状態から新しく作り直す形で行われる
  (画面の再読み込みはしない)。
- 読み込むと、そのスナップショットより後の時点に記録されていた、クリップされていない(自動保存の)
  スナップショットは破棄される。クリップ済みのスナップショットは、読み込んだ時点より後であっても
  消えない。
- 保存されている天文暦の元期・精度・データが現在のものと一致しないスナップショットは読み込めない。
  壊れている、または対応しない形式のスナップショットも読み込めない。

## 保存される内容

- 自艦・敵機の状態(位置・速度・姿勢・耐久・搭載部品・弾薬など)と、いまどの艦を操作しているか。
- 基地の状態(所持金・保管庫・ドックしている艦)。
- ステージの進行状況(経過時間や撃墜数などの記録、勝敗が確定しているかどうか)。
- カメラの視点と、直前に選んでいた画面(戦闘ビュー/マップビュー/ドック)。
- 地球の自転の位相、天体暦の初期位相 — いずれもゲーム開始時に一度だけランダムに決まる値。
- 勝敗確定後に表示される結果画面そのものの内容は保存されない。読み込んだ際は、保存されている勝敗の
  記録から簡易的に組み立て直される。

## セーブデータの操作

- 改名・削除ができる。
- **複製**: 既存のセーブデータを丸ごと複製し、新しいセーブデータを作る。
- **「ここから分岐」**: あるスナップショットの時点でセーブデータを複製し、新しいセーブデータを作る。
  分岐元のうち、その時点より後の記録は複製先に持ち込まれない。
- **書き出し・読み込み**: セーブデータをファイルへ書き出せる。書き出したファイルは、別の環境からでも
  読み込める。読み込んだファイルは常に新しいセーブデータとして追加され、既存のセーブデータを上書き
  することはない。ファイルに含まれるスナップショットのうち壊れているものは個別に除外され、それだけ
  で読み込み全体が失敗することはない。セーブデータと無関係な形式のファイルは、壊れたセーブデータ
  としてではなく「セーブファイルではない」ものとして拒否される。

## 画面と操作

- [F9]: セーブデータ/スナップショット画面を開閉する。[Esc] メニューの「スナップショット」項目からも
  同じ画面を開ける。
- 画面が開いている間、ゲームは一時停止する。
- 設定メニュー([Esc] で開くメニュー)とは同時に開けない。片方を開くと、開いていたもう片方は閉じる。
- 画面を開いている間は、[Esc] でも閉じられる。
- 画面は左右2ペイン: 左はセーブデータの一覧(名前変更・複製・書き出し・削除・切り替え)、右はいま
  見ているセーブデータのスナップショット一覧で、「クリップ済み」と「自動」の区画に分かれて並ぶ。
