# MARKERS — 画面の印

画面に重ねる記号とラベル、そして混み合ったときの捌き方。**戦闘ビューとマップビューに共通する。**
どの印がいつ立つかは、その印を持つ分野が定める(軌道上の交点は [MAP.md](MAP.md)、計画のノードと
近地点/遠地点は [PLAN.md](PLAN.md))。何色で描くかは [UI-DESIGN.md](UI-DESIGN.md)「全体のトーン」。

**この文書は目指す振舞いを書いたもので、実装状況ではない。未実装の記述が混じっているのは正常。**

## 記号の体系

画面に出る記号は、読み手が最初に判断する「それは物か、向きか、軌道上の点か、狙いか」に対応して
4つの族に分かれる。

- **塗りつぶし = 実体**: 艦・基地 ▲ / 天体 ● / 弾薬 ▣ / 計画上の自機ゴースト ⬢ / 配置プレビュー ▷。
  天体のうち恒星は二重丸 ⊚、衛星は中抜きの丸 ○ で他の分類と見分けられるようにし、
  惑星・準惑星・小天体は共通の ● のままにする。
- **矢 = 方向**: プログレード ⊙・レトログレード ⊗、ノーマル ⇧・アンチノーマル ⇩、
  ラジアルアウト ◎・ラジアルイン ◉、ターゲット ⇨・反ターゲット ⇦、画面外の対象を指す方位矢印 ↑、
  天球グリッドの極 ⇕。
- **中空 = 軌道上の点**: 近地点/遠地点 ◇ / 昇交点 △・降交点 ▽ / 再接近点 ✧ / マニューバノード ◈ /
  バーン点 ⬡ / 衝突点 ✕。
- **十字 = 狙い**: 偏差射撃の照準点 ✛ / 標的面の通過点 ✦。物でも向きでも軌道上の点でもなく、
  いま撃てばどこへ行くかを指す。

船が同時に操作対象かつターゲットであることはあり得るが、その場合はターゲットの色を優先する。

UIの縦方向の折りたたみ矢印(▾ = 開いている / ▸ = 閉じている)は上記のいずれの族とも重ねない
(折りたたみと方向マーカーが読み違えられないようにするため)。

## 天体ラベル

- 登録天体それぞれに1つの位置ラベルが付き、力学的に意味を持つラグランジュ点(MAP.md
  「表示するオブジェクトの選択」)にはさらに専用のラベルが付く。ラグランジュ点のラベルは「L1」を
  「地球」の上に2段で表示するなど、点自体を主役に、天体名を補足として示す。
- 画面上でラベルが密集した場合、優先度(惑星/恒星 > 準惑星 > 衛星/小天体 > ラグランジュ点)に従って
  近接するラベルの名前を間引く。名前の間引きが起きる近接度と、位置の点(マーカー)自体が間引かれる
  近接度は別の閾値であり、点の間引きは名前よりも顕著に近接した場合にのみ起こる(名前だけが消えて
  点は残る距離帯が存在する)。ただしカメラからの距離が著しく離れている対象同士が重なった場合は、
  優先度に関わらずカメラから遠い側を間引く(手前の対象が奥の対象の陰に隠れて見えなくなることを
  防ぐ)。この遠い側を間引く判定も、名前用と点用でそれぞれ独立した近接度で働く(点は名前より近接
  しないと間引かれない)。
  この「カメラからの距離が著しく離れている対象同士は遠い側を間引く」規則は天体ラベル同士に限らず、
  自艦・敵・基地・ターゲット・ノード類など画面上で近接するマーカー全般に働く——手前の
  低優先度マーカーが、奥にあるだけの高優先度マーカー(天体ラベルを含む)に隠され続けることはない。

## 機体のマーカー

自艦・敵・基地・弾薬(補給ピックアップ)のマーカーは、両ビューに常設される。

- **向き**: マップビューでは進行方向(ECI速度の投影)へ回転する(円軌道は静止画からでは回転方向が
  読み取れないための対策)。速度が視線方向とほぼ平行で投影上の向きが定まらない場合は回転させず、
  直前の向きを保持する。戦闘ビューでは機体メッシュ自体が姿勢を示すため、マーカーは回転しない。
- **残HP**: 自艦・敵マーカーは、マップビューでは鏃形内部の塗り高さで、戦闘ビューでは辺の切り欠きで
  示す——マップビューでは進行方向へ回るので、輪郭の刻みでは読み取れない。基地・弾薬にHPの概念は
  無く、塗り高さ表示も無い。
- **名前**: **自艦の艦名ラベルは1隻につき1つだけ出る**。複数隻を操作できるステージでは、操作対象の
  艦は自艦マーカー側に、それ以外の自艦は既定色のマーカー側にだけ艦名が付く。艦名ラベルには距離
  などの副情報を添えない。
- **距離**: 戦闘ビューでは自機からの距離を併記する。マップビューで併記するかは対象による——
  弾薬には添えない(軌道上の位置で見つけるもので、縮んでいく数字を追いかけるものではないため)、
  基地には添える。
- **画面外**: 戦闘ビューでは、画面外に出た対象を画面端の円周上の方位矢印 ↑ に置き換えて方位を示す。
  マップビューは俯瞰なので置き換えを行わない。
- 未来位置スライダーがその対象の予測が届いていない時刻を指している間は非表示になる(PLAN.md)。

### 近接時のまとめ表示

- 自艦・敵・基地・弾薬のマーカーは、画面上で一定距離より近接した2隻以上を1つの代表マーカーへ
  まとめる。まとめる/まとめないの判断は対象の種別・操作対象かどうか・ターゲットかどうかに関わらず、
  画面上の近さだけで決まる——操作対象の艦、ターゲットの船も他の船と同様にまとめの対象になる。
- 2隻が近接した場合、代表マーカーの下に両者の正式名称を2行で表示する。各行は該当する船自身の色で
  表示され、代表側の色に統一されることはない。
- 3隻以上が近接した場合は正式名称を省略し、"×N" の件数表示にまとめる。
- まとめられて代表に吸収された側のラベルは消えるが、マーカー本体(アイコン)は消えず、各自の色で
  その場に残り続ける。
- 代表の選出は優先度(ターゲット > 基地 > 自艦 > 敵)で決まる——操作対象かどうかはこの優先度に
  影響しない。

### 天体ラベル下の省略表示

- 天体のラベルに画面上で近接した船(操作対象の艦・僚艦・敵・基地・弾薬すべてを含む)は、
  個別のラベルの代わりに、所属する天体のラベル直下へサブ行としてまとめて表示される。所属天体は
  各船に最も強く重力を及ぼす天体で、その天体自身にラベルが出ていなければ、ラベルの出ている
  親天体へ繰り上げる。この折りたたみ自体も「天体ラベル」の「遠い側を間引く」規則に従い、船がカメラに
  著しく近く天体が著しく遠い場合は折りたたまず、船自身のラベルを残す。
- カメラから所属天体までの距離が 500万 km 未満の間は、優先度順に最大3隻まで「グリフ 正式名称」を
  1行ずつ縦に並べ、4隻目以降は「+N 隻」の1行にまとめる。繰り上げが起きた船の行には、元の所属天体名
  (例:「月: 」)を接頭辞として添える。
- カメラから所属天体までの距離が 500万 km 以上になると、正式名称を出さず、種別ごとの記号と隻数
  だけの1行に切り替わる。同じ天体の衛星系に属する船もまとめて数える。
- このサブ行は天体ラベルと同じ控えめな単色(目立たない灰色)で表示され、操作対象・ターゲットの
  強調色は適用されない。

## 狙いの印(戦闘ビュー)

**いずれもマップビュー中、および自機が失われている間は表示されない。**

- **LEAD マーカー(✛)**: 自機と敵の双方の位置・速度から求まる偏差射撃の照準点に表示される。
  対象のロックが外れたり画面外へ出たりした直後もしばらく表示され続けてから消える。
- **標的面通過マーカー(✦)**: ターゲット位置に、自機の方を向いた仮想的な標的板があるとみなし、
  発射した弾がその面を自機側から通過した点を検出して表示する。判定はターゲットの軌道面とではなく、
  視線方向を法線とする平面との交差で行う。通過点はターゲットに追従する光点として描画される。
  ターゲットの中心から半径 4,000 m を超える通過は無視する。表示は 2.5 秒でフェードアウトする。
- **タンパク質敵の機能部位マーカー**: タンパク質型の敵が自機から 3 km 以内にあるとき、通常の敵
  マーカーに加えて、各機能部位ごとの HP と名称(PROTEIN.md)を示すマーカーを表示する。3 km を
  超えると通常の敵マーカーだけに戻る。ロックオン中のターゲット情報とは独立して表示され、ロックの
  有無に関わらず 3 km 以内であれば両方同時に出てよい。
