# CONTROLS — 操作

キーボード・マウス・タッチの割り当てと、視点操作(カメラ)の挙動をまとめる。

## キー割り当て

### 並進

並進は**機体座標系**に基づく(軌道座標系ではない)。艦首方向が常に基準になるので、同じキーでも
艦の姿勢を変えれば実際に加速する向きは変わる。

| キー | 機能 | 有効なビュー・条件 |
| --- | --- | --- |
| W | 艦首前方向へ噴射 | 戦闘ビュー・マップビュー(マニューバノード未選択時) |
| S | 艦尾後方向へ噴射 | 同上 |
| A | 横方向(片側)へ噴射 | 同上 |
| D | 横方向(逆側)へ噴射 | 同上 |
| Q | 上方向へ噴射 | 同上 |
| E | 下方向へ噴射 | 同上 |
| [1] | エンジン出力を第1段階(5.0 m/s²)に設定 | 常時 |
| [2] | 第2段階(20.0 m/s²)に設定 | 常時 |
| [3] | 第3段階(100.0 m/s²)に設定 | 常時 |
| [4] | 第4段階(400.0 m/s²、第3段階の4倍)に設定 | 常時 |

並進6キーは出力段階の選択とは独立で、キーを押している(またはラッチしている)間だけ噴射が生じる。
出力段階を選ぶだけでは何も起きない。マップビューでマニューバノードを選択している間は、この6キーは
実機の並進ではなくΔv編集(プログレード・ノーマル・ラジアル基準)に奪われる(「キー入力の優先順位」参照)。

### 回転

| キー | 機能 | 有効なビュー・条件 |
| --- | --- | --- |
| I / K | ピッチ(機首上げ / 下げ) | 常時(自機がある場合) |
| J / L | ヨー | 同上 |
| U / O | ロール | 同上 |
| T | RCS 回転制動の ON/OFF 切替 | 同上 |
| V | 微調整姿勢制御の ON/OFF 切替(詳細は後述) | 同上 |
| F | プログレード姿勢を単発でリセット(ホールドを ON にするだけの一発操作) | 同上 |
| C | プログレードホールド・オートパイロットの ON/OFF 切替 | 同上 |

角速度に上限はなく、回転キーを押し続ける限り加速し続ける。姿勢制御ノズルは機首側4隅に2基ずつ
計8基あり、いずれも艦の外向きに固定されている。実際に噴射して見えるのは、そのノズルが生む
トルクが指令トルクと同じ向きを持つものだけなので、どのキーを押しても複数基が同時に噴くが、
押しているキーと噴いているノズルの対応は常に一致する。プログレードホールド(C)は自機の速度方向へ
機首を向け続ける自動操縦で、手動の回転キーを押すと自動的に解除される。

回転キーを握り続けたときの RCS 角加速度の立ち上がり(最小出力から数秒かけて増加するランプ)は
実時間で進む — タイムワープを上げてもランプが早く終わることはない。逆に燃料消費はシミュレーション
時間で進むため、Δv あたりの燃料消費はワープ倍率によらず一定になる(手動並進・RCS・軌道計画の
自動操縦のいずれも同じ)。

### カメラ

| キー・操作 | 機能 | 有効なビュー・条件 |
| --- | --- | --- |
| 左ドラッグ / 右ドラッグ / 矢印キー | ヨー・ピッチ | 戦闘ビュー・マップビュー |
| テンキー[0]/[1](代替キー: `/`・`_`)、または2本指ひねりジェスチャ | ロール(視線軸まわり) | 同上 |
| ホイール / 2本指ピンチ | ズーム距離 | 同上 |
| 中ドラッグ、または `@`/`:`/`;`/`]`(上/下/左/右)、または2本指ドラッグ | パン | 同上 |
| [Z](長押し) | ガンサイトズーム(視野角 55°→6°) | 戦闘ビューのみ |
| G | 追従カメラの基準系(艦の姿勢 / 慣性系)を切替 | 戦闘ビューのみ(マップビューでは読まれない) |

上段の数字キー[9]/[0](ラジエーター展開・収納、後述)とテンキーの[0]/[1](カメラロール)は別の
物理キーであり、機能も無関係。

### ゲーム進行

| キー | 機能 | 有効なビュー・条件 |
| --- | --- | --- |
| [Space] | 機関砲を発射(連射開始時に起動遅延、連射間隔あり) | 常時(弾切れなら不発) |
| [,] | タイムワープを1段減速 | 常時(×1〜×131072) |
| [.] | タイムワープを1段増速 | 同上 |
| [9] | 片側ラジエーターの展開・収納を切替 | 常時 |
| [0] | 逆側ラジエーターの展開・収納を切替 | 常時 |
| M | マップビューと戦闘ビューを切替 | 自機がなければ戦闘ビューへは戻れない(ヒント表示で拒否) |
| N | 選択中の次のマニューバノードへ自動ワープ | マップビュー、ノードがある場合 |
| X | 選択中のノードを削除(未選択なら計画全体を破棄) | マップビュー |
| R | 手動装填 / (勝敗決着後は)同じステージを再出撃 | 常時 |

推進・射撃・敵の射撃・剛体接触は、タイムワープが×4を超えると働かなくなる(操作できない倍率へ
上げたときは、その旨をタイムワープ表示のヒントに併記する)。高いワープでは軌道積分の刻みも粗くなり、
最高ワープの地球低軌道では1周を最大54歩まで粗くするが、そのときの数値的な軌道減衰は同高度の大気抵抗が
削る量の3%にとどまり、艦が焼失する時期は変わらない。高度200 km以下、またはそこへ降下中の再突入域では、
この粗さの上限より細分化が優先される。

勝敗が決まった後も、結果画面の裏で自機の並進・回転・射撃・RCS噴射は制限なく働き続ける(止まるのは
自機を喪失した場合のみ)。敵の行動・補給・タイマーも通常どおり進み、勝敗の再確定だけが起きない。

### ウィンドウ

| キー | 機能 | 有効なビュー・条件 |
| --- | --- | --- |
| H | ヘルプパネルの開閉 | 常時 |
| Esc(または⚙アイコン) | 開いているオーバーレイのうち最前面のものを1つ閉じる。何も開いていなければ一時停止メニューを開く | 常時 |
| F3 | 負荷確認ウィンドウの開閉 | 常時(非モーダル、ゲームは停止しない) |
| F5 | 現在の瞬間を名前付きスナップショットとして保存 | 勝敗決着後は拒否(ヒント表示、保存されない) |
| F9 | スナップショットブラウザの開閉 | 常時 |

一時停止中(一時停止メニューが開いている間)はシミュレーションが完全に停止する。セーブブラウザと
一時停止メニューは同時に開けない(片方を開くともう片方は自動的に閉じる)。負荷確認ウィンドウ(F3)は
非モーダルで、開いていてもゲームの進行にも一時停止の排他関係にも影響しない。

## マウス操作

マウスの左右ボタンは素直な既定と入れ替わっている。左右どちらのボタンでも、押したまま動かした距離が
6 px 未満ならドラッグではなくクリックとして扱われる。

- **左ボタン**: ドラッグでカメラのヨー・ピッチを操作する。6 px 未満の動きはクリックとして扱われ、
  マップビューでは自艦または基地に当たればそれを選択する(自艦ならプロパティウィンドウを開く、
  基地はドック候補として選ばれる)。それ以外は、軌道上のマニューバノードの配置・選択に使われる。
  単独のクリックでは、操作対象の切替やドックへの進入のような取り消しにくい操作は起きない —
  それらはプロパティウィンドウの項目か、後述のダブルクリックからのみ到達する。
- **右ボタン**: 左ボタンと同じ働きでカメラをドラッグできる(トラックパッドの2本指ドラッグに相当し、
  右クリックには自然な等価操作がないため)。6 px 未満の動きはクリックとして扱われ、対象・
  コンテキストメニューを開く。戦闘ビューで敵機や自艦(他機)に当たればプロパティウィンドウが開き
  ターゲット設定の項目を持つ。マップビューで天体ラベル・生存艦・基地・弾薬補給・近地点/遠地点
  アイコン・相対昇交点/降交点アイコンに当たった場合も同様にプロパティウィンドウが開く。何にも
  当たらなければ、代わりに簡易なコンテキストメニューが開く。
- **中ボタンドラッグ**: パン(視点の平行移動)。
- **ホイール**: ズーム距離の変更。
- **ダブルクリック**(ネイティブのダブルクリック判定、左ボタンのみ): 画面上でピック可能な任意の
  オブジェクト(天体・自艦・基地・弾薬補給・近地点/遠地点アイコン・昇交点/降交点アイコンなど)の
  上で、俯瞰カメラのフォーカスをそこへ移す。対象が自艦であれば、同時にその艦を操作対象にもする。
  ラベルが画面上で隠れている(表示の重なり回避で省略された、または手前の天体に遮られた)対象は
  ダブルクリックの対象にならない。

プロパティウィンドウは既定で一時的なもので、別のオブジェクトを右クリックする・ウィンドウの外側を
クリックする・操作項目を選ぶ・マップビューを離れる、のいずれかで自動的に閉じる。ヘッダの📌ボタンで
固定すると、自身の✕ボタンを押すか対象そのものが消える(破壊・回収・削除)まで閉じなくなり、
複数のウィンドウを並べて開いたままにできる。既にそのオブジェクトのウィンドウが開いていれば、
新しく開かず既存のウィンドウをクリック位置へ移動して最前面にする。

発射はいずれのマウスボタンにも割り当てられていない([Space]キーのみ)。

## タッチ操作

- **仮想操作パッドの出現**: 起動直後は不可視・無反応。ゲーム画面(キャンバス)への最初のタッチ入力で
  現れる。以後は消えることがなく、マウス操作(移動・クリック・キー入力)を検知するたびに半透明化する
  だけで、再びタッチすれば元の不透明度に戻る。タッチとマウスを併用するハイブリッド端末でも両方の
  操作系を行き来できる。
- **1本指ドラッグ**: 右クリック相当ではなく、左ドラッグと同じくカメラのヨー・ピッチ操作になる。
- **長押し**(右クリック相当): 押し始めてから300 ms経過すると、指の位置にリングが表示される。
  そのまま500 msまで押し続けると右クリックとして成立してリングは消える。途中で指を動かす・離す・
  ジェスチャが中断される(タブ切替など)のいずれでもリングは消え、右クリックは成立しない。
- **2本指ドラッグ**: パン(中ドラッグに相当)。
- **2本指ピンチ**: ズーム。
- **2本指ひねり**: カメラのロール。ひねった角度の変化がそのままロール角へ1対1で加算される。
- **ダブルタップ**: マウスのダブルクリックと同じくフォーカス移動(対象が自艦なら操作対象への切替も
  兼ねる)。

戦闘ビューの SHIP STATUS パネルには、装填・プログレード姿勢リセット・視点のRCS追従切替に対応する
常設ボタンがあり、タッチ・マウスどちらでも押せる。ラジエーターの展開・収納ボタンも既存のステータス
ウィンドウのボタンと同一のものが使える。

エンジン出力の4段階選択ボタン列は、戦闘ビューの SHIP STATUS パネル内に**仮想操作パッドが表示されて
いる間だけ**追加で表示される(常設ではなく、マウス操作のみの環境では画面を占有しない)。マップ
ビューでは、並進・回転・射撃・ズームの各パッドに加え、制動・微調整のトグル列も隠れ、ワープ・
軌道計画・ノードへ・ヘルプの列だけが残る(ワープの減速/加速ボタンは「減速」「加速」と短く表示)。

キー入力に対応するもの以外の操作にも、タッチのみでの到達手段が用意されている: マニューバノードの
削除は軌道計画パネルのノードコンテキストメニュー(長押し = 右クリック)から、開いているモーダルを
閉じる操作はそのモーダル自身の✕ボタンから、負荷確認ウィンドウとスナップショットの保存・閲覧は
一時停止メニュー内の項目(「負荷を表示」「スナップショット」)から、それぞれキーボードなしで到達できる。

## カメラ操作

### 戦闘ビューの追従カメラ

三人称のチェイスカメラで、艦からのオフセットを1つの回転として保持する。**そのオフセットが何を
基準にしているかを[G]キーで切り替えられる**(既定はON):

- **ON(既定)**: 艦自身の姿勢を基準にする。回転キー(I/K/J/L/U/O)で艦を回転させると、ロールも
  含めカメラ全体が艦と一緒に振れる — RCSでの姿勢操作とカメラの向きが連動する。
- **OFF**: ECI慣性系を基準にする。艦がどう回転してもカメラは一定の向きを保ち続け、ドラッグで
  動かすまで変わらない。

切り替えた瞬間に視点が跳ばないよう、保持していたオフセットは新しい基準へその場で読み替えられる。
自機が撃破されて姿勢が乱れて回転している間は、ONの設定でもその暴れる姿勢は追従せず、直前の
向きを保持したまま止まる。

ヨー・ピッチ・ロール・ズーム・パンの操作方法は「カメラ」の表のとおり(戦闘ビュー・マップビュー共通)。

### マップビューの俯瞰カメラ

地球中心の俯瞰視点で、ヨー・ピッチ・ロール・ズーム・パンの操作は戦闘ビューと同じキー・マウス
ジェスチャを使う。ドラッグによるヨーの回転方向は、戦闘ビューとは意図的に逆符号にしてある —
これにより、左右にドラッグしたときの見た目の回転方向が両ビューで揃う。

マップビューは物理演算を止めない: マップを開いていても軌道積分は通常どおり進み続け、射撃・
手動回転(RCS)もマップの開閉に左右されない。マニューバノードの選択状態によって、並進6キーが
実機の推進とΔv編集のどちらに使われるかが変わる(「キー入力の優先順位」参照)。

### ガンサイトズーム

[Z]キーを長押ししている間だけ、戦闘ビューが艦首方向を見るズームカメラに切り替わる。視野角は
55°から6°まで絞り込まれ、キーを離すと通常のチェイスカメラへ戻る。

## スラスターのラッチ操作

並進6キー(W/S/A/D/Q/E)は単押しなら押している間だけ噴射する。**0.3秒以内に同じキーを2回押すと、
押しっぱなし相当で噴射し続ける「ラッチ」状態になる。** これにより、マップを開いてマウスで
カメラや計画を操作している間も、キーを押さえたままにせず持続噴射を続けられる。

ラッチはキーごとに独立していて、軸単位ではない(例: Wだけラッチしても、Sには影響しない)。
解除は次のいずれかで起こる:

1. 同じキーをもう一度0.3秒以内に2回押す。
2. 逆方向のキーを押す。押している間だけ解除され、離しても復活しない(例: Wをラッチした後にSを
   押すと、その間は逆噴射になり、Sを離してもWのラッチは戻らない)。
3. 艦が操作できない状態になる(操作対象から外れる・格納される・タイムワープが×4を超える)。

**緊急停止**: W+S、A+D、Q+Eのいずれか一組を同時に押すと、押した軸だけでなく**全軸**の噴射を
即座に止め、ラッチも全て解除する。他の軸が保持中・ラッチ中であっても無条件に止まる。

タイムワープが×4を超えている間は、噴射・射撃・姿勢指令がその場で畳まれ、ダブルタップの判定も
行われない(キー入力自体が消費されない)。そのため、ワープを×4以下へ戻しても、ワープ中に保留
されていた入力が急に反映されてラッチが発火することはない。

## キー入力の優先順位

各フレームのキー入力は、その瞬間に有効な機能のうち早い者勝ちで消費される — 一度ある機能に
読み取られた入力は、以後どの機能にも渡らない。同じキーが状況によって別の意味を持つのはこの
ためで、代表的な例は次のとおり。

- **並進6キー(WASDQE)**: マップビューでマニューバノードを選択している間は、Δv編集がこれらの
  キーを実機の並進より先に奪う(プログレード・ノーマル・ラジアル基準の編集になり、艦は
  そのフレームでは何も噴射していないものとして扱われる)。ノードを選択していなければ、戦闘
  ビューと同じく実機の並進に使われる。射撃と手動回転(I/K/J/L/U/O)はΔv編集とキーを共有しない
  ので、マップビューでも常に艦側で有効。
- **Esc**: 開いているオーバーレイを閉じる動作が、一時停止メニューを新たに開く動作より優先される。
  何も開いていない場合に限り一時停止メニューが開く。セーブブラウザと一時停止メニューは排他関係に
  あり、片方を開くと他方は自動的に閉じる。
- **G**: 戦闘ビューでのみ読み取られる。マップビューでは押しても何も起きない。
- **微調整姿勢制御**: 射撃中は[V]トグルの状態にかかわらず、自動的に同じ制限がかかる(詳細は後述)。
- **緊急停止**: 対向するキー(W+S、A+D、Q+E)の同時押しは、他のどんな噴射・ラッチ状態よりも
  優先して全軸を止める。
- **R**: プレイ中は装填、勝敗決着後は同じステージの再出撃という別の操作になる。
- **上段の[9]/[0]とテンキーの[0]/[1]**: ラジエーター展開・収納とカメラロールという無関係な機能に
  それぞれ割り当てられた別の物理キーであり、混同しない。

## 微調整姿勢制御

[V]キーは、角速度制御の角加速度を通常の50%に絞る微調整姿勢制御モードのON/OFFを切り替える。

**発射している間は、このトグルの状態にかかわらず自動的に同じ50%の制限がかかる** —
反動による狙いのぶれを抑えるための措置で、引き金を離すと状態を持ち越さずに即座に通常の
制御(100%)へ戻る。
