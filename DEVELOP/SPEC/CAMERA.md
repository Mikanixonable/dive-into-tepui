# CAMERA — 視点カメラ

両ビュー共通の視点カメラの仕様。キー・マウス・タッチの割り当ては [CONTROLS.md](CONTROLS.md)、
参照フレーム(座標系)そのものの定義は [CELESTIAL.md](CELESTIAL.md)「座標系と参照フレーム」、
座標系パネルという UI 部品の構成は [MAP.md](MAP.md)、計画軌道の描画基準は [PLAN.md](PLAN.md)。

## 1. 視点カメラ

両ビューの視点は同じ仕組みの注視カメラで、**フォーカス対象**を注視点に置く。
**カメラはビューごとに1つずつあり、状態は互いに独立で、セーブにも別々に残る** — ビューを
行き来しても、それぞれのビューで最後に見ていた視点がそのまま戻る。

カメラが持つ状態は次のとおり(セーブに何を残すかは SAVE.md)。

| 状態 | 内容 |
| --- | --- |
| フォーカス | 何を注視するか(2節) |
| 回転の固定先 | 視点の向きを何に固定するか(3節) |
| 向き | 注視点まわりの方位・仰角・ロール(4節) |
| 注視距離 | 注視点からカメラまでの距離(5節) |
| パン | 注視点をフォーカス位置からずらす変位(5節) |
| 画角・投影 | 垂直画角と、透視/平行投影の別(5節) |

- ヨー・ピッチ・ロール・ズーム・パンの操作は両ビュー同一で、同じ操作に対する画面上の見た目の
  動きも感度も両ビューで一致する。
- 一時停止中もカメラ操作は効く(見回しができる)。

## 2. フォーカス(注視対象)

既定では原点天体(地球)を中心とした軌道カメラで、フォーカス先の天体・オブジェクトを注視点とする。
戦闘ビューの既定フォーカスは役割「操作対象の船」で、操作対象を乗り換えると視点も自動で移る。

**フォーカス**は「特定の被選択物を追う」か「空間上の1点に固定する」かのいずれか。

- **被選択物を追う** — その対象の位置を毎フレーム再解決する。対象は天体・自艦・敵・基地・弾薬と、
  それらへ解決される役割(操作対象の船 / ターゲット)。役割は特定の対象を名指しせず毎フレーム
  その時点の対象へ解決されるので、操作対象を乗り換えてもターゲットを付け替えても選択が保たれる。
- **空間上の1点に固定する** — 選んだ座標系に焼き込まれた位置を、毎フレームその座標系から実位置へ
  変換して使う。回転する座標系を選んでいれば、固定点はその座標系の回転にそのまま追従する。

**解決できないフレームには2フレームの猶予を置く。** 2フレーム連続で解決できなくなったら、
マップビューでは原点天体へフォーカスが戻り、戦闘ビューでは注視点が最後に解決できた位置へ留まって
視点操作は引き続き効く。操作艦を喪失してもビューが自動で切り替わることはない(GAME.md)。

**フォーカスを移す入口**は、座標系パネルの基準ゾーン(MAP.md)、ピック対象上でのダブルクリック /
ダブルタップ(CONTROLS.md)、プロパティウィンドウと軌道物体一覧の「フォーカスを移動」(MAP.md)。
対象が自艦であれば、ダブルクリックと一覧からの移動は同時にその艦を操作対象にもする。
軌道そのものはフォーカスできる実体ではない(MAP.md)。

## 3. 視点の回転の固定先

視点の向きを何に固定するかは、フォーカス対象から導かれる選択肢の中から選ぶ。固定先は
「慣性系」「座標系の回転」「機体の姿勢」の3種で、**座標系の回転**は CELESTIAL.md が定める参照
フレームの回転(公転・自転)そのもの、**機体の姿勢**は座標系ではなくカメラ固有の固定先である。

- **慣性系**(ECI 上で向きが変わらない)は、どのフォーカスでも常に選べる。
- **天体**をフォーカスしているときは、その天体の**公転**(主星との回転座標系。恒星には無い)と
  **自転**(自転モデルを持つ天体のみ)、および**その天体の衛星(恒星なら惑星)の公転**が加わる
  (地球をフォーカスしたまま地球-月回転系で月を静止させる、などの組のため)。
- **機体**(自艦・敵・基地・弾薬と、それらへ解決される役割)をフォーカスしているときは、
  その機体の**姿勢**が加わり、対象が離心率1未満の周回軌道にあるあいだは**公転**も加わる。
- **固定点**をフォーカスしているときは慣性系のみ(固定点自身は焼き込まれた座標系の回転に追従する)。
- どの切り替えでも、切り替えた瞬間に視点は跳ばない(保持していた向きを新しい基準へ読み替える)。
- フォーカスの変更や条件の喪失(機体の消滅・周回条件の崩れ)で選択中の固定先が選択肢から外れた
  ときは慣性系へ落ち、選択表示も慣性系へ戻る。姿勢が解決できないフレームでは直前の向きを保つ
  (視点が跳ねない)。
- [G] はフォーカスが機体のとき、姿勢追従⇄慣性系をトグルする(両ビューで効く)。戦闘ビューの
  既定は姿勢追従、マップビューの既定は慣性系。

### 3.1 画面に出す名前

固定先には**正式名**と**短縮形**の2つの綴りがあり、選択肢のボタンには正式名を、1行のサマリには
短縮形を使う。〈 〉は対象の表示名で埋める。

| 固定先 | 正式名(ボタン) | 短縮形(サマリ) |
| --- | --- | --- |
| 慣性系 | 慣性系 | 慣性系 |
| 天体の公転 | 〈主星〉-〈天体〉回転座標系 | 〈天体〉回転系 |
| 天体の自転 | 〈天体〉自転座標系 | 〈天体〉自転系 |
| 機体・役割の公転 | 〈対象名〉の公転 | 公転系 |
| 機体・役割の姿勢 | 〈対象名〉の姿勢 | 姿勢追従 |

- **短縮形は正式名から主星と「座標」を落とす。** 天体の公転なら「太陽-地球回転座標系」→
  「地球回転系」。
- **同じ綴りを、計画軌道の描画基準の回転(PLAN.md)にも使う。** 指しているものが同じ参照フレームの
  回転だからで、姿勢だけがカメラ固有のため計画側には現れない。
- **機体を追っているときの短縮形は主語を落とす。** 機体をフォーカスしているときの固定先は必ず
  フォーカス対象自身のものなので、サマリの基準欄と重複する(「基準: 操作対象の船・公転系」)。
  天体は子の公転も選べるため、主語を落とさない。
- **慣性系の選択肢を「解除」とは書かない。** 慣性系は他の選択の否定ではなく、向きを ECI に固定する
  という積極的な選択である。基準ゾーンの「固定を解除」(MAP.md)は本当に外す操作なので別語でよい。
- **[G] が切り替える状態と、艦のステータスに出る状態語は短縮形の「姿勢追従」を使う。**
- **対象の表示名は、役割・機体・天体のどれであっても同じ引き方で求める。** 役割は役割名
  (「操作対象の船」「ターゲット」)、機体は艦名、天体は天体名。id をそのまま画面へ出さない。

## 4. 視点の向きの操作

- 回転(ドラッグ・矢印キー)はカメラの**現在の**上方向・右方向を軸に行われる(固定した世界座標軸
  ではない)。そのためロール操作の後でもドラッグの感覚が画面表示と一致し続ける。
- ロールはカメラ自身の現在の視線方向を軸に回転し、ロール適用前に上方向を視線方向へ直交化し直す。
  タッチの2本指ひねりは、ひねった角度の変化がそのままロール角へ1対1で加算される。
- **視点リセット**(中クリック / 視点リセットボタン)は両ビューで効き、戻すものがビューで違う。
  - **戦闘ビュー**: フォーカスを操作対象へ、回転の固定先を姿勢追従へ、向きと画角を既定の後方
    見下ろしへ、パンをゼロへ戻す。
  - **マップビュー**: ロールとパンだけを戻す。フォーカス・回転の固定先・方位・仰角・注視距離は
    そのまま保つ。

## 5. 注視距離・パン・画角・投影

- ズームの下限はフォーカス対象に応じる: 天体はその半径、機体などは艦を間近に見る距離。上限は
  どちらのビューでも太陽系全体が収まる引き(1×10¹¹ km)。**どこまで寄せても引いても、
  近すぎる/遠すぎるという理由で物体が切り取られることはない。**
- パンは注視点をフォーカス位置からずらす。フォーカスを移すとパンはゼロへ戻る。
- **近平面・遠平面**は、切り取らないという上の要求を満たすようにビューごとに決まる。戦闘ビューでは
  常に固定(近平面 2 m・遠平面 2 兆 m。遠平面は、球として描かれる天体のうち見かけ直径が 2px を
  超える最遠のもの — 最大の恒星 — が入る距離)。マップビューでは近平面・遠平面とも注視距離に連動し、
  近平面はズームインするほど手前へ寄り、遠平面はズームアウトするほど 1.5×10¹⁰ m 〜 1×10¹⁶ m の
  範囲まで広がる。星・天球グリッドを乗せた球殻の半径は遠平面によらず一定(遠平面の下限より
  わずかに内側)で、どれだけズームアウトしても画面の隅を含めて球殻の外へ出ることはない。
- 画角・透視/平行投影・基準面の各操作はマップビューの座標系パネル(MAP.md)にあり、戦闘ビューから
  は触れない。

## 6. ガンサイトズーム

[Z]キーを長押ししている間だけ、戦闘ビューが艦首方向を見るズームカメラに切り替わる
(視野角 55°→6°)。キーを離すと通常の視点カメラへ戻る。マップビューでは効かない。

## 7. カメラ位置から導かれるもの

- **いまカメラがいる系** — カメラ位置に対して最も強く重力を及ぼす天体を起点に、その祖先を主星まで
  遡った系列と、系列上の各天体の子をあわせたもの。マップの可視性の規則と、座標系パネルの
  クイックボタンがこれを使う(MAP.md)。**勢力圏の境界付近にカメラを置いても、系のラベルが明滅して
  はならない** — 系が切り替わるのは、新しい系が明確に優勢になったときだけである。
- **フォーカス深度** — カメラからフォーカス対象までの距離。スケールバーの刻み(MAP.md)は画面中央
  ではなくこの深度を基準に決まるので、フォーカスが同じ天体のままズームせずにパンする限り表示は
  変わらない。

## 未確定の案

  定まっていない。
- 戦闘ビューに座標系パネル(カメラ区画)を出すこと。
- マップビューのダブルクリックによるフォーカス移動を、戦闘ビューにも入れること。
