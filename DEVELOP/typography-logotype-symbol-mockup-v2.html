Use / Context carries meaning

通常値はSans、機械出力だけMono

速度や高度に数字が含まれるだけではMonoへ変えない。座標、ログ、コマンドなど桁と機械文脈を見せるときにIBM Plex Monoを使う。

Avoid / Decoration carries nothing

未来感のために全画面を等幅にしない

極小文字、過大な字間、疑似コード表記を通常UIへ広げない。読みやすい通常状態があるからこそ、Consoleの声が区別できる。

06 / Tokens & AI contract

Readable by people.
Parseable by agents.

このページ自身がデザイン資料であると同時に、末尾の`application/json` manifestが機械可読な 正規要約を持つ。AIは見た目を推測せず、role、token、license、禁止事項を直接参照できる。

RoleMeaningToken
ui通常UI、本文、見出し--font-ui
editorial副題、章扉、短い叙述--font-editorial
consoleログ、座標、機械出力--font-console
title低彩度の最上位文字--ink-title
body同色相を灰色化した通常文--ink-body
subtitle高彩度の短い副題--fluorescent
marker24px SVG、意味族を形で表現#m-*
 
:root {
  --font-ui: "Arimo", "Zen Kaku Gothic Antique", sans-serif;
  --font-editorial: "Cormorant Garamond", "Zen Old Mincho", serif;
  --font-console: "IBM Plex Mono", "Zen Kaku Gothic Antique", monospace;

  --ink-title: #eeeaf5;
  --ink-body: #c3bec9;
  --ink-muted: #89838f;
  --ink-bright: #ffffff;
  --fluorescent: #ff5a00;
}

.value {
  font-family: var(--font-ui);
  font-variant-numeric: tabular-nums lining-nums;
}

.console {
  font-family: var(--font-console);
}
AI rule 01

文脈を先に選ぶ

Neutral、Editorial、Consoleの順に判断し、その後にサイズと文字種を決める。

AI rule 02

蛍光色を面積で制限

副題と現在注目だけ。長文、小ラベル、無効状態を蛍光色へしない。

AI rule 03

記号はSVGを参照

似たUnicode字形や絵文字で代用せず、24pxの意味族と線幅を維持する。
