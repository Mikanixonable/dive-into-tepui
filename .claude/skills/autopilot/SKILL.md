# autopilot — 節約・委譲・眠る

ユーザーが毎回書いていた指示の恒久版。**この手順を、指示がなくても守る。**

## 原則

1. **Claude のトークンは判断に使う。** 設計・仕様の選択・差分のレビュー・統合の衝突解消・目で見る判断だけを自分で持つ。
   調査・実装・計測の反復・一括編集・片付けなどの単純作業は委譲する。自分で長く調べ始めたら委譲の取りこぼし。
2. **委譲先は `npm run usage` の「委譲先」に従う。** SWE-2 は無料モデルで、有料の quota を消費せず、別枠のレート制限だけがかかる。
   制限中でなければ SWE-2(`/delegate-devin`)、制限中なら Agent ツールの `model: haiku`(Haiku 5.5。Sonnet は使わない)。
   Haiku には設計の自由度を渡さず、具体的な実装案と手順を渡す。配り方とレビューは `/delegate`。
   Devin の有料モデル(luna など)を使うときだけ、`npm run usage` の「有料モデル枠」の日次・週次の残量を読む(0% なら使えない)。
3. **5h 枠を使い切って途中で止まらない。** 止まるなら自分の意思で、区切りで、引き継げる形で止まる。
4. **自走する。** 段取りの判断はユーザーへ問い返さず、決めた判断を事後に報告する(AGENTS.md「SKILL は自分から起動する」)。

## 手順

### 1. 着手前と、区切りごとに `npm run usage`
区切り = 計画のステップ完了・commit 直後・委譲の回収とレビューが終わった時点。Devin を起動する前にも見る。
セッション開始時は SessionStart フックが 1 行(`[利用枠] ...`)を出すので、それを読む。
- `CONTINUE`(終了コード 0): 続行。「委譲先」の表示どおりに配る。
- `SLEEP`(1): 新しい作業を始めない。下の「眠る」へ。
- `UNKNOWN`(2): Claude の枠が取れていない(OAuth も statusline も不可)。ユーザーが解除時刻を与えているならそれを使い、
  `npm run usage -- --reset-5h=HH:MM` で再実行する。与えていなければ 1 回だけ聞く(区切りごとには聞かない)。

### 2. SWE-2 がレート制限中のとき
- Haiku へ委譲して進める。復活のタイマーは `npm run usage -- --wait=swe2` を `run_in_background` で走らせる
  (解除時刻まで待ち、実際に戻ったかを確かめて終了する。終了の通知が合図)。戻ったら次の起動から SWE-2 へ戻す。
- 制限の検出元は Devin の転写に残るエラー文。ユーザーが復活時刻を与えているなら、それを優先する。

### 3. 眠る(5h 枠が尽きそう・尽きた)
1. 実行中の Devin・サブエージェントは完了を待つか TaskStop で止め、結果の扱いを記す。
2. 作業ツリーに未完の変更を残さない。残すなら何を残したか書く。
3. **起こすタイマーを置く**: `npm run usage -- --wait=claude` を `run_in_background` で走らせる。
   解除時刻まで待ち、実際に Claude の枠が戻ったかを 1 分ごとに確かめて、戻ったら終了する(終了の通知が起床の合図)。
   時刻が取れない `UNKNOWN` のときは `--reset-5h=HH:MM` を付ける。起きたら最初に `npm run usage` を実行する。
4. 引き継ぎメモを最終メッセージに書く(完了したこと・残ったこと・次の一手・起動中だった委譲・タイマーの時刻)。
   同じ内容を `project` 種別のメモにも保存する(`memos/` は書き換えない)。

### 4. 起きたとき
`npm run usage` → 引き継ぎメモを読む → 次の一手から再開。SWE-2 が使えれば常時 3 本まで走らせる
(同時 5 本で全部が止まった実測があるため、3 本を超えない)。

## 罠
- 単純作業を「自分でやったほうが速い」と判断しない。再導出のコストが高い場面(読むファイルが 1〜3 個に絞れている)だけが例外(CLAUDE.md「使わない場面」)。
- Devin の quota(日次・週次)は有料モデル専用。SWE-2 の可否には使わない(0% でも SWE-2 は使える)。
- どの値も文書化されていない API 由来。形が変わると「不明」になる。従量課金は見ない(購読枠だけ)。
- Claude の取得は keychain の OAuth トークンが元。取れなければ statusline の値(15 分より古いと不明)。
