# 固体の黒体放射 — 残件

**組み上がっている形は [`pipeline.md`](pipeline.md) §2-4。** ここにあるのは、**まだ温度に
繋がっていないもの**と、**判断の材料になる較正表**だけ。優先度は低く、互いに独立している。

---

## 1. 温度の経路に乗っていないもの

| 何が | なぜ乗っていないか |
| --- | --- |
| **タンパク質型の敵** | 独自のノードマテリアルで描いていて、自照を足すには別の配線が要る。敵機は 500 K で焼失するので見える明るさには届かないが、**「温度を持つものは全部同じ式に乗る」は満たしていない。** |
| **分離ブースター** | 爆砕ボルトが手で置いた emissive を持っていて、温度から引く自照へ置き換えるとその光が消える(`render/booster.ts`)。**ボルトの光を何から出すかを決めてから載せる。** |

## 2. 温度由来ではない自照が残っている場所

**基地**(`render/base-station-model.ts` の窓・ネオン・ハザード帯)、**分離ブースター**
(上記)、**タンパク質の鉄配位子**(`render/protein-atom-view.ts`)。

**どれも赤熱ではない** — 灯りや標識であって、温度から出るものではない。**黒体放射へ寄せるのが
正しいのか、別の根拠(照明として持つ)を与えるのかを決めていない。**

## 3. 太陽の球と星殻

**太陽面は 5,772 K の黒体そのもの**なので、同じ表から色と明るさを引ける。いまは world パスの
住人で、行き場が決まっていない([`pipeline.md`](pipeline.md) §4)。**表の上端を伸ばせば
同じ 1 本の式に乗る。**

## 4. 表の上端

いまは 3,000 K まで。固体には十分(鋼の融点 1,700 K)だが、[`volume.md`](volume.md) の
衝撃層が同じ表を使うなら足りない。**使う側が決まった時点で伸ばす**(半精度の表現域は
5,900 K まで持つ)。

**CPU 側から表を引く口も出してある。** いまは較正のテストだけが読んでいる。

## 5. 砲身まわり

- **装着中の砲身の温度は画面に出ない。** 自機モデル(`assets/models/player.json`、マテリアル
  24 個)は砲身に相当するメッシュを名前で取り出せないので、`thermalShape` を焼く先がない。
  **出したいならモデル側の分割から。**
- **装着中の砲身の放熱面積。** いまは排出後と同じ。遮蔽されているぶん小さく取ると、ゆっくり
  撃っても熱が溜まる。**「ゆっくり撃つと排出時に光らない」が気になったときに検討する**
  (1 秒に 1 発で撃ち切っても薬室側 1,323 K には達する)。
- **融点の高いデブリ。** 個体ごとの温度は `InstancedPool` まで通してあるので、種別ごとの
  上限温度を上げるだけで赤熱する。

## 6. ここではないもの

- **再突入の輝き**(`player/reentry-effects.ts`)。いまは動圧から強度を引いている。
  **実際に発光するのは物体より先に断熱圧縮された周囲の大気であり、衝撃層の発光は黒体放射では
  ない** — 艦体の赤熱と同じ式には乗らない。[`volume.md`](volume.md) が引き取る。
- **ブルーム。** 赤熱が白を超えると出力段のレンズ効果が滲ませる([`pipeline.md`](pipeline.md) §2-5)。

## 温度と表示値(較正表)

**判断はこの表から行う。** プランクの式 × CIE 1931 等色関数の積分を **輻射率 1** で出した
表示値で、実際の絵はこれに輻射率(艦・デブリとも 0.85)が掛かる。

| T [K] | R | G | 見え方 |
| ---: | ---: | ---: | --- |
| 800 | 9.0e-7 | 0(色域外) | 見えない(表の下端) |
| 933 | 5.1e-5 | 8.9e-7 | 見えない(破片・薬莢の焼失温度) |
| 1000 | 2.6e-4 | 8.6e-6 | 見えない |
| 1100 | 2.1e-3 | 1.2e-4 | ほぼ見えない |
| 1200 | 1.2e-2 | 1.0e-3 | 影の中でかすかに赤い |
| 1300 | 5.3e-2 | 5.8e-3 | 影の中で赤い(**自機の喪失温度**) |
| 1400 | 1.9e-1 | 2.6e-2 | 日照下でも分かる |
| 1500 | 5.6e-1 | 9.2e-2 | 橙(**撃ち切って排出した直後の砲身の薬室側**) |
| 1600 | 1.5 | 2.8e-1 | 白を超える |
| 1700 | 3.4 | 7.5e-1 | 鋼の融点付近 |
| 2000 | 26 | 7.9 | 黄白 |
| 5772 | 4.6e4 | 4.6e4 | 太陽面(白) |

**比較の基準:** 日照下(1 天文単位)のアルベド 0.3 の面 = **0.30**。影の中
(`AMBIENT_IRRADIANCE` = 0.093π)の同じ面 = **0.028**。

**勾配の見え方もこの表から読める。** 薬室側 1,500 K・平均 950 K の砲身では、温度差の分布が
0.5 に落ちる位置で 1,225 K(0.015)、0.3 で 1,115 K(0.003)。**1,500 K の 1/40 と 1/200** な
ので、**明るい範囲は分布が 0.8 を超えるあたりに収まる。** なだらかな分布を焼いても赤熱の縁は
硬い — 補間の粗さではなく、可視域の放射が急峻であることの帰結。**光る範囲を広げたいなら
分布の減衰長を伸ばす。**

**表の値は render-lab の `blackbody` ケースで画素と突き合わせられる。** 1,500 K・輻射率 0.85 の
面の夜側が sRGB (183, 79, 0)、1,300 K で (59, 15, 0) — どちらも表の値をトーンマッピング
(PBR Neutral)に通した計算値と 1/255 以内で合う。
