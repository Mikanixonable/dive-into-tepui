# 雲生成の第三次改善 — 目視評価にもとづく計画

**目標は、cloud-lab の生成(被覆率・雲頂高度・薄い雲)を実写 8k_clouds と並べて見たとき、前線・台風・
積雲の塊・薄い雲の 4 つが「実写と同じ尺度と同じ階調で」読める絵になること。** 第二次改善で前線・気団・
気候の構造は入ったが、目で見比べると、前線は小さく淡く、芯のまわりで深く巻いて東西にだけ伸びる、台風は
雲頂がなだらかな山で雲の濃さが周りと変わらない、全体は実写よりぼんやりして中間調が多く、雲塊と細胞のあいだの尺度が抜けている。
大部分は定数の調整で届く段階なので、この版は定数と伝達関数の形の調整を主にする。基準値はすべて
`8dd67b67`(コードは `58192aac` と同じ)で `npm run cloud-lab:compare` を回した実測と、同じ版の撮影の
目視(2026-09-04)。

## 計測の物差し

`npm run cloud-lab:compare`(`tools/cloud-lab-compare.mjs`)が全球(正距円筒 1024×512 = 39 km/texel)と
地域別 cap(正射影・半径 20° = 8.5 km/texel、中央 362×362)を撮り、実写(実写計)と分離成分(実写厚・
実写薄)へ再標本化して、帯状平均・階調・行方向スペクトル・構造テンソル・地形の箱・雲頂の分位を印字する。
`npm run cloud-lab:shot` は全ビューを 0 h と 25 h で `.cloud-lab/shots/` へ撮る。目視の見比べは
`npm run cloud-lab`(dev サーバ)で定数を書き換えて行う。**撮影の非決定性は最大 3 LSB ≈ 0.012。**

この計画で物差しへ足すもの(手順 2): 細かい刻みの階調ヒストグラムと 200 km の局所コントラスト、
薄い雲 vs 実写薄 のスペクトル、暴風帯 cap の前線ビュー、台風の実写リファレンス(NASA Worldview の
静止衛星画像。8k_clouds に台風は写っていない)。

**cap の判定は中央に限る。** 移流前の写しは出力と同じ cap に焼かれ、移流はそこから風上へ遡って読むので、
cap の縁は写しの外(縁の texel の張り付き)を読む — 上層では縁に平行な同心の弧、表層では縁から内へ
伸びる縦縞、気団では縁の明るい柱になる。**直すのは別の計画(`cap_margin.md`)で、この計画では判定の
範囲を絞って避ける。** 99 パーセンタイルの風 13.4 m/s と 2 位相移流(0 h は 10 h の歩だけ、25 h は 5 h と
15 h の混合)で、写しの外を読む範囲は風上側(上層は西)の縁から:

| 場 | 0 h | 25 h |
|---|---|---|
| 表層の湿度 | 4.3° | 6.5° |
| 対流(歩 × 1.3) | 5.6° | 8.5° |
| 上層 15°N(歩 × 2、ジェット 1.3 m/s) | 9.5° | 14.3° |
| 上層 20°S・22°N(帯 5 m/s) | 11.9° | 17.9° |
| 上層 35° 以上(ジェット 16.5 m/s) | 19.4° | 29° |

半径 20° の cap の中央 362 px(±10°)では、**被覆率・雲頂は 0 h・25 h とも箱の全域が写しの中。薄い雲・
合成は、0 h の台風(15°N)と収束帯(5°N)だけ箱の全域が写しの中**で、亜熱帯・サハラは西端 2°、暴風帯
3 cap は西半分が写しの外を読む。したがって: (a) 暴風帯 3 cap の薄い雲・合成の統計は判定に使わず、
中緯度の薄い雲は全球面(39 km/texel)と全球の構造テンソルで判定する。(b) 25 h の cap は被覆率・雲頂
だけを見る。(c) 半径 10° の cap は被覆率・雲頂・前線・気団の目視だけに使い(上層は箱 ±5° の西 4.5° が
外)、合成の目視は半径 20° で行う。(d) 前線ビュー・気団ビューの縁 1.4° の柱は判定に入れない。

**雲頂の基準は気象学の事実**(実写にも分離にも雲頂は無い): 台風の中心濃密雲域は半径 250〜400 km が
圏界面(熱帯 16〜17 km)に張り付いた平らな天蓋で、その外は螺旋状の雨帯だけが高い。

## 目的 — 目で見て違うところ

**1. 前線。** 低気圧の周りに気団の境目の折り目は出るが、(a) **小さく、芯のまわりで深く巻き、東西にだけ
伸びる。** 実写の中緯度(南半球が読みやすい)の前線は、中心から北半球なら南西と北東へ、南半球なら北西と
南東へ数千 km 伸びる**浅い弧**で、1 周も巻かない。生成は前線ビュー(合成では埋もれる)で、芯から半径の
0.7〜1.5 倍(350〜1600 km)の環の中にだけ折り目が立ち — 芯の内側は剛体回転で折れず、外は回転が
弱い — そこでの 1 歩の巻きが 1.3〜3 rad(並の低気圧 18 hPa・半径 800 km で 600 km 2.3 rad、900 km
1.35 rad)あるので、180° 以上巻いた小さな螺旋になる。渦の外では、渦の風と帯の平均風(45° で 6.4 m/s)が
釣り合う半径(≈ 1100 km)を境に、閉じた流れ(猫の目)と通り抜ける流れに分かれ、折り目はその境目に沿う
— 境目は流れの向き(東西)に伸びた対称な形で、実写の傾いた弧にならない。前線の上昇流は圧縮 6 で
0.019 m/s、湿度にして +0.04(伝達関数の幅 0.28 の 15%)しか無く、合成では読めない。構造テンソル
(35-60°・800 km)の被覆率の卓越する向きは N 118°・S 53° で、実写厚(N 31°・S 127° — 北半球で南西–北東、
南半球で北西–南東)と直交に近く、揃い R は 0.13 / 0.04(実写厚 0.5)。(b) **前線が幅 0 の点へ収束する**
(全球の前線ビュー 0 h、44°S 56°E。低気圧 #5(46°S 46°E)と #3(49°S 78°E)のあいだ)。猫の目の
東西の先端は追跡の風が 0 になる淀み点(鞍点)で、風上への遡りが両側から同じ点へ折り畳まれ、圧縮が
1 点に集中する。ベクトル場の性質なので消せない — 風の淀む所で前線の強さを滑らかに落として隠す。
(c) 芯のすぐまわりでは 1 歩の巻きが 2π を超えて折り目が同心の輪になる(台風の芯で顕著)。半径を
広げて追跡を縮めれば芯の 400 km 以内に収まるので、閉塞の写しとして残す。

**2. 台風。** (a) 雲頂が芯から外へなだらかに下がる山(金床がガウス、1/e 半径 440 km: 250 km で 0.72、
400 km で 0.44、600 km で 0.16)。実写(Worldview: Trami 2018-09-26・Mawar 2023-05-25・Hagibis
2019-10-09)は直径 600〜800 km(Hagibis は 1250 km)の**平らな白い円盤**が縁で急に切れ、その外に
2〜3 本の雨帯が 1000〜1500 km まで巻く。(b) 雲の濃さが周りと変わらない: 上昇流は芯で頭打ち
(0.06 m/s)に張り付いて湿度を +0.13 押し上げるだけで、被覆率は芯の内側でも 0.4〜0.8 の筋。実写の
円盤は 1.0 で塗り潰され、雨帯も 1.0、帯のあいだは 0。(c) 芯から 600 km より外で、粒が**放射状の筋**
(スポーク)に伸びる。15°N ではコリオリが弱く、摩擦だけで決まる横切り角が 湿度の風 57°・対流の風 78°
(45°N では 30°・60°)と、流れがほぼ気圧勾配に沿った吸い込みになり、粒が中心へ向けて引き伸ばされる
ため。(d) 実写のリファレンスが無い — 手順 2 で取り込む。

**3. 全体(階調と帯域)。** ±60° の細かい階調(撮影の全球面から取った実測、刻みは 0.03 / 0.06 / 0.1 /
0.15 / 0.25 / 0.4 / 0.6 / 0.8 / 0.94):

| 場 | 平均 | 200 km の局所コントラスト(5×5 texel の標準偏差の平均) | <0.03 | 0.03-0.15 | 0.15-0.4 | 0.4-0.6 | ≥0.6 |
|---|---|---|---|---|---|---|---|
| 実写計 | 0.215 | **0.075** | 20.4% | 27.9% | 32.3% | 14.3% | 5.2% |
| 合成 | 0.216 | **0.046** | 22.4% | 20.9% | **39.3%** | 13.5% | 3.9% |
| 実写薄 | 0.135 | 0.028 | 20.6% | **45.6%** | 28.2% | 5.6% | 0% |
| 薄い雲(輝度) | 0.134 | 0.032 | 32.9% | 25.1% | **39.8%** | 2.3% | 0% |
| 実写厚 | 0.115 | 0.067 | 35.0% | 35.8% | 24.8% | 4.1% | 0.4% |
| 被覆率 | 0.100 | 0.034 | 54.3% | 21.4% | 17.6% | 5.1% | 1.6% |

平均は合っているのに、**局所コントラストが実写の 6 割**しか無く、中間調 0.15-0.4 が 7 ポイント多い。
薄い雲は「無いか、中間調の斑か」で、実写薄の「ごく薄い靄(0.03-0.15 が 46%)の上に濃い筋」と
分布の形が違う。スペクトル(合成/実写計)は 3 帯とも 212-423 km で 0.32〜0.48、106-212 km で
0.07〜0.15 と、**中間の尺度から下が抜けている。** cap の 被覆率/実写厚 は 770 km 超で 1.5〜8 倍
(滑らかな塊が大きすぎる)、24-48 km で 0.2〜0.3(粒が淡い)。目視では、収束帯と亜熱帯の cap で実写が
100〜300 km の白い塊(積雲のクラスター)と黒い隙間を持つのに対し、生成は同じ濃さの網目が一面に
広がる。

|---|---|---|---|
| 1 | **cap の判定は中央 362 px に限り、暴風帯 3 cap の薄い雲・合成の統計と 25 h の cap の上層は判定に使わない**(「計測の物差し」の表) | 移流前の写しが cap の外を読む欠陥は別の計画で直す(ユーザーの指示)。写しの外を読む範囲は風と位相から数えられるので、判定の範囲を絞れば残りは信用できる | 直すなら `cap_margin.md`。直したあとはこの制限を外す |
| 2 | **前線の上昇流は、追跡の風の速さで門を掛ける**(2 → 6 m/s で 0 → 1) | 淀み点(猫の目の東西の先端の鞍点)の圧縮は風速 0 の 1 点に集中する。腕は 6〜12 m/s の風の中にあるので門に掛からない | 門を外すと点への収束が戻る。圧縮そのものに上限を置く案は、点は残ったまま淡くなるだけ |

| 4 | **台風の天蓋は超ガウス exp(−(r/R)⁶)、R = 300 km**(200 km で 0.92、250 km で 0.72、350 km で 0.08)。同じ形を湿度へも足して(+0.5)円盤を塗り潰す | 実写の中心濃密雲域は直径 600〜800 km の平らな円盤。ガウスでは縁が無い | 指数を 4 にすると縁が 100 km 広がる。R は Mawar(600 km)と Trami(800 km)のあいだ |
| 5 | **上昇流は湿度を足すのではなく、移流後の湿度の偏差を増幅する**(偏差 × (1 + 上昇流/頭打ち))。足す分は残すが半分にする | 足すと円盤が渦を塗り潰す。増幅なら湿った筋はより白く、乾いた隙間はより晴れて渦が残る。並の低気圧(上昇流 0.5 頭打ち)でもコンマの帯と乾いた切れ込みの対比が上がる | 増幅を 0 に戻すと台風は現状の淡い筋に戻る。円盤だけ塗るなら決定 4 の湿度の項だけ残す |

| 7 | **湿度の段の取り分を中間の尺度へ寄せ、伝達関数の幅を狭める**(段 [0.5, 1, 0.65, 0.42, 0.27] → [0.4, 0.8, 0.8, 0.7, 0.5]、幅 0.28 → 0.20)。気団の不安定へ 250 km の段を 1 つ足し(段の総数 15 → 16)、粒を塊に群れさせる | 中間の尺度の分散を上げなければ、幅を狭めても地域差が塊の密度ではなく一色へ潰れる。塊は粒の包絡で出す | 段を足さないなら、湿度の 100 km の段を落として気団へ移す(総数据え置き) |

## 達成目標

1〜7 は compare の表で、8 は撮影と grep で、9 はユーザーの目視で判定する。「基準」は `8dd67b67`。
cap の統計は「計測の物差し」の範囲(中央の箱、上層は熱帯・亜熱帯の 0 h だけ)で読む。

1. **前線**: 前線ビュー(0 h と 25 h)で、両側から来た帯が 1 点で交差して明るくなる所が無い。低気圧の
   折り目が芯から両側へ合わせて 3000 km 以上伸び、芯から 500 km より外では曲がりが 90° 以内の浅い弧で、
   向きが北半球で南西–北東(東から 45° ± 25°)、南半球で北西–南東(135° ± 25°)。180° 以上巻くのは
   芯から 400 km 以内だけ。暴風帯 3 cap の被覆率で、折り目に沿って被覆率 ≥ 0.6 の帯が 1500 km 以上
   つながる(目視)。構造テンソル 35-60° の 800 km で、被覆率の卓越する向きが実写厚(N 31°・S 127°)の
   ±35° 以内、揃い R ≥ 0.2(基準 N 118° / 0.13、S 53° / 0.04)。前線ビューの圧縮で、35-60° の背景
   (低気圧の芯から 2500 km より外)の 90 パーセンタイルが効き始めを超えない。
2. **台風**(cap 15°N 140°E・0 h): 雲頂の方位平均の径方向プロファイルが、中心の 0.9 倍以上を 200 km まで
   保ち、400 km までに 0.5 倍を切る(基準: 250 km で 0.72、400 km で 0.44 のガウス)。中心 250 km の
   被覆率の平均 ≥ 0.9(眼を除く。基準 0.4〜0.8 の筋)。250〜1000 km の被覆率で、0.06〜0.25 の中間調の
   割合 ≤ 25%。眼が厚い雲にも薄い雲にも開いたまま。放射状の筋が無く、雨帯が螺旋に巻く(目視、
   リファレンスの Mawar と並べて)。合成の 96〜770 km のスペクトルが、リファレンスの輝度の 0.5〜2.0。
3. **階調**(±60° の全球面): 合成の局所コントラスト ≥ 0.065(基準 0.046、実写計 0.075)。合成の 0.15-0.4
   ≤ 34%(基準 39.3%、実写計 32.3%)、0.03-0.15 ≥ 25%(基準 20.9%)、≥ 0.6 が 4.5〜7%(基準 3.9%)。
   薄い雲(輝度)の 0.03-0.15 ≥ 38%(基準 25.1%、実写薄 45.6%)、0.15-0.4 ≤ 32%(基準 39.8%)、
   平均 0.11〜0.15。
4. **帯域**: 合成/実写計 の行方向スペクトルが 3 帯とも 212-423 km で ≥ 0.6(基準 0.32〜0.48)、
   106-212 km で ≥ 0.2(基準 0.07〜0.15)、3384 km 以上の各帯で 0.5〜2.5(基準 0.56〜3.77 — いちばん
   長い波長帯は実写が 1 時点の静止画で力を持たないので 2.5 まで許す)。cap の 被覆率/実写厚 が
   暴風帯 3 cap で 770-1541 km ≤ 2.0(基準 1.45〜3.3)、96-385 km 0.7〜1.6、24-48 km ≥ 0.5
   (基準 0.22〜0.30)。
