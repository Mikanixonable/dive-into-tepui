# 写しの余白 — cap の外を読む移流を直す計画(保留)

**目標は、移流前の写しが風上へ届く範囲を必ず持ち、cap をどこへ向けても・どれだけ広く取っても、同じ
場所の雲が同じに見えること。** いまは移流前の写し(湿度・上層湿度・対流)が出力と同じ cap に焼かれ、
移流はそこから風上へ最大で 表層 6.5°・対流 8.5°・上層 29°(中緯度、ジェット込み、25 h の位相)遡って
読む。cap の外へ出た読みは縁の texel に張り付き、上層は縁に平行な同心の弧、表層は縁から内へ伸びる
縦縞、気団は縁の明るい柱になる。

**この計画は保留。** 当面は利用側が「視野 + 届く距離」の余裕を持つ半径を指定し、cloud-lab の判定は
cap の中央に限ることで避ける(判定の運用は `improvement3.md`「計測の物差し」)。着手するのは、
(a) 生成の場をゲーム本体へ繋ぎ、cap がカメラに追従するようになるとき、または (b) cloud-lab で
中緯度の cap の西半分や 25 h の cap の上層を判定に使いたくなったとき。**余裕の半径で避けるなら、
上層の届く距離は視野 + 19〜29°**(ジェット 16.5 m/s + 風 13.4 m/s × 上層の歩 40 h)で、視野 20° の
cap なら半径 40〜50° になる — 8.5 km/texel を保つには texel 数が 4〜6 倍要る。

基準値は `8dd67b67` で `npm run cloud-lab:compare` を回した実測(2026-09-04)。

## 目的

**1. 写しの外を読む。** 移流は 2 位相で、位相 A は周期(20 h)の φ 倍、位相 B は (φ + 0.5) 倍だけ風上へ
遡る。0 h では位相 B だけ(10 h)、25 h では 5 h と 15 h の混合。99 パーセンタイルの風 13.4 m/s で
届く距離と、半径 20° の cap の中央 362 px(±10°)がどこまで汚れるか:

| 場 | 0 h | 25 h |
|---|---|---|
| 表層の湿度(× 1) | 4.3°(箱は無事) | 6.5°(無事) |
| 対流(× 1.3) | 5.6°(無事) | 8.5°(無事) |
| 上層 15°N(風 + ジェット 1.3 m/s、× 2) | 9.5°(無事) | 14.3°(箱の西 4°) |
| 上層 20°S(風 + 帯 5 m/s) | 11.9°(箱の西 2°) | 17.9°(箱の西 8°) |
| 上層 50°N(風 + ジェット 16.5 m/s) | 19.4°(箱の西 9°) | 29°(箱の全域) |

北大西洋(50°N 30°W)と南大洋(55°S 100°E)の cap の薄い雲と合成に見える同心の弧、半径 10° の cap の
被覆率の左端の縦縞、前線ビューの左右の縁の明るい柱がこれ。ゲームで cap がカメラに追従すると、
**同じ場所の雲が cap の置き方で変わる** — 仕様「同じ時刻の同じ場所はいつ見ても同じ空」に反する。

**2. 上層の見えの動きが 2 倍。** 上層の模様は帯表(ジェット 20°/日)で既に動いており、移流の歩へも同じ
ジェットを足しているので、見えの動きは帯 + 風(ジェット込み)= ジェットの 2 倍で滑る。ジェットは
経度に依らない一様な流れなので伸びは作らず、変位だけを膨らませている。

**修正後**: 写しが風上へ届く範囲を必ず持ち、置き方に依らない。歩の長さに全球一律の上限があり、上限が
写しの余白と一致する。上層の歩はジェットを含まず、巻雲の筋の向きはノイズ空間の伸びで出る。

## 決めたこと

| # | 決定 | 根拠 | 覆すとどうなるか |
|---|---|---|---|
| 1 | **移流前の写しは、出力の cap より「風上へ届く距離」ぶん広い cap に焼く。** 届く距離は 1 歩の長さに置く全球一律の上限(表層 1000 km・対流 1300 km・上層 2000 km、tanh で漸近)で決め、写しの texel 数は据え置く | 上限が場所に依らないので、cap の置き方で雲が変わらない。texel 数を据え置けば費用は増えない(細かさだけ 湿度 17 → 24 km/texel、上層 17 → 31、対流 8.5 → 12.8 に落ち、対流の 40 km の段の振幅が 0.64 になる) | 縁で歩を縮める案は、同じ場所の雲が cap の置き方で変わるので不可。texel 数を増やすなら費用は半径比の二乗(対流 2.4 倍) |
| 2 | **上層の 1 歩から帯の平均風(ジェット)を外す。** | ジェットは一様な流れで伸びを作らず、変位だけを 29° に膨らませる。しかも見えの動きを 2 倍にしている(目的 2) | 外すと 35-60° の薄い雲の揃い R(基準 N 0.16 / S 0.14、400 km)が下がる。代わりに決定 3 |
| 3 | **上層のノイズ空間を自転軸方向へ伸ばし、巻雲の模様を緯線に沿って長くする**(伸び 2.5。緯度 φ での異方性は √(sin²φ + 2.5² cos²φ): 赤道 2.5、45° 1.9、60° 1.5、極 1) | 実写薄の卓越する向きは 10°S-10°N で 177°(緯線)、35-60° で 43° / 133°(斜め)。緯線方向の伸びに、釣り合い風の歩が渦のまわりで傾きを足す。写像は位置だけの関数で継ぎ目が無く、費用は段あたり数命令 | 伸びを 1 に戻せば手順 4 が消える。斜めの向きが出なければ、伸びの向きを帯ごとに変える案へ |

## 達成目標

1. **cap の置き方に依らない**: 同じ中心(50°N 30°W と 44°S 56°E)を半径 10° と 20° の cap で撮り、
   半径 10° の面が写す共通部を 50 km へ落として比べた被覆率・薄い雲の差が 平均 ≤ 0.01・最大 ≤ 0.05。
   薄い雲・合成の cap に縁と平行な弧が無く、被覆率の cap に縁から伸びる縦縞が無く、前線ビューの縁に
   明るい柱が立たない(目視)。
2. **費用**: 写しの texel 数が基準と同じ(湿度 256² × 2 場、対流 512²、気圧 512²、気団 512²、
   不安定 64²)。
3. **薄い雲の筋**: 構造テンソルの薄い雲(全球面)が、10°S-10°N の 400 km で向き 177° ± 20°・R ≥ 0.3
   (基準 1° / 0.45)、35-60°N・S の 400 km で実写薄(43° / 133°)の ±35° 以内・R ≥ 0.2(基準 N 174° / 0.16、
   S 162° / 0.14)。
4. **上層の見えの動き**: 0 → 72 h の再生で、上層湿度の模様が経度方向へ滑る角がジェットの帯で
   60° 前後(基準 120° 前後 = 2 倍)。
5. **退行の枠**: ±60° の合成の晴れ(< 0.06)≥ 25%。被覆率/実写厚 の帯状比が 30〜60° で 0.5〜1.6。
   のっぺり率 合成 ≤ 2%。白飽和 ≤ 2%。cap の 被覆率/実写厚 の 24-48 km の比が実施前の値
   (0.22〜0.30)を下回らない(対流の写しが粗くなる代償の枠)。0 → 72 → 0 h の再生で最大差 0 LSB。
   緯線に沿った継ぎ目が立たない。

### 手順 2. 置き方に依らないことの検査を物差しへ足す

**目的**: 達成目標 1 を compare の表で当てられるようにする。生成の挙動は変えない。

**変更が必要な箇所**

| ファイル | 何をするか |
|---|---|
| `tools/cloud-lab-compare.mjs`(新設の節「cap の置き方に依らないこと」、`main` L436 の撮影ループのあと) | 50°N 30°W と 44°S 56°E を半径 10° と 20° で撮り、半径 10° の面を半径 20° の面の中央 260 px へ重ねて(正射影の中心が同じなら平面座標は sin 10° / sin 20° = 0.508 倍の相似)、50 km の箱で落とした被覆率・薄い雲の差の平均と最大を印字する |

**達成条件と検証**: 表に節が出る。直す前の基準値を控える — 縁の欠陥があるので差は 0.05 を超えるはず。
既存の表の値は基準と 3 LSB 以内で一致する。`npm run typecheck`。

### 手順 3. 写しの縁を直し、上層の歩からジェットを外す

**目的**: 移流前の写しが風上へ届く範囲を持つようにし、1 歩の長さに全球一律の上限を置き、上層の歩から
ジェットを外す(決定 1・2)。上層の見えの動きが半分になる。

**変更が必要な箇所**

| ファイル | 何をするか |
|---|---|
| `src/render/cloud/field-projection.ts` L73-128(`OrthographicCap`) | `widen(margin)` を足す: 中心・東・北の uniform を親と共有し、半径だけ `radius + margin` の `FieldProjection` を返す。親の `aim()` が子の `sinRadius` も書き換える(子を配列で持つ)。`EquirectProjection` の `widen` は自分を返す。`FieldProjection` 型に `widen(margin: number): FieldProjection` を足す |

| 同 L400-427(`advected`) | `sourceAt` の `windStep` に、場ごとの届く上限を渡す(表層 1000 km、対流 1300 km、上層 2000 km) |
