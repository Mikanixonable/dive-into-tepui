## 天体候補の絞り込みから `Vec3` の割り当てを落とす

対象コミット: `3d0f5241`(行番号はこの時点)。

**見送っている理由:** 中身は距離比較だけの短い式が、スカラー展開で 3 倍近い行数になる。
いまの負荷では、可読性を捨てて得る 0.3 ms(倍率 ×1)に見合わない。
**戻ってくる条件は、負荷確認ウィンドウの「天体接触」が高倍率で実際に予算を食っていることを
実測で確かめたとき。** node 実測では最高倍率で 9.6 ms/frame になりうるが、実機の負荷ウィンドウで
この区間を控えたことがまだ一度もない。まずそれを控えるところから始める。

### 目的

`narrow` と `into` は毎 substep、全個体ぶん走る。中身は距離比較だけなのに、
`sub` / `len` / `add` / `scale` で参加者1体あたり 10 個以上の `Vec3` を作っている。
node 実測(天体 95 体、LEO 殻、N = 2000)で `narrow` 190 µs + `into` 316 µs = **506 µs/substep**。
天体接触は倍率に依らず走り、高倍率では 1 フレームに最大 64 substep 走るので、破片 600 体でも
64 × 150 µs ≈ **9.6 ms/frame** になる。`sphere-contact.ts:108` が同じ理由で既に
「棄却されるところまでは `Vec3` を1つも作らない」形を採っているので、規則としても揃う。
**判定の答えは変えない。**

削るのが割り当てであって候補数でないのは実測による。全員が地球圏にいるとき `narrow` は
95 体 → 1 体まで落としており、上の 506 µs は `reachable = 1` で出た値である。
天体側に 27 近傍グリッドを組む案は測って**却下した** — 問い合わせが1体 0.33 µs で、
いまの `narrow` + `into`(1体 0.25 µs)より高い。`surfaceCandidates`(延べ候補天体数)が
参加者数の数倍を超え続けるなら、`narrow` が絞れていないということなので、この判断は崩れる。

### 変更が必要な箇所

| ファイル | 何をするか |
| --- | --- |
| `src/game/dynamic/surface-candidates.ts:25-34` | `chordDeviationBound` と `intervalReach` を、`Vec3` を作らないスカラー演算へ書き換える |
| `src/game/dynamic/surface-candidates.ts:70` | `narrow` の重心と margin をスカラーで求める(`sum = add(sum, ...)` の累積と `len(sub(...))` をやめる) |
| `src/game/dynamic/surface-candidates.ts:89` | `into` は既に距離をスカラーで測っているので、`intervalReach` の書き換えだけで済む。参加者の `reach` を1度で求めていることを確認する |

非有限の扱いは `!(x <= y)` の否定形で書く — `x > y` と書くと NaN が絞り込みを素通りする
(`sphere-contact.ts:72-74` と同じ規則)。

### 達成条件と検証

- `npm run typecheck`、`npm run test:game`。
  **`tests/game/surface-candidates.test.ts`(総当たりとの一致)が通ることが、この手順の砦。**
  絞り込みが1体でも落とすと、判定器はそもそも呼ばれないので、判定器のテストでは見えない。
- 負荷確認ウィンドウで、着手前と着手後を**同じ条件で**控えて比べる(基準値は控えていないので、
  着手時に自分で採る)。条件は高負荷デバッグステージ(`DEBUG(高負荷)`、破片 500〜600)の
  最高倍率。「天体接触」が **60% 以下**、かつ `候補天体`(`surfaceCandidates`)が**同じ値**。

### リスクと落とし穴

| リスク | 影響 | 露見する場所 |
| --- | --- | --- |
| スカラー化で非有限の扱いが変わる | NaN が絞り込みを素通りし、判定器の側で落ちる | 比較を `!(x <= y)` の否定形で書く(`sphere-contact.ts:72-74` と同じ規則) |
| 展開した式で軸を取り違える | 落としてはいけない天体を落とす。判定器が呼ばれないので無言で当たらなくなる | `tests/game/surface-candidates.test.ts`(総当たりとの一致) |
| 効果を倍率 ×1 で測って「効かない」と誤判定する | 倍率 ×1 では −0.3 ms しか出ない。この手順が効くのは substep が増える高倍率 | 最高倍率で控える |
