# 実装される可能性のある機能(未決定)

**決定事項ではない。** ユーザーが「実装するかもしれない」と言及したものを、共通化・一般化の
判断材料として記録する場所。確定したものは `DEVELOP/SPEC/` の該当ファイルへ移し、可能性が
消えたら削除する。

判断に必要になったとき、ここに無いものはユーザーに問い、返答をここへ追記する。

- 恒星が2つ以上、相互に公転しあう連星系(`Ephemeris`/`primaryOf`/`starOf` は主星0または1つの
  星系のみ対応)。
- 3階層(恒星/惑星/衛星)を超える公転階層(衛星の衛星など)。
- 地球の大気圏熱管理・機体初期配置(`makeInitialState`)・エネミー生成式の、地球以外の天体への
  一般化。
- 静止軌道高度・太陽同期傾斜角プリセット、基地配置を月に限定するルールの、他天体への一般化。
- 小惑星帯・トロヤ群・ヒルダ群・カイパーベルト・散乱円盤の点群(`point-field.ts`/`point-field-view.ts`)の、任意レジストリへの対応。
- 小惑星帯の点群1点を、接近時に実体の `Asteroid` へ昇格させる LOD。
- 静止接触(resting contact)の安定化(摩擦・スリープ処理)。現状は撃力ベースの解決のみで、
  接地した物体がわずかな反発を繰り返しうる。
- 高ワープ中に再突入する艦を「待たない」こと。再突入域では刻みが 1 s まで細かくなり、この
  細分化はサブステップ数の上限に優先するので、最高ワープでは1フレームが数秒かかる。上限を
  効かせれば軽くなるが、加熱と動圧の積分結果が変わる = 艦が焼けるかどうかの結果が変わるので、
  性能ではなく仕様の判断になる。
- 大気を持つ天体の一般化。現状は地球のみが大気モデル(`atmosphere.ts`)を持ち、加熱・大気抵抗も
  地球にしか掛からない。
- 弾のダメージを、撃った武装のスペック値(`Part.damage`)から、剛体接触と同じ物理量(`Δv`/力積)へ
  置き換えること。ゲームバランス上の武器の意味とどう折り合いを付けるかは独立した判断が要る。
- 双曲線軌道のケプラー外挿(平均近点角→双曲線離心近点角のソルバ。順方向は `elements.ts` の
  `timeSincePeriapsis` に既にある)。
