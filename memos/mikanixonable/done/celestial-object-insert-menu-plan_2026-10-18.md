# 天体プロパティウィンドウから OBJECT INSERT パネルを開く項目 — 実装計画

## 目的

マップで天体を調べている最中に、その天体を周回する物体の配置へ直行したい。現状、物体配置
パネル(OBJECT INSERT)を開けるのは空域の右クリックコンテキストメニューからだけで、基準天体の
初期値はマップのフォーカス天体に依存する。天体のプロパティウィンドウの操作項目に
「その天体を周回する物体の配置」への入口を増やす。

**`DEVELOP/SPEC/GAME.md` §9.1「物体配置パネル」へ追記する文面**(「マップモード中のみ表示
される」の段落の直後):

> **開き方**: 空域の右クリックコンテキストメニューの「オブジェクトを配置」(MAP.md「クリックと
> ピック」)か、公転天体のプロパティウィンドウの操作項目から開く。天体のウィンドウから開いた
> ときは、その天体が基準天体として選ばれた軌道要素方式のフォームになる。基準天体に選べない種類
> (基地は月のみ)を選んでいたときは、その天体へ配置できる種類へ切り替わって開く。恒星は基準
> 天体になれないので、恒星のウィンドウにはこの項目を出さない。

## 決めたこと

| 決めたこと | 根拠 | 覆されたとき |
| --- | --- | --- |
| 恒星のウィンドウに項目を出さない | ユーザー回答。UI-DESIGN §3「恒久的に意味を持たない操作は表示しない」と GAME.md §9.1「恒星は周回の中心に選べない」の両方と一致 | 手順1の文面と、手順2の可否条件が変わる |
| 天体の項目から開くときは軌道要素方式へ切り替える | ユーザー回答。ラグランジュ方式が表示されたまま開くと、選んだ天体が見えるフォームに反映されず項目の約束を果たせない | 手順3から方式切替を外す |
| `open({ kind: 'body' })` プリセットの意味を「その天体を基準天体とする軌道要素フォームで開く」に確定し、種類がその天体を選べない(基地=月のみ)なら配置できる種類(既定戦闘船)へ戻してから基準天体を適用する | プリセットの意味を呼び出し経路で分岐させないため。この意味づけは空域メニュー経路(マップフォーカスを基準天体にする)にもそのまま乗る — そちらでも「フォーカス天体を選べる種類・方式へ揃えて開く」に揃う | 空域経路の挙動を変えたくないなら、プリセットへ別種別を増やす形に手順3を変える |
| act は既存の `'openObjectPlacer'` を再利用し、新しい MenuAction は増やさない | 操作は同じ「配置パネルを開く」で、変わるのは基準天体の与え方だけ | 手順2が MenuAction 追加+別経路の形に変わる |
| 項目ラベルは「周回する物体を配置」、ショートカットは付けない | 既存項目「オブジェクトを配置する」との並行。艦の「複製」などショートカットを持たない項目の例に倣う | 文面だけ変わる |

## 達成目標

- CREATIVE ステージのマップビューで、地球・月など公転天体のプロパティウィンドウの操作項目に
  「周回する物体を配置」が出る。
- その項目を選ぶと OBJECT INSERT パネルが、基準天体=その天体・配置方式=軌道要素の状態で開く。
- 太陽(恒星)のプロパティウィンドウにはこの項目が出ない。
- 戦闘ビュー、および配置機能を持たないステージではこの項目が出ない(従来どおり)。
- 空域のコンテキストメニュー「オブジェクトを配置する」は従来どおり、マップのフォーカス天体を
  基準天体にして開く(プリセットの意味確定で、フォーカス天体が選べない種類・ラグランジュ方式を
  選んでいた場合の開き方だけが揃う)。

## リスクと落とし穴

| リスク | 影響 | 露見する場所 |
| --- | --- | --- |
| 恒星のウィンドウに項目が残る | 選んでも基準天体が変わらず、項目が嘘をつく | 手順2 — `offeredItems` に恒星除外を畳み忘れると太陽の窓に出る |
| 種類=基地のとき基準天体プリセットが黙って無視される | 地球の窓から開いたのに基準天体が月のまま | 手順3 — 種類フォールバックを入れないと残る |
| ラグランジュ方式のまま開くと基準天体が見えない | 項目を選んだのに表示中フォームがその天体と無関係 | 手順3 — 方式切替を入れないと残る |
| 空域メニュー経路の開き方が変わる | フォーカス天体が選べない種類・ラグランジュ方式を選んでいた場合の開き方が揃う(意図した変更) | 手順3 — `'body'` プリセットへ乗せるため既存経路にも効く。「決めたこと」の表で合意を取る |
| 戦闘ビューや非 CREATIVE ステージで項目が出る | 配置パネルはマップの操作面なので出てはいけない | 手順2 — 既存の `authoring !== null` ゲートが防ぐ。条件を書き足すときにこのゲートを壊さない |
| `runAct` で `target.id` を無条件に渡す | 空域(id='empty')や艦の id がパネルへ届き、フォーカス由来の基準天体既定が失われる | 手順2 — `instanceof CelestialEntity` で絞ること |
