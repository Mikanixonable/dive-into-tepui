第2講：main.ts と Launcher
――起動・周回遷移・フレームループ

「ページ寿命で生きる装置」と「1ランで死ぬゲームモデル」の境界を明確に理解する。エントリーポイントから初期化シーケンス、周回オーケストレータ（Launcher）、そして requestAnimationFrame による毎フレームのループ駆動までを読み解く。

1. ページ寿命の装置 (PageDevices) と 1ラン (Run) の分離

src/main.ts はゲームルールを実装する場所ではありません。その本質は「工場の設備を組み立て、ラン（周回）へ貸し出す」ことです。

なぜこの分離が重要なのか？

もし Game クラスが WebGPU キャンバスの初期化やオーディオエンジンの管理まで持ってしまうと、ステージをやり直す（リトライする）たびに 3D キャンバスを再構築したり音声を再読み込みしなければならず、ロード時間が膨大になりメモリリークの温床となります。

Dive into Tepui では、「重い装置（ページ寿命）」は main.ts が一度だけ作り、何回リトライしてもそのまま再利用します。死んだりステージを切り替えるときは Run だけをポイと捨てて新しく作るため、一瞬でシームレスに再出撃できます。

2. 起動シーケンス：main() の非同期初期化

src/main.ts の main() は、画面にローディングオーバーレイを表示しながら、次の順番で初期化を進めます。 

async function main(): Promise<void> {
  // 1. 設定の復元と CSS カスタムプロパティ（テーマ）の適用
  const settings = new UserSettings(browserSettingStorage());
  applyThemeVariables(themePresetOf(settings.hudThemePreset.current));

  // 2. WebGPU キャンバスの生成と非同期初期化
  const gameScene = await initScene(settings.graphics.current);

  // 3. 各種 HUD、音声、セーブ管理装置の生成
  const hud = new Hud(new HudShell(), ...);
  const audioEngine = new AudioEngine();
  const saveSlots = await SaveSlots.create(new LocalStorageSaveStore());

  // 4. Launcher の構築
  const launcher = new Launcher(pageDevices, saveSlots, ...);

  // 5. URLパラメータやセーブ状況に応じた初期ステージの起動
  await launcher.launchInitialStage();

  // 6. 毎フレームの描画ループ（rAF）を開始
  startAnimationLoop(launcher, gameScene, settings, ...);
}

3. フレームループと「外部ポート」の交通整理

startAnimationLoop 内の animate(now) は、毎フレーム launcher.current（アクティブな Run）を呼び出します。

外部ポート（External Ports）の役割：
プレイヤーが「F5（クイックセーブ）」や「R（リトライ）」キーを押したとき、そのキー入力はゲーム内の自機操作ではなく「周回・セーブの制御」です。
run.frame() はゲーム側で消費されなかった入力エッジを外部ポートへ返し、SnapshotControls や Launcher が外側で安全に処理します。 
function animate(now: number) {
  const dt = (now - lastTime) / 1000;
  lastTime = now;

  const viewport = browserViewport();
  gameScene.syncFrame(viewport, settings.graphics.current, ...);

  const run = launcher.current;
  if (run === null) {
    requestAnimationFrame(animate); // 遷移中は待機
    return;
  }

  // 1フレームを回し、未消費の操作を外部ポートで受け取る
  run.frame(dt, now, viewport, [
    {
      feature: 'snapshot',
      commands: [gameCommand(K.manualSave.code), gameCommand(K.openSaveBrowser.code)],
      handleCommand: cmd => snapshotControls.handleCommand(cmd.id, run.snapshot),
    },
    {
      feature: 'launcher',
      isEnabled: () => !run.game.activeStage.isPlaying,
      commands: [gameCommand(K.restart.code)],
      handleCommand: cmd => launcher.handleCommand(cmd.id),
    },
  ]);

  requestAnimationFrame(animate);
}
