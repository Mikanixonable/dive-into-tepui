# 用語集

## ship

健全な `cockpit` を1個以上持つ、ユーザー向けの船体分類。`vessel` は一般文でのみ使い、正規のドメイン語にはしない。

## 物資

健全な `cockpit` を持たない接続グラフ。船と同じ物理・保存単位として漂流・ドッキングできるが、自身は操縦できない。

## cockpit

健全な状態で操縦能力を与える船体モジュール。cockpit が不健全または不在になっても、残ったモジュールは物資として存続する。
_Avoid_: command（船体モジュール名として）

## thruster

主推進を担う船体モジュール。旧称・同義語の `engine` は船体モジュール名として使用しない。
_Avoid_: engine（船体モジュール名として）

## booster

タンクを持たず、固体燃料を内部に持つノズル付き円筒モジュール。点火後は停止・再点火せず、燃料切れまで燃焼する。役割名ではなく部品名である。

## ShipAssembly

モジュールと接続 edge からなる一つの接続グラフ。船と物資の物理・保存単位を共通に表す。

## module definition / module instance

`module definition` はカタログの設計定義、`module instance` は船体へ取り付けられた個体。HP、燃料、点火などの可変状態は個体が持つ。

## command

船体モジュール名としては使用しない。`flight command` など、入力された操縦命令を指す一般語としてのみ使用する。
