# 環境光暗部彩度抑制 LUT 要件・実装計画

## 目的

環境光を有効にしたとき、地球の夜側・影側で環境光によって見えるようになった大陸の彩度が高く
見えすぎる問題を解消する。

環境光そのものは照明として正しく加え続ける。彩度を下げる処理は物理ライティング、地球の材質、
影の計算へ混ぜず、トーンマッピング後の全画面色へ適用する視覚効果 LUT レイヤーとして扱う。

## 結論

次の構成を採用する。

```text
HDR の物理ライティング
  └─ 環境光を含む
      ↓
レンズ効果
      ↓
露出・トーンマッピング
      ↓
既存のフィルム LUT
      ↓
視覚効果 LUT: 低明度域の彩度抑制
      ↓
3D UI オーバーレイ
      ↓
アンチエイリアス・画面出力
```

つまり、環境光は `LightPrepass` の照明寄与として残し、暗部の色の見え方だけを後段の LUT レイヤーで
調整する。地球だけを識別するマスクや、影パスの透過率を使った特別扱いは行わない。

## 要件

### R1. 環境光の物理寄与を変更しない

- 環境光は、現在の環境光設定とビューごとの強さに従って、従来どおり全ての面へ加える。
- 環境光の強さ、減衰、影によって遮られない性質、環境光の無彩色という性質は変更しない。
- 地球表面のアルベド、地表テクスチャ、法線、影パス、照明プリパスの計算へ、彩度抑制の係数を追加
  しない。
- 「環境光を弱めて大陸をくすませる」実装は採用しない。明るさと色の物理寄与は維持し、表示段だけ
  で色を変える。

### R2. 視覚効果 LUT を独立したレイヤーとして適用する

- 既存のフィルム LUT と、今回の暗部彩度抑制 LUT は別のレイヤーとして管理する。
- フィルム LUT の選択肢へ、暗部彩度抑制用 LUT を表示しない。これは利用者が選ぶフィルムのルック
  ではなく、環境光使用時の表示補正である。
- 視覚効果 LUT は写実表示の通常出力へ適用する。模式図表示、3D UI オーバーレイ、HUD の DOM は
  対象外とする。
- 既存のフィルム LUT が「なし」の場合も、環境光が有効なら視覚効果 LUT は独立して機能する。

### R3. 暗部だけを一括して彩度抑制する

視覚効果 LUT の入力は、露出・トーンマッピング・既存のフィルム LUT を通過した作業色空間の RGB と
する。RGB から Rec.709 輝度 `Y` を求め、次のカーブで彩度を調整する。

- `Y <= 0.12`: 彩度を元の 50% まで下げる。
- `0.12 < Y < 0.30`: 彩度抑制量を滑らかに 50% から 0% へ戻す。
- `Y >= 0.30`: 彩度を変更しない。
- 彩度は RGB をその輝度 `Y` の無彩色へ補間して下げる。彩度抑制によって輝度を意図的に増減
  させない。
- 黒へ近づくほど特定の色相を残すのではなく、暗部は中性の灰色へ近づく。

上記は初期採用値である。目的は、環境光で持ち上がった地表の暗部に残る強い海・陸・氷の色を
抑えつつ、昼側と中間調の地表色を維持することにある。

### R4. 環境光の ON/OFF と効果を連動させる

- マップビューで環境光が OFF のとき、視覚効果 LUT は恒等変換として振る舞う。
- 戦闘ビューで環境光が OFF のときも、視覚効果 LUT は恒等変換として振る舞う。
- 環境光が ON のときは、地球に限らず、最終画像内の `Y < 0.30` の物理量へ同じ彩度抑制を適用する。
- 地球・大陸・影の種類を条件にしない。これにより、暗部を個別の物体分岐で増やさず「低明度部分を
  一括で扱う」という要件を満たす。
- ビュー切り替え、環境光設定の変更、時間経過で、効果の適用状態が不連続にちらつかない。

### R5. フィルム LUT との順序を固定する

- 暗部彩度抑制は、トーンマッピングと既存のフィルム LUT の後に適用する。
- これにより「低明度」は、露出補正・トーンマッピング・選択中のフィルムルックを通過した後に画面へ
  出る明度を意味する。
- 彩度抑制の後にフィルム LUT を通して、フィルム LUT が暗部の彩度を再び持ち上げる構成は採用しない。
- トーンマッピング前の HDR 値へ彩度抑制を掛ける構成も採用しない。露出や場所によって暗部の判定が
  変わり、今回の表示上の問題を安定して抑えられないためである。

### R6. 3D UI と HUD の色を変えない

- 軌道線、軌跡線、天球グリッド、縮尺グリッド、Δv ギズモなど、合成後に描く 3D UI は彩度抑制を受け
  ない。
- HUD の文字、マーカー、パネル、設定画面の色も変えない。
- 物理量の暗部だけがくすみ、操作・識別のための表示値の色は従来どおり読めること。

### R7. 既存設定へ新しい品質項目を追加しない

- 暗部彩度抑制は、今回の表示上の不自然さを解消するための固定された視覚効果であり、描画品質設定の
  ON/OFF 項目にはしない。
- 新しい設定項目を増やさず、環境光の有効状態から効果の適用状態を決める。
- 既存の「フィルムのルック」の選択肢、保存値、品質プリセットは変更しない。

### R8. 表示の連続性を保つ

- `Y=0.12` と `Y=0.30` の境界で段差、バンディング、明滅が見えない。
- 環境光の ON/OFF を切り替えたとき、暗部の色は連続的に切り替わり、明度が飛ばない。
- 明るい昼側、中間調、鏡面反射、発光、レンズ効果のハイライトを、暗部彩度抑制の副作用で白く潰さ
  ない。

## 実装方針

### 1. LUT の共通基盤とレイヤー分類を分離する

現在の LUT 実装は、`assets/luts/*.cube` をフィルムルックの候補として収集し、合成段の色へ 1 本の
3D LUT を適用している。これを複数用途の LUT を扱える構成へ拡張する。

- フィルム LUT と視覚効果 LUT が同じ 3D LUT 読み込み・サンプリング処理を共有する。
- フィルム LUT は既存どおり設定から選択する。
- 視覚効果 LUT は専用の固定レイヤーとして組み込む。
- レイヤーの切り替えで合成マテリアルを毎回再構築しない。テクスチャ参照、適用量、環境光有効状態を
  ユニフォームで更新する。
- 視覚効果 LUT のデータはフィルム LUT と別のアセット分類へ置き、フィルム LUT の UI 候補へ混入させ
  ない。

### 2. 暗部彩度抑制 LUT を用意する

- R3 のカーブを満たす 3D LUT アセットを追加する。
- 暗部の滑らかな遷移を保つため、既存 LUT の格子数に依存せず、暗部の変化が階段状に見えない格子密度
  で生成する。
- LUT の生成元となる変換規則は再生成可能な形で保ち、手作業で個別の格子点を修正しない。
- LUT の入力・出力は現在の合成段が使う作業色空間に揃える。画面出力時の色空間変換を LUT の前後で
  二重に適用しない。

### 3. 通常出力の両経路へ同じ効果を適用する

- レンズ効果 OFF の通常合成と、レンズ効果 ON の通常合成の双方に視覚効果 LUT を組み込む。
- どちらの経路でも、HDR の物理画像へ直接掛けず、トーンマッピング済みかつフィルム LUT 済みの色へ
  掛ける。
- デバッグ表示の中間ターゲットは、既存の「中間結果をそのまま見る」という意味を変えない。必要なら
  視覚効果適用前後を比較できる開発用表示を追加するが、通常の表示値や HUD の仕様へ影響させない。

### 4. 適用量を環境光の状態から供給する

- 環境光の ON/OFF は、マップビュー／戦闘ビューで実際に環境光を加える状態と同じ正本から供給する。
- ON では視覚効果 LUT の適用量を 1、OFF では 0 とする。
- ビュー切り替えで環境光の状態が変わる場合も、既存の毎フレーム同期経路から適用量を更新する。
- この状態変更でシェーダーを再コンパイルしない。

## SPEC へ反映する内容

実装承認後、コードより先に `DEVELOP/SPEC/RENDERING.md` を単独で更新する。

- 「描画パイプライン」の合成段へ、トーンマッピング後にフィルム LUT、その後に環境光連動の視覚効果
  LUT を適用することを追加する。
- 「露出とトーン」へ、環境光を有効にした写実表示では低明度域の彩度を表示上の例外として抑制すること
  を追加する。明るさを決める物理照明は変更しないことも併記する。
- 「描画品質設定」へ、新しい ON/OFF 項目を追加せず、環境光の状態に連動する固定の視覚効果であること
  を追加する。
- 既存の「中間調の色相・彩度はそのまま保つ」という規則は維持し、今回の例外が低明度域に限定される
  ことを明記する。

## 達成条件

### 自動検証

- LUT パーサーが既存のフィルム LUT と新しい視覚効果 LUT の双方を読み込める。
- フィルム LUT の設定候補へ視覚効果 LUT が現れない。
- 視覚効果 LUT の R3 の変換規則を、黒、暗部、遷移域、中間調、白、原色に近い色の固定サンプルで検査
  できる。
- 環境光 OFF では視覚効果レイヤーが恒等変換となる。
- 環境光 ON では低明度域だけが変化し、`Y >= 0.30` のサンプルが変化しない。
- `npm run typecheck` が通る。
- `npm run test:render` が通る。

### 目視検証

`npm run render-lab:shot` または `npm run dev` で、同じカメラ・同じ時刻について次を比較する。

1. マップビューで環境光 OFF / ON。
2. 戦闘ビューで環境光 OFF / ON。
3. フィルム LUT「なし」および既存フィルム LUT 選択時。

確認する内容は次のとおり。

- 環境光 ON で、地球の夜側・影側の大陸が元の色相を残しながら彩度だけ落ち、灰色寄りに見える。
- 環境光 ON でも、地球の暗部の輪郭・地理模様・明るさは失われない。
- 昼側と中間調の海・陸・氷の彩度は変わらない。
- 地球以外の低明度の物理量にも同じ処理が掛かる。地球専用の不自然な境界が現れない。
- 軌道線、マーカー、グリッド、HUD の色は変わらない。
- フィルム LUT の選択を変えても視覚効果 LUT が無効化されたり、暗部彩度が再び過剰になったりしない。
- 環境光設定とビューを切り替えたとき、画面がちらつかず、明度が跳ねない。

## 不採用案

### 環境光の強さ自体を下げる

不採用。環境光は暗部の形状を読ませるための照明として必要であり、強さを下げると今回の彩度問題と
引き換えに大陸の可読性まで失うため。

### 地球または影パスだけへ彩度係数を掛ける

不採用。表示層で解決できる問題を地球材質・影・照明の各経路へ分散させ、同じ見え方を得るための分岐を
増やすため。また、低明度の他の物理量との見え方が不統一になる。

### 彩度抑制用の新しい描画品質設定を追加する

不採用。切り替えによる性能差を選ばせる機能ではなく、環境光を有効にした場合の表示方針であるため。

### トーンマッピング前に LUT を適用する

不採用。HDR の明るさ、露出補正、場所による順応の影響を受け、画面上の「低明度部分」を安定して定義
できないため。

## 実装前に確認する判断

今回の要求には彩度を何%まで下げるかの指定がないため、本文では初期採用値を `50% / Y=0.12〜0.30`
としている。この値で目視した結果が強すぎる、または弱すぎる場合は、SPEC 更新前にこの値だけを合意
し直す。物理ライティングを変更するか、地球専用マスクを導入するかという方針は変更しない。
