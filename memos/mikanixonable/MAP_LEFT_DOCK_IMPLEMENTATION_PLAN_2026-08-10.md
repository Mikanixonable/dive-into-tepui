# マップビュー左ドック UX 改修 実装計画書

作成日: 2026-08-10  
対象: マップビュー左部の「表示」「PREDICT」「MAP VIEW」「座標系」および左ドック共通操作  
目的: 各機能を独立に採否判断できるエピック／チケットへ分解し、実装順序・依存関係・完了条件を明確にする。

## 採否・見積もりの記法

- 採否: `[ ] 未決` / `[x] 採用` / `[-] 保留` / `[!] 不採用`
- 規模: `XS`（半日以下）/ `S`（1日前後）/ `M`（2～4日）/ `L`（1週間前後）/ `XL`（複数週）
- 優先度: `P0`（快適性の土台）/ `P1`（直感性・楽しさ）/ `P2`（発展）
- チケット番号は安定した参照IDとし、廃止・統合しても再利用しない。
- 見積もりは実装可否を比較するための相対値。着手前に対象コードを再確認して確定する。

## 推奨リリース順

### Release A: 分かりやすさの土台

- MAP-001～006: 左ドック再編・個別折り畳み
- MAP-201～202: マップレイヤーへの改名と列見出し
- MAP-301～305, MAP-307, MAP-309～310, MAP-313: タイムスコープの基本
- MAP-501～505: 座標系プリセットと詳細設定
- MAP-801～803, MAP-807: 操作性・レスポンシブ

リリース判定: 初見プレイヤーがヘルプを開かず「未来を見る」と「ワープする」を区別できる。

### Release B: 計画結果を理解する

- MAP-102～104, MAP-203～206: ガイド／レイヤープリセット
- MAP-306, MAP-308, MAP-311～312: 時刻入力・未来比較
- MAP-401～404, MAP-409: 基本イベントタイムライン
- MAP-506～509, MAP-511: 座標系の説明・状態表示・復帰
- MAP-607: 自動ワープ進行表示

リリース判定: ノード操作の結果と最接近時刻を、マップ内の情報だけで比較・確認できる。

### Release C: 危険予測とゲームフィール

- MAP-105～106, MAP-207～208: 縮尺案内・探索表示
- MAP-405～408: 食・SOI・危険イベント・相対入力
- MAP-510: 座標系3D可視化
- MAP-601～606: チュートリアル・演出・探索カード
- MAP-804～806, MAP-808: 保存・履歴・検証・性能

リリース判定: マップで次の出来事を発見でき、危険を理解したうえで計画を実行できる。
