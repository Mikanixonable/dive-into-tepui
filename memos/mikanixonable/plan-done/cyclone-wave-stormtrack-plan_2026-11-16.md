# 低気圧・高気圧の配置を気候統計と偏西風の蛇行へ合わせる — 計画書(2026-11-16)

低気圧の配置と動きを「データに基づいてより正確な数・位置・動き・ばらつき」にする要求から
出発し、R2 提案(移動を基本流へ整合、feat/wave-train の復元)を批判的に検証したうえで、
偏西風の蛇行と低・高気圧を一つの系として再構成する計画。

仕様は `DEVELOP/SPEC/RENDERING.md`「雲の描画」へ反映済み(作業ブランチ上、commit 前)。

## 背景と経緯

- 現行: 中緯度は 8 枡(半球 4)で経度ほぼ一様・各枡 7 日周期で自律再生。熱帯低気圧は
  全球 1 個・14 日周期・6 本の固定進路を巡回。偏西風の蛇行(rossby-wave)とは無関係。
- `feat/wave-train`(d2ab3309e で main 入り、21dc2a7f1 で巻き戻し)がやっていたこと:
  低気圧の発生経度を波の谷+下流 25° へ錨づけ、一生のあいだ波の位相速度(3°/日)で
  東へ運ぶ。高気圧は尾根(谷+半波長)+下流 25° に同じ錨で配置。谷の間隔が 90→72° に
  狭まったことへの対応として、深い谷が浅い谷を呑む「吸収則」あり。
- revert はこの機構の失敗ではなく「ブランチ全体の雲が main より不自然」という大域
  巻き戻しの巻き添え。**単独では一度も検証されていない。**
- 先行設計メモ: `cloud-circulation-redesign_2026-11-15.md` 第 3 弾(波列)が原案。
  本計画はそれを気候統計で肉付けし、ストームトラックの地理的偏りと両立させる。

## R2 提案の検証結果

採用: 谷への錨づけ + 波ドリフト(気象学的に正しい・計測済み)、空の谷の巡回
(数のばらつきを機構から得る)、吸収則(近接が増えるので必須・実際の併合に対応)、
高気圧の実体(交互配置・気圧場の均衡・晴れ間)。

修正して採用: 海域への絞り込みは錨の上に「海域ゲート」として載せる(旧実装は全球の谷へ
一様に錨づけていた = 発生海域の偏りと矛盾)。南北半球の位相を独立化(同一経度で両半球の
谷が揃うのは気象学的に誤り)。

留意: 「移動速度=上層風+位相速度」は旧実装でも近似(自力+ドリフト)。操縦流 ~10-14 m/s
に乗るよう速さを再調整する。「復元コストは低い」は半分 — `anticyclone-*` は削除済み、
`cyclone-tracks.ts` も進化済みなので再構成になる。

## 導出構造のレビュー(2026-11-16 再検証)

「大きな構造が先、小さな構造が後に導かれる」連鎖で点検した。

| 段 | 構造 | 連鎖の評価 |
| --- | --- | --- |
| 0 | 気候(海陸・地形) | 発生海域を固定帯として与えるのは「境界条件」であり導出ではない。気象学的には海陸対比とチベット高原・ロッキー由来の定常波がストームトラックの位置を決める(Wilson, JAS)。完全な導出は今回の範囲外として、一段上げる余地を下記に示す |
| 1 | 偏西風の蛇行 | 現計画は振幅が経度一様。実際はトラック上で渦動ジェットが強く蛇行も大きい → 振幅を経度変調すれば「発生海域」は振幅の大きい所として波自体から導出できる |
| 2 | 気圧配置 | 谷+下流(低気圧)・尾根+下流(高気圧)の錨づけで波から導かれる。群発は「強いジェットが張り続ける期間に同じトラフ上へ連続発生」が実体 — 2 次低気圧は群発日の約 50%(Priestley)。枡→固有の谷の巡回割当では同じ谷に連続して生まれないので、家族は出ない |
| 3 | 前線 | 気圧場からの圧縮の診断(既存)で導出済み。波→低気圧→圧縮→帯の連鎖がつながる |
| 4 | 北上 | トラックの北東傾斜(チベット由来の定常波列)の結果。海域ごとに傾きが違うので、全低気圧で一様のターン割合ではなくトラック軸から決めるべき |
| 5 | 消滅 | トラック軸の終端(太平洋湾奥・欧州/高緯度・南極縁)として導出 |

## 根拠とする気候統計

### 中緯度(温帯低気圧)

- 発生は経度一様ではない — 北半球は大陸東岸沖(北西太平洋・北大西洋西岸)に集中、
  南半球は南大西洋〜南インド洋を源に南極へらせん状に延びる帯(Hoskins & Hodges 系)。
- 寿命: 中央値 ~4.5 日、幅 2〜10 日(SH では 1 日超の系の平均 3 日強)。
- 移動速度: 平均 10〜15 m/s、南半球はやや速く 16〜20 m/s に達するものも。冬季の
  北大西洋では 40 m/s 級の急行もある。操縦流は深層(1000-500 hPa 級)の平均風。
- 同時存在数: 半球あたり活発な低気圧は数個で増減(NH 冬季の発生ペース ~1.3/日 ×
  寿命 ~4.5 日 ≒ 同時 6 個前後が上限側)。
- 深さ: 弱い系が多く深い爆弾低気圧はまれ(右裾の長い分布)。
- 地表低気圧は上層の谷の下流側で発達する — 旧実装の「谷+25°」はこれに対応。
- 群発(serial clustering): 強く直線的なジェットが数日張り続ける間に同じ海域へ
  低気圧が連続して発生・通過する。群発日の増分の約半分は 2 次低気圧(親の前線上に
  発生する後続の低気圧)が担う。

### 前線まわりの雲域・閉塞ライフサイクル

- 閉塞の形は 2 系統 — ノルウェー型(寒冷前線が温暖前線に追いつき暖域が狭まる)と
  Shapiro-Keyser 型(寒冷前線が T 字に折れ、温暖前線が芯へ巻き付いて暖核を隔離)。
  海洋性・急速発達型は後者が多い。**終端は共通**: 暖域の舌が芯から切り離され、
  乾いた舌が巻き込んで雲はコンマ型へ。
- 雲量の非対称(衛星合成・Naud/Govekar): 前線帯と暖域・コンマの頭は被覆率高い
  (~90% 級)。寒冷前線の後側は低くて千切れた雲 — 細胞状対流で**閉じた細胞 ~90%、
  開いた細胞 ~51%、乱れた細胞 ~40%**。前線帯から寒気側へ雲量が急落する。
- 寒気噴出(MCAO): 寒気が暖かい海面上を流れると細胞状対流が発達し、閉じた細胞から
  開いた細胞へは**海上の流路距離(fetch)で移行**。開いた細胞は南大洋で世界最多 —
  SH の寒気側で特に出る。
- 閉塞の時期: 低気圧の深さが最深へ達する頃に始まり、その後に埋まる — 深さカーブの
  ピーク以降を閉塞段として扱える。
- 既存資産: air-mass.ts の気団追跡が warmth(暖気/寒気の流入)と compression(前線)を
  流れから導出済み。revert で消えた cycloneFront/drySlot/coldSector は低気圧従属の
  スタンプだった — 今回は**診断から導出**する形へ再構成する(下記設計)。

### 熱帯低気圧(IBTrACS 1981-2010 平均・熱帯暴風以上)

- 全球で年 ~85 個。海域別: 西太平洋 25・東太平洋 16.5・北大西洋 12・南インド洋 8.4・
  豪州/南太平洋 8・北インド洋 3.9 — 西太平洋が最多、北インド洋が最少。
- 平均同時存在 ≒ 1.6 個(年数 × 平均寿命 ~7 日 / 365)。0 の期間も 3 個以上並ぶ期間も。
- 転向率は海域で違う — 東太平洋は転向せず西へ走って冷たい海で消えるものが多い、
  西太平洋・北大西洋は転向が多い。

## 設計

### rossby-wave.ts

- `WAVE_NUMBER`・`WAVE_PHASE_SPEED`・`waveTroughLongitude(index, seconds, hemisphere)` を
  export(旧実装と同じ形)。
- **半球で独立の位相** — 包絡が熱帯(立ち上がり 10〜35°)で消えることを利用し、
  南北で位相オフセットを持たせる。熱帯では波が見えないので継ぎ目は出ない。
  両半球で同じ進行方向(東)・同じ波数のまま、位相と(必要なら)位相速度だけ分ける。
- **振幅を経度方向へ変調** — 実際の渦動ジェットはストームトラック上で強く、
  蛇行の振幅も海域で大きい。包絡へ経度の重み(発生候補となる海域で大きく)を掛ける。
  これにより「発生海域」は振幅の大きい所として波自身から導出される — 固定帯を
  別途持たなくて済む一段上の導出構造。

### cyclone-tracks.ts(中緯度)

- **発生は谷の振幅で決める**: 枡→谷の錨づけは維持(谷の数 > 枡数で空の谷が巡る)。
  その世代で谷の下流点の振幅が門を超えていれば誕生 — 波の経度変調と組み合わせて
  「海域でしか発達しない」を機構として作る。固定の海域帯をゲートとして別に持たない。
- **低気圧の家族(2 次低気圧)**: 同じ海域に連続して生まれる姿を出す。実装は
  枡内に複数の onset を許す(親の消散後に同じトラフが海域内に残っていれば後続が
  生まれる)か、誕生時に「後続を連れてくる確率」を持たせる。群発日の約半分を
  2 次低気圧が担うという観測に沿う。
- **移動 = 自力 + 波ドリフト**: 進路の東進成分に波の位相速度を足す。合計が
  10〜15 m/s(SH はやや速め)に乗るよう自力成分を調整。波より速いので一生のうちに
  谷を追い越していく(実際の低気圧も波の位相を横断する)。
- **北上の傾きはトラック軸から**: 太平洋・大西洋トラックの北東傾斜(定常波列由来)は
  海域ごとに違う。ターンの形状を一様な割合ではなく発生海域のトラック軸の傾きから
  決める。消える場所も同じ軸の終端(湾奥・欧州・南極縁)として導出する。
- **吸収則**: 同じ半球の谷どうしが半径の和へ近づいたら、深い側が残り浅い側の
  深さを近さで削る(旧実装の式を踏襲: 半径和の 1.3 倍から 0.85 倍でフェード)。
- **分布**: 寿命は右裾の長い幅(数日〜10 日ほど)、深さは右裾の長い分布
  (弱い系が多く深い系はまれ)、速さ・生まれ緯度もばらつきを持つ。

### 前線と被覆度の非対称(weather-model.ts / air-mass.ts)

「雲の被覆度として表す」— 帯を描くのではなく、気団診断から被覆率へ伝える設計。

- **寒気側の細胞域は warmth 診断から導出**(coldSector スタンプの代替): warmth < 0
  (寒気の流入)かつ海上の点で地表湿度を底上げし、雲は粒状のまま残す。寒気が暖かい
  海を渡って湿る MCAO の機構そのままで、低気圧従属でなく流れ全体に効く — 東アジア
  の季節風噴出の雲街も副産物として出るはず。
- **細胞の開きは fetch で**: 追跡履歴から「寒気が海上を流れた距離」を推し、
  近い所は閉じた細胞(高被覆・均一)、遠い所は開いた細胞(中程度被覆・網目)へ移す。
  air-mass の追跡に海上滞在の履歴を足す形。
- **閉塞段の構造**: 低気圧の深さカーブのピーク以降を閉塞段とし、(a) 暖域の舌を
  芯から切り離す(芯まわりで warmth の底上げを止める)、(b) 乾いた舌を巻き込む側
  (赤道側〜下流側)から差し込み被覆率を削る(drySlot を lifecycle 連動で復元)、
  (c) コンマの頭(芯の極側の広い層状域)を深さ連動で維持する。
- **閉塞の 2 系統**: ノルウェー型(追いつき型)と Shapiro-Keyser 型(T字骨折・巻き付き)
  は終端が共通なので、まず終端構造(暖域切り離し + 乾いた舌 + コンマ頭)を作り、
  系統の違いは巻きの形の差として後から足せる。

### anticyclone-tracks.ts / anticyclones.ts(新設・旧実装を再構成)

- 高気圧は尾根(谷+半波長)+下流側へ錨づけ、同じ波ドリフトで運ぶ。
- 低気圧より遅く(1.5〜5 m/s)、長命(7〜12 日)、浅く(6〜14 hPa)広く(800〜1200 km)。
  正の深さ → 気圧場で盛り上がり → 沈降 → 晴れ間。
- `Trough` の実体を正の深さで再利用(旧実装と同じく `pressureAt` の符号を戻す形)。

### 熱帯低気圧

- **複数同時存在**: 海域別の発生頻度(西太平洋最多・北インド洋最少)を重みとして、
  世代ごとに発生するか・どの海域かを乱数で引く。同時存在数は 0〜複数でばらつく。
- **進路**: 海域ごとに転向型と西進直進型の割合を持つ。現行の 6 本コースを雛形に
  海域・型を増やすか、コースを生成する形へ。
- 時刻→配置は引き続き世代ごとの乱数の閉じた関数。

## 実装手順(案)

1. rossby-wave.ts: export と半球別位相(継ぎ目の無い範囲で)+ 振幅の経度変調。
2. cyclone-tracks.ts: 中緯度の枡を谷錨+振幅門へ再構成、ドリフト・吸収則・
   トラック軸由来のターン傾き・分布の再調整。家族(2 次低気圧)の機構を足す。
3. anticyclone-tracks.ts + anticyclones.ts: 新設。Trough の共有形へ整える。
4. weather-model.ts: Highs を気圧場へ組み込み。
5. 前線・被覆度: 寒気側細胞域を warmth 診断から導出(海上滞在履歴=fetch を
   air-mass の追跡へ追加)、閉塞段の乾いた舌・暖域切り離しを lifecycle 連動で。
6. 熱帯: 複数同時存在 + 海域別頻度・進路割合。
7. 検証: `npm run typecheck`、`npm run test:render`、cloud-lab の天気図・
   動き計測・比較で確認(低・高の蛇行への従属、海域別の発生分布、同時存在数の
   増減、家族・併合、寒冷前線前後の雲量勾配 ~90%→40-60%、閉塞段のコンマ型、
   熱帯のばらつき)。

## 未決・検討メモ

- 波数・位相速度(現行 k=5・3°/日)は据え置くか。k=6-7 にすると谷間隔が狭まり
  発生海域への同時入りが増える。波そのものの振幅・停滞・逆行(実際のブロッキング)
  は今回の対象外。
- 熱帯低気圧の温帯移行時に波の谷へ編入(転向後の進路を谷へ吸収)させるかは
  今回の対象外 — SPEC「温帯の気団へ接続した後には前線を伴いうる」の範囲で済ませる。
