# 雲の生成基盤の構造とフィードバックループの現況

(2026-11-15 時点、devin/dev。最新はコードが原本 — ここは入口の説明)

## 構造(1000字程度)

生成は気象モデル→雲量場→細部の 3 段。

**気象モデル(src/render/cloud/weather-model.ts 系)**: 気圧場を「大域ノイズ 3 オクターブ
+ 低気圧の実体(温帯 8 個・熱帯 1 個、誕生〜移動〜消滅の一生を持つ)」で組み立て、
勾配から平衡風(上層は別の摩擦・ゲイン、エクマン層の回り込み、尾根差し引き)を出す。
風・気団の追跡(air-mass)で湿度・温度勾配と圧縮を測り、上昇流(大域の谷＋中規模ノイズ＋
前線・地形項)を立てる。そこから雲量(積雲・巻雲)・上層風・対流活動を場として出し、
テクスチャ 2 枚へ焼いて表示時刻で補間する。**高気圧は実体が無く**、気圧ノイズの正側が
沈降として効くだけ。前線も「この低気圧の温暖/寒冷前線」ではなく気団圧縮の診断的な帯。

**描画(src/render/cloud/cloud-detail.ts)**: 焼かれた雲量へ細部乗数を掛ける
(広い尺度の濃さは変えない — SPEC の原則)。巻雲は筋状・鱗雲状・薄く広がる・金床の
4 型を、数百 km の静的領域ノイズとジェット(上層風速)で配分し、繊維は流れ方向へ
伸ばして読む。積雲は細胞・雲列・対流の塊を環境(陸・風・対流)で混ぜる。

**フィードバックでいじるもの**: 気象側は風則・上昇流・湿度・雲量写像の係数と
ノイズ構成(オクターブ・エンベロープ)、低気圧の数・進路・深さ。描画側は型の重み・
伸ばし率・波長・間欠性。評価は実写との分布距離で、視覚の違和感は直接実装しない。

## ユーザーの基盤見直し(2026-11-15、進行中)

「晴れ間が少ない・1000-5000 km の帯状構造が少ない・中緯度一周 7 個の低気圧+前線が
見えない」→ 生成を**ハドレー(熱帯)・フェレル(中緯度)・極の三循環**で責務分けする
方向を検討中。判明している空隙: 高気圧の実体、低気圧に従属する前線、熱帯の
中規模対流クラスタ(500 km・湿度を消費して発達・衰退する実体)。
