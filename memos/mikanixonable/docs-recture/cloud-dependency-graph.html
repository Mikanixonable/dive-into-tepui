雲の生成・描画 — 値の依存グラフ

ドラッグ: 移動 / ホイール: ズーム / クリック: 詳細
パイプライン: すべての値は 天体固定の単位方向 direction と 表示時刻 seconds の閉じた関数(同じ時刻には同じ空が出る)。 direction・seconds はほぼ全ノードへ入るため、グラフでは主要な依存先のみ辺を引いている。 矢印 A → B は「B は A から計算される(B が A に依存)」。
① 気候・地形入力→ ② 気圧場を焼く→ ③ 風場(釣り合い+大循環+地形)→ ④ 気団追跡・湿度輸送を焼く→ ⑤ WeatherSample 診断合成→ ⑥ 凝結 condense → CloudSample→ ⑦ 雲場テクスチャ(2枚 blend)→ ⑧ cap サンプリング→ ⑨ 形状・細部評価→ ⑩ 不透明殻 / 大気殻 / 影へ合成
ノードをクリックすると、その値が何に依存しているか(入力)と、 どこへ使われているか(出力)をここに表示します。
