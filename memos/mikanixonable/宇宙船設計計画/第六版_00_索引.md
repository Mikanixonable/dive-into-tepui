# 宇宙船設計計画 第六版 — 索引

宇宙船の設計・推進・多段化・資源進行に関する実装計画を4巻に分けて置く。各巻はそれ単体で読んで実装に入れるように書いてある。この索引は、どの巻が何を扱い、どの順に着手するか、および計画の点検で挙がった事項をどう解決したかを示す。

## 各巻の範囲

| 巻 | ファイル | 扱うもの | 依存 |
|---|---|---|---|
| 第1巻 | `第六版_1_推進系と推進剤.md` | 艦艇と基地を統合した `Vessel`、搭載要素の型と性能値、主機／並進RCS／フライホイール／磁気トルカの4系統、任意配置のアクチュエータに対するトルク配分、重力傾斜トルク、推進剤の物性表、エンジンのサイクル、ツィオルコフスキーによる燃焼計算 | なし |
| 第2巻 | `第六版_2_船体設計システム.md` | 断面の幾何、背骨とロフトによる外皮、形状からの質量特性の導出、カプセルによる接触形状、姿勢依存の空力、搭載要素の配置と内容積、設計の保存・検証・生産、設計エディタ | 第1巻 |
| 第3巻 | `第六版_3_配管・多段・ペイロード.md` | 分離機構と多段、ペイロードの軌道投入、配管による推進剤の流路と自動敷設、タンクの与圧とイナートガス、弾薬の供給 | 第1巻・第2巻 |
| 第4巻 | `第六版_4_資源と推進の進化.md` | 元素と産地、設備の連鎖、Δv による到達可能性、大気制動、化学推進から核熱・電気推進を経て核融合に至る道筋 | 第1巻・第2巻 |

## 依存と着手順

```
第1巻 ──────────────► 第2巻 ──────┬──► 第3巻
   │                              │
   └──────────────────────────────┴──► 第4巻
```

**第2巻の §3・§5・§6（断面と立体の幾何）は依存がゼロである。**`src/physics/` に閉じた純関数とテストのみであり、ゲームに一切繋がない。この計画全体で最大の未知は「複合断面と一般化角錐台の物理量が閉形式で求まるか」であり、ここが崩れると第2巻の設計思想ごと組み直しになる。失敗しても捨てる費用がゼロであるため、第1巻と並行して真っ先に着手する。

**第4巻の §3・§5（元素・産地・設備のデータ定義）と §8-2（生産可能性の判定）も依存がない。**純粋なデータと純関数であり、早期に着手できる。

**第1巻の `Vessel` 統合は最初に通す。**第2巻も第3巻も同じクラス群（`ship.ts` / `player.ts` / `base.ts`）を書き換えるため、統合を後回しにすると同じ変更を複数回書くことになる。

## 進行の仕組み

**技術ツリーは存在しない。**研究点も、前提技術の木も、解禁の状態も実装しない。使える推進剤・エンジン・構造材は、手に入れた資源と、それを変換する設備の連鎖によって広がる。設計は常に自由に作れ、保存でき、制約を受けるのは生産だけである。詳細は第4巻にある。

生産に必要なのは**資源・設備・電力**であり、通貨は使わない。通貨は基地の市場での資源の売買にのみ用いる。

## 対象外

月面着陸、月面地形、月面基地、資源採掘の実装そのもの、ドッキングポートによる機体の結合は、実装費用が大きいため4巻には含めない。設計は `延期_月面着陸・月面基地・資源採掘・ドッキング.md` にある。

第4巻の資源進行は、これらの完了を待たずに前半が成立する。大気捕集による産地は着陸を必要としないためである。

## 計画の点検で挙がった事項とその解決

`old/第五版_レビュー.md` に挙げた41項目の解決先を示す。判断を要した事項は、下した判断も併せて記す。

### 現在の実装との矛盾

| 事項 | 解決 | 場所 |
|---|---|---|
| 接触・被弾の形状が球のまま | **背骨の各エッジに対応するカプセルの集合で判定する。**外接球は広域の絞り込みと天体表面への到達判定に残す。被弾したカプセルから損傷する搭載要素が決まる | 2巻 §1-6、§7-1 |
| `bcInv` と `srpCoeff` が食い違っている | 両方を形状と実質量から導出する。**`Cd` は自由分子流域の 2.2 の定数とし、投影面積のみを姿勢と速度方向から求める。**自由分子流では抗力係数は形状にほとんど依存しない | 2巻 §7-2 |
| RCSスラスタと武装の位置が動的になる | **任意配置のアクチュエータに対する配分に改める。**推力の組み合わせは減衰最小二乗で解き、0以上・最大推力以下にクランプする。正則化項が推進剤消費を抑える | 1巻 §5 |
| 可動部の取り付けが固定座標 | **接続口ごとのローカル座標系を定義し、可動部はすべてそれを基準に動く。**固定座標を持つ要素は存在しない | 2巻 §4-1 |
| 敵艦の質量特性の出所が2系統になる | **敵艦は背骨を持たない。**`Vessel` は質量特性を直接与える経路も持つ | 1巻 §3-3 |
| 基地の格納ドックとハッチ | 基地モジュール部品が持つ。ドッキングポートによる結合は実装しないため、**現在の距離と相対速度による判定を維持する** | 1巻 §3-4 |
| `MapPickable.kind` の導出 | `hasBaseModule` と所属勢力の2軸から導く。4トグルはそのまま使える | 1巻 §3-5 |
| `EntityManager` の波及範囲 | 影響する関数を一覧で挙げた | 1巻 §3-6 |
| スロットルの4段と絞り範囲の不整合 | **絞り率 0〜100% の連続値に改める。**キー `[1]`〜`[4]` はプリセットに割り当てる。絞り下限を下回る出力は並進RCSで出す | 1巻 §5-4 |

### 曖昧で判断が必要だった箇所

| 事項 | 下した判断 | 場所 |
|---|---|---|
| ノードの体積が誰のものか | 軸方向に連なるエッジは内容積が**連続し、1つのタンクにできる**。側面分岐の内容積は母体と**連続しない**（分岐は母体の外皮の外側から始まる）。ノード自身は面であり体積を持たない | 2巻 §4-2 |
| 側面の口の「規定の幅」 | 周方向はその辺の長さ、軸方向は**母断面の外接円半径に比例**させる。大きな断面には大きな分岐が付く | 2巻 §3-3 |
| 外皮の肉厚と構造質量 | 内圧を持つ区画は**薄肉圧力容器の式**、持たない区画は座屈と製造上の下限。タンクを大きくすると質量が半径に比例して増える | 2巻 §6-3 |
| 段跨ぎ燃焼の判定 | `propellantForDv` が段の推進剤残量を超えるかで判定する。**禁止せず、ノードを2つに分割することを提案する** | 3巻 §4-4 |
| 生産コストの通貨と資源 | **生産は資源・設備・電力のみ。通貨は使わない。**通貨は基地の市場での資源売買に残す | 2巻 §10-3、4巻 §8-3 |
| 円の弓形を切った後の輪郭サンプリング | **弧長で等分する。**角度で等分すると直線部の点が疎になり、ロフトの帯の面積が不均一になる | 2巻 §6-1 |

### 宇宙工学的な訂正

| 事項 | 訂正 | 場所 |
|---|---|---|
| 液体酸素／シランの比推力 330 秒 | **265 秒**に訂正。燃焼生成物の二酸化ケイ素が凝縮相であり膨張過程で仕事に寄与しない。ノズルスロートへの堆積により連続燃焼時間に上限がある | 1巻 §6-1、4巻 §6-1 |
| ハイブリッド（ABS＋亜酸化窒素）300 秒 | **260 秒**に訂正。亜酸化窒素は分子内の酸素比率が低い。ただし**自己加圧できる**という利点を明記。**ABS＋液体酸素（305 秒）を新設** | 1巻 §6-1 |
| 四酸化二窒素／MMH の混合比 2.0 | **1.65** に訂正（実機の最適値） | 1巻 §6-1 |
| エキスパンダーサイクルが液体水素専用 | **極低温全般**に改める。再生冷却で受け取れる熱量が**推力の上限**を決めることを明記 | 1巻 §6-2 |
| 磁気トルカが考慮されていない | **搭載要素として追加。**地球磁場のある領域では推進剤ゼロでアンローディングできる。磁場に平行な軸のトルクは出せない。低軌道では姿勢制御が事実上無料になり、月周辺では RCS を消費する | 1巻 §5-3、4巻 §3-4 |
| 重力傾斜トルクが考慮されていない | `τ_gg = 3(μ/r³)(r̂ × I r̂)` を全機体に適用する。慣性テンソルを形状から導出する以上、形状の帰結として現れる | 1巻 §5-6 |
| 極低温の始動損失 | エンジンの性能値に**点火1回あたりの推進剤損失**を追加。細かい軌道修正を繰り返す運用で積み上がる | 1巻 §6-2 |
| ヒドラジンの劣化機構 | 「触媒毒による自己分解」を削除。劣化するのは**触媒床**であり、累積の噴射時間に応じて**比推力が低下**する。整備で回復する | 1巻 §6-4 |
| 凝固点と加熱電力 | 推進剤の表に**凝固点**の列を追加。常温貯蔵性推進剤ほど凍結の危険があり、ヒータ電力を要する | 1巻 §6-1 |
| ヘリウム冷ガス | **比推力 165 秒**として追加（窒素は 70 秒）。イナートガスとして積んだヘリウムをそのまま使える | 1巻 §6-1、4巻 §6 |
| 材料適合性 | 推進剤の表に**タンク材料の要求**を追加。液体水素は水素脆化に耐える材料、四酸化二窒素はチタン不可、過酸化水素は限られた材料のみ。**推進剤の選択が材料を通じて質量と資源に効く** | 1巻 §6-1、2巻 §6-3、4巻 §3-2 |
| ノズル膨張比と機体長 | エンジンの性能値に**全長**を追加。比推力の高いエンジンほどノズルが長く、機体後端から突き出す | 1巻 §6-2、2巻 §8 |

### 実装順

| 事項 | 解決 | 場所 |
|---|---|---|
| 第2巻 S3 が大きすぎる | **S3a（導出して現在の定数と一致することを確かめる）と S3b（適用して定数を廃止する）に分割。**姿勢運動が変わった原因を切り分けられる | 2巻 §12 |
| 第3巻の順序 | **分離 → ペイロード → 配管 → 与圧 → UI** に変更。分離は配管に依存せず、軽く、単体で価値が大きい | 3巻の構成全体 |

| 事項 | 解決 | 場所 |

| 配管の敷設が単調作業になる | **自動敷設を既定とし、手動はその上書きとする。**手で触るのはクロスフィード、口径による軽量化、タンクの割り当てを変えたいときだけになる | 3巻 §3-5、§6-1 |

### 推進剤・エンジンの未考慮だった性質

推進剤の表に**凝固点・日あたり損失率・タンク材料の要求・毒性**の列を追加した（1巻 §6-1）。エンジンの表に**全長・点火1回あたりの推進剤損失・連続燃焼時間の上限・ジンバル速度・要求与圧の桁**を追加した（1巻 §6-2）。与圧低下による推力低下は3巻 §7-1 に、亜酸化窒素の自己加圧は3巻 §7-2 に置いた。電気推進と原子力推進は4巻 §6 が扱う。
