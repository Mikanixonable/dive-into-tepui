# 宇宙船設計計画 第五版 — 索引

宇宙船の設計・推進・多段化に関する実装計画を3巻に分けて置く。各巻はそれ単体で読んで実装に入れるように書いてある。この索引は、どの巻が何を扱い、どの順に着手するかだけを示す。

## 各巻の範囲

| 巻 | ファイル | 扱うもの | 依存 |
|---|---|---|---|
| 第1巻 | `第五版_1_推進系と推進剤.md` | 艦艇と基地を統合した `Vessel`、搭載要素の型と性能値、主機／並進RCS／フライホイールの分離、姿勢トルクの配分と飽和、推進剤の物性表、エンジンのサイクル、ツィオルコフスキーによる燃焼計算 | なし |
| 第2巻 | `第五版_2_船体設計システム.md` | 断面の幾何、背骨とロフトによる外皮、形状からの質量特性の導出、搭載要素の配置と内容積、設計の保存・検証・生産、技術ツリー、設計エディタ | 第1巻 |
| 第3巻 | `第五版_3_配管・多段・ペイロード.md` | 配管による推進剤の流路、タンクの与圧とイナートガス、弾薬の供給、分離機構と多段、ペイロードの軌道投入 | 第1巻・第2巻 |

## 依存と着手順

```
第1巻 ──────────────► 第2巻 ──────┐
   │                              ├──► 第3巻
   └──────────────────────────────┘
```

第2巻の §3 と §5（断面の面積・断面二次モーメント）および §6（ロフトの体積・慣性テンソル）は `src/physics/` に閉じた純関数であり、いかなる依存も持たない。**この計画全体で最大の未知は「複合断面と一般化角錐台の物理量が閉形式で求まるか」であり、ここが崩れると第2巻の設計思想ごと組み直しになる。**ゲームに一切繋がず、テストだけで確かめられるため、第1巻と並行して真っ先に着手する。

第1巻は `Ship` / `Player` / `Base` を `Vessel` に統合する作業を含む。第2巻も第3巻も同じクラス群を書き換えるため、これを後回しにすると同じ変更を複数回書くことになる。第1巻を先に通す。

## 対象外

月面着陸、月面地形、月面基地、資源採掘と生産、ドッキングポートによる機体の結合は、実装費用が大きいため上の3巻には含めない。設計は `延期_月面着陸・月面基地・資源採掘・ドッキング.md` にある。

`old/` には、3巻に分割する前の計画書を置いてある。内容は上の3巻に引き継がれている。
