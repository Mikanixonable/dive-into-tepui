# 宇宙船設計計画 第8版 2.1 — 残作業

第1巻 `第8版_1_基盤.md` と第2巻 `第8版_2_設計・建造・資源.md` の段階のうち、実装が残っているものだけを、実際の依存関係に従って並べ直した作業計画である。

## 1. この文書の位置づけ

第1巻と第2巻の段階表は、**何も実装されていない状態**を出発点として依存を引いている。実装が進んだ現在、その依存の一部は既に満たされており、表のうえで前段に見えるものが実際には障壁でなくなっている。逆に、表では独立に見えて実際には別の段階に塞がれているものもある。**この文書は、いまの実装を出発点として依存を引き直し、着手できるものと塞がれているものを分ける。**

第1巻・第2巻・第3巻の段階表を置き換えるものではない。各段階が何を作るかの定義はそれらが持つ。この文書が持つのは、**どれが残っていて、どれから着手できるか**だけである。

`第8版_実装中の追加事項.md` の追加タスクのうち未解決のものは、§5 で残りの段階へ割り当てる。

## 6. 着手順

**F12・B6・F9 を並行して始める。**この3つは互いに依存せず、それぞれが別の壁を崩す。

**F12（ロフトメッシュの生成）を最優先に置く。**現在の実装で最も大きな欠落は、設計を編集する手段が無いことである。編集の入口は B7 の骨格モードであり、B7 を塞いでいるのは F12 だけである。F12 は F7 の質量特性が済んでいるため今すぐ着手でき、通れば B7 → B8 → B12 → B13 という第2巻の最長の連鎖の先頭が開く。**残っている段階のうち、後続を最も多く抱えているのが F12 である。**

**B6（生産）を同時に始める。**B6 は `VesselBlueprint` から `Vessel` を得る経路そのものであり、これが無いために設計データと資源の帳簿の両方が到達不能なコードとして置かれている。F12 とは何も共有せず、依存も互いに無い。B6 が通れば、設計ファイルを手で書いて機体を作るという第2巻 §19 が B5 に定めた状態に初めて到達する。**T-4 の建造費の表と T-5 の白金族の質量は、この段階が要求して初めて埋まる。**

**F9（姿勢制御系の分離）を3本目に置く。**F10 → F13 と F10 → B10・B16 を塞いでいるのは F9 だけであり、機体の系列でこれ以上先へ進む道は F9 を通る以外に無い。F9 を通せば磁気トルカの配線（B14 の一部）も同時に片付き、置かれたまま参照されていない `src/physics/geomagnetic.ts` に読み手ができる。

**B1（分離の物理）と F8（接触形状のカプセル化）は、上の3本と並行できる。**B1 の分離の物理は F10 を要さず、通れば B2・B4・B9 が開く。F8 は他の何も塞いでいないが、細長い機体の貫通が捕まらない現状を直すものであり、機体が長くなる多段（B1）と同時期に要る。

**通信パネルは、上のどれとも独立に、いつでも置ける。**通信圏の判定は動いていて無人機の計画実行を実際に止めているのに、プレイヤーには**なぜ無人機が動かないのかが分からない**。パネル1枚で、既に払った実装の費用が初めて見えるようになる。B11 の他の内容（段の一覧、ペイロード）は B1〜B10 を待つが、通信パネルだけを先に出すことに障害は無い。

**T-14（通信圏の判定のフレーム内記憶）も待たない。**時間加速中に毎フレーム 101 天体の走査を機体ごと・サブステップごとに行う形は、フレーム予算が最も苦しいときに最も重くなる。

その後の順序は依存に従う。F10 は F9 の直後に置き、通れば F13 と B16 が開き、B1 の段を跨ぐ燃焼の判定も足せる。B9（配管）と B10（与圧）は B1 と F10 の両方が済んでから続けて通す。B2（ドッキング）は B1 の逆向きの計算であり、B1 の直後が最も安い。
