# 資源と推進の進化 — 実装計画

この文書は、プレイヤーが利用できる推進剤・エンジン・構造材が、**手に入れた資源を使って別の資源を手に入れる連鎖**によって広がっていく仕組みを定める。

対象は次の5つである。

1. 進行の原理（§2）
2. 元素と資源、およびその産地（§3）
3. 到達可能性 — Δv が進行そのものであること（§4）
4. 設備の連鎖（§5）
5. 推進の世代 — 化学から核熱・電気推進を経て核融合に至る道筋（§6）

**他の巻との関係** — この巻は『推進系と推進剤』の巻が定義する推進剤とエンジンの型式、『船体設計システム』の巻が定義する設計と生産の仕組みの上に載る。この巻は**技術ツリーによる解禁を持たない**。研究点も、前提技術の木も存在しない。あるものを作れるかどうかは、その時点で持っている資源と設備だけで決まる。

月面基地、資源採掘の実装そのもの、ドッキングによる物資の移送は『延期_月面着陸・月面基地・資源採掘・ドッキング.md』の対象である。この巻は、それらが何を生産し、何を可能にするかという構造を定める。

## 1. 対象外

設計エディタの操作、背骨と断面の幾何、配管と与圧の実装、多段の分離処理は、この巻の対象に含めない。月面の地形と着陸、機体同士のドッキングも含めない。

## 2. 進行の原理

### 2-1. 解禁ではなく連鎖

プレイヤーが使える技術は、研究点を払って解禁するのではない。**ある資源で作った設備が次の資源を生み、その資源が次の設備を可能にする**という連鎖によって広がる。

```
資源 ──► 設備 ──► 別の資源 ──► 別の設備 ──► さらに別の資源
                      │
                      └──► 推進剤 ──► より大きな Δv ──► 遠くの産地 ──► 新しい資源
```

この構造の要点は、**進行を止めるものが常に物理的な事実である**ことにある。メタンを作れないのは技術が未解禁だからではなく、炭素を持っていないからである。炭素を持っていないのは、月に炭素がないからである。炭素を得るには、炭素のある場所へ行くか、炭素を持つ敵を倒すしかない。

### 2-2. 進行を止める4つの制約

| 制約 | 内容 | 解消の手段 |
|---|---|---|
| **資源** | 必要な元素を持っていない | その元素のある場所へ行く、または敵から得る |
| **設備** | 変換する設備を持っていない | 設備の建設に必要な金属と電力を確保する |
| **電力** | 設備を動かす電力が足りない | 太陽電池を増やす。太陽から遠い場所では原子炉が要る |
| **到達可能性** | その場所へ行くだけの Δv が出せない | より比推力の高い推進系、多段化、または大気制動 |

**この4つは互いに絡み合っている。**遠くへ行くには高い比推力が要り、高い比推力の推進剤には特定の元素が要り、その元素は遠くにしかなく、そこへ行くには電力を生む原子炉が要り、原子炉の燃料もまた特定の場所にしかない。

### 2-3. 生産に通貨は要らない

機体と搭載要素の生産に必要なのは、**資源・設備・電力の3つだけである。**通貨は生産の要求に含まれない。作れないものは、金がないから作れないのではなく、材料か設備か電力が足りないから作れない。

クレジットは廃止しない。**基地の市場での資源の売買**に用いる。余った資源を売り、足りない資源を買える。ただし市場で買える量には上限があり、遠方の資源（ヘリウム3、白金族など）は市場に出回らない。**それらは自分で採りに行くしかない。**市場は近距離の資源のやりくりを滑らかにするだけであり、進行の壁を金で越えることはできない。

### 2-4. 設計は自由、生産だけが制約を受ける

プレイヤーは、持っていない推進剤やエンジンを使った設計を**作ることも保存することもできる**。制約を受けるのは生産だけである。

設計エディタは、生産できない設計に対して「何が足りないか」を表示する。足りないものは、資源・設備・電力のいずれかであり、それぞれが「どこで手に入るか」「何から作れるか」を辿れる形で示される。

この扱いによって、設計エディタは**目標を提示する装置**になる。核融合エンジンを積んだ機体を最初から設計でき、それを作るには何が要るのかが一覧として見える。

## 3. 元素と資源

### 3-1. 元素の一覧と用途

| 元素 | 主な用途 |
|---|---|
| 水素 (H) | 液体水素、メタンの合成、シランの合成、アンモニアの合成、核熱推進の作動流体 |
| 酸素 (O) | 液体酸素、過酸化水素、四酸化二窒素 |
| 炭素 (C) | メタン、ケロシン、ABS樹脂、末端水酸基ポリブタジエン、**炭素繊維複合材（熱防護材）** |
| 窒素 (N) | ヒドラジン、四酸化二窒素、冷ガス、与圧ガス |
| ケイ素 (Si) | シラン、太陽電池 |
| アルミ (Al) | 構造材、固体推進剤の燃料成分、**四酸化二窒素と過酸化水素のタンク** |
| チタン (Ti) | 高強度構造材、**液体水素の極低温タンク**（水素脆化に耐える） |
| 鉄 (Fe) | 構造材、電磁機器、**ステンレス（推進剤タンクの代替材）** |
| マグネシウム (Mg) | 軽量構造材 |
| 硫黄 (S) | 高エネルギー密度電池、化学処理（金属の抽出） |
| ヘリウム (He) | 極低温推進剤の与圧ガス、**冷ガススラスタの推進剤（比推力 165 秒）** |
| ヘリウム3 (³He) | 核融合燃料 |
| 重水素 (D) | 核融合燃料 |
| 白金族 (Pt, Ir, Rh) | **ヒドラジン分解触媒（イリジウム）**、水の電解の電極、高温部材 |
| トリウム・ウラン (Th, U) | 核分裂燃料 |
| 希土類 | 高性能磁石（フライホイール、電気推進、**磁気トルカ**） |
| キセノン・アルゴン (Xe, Ar) | 電気推進の推進剤 |

### 3-2. 材料適合性 — 推進剤がタンクの金属を要求する

推進剤は、どんな容器にでも入るわけではない。**推進剤の選択は、その推進剤に耐える金属を持っているかどうかに縛られる。**

| 推進剤 | 使える材料 | 理由 |
|---|---|---|
| 液体水素 | チタン合金、特定のステンレス | 水素脆化。ふつうの合金は水素が拡散して脆くなる |
| 四酸化二窒素 | アルミ合金 | **チタンとは応力腐食割れを起こす。**チタン製タンクには入れられない |
| 過酸化水素 | 高純度アルミ、特定のステンレス | 多くの金属と接触すると分解する |
| 液体酸素・液体メタン・シラン | アルミ合金、ステンレス、チタン | 特段の制約はない |
| ヒドラジン | アルミ合金、ステンレス | タンク自体の制約は緩い。**触媒床にイリジウム（白金族）が要る** |

この適合性は、資源の依存としてそのまま働く。液体水素を積むにはチタンかステンレスが要り、四酸化二窒素を積むにはアルミが要り、その両方を積む機体は両方の金属を要する。**月のレゴリスの電解はチタンとアルミと鉄を同時に生むため、月面の基地はこの層の制約を最初から満たしている。**

**ヒドラジン単推進剤スラスタだけは、月の資源だけでは作れない。**触媒床のイリジウムは白金族であり、白金族は敵のドロップかM型小惑星からしか得られない。姿勢制御と軌道修正に最も扱いやすいこの推進系は、低軌道での戦闘を経るか、小惑星へ出るかしなければ手に入らない。

### 3-3. 産地

| 産地 | 得られる元素 | 手段 |
|---|---|---|
| **月レゴリス** | O, Si, Fe, Ti, Mg, Al | 溶融塩電解。酸素と金属合金が同時に得られる |
| **月南極の永久影** | H₂O（→ H, O） | 氷の採掘 |
| **月の KREEP 岩** | Th, U, 希土類, P | 精錬。産出量は少ない |
| **敵の残骸** | C, N, S, 白金族, 希土類 | 低軌道での戦闘 |
| **近地球小惑星（C型）** | H₂O, C, 有機物 | 採掘 |
| **近地球小惑星（M型）** | Fe, Ni, 白金族, 希土類 | 採掘 |
| **ケレス** | H₂O（大量）, 炭酸塩（C）, アンモニア塩（N） | 採掘。小惑星帯で最も水が豊富 |
| **火星** | CO₂ 大気（C, O）, 水氷, N₂ 大気（2.8%）, Ar 大気（2%） | 大気捕集と採掘 |
| **金星** | N₂ 大気（3.5%）, CO₂ 大気（96%）, 硫酸雲（S） | 大気捕集。着陸はしない |
| **木星大気** | H₂, **He**, ³He | 大気捕集。深い重力井戸からの脱出が課題 |
| **カリスト** | H₂O | 採掘。木星系で放射線が最も弱く、拠点に適する |
| **イオ** | S, SO₂ | 採掘。木星系で放射線が最も強い |
| **タイタン** | CH₄, C₂H₆（C, H）, N₂ 大気 | 採掘と大気捕集。炭素と窒素が事実上無尽蔵 |
| **エウロパ・ガニメデ** | H₂O | 採掘 |

**月には炭素と窒素がない。**これがこの進行全体の出発点にある制約である。月の資源だけで閉じる経路は存在するが、そこで得られる推進剤は性能が限られる。炭素と窒素を得るには、低軌道で敵を倒すか、月を出るしかない。

**ヘリウムは木星大気からしか大量には得られない。**月のレゴリスにも太陽風起源のヘリウムが含まれるが、濃度が極めて低く、極低温推進剤の与圧に足るほどは採れない。ヘリウム冷ガスという安価で高性能な姿勢制御手段は、木星系に届いてから初めて実用になる。

### 3-4. 希土類と磁気トルカ

姿勢制御には磁気トルカが使える。機体の電磁石が周囲の磁場と作るトルクでフライホイールをアンロードするもので、**推進剤をまったく消費しない。**製造には高性能磁石が要り、そのために**希土類**が要る。希土類は月の KREEP 岩、敵のドロップ、M型小惑星から得られる。

磁気トルカが働くのは磁場のある場所だけである。

| 活動領域 | 磁場 | 姿勢制御の性格 |
|---|---|---|
| 地球低軌道 | 強い | 磁気トルカが使え、アンローディングが事実上無料になる |
| 近直線ハロー軌道・月周辺 | ほぼ無い | フライホイールのアンロードにRCS推進剤を消費する |
| 惑星間・小惑星帯 | ほぼ無い | 同上 |
| 木星系 | 極めて強い | 磁気トルカが使える。ただし放射線帯が厳しい |

**低軌道での活動は姿勢制御が安価であり、月周辺へ出るとRCS推進剤の消費が効いてくる。**同じ機体でも、どこで運用するかによって推進剤の収支が変わる。磁気トルカは電力を消費し、トルクは小さく、磁場に平行な軸まわりのトルクは出せない（3軸のうち1軸が瞬間的に制御できない）。

## 4. 到達可能性

### 4-1. Δv が進行そのものである

どこへ行けるかは、機体が出せる Δv で決まる。Δv はツィオルコフスキーの式により、比推力と質量比で決まる。比推力は推進剤で決まり、推進剤は持っている元素で決まる。**したがって、資源の進行と到達可能性の進行は同じものである。**

### 4-2. Δv の表

代表的な区間の Δv を示す。単位は km/s である。

| 区間 | Δv（推進のみ） | Δv（大気制動を使う） |
|---|---|---|
| 月面 → 低月軌道 | 1.9 | — |
| 低月軌道 → 近直線ハロー軌道 | 0.7 | — |
| 月面 → 近直線ハロー軌道 | 2.7 | — |
| 近直線ハロー軌道 → 地球低軌道 | 3.2 | 0.7 |
| 地球低軌道 → 近直線ハロー軌道 | 3.4 | — |
| 地球低軌道 → 到達しやすい近地球小惑星 | 4.5 | — |
| 地球低軌道 → 一般の近地球小惑星 | 6.0 | — |
| 地球低軌道 → 火星周回 | 5.7 | 3.6 |
| 地球低軌道 → 金星周回 | 6.8 | 3.5 |
| 地球低軌道 → ケレス | 9.5 | — |
| 地球低軌道 → 木星系（カリスト） | 11.0 | 6.5 |
| カリスト → イオ | 3.5 | — |
| 地球低軌道 → タイタン | 12.0 | 7.5 |
| 木星大気の捕集 → 木星脱出 | 20.0 | — |

### 4-3. 大気制動 — 熱防護が炭素を要求する

**大気のある天体では、捕獲の Δv がほぼ不要になる。**地球・火星・金星・タイタン・木星がこれにあたる。双曲線軌道のまま大気の上層を通し、空力抵抗で減速して捕獲される。上の表の右列がその値であり、化学推進の到達範囲を1世代ぶん広げるほどの差になる。

代わりに要るのが**熱防護**である。制動の間、機体の前面は高温の衝撃層に晒される。熱防護材は炭素繊維複合材で作るため、**大気制動を使うには炭素が要る。**

| 天体 | 大気の性格 | 熱防護の負担 |
|---|---|---|
| 火星 | 薄い | 軽い。1回の通過で捕獲できず、複数周にわたる |
| 地球 | 中程度 | 中。既存の突入加熱と動圧の実装がそのまま働く |
| タイタン | 厚く低重力 | 軽い。速度が小さいため加熱が穏やか |
| 金星 | 極めて厚い | 重い。突入速度が大きく、加熱が厳しい |
| 木星 | 極めて厚く高重力 | 極めて重い。捕獲は可能だが脱出は別問題である |

この作品はすでに大気圏突入の加熱と動圧を実装しており、加熱率と動圧の閾値によって機体が失われる。大気制動は**その仕組みをそのまま使う**。熱防護材を積んでいれば閾値が上がり、積んでいなければ現在と同じ値のまま燃え尽きる。

炭素を持たない段階では大気制動は使えない。**つまり、月の資源だけで自立している間は、右列の値には手が届かない。**炭素を得ることは、推進剤の性能を上げるだけでなく、Δv の表そのものを書き換える。

### 4-4. 推進系ごとに届く範囲

質量比を現実的な範囲（乾燥質量に対する初期質量が3〜6倍）に置くと、推進系ごとの到達範囲はおおよそ次のようになる。

| 推進系 | 比推力 | 実用的な Δv | 届く範囲 |
|---|---|---|---|
| 固体・貯蔵性化学 | 230〜320 s | 3〜5 km/s | 月面と近直線ハロー軌道、地球低軌道 |
| 液体酸素／シラン | 265 s | 3〜5 km/s | 同上。月の資源だけで作れる |
| 極低温化学（メタン） | 370 s | 5〜7 km/s | 近地球小惑星、火星、金星 |
| 極低温化学（水素） | 450 s | 6〜8 km/s | 火星、金星。蒸発損失のため長期の航行には不利 |
| 核熱推進 | 900 s | 12〜16 km/s | ケレス、木星系 |
| 電気推進 | 3000 s | 30 km/s 以上 | 太陽系内のどこへでも。ただし推力が小さく、時間がかかる |
| 核融合推進 | 10⁴ s 以上 | 100 km/s 以上 | 木星の重力井戸からの脱出 |

## 5. 設備の連鎖

### 5-1. 設備の定義

設備は、電力を消費して入力資源を出力資源に変換する。設備そのものの建設には金属と電力が要る。**通貨は要らない。**

```ts
// src/game/economy/facility.ts
export interface FacilityDef {
  readonly id: string;
  readonly name: string;
  readonly inputs: readonly { resourceId: string; rate: number }[];   // kg/s
  readonly outputs: readonly { resourceId: string; rate: number }[];  // kg/s
  readonly powerDraw: number;         // W
  readonly buildCost: readonly { resourceId: string; mass: number }[];
  readonly requiresFacility: readonly string[];  // これを作るのに要る別の設備
}
export const FACILITIES: readonly FacilityDef[];
```

`requiresFacility` は技術の前提ではなく、**物理的な前提**である。液化装置がなければ極低温タンクに詰められない、という類の関係だけを表す。

| 核燃料精製炉 | KREEP 岩, M型小惑星の鉱石 | U, Th | 大 | Ti, 白金族 |
| 原子炉 | U または Th | **電力** | — | Ti, 白金族, 希土類 |
| 太陽電池製造炉 | Si, 希土類 | 太陽電池パドル | 中 | Fe, Si |

### 5-3. 電力が最初の壁になる

**溶融塩電解は極めて大きな電力を要する。**アルミの電解精錬は工業的に最も電力を食う工程の一つであり、月のレゴリスから金属と酸素を取り出す工程も同様である。

したがって進行の最初の段階は「電力を確保すること」になる。月の南極の高地は日照率が高く、この立地の価値が電力として直接現れる。太陽電池を増やすにはケイ素が要り、ケイ素を得るには電解が要り、電解には電力が要る。**この循環は、最初の小さな設備から徐々に規模を拡大していく形でしか抜けられない。**

太陽から遠ざかると太陽光が弱くなる（木星では地球の27分の1）。外惑星で設備を動かすには原子炉が要る。原子炉の燃料は月の KREEP 岩か M型小惑星から得る。

## 6. 推進の世代

### 6-1. 第1世代 — 貯蔵性化学推進

月の資源と敵のドロップだけで成立する。

| 推進剤 | 比推力 | 必要な元素 | 産地 |
|---|---|---|---|
| 固体（過塩素酸アンモニウム + HTPB + Al） | 265 s | Al, C, H, N, O, Cl | Al は月、C と N はドロップ |
| 液体酸素 / シラン | **265 s** | Si, H, O | **すべて月で得られる** |
| 四酸化二窒素 / モノメチルヒドラジン | 320 s | N, H, O, C。**タンクに Al** | N と C はドロップ |
| ヒドラジン単推進剤 | 230 s | N, H。**触媒床に白金族（Ir）** | ドロップまたはM型小惑星 |
| 窒素冷ガス | 70 s | N | ドロップ |
| ヘリウム冷ガス | 165 s | He | 木星大気 |

**液体酸素／シランは、月の資源だけで作れる唯一の液体推進剤である。**燃焼生成物の二酸化ケイ素が凝縮相であり、膨張過程で仕事に寄与しないため比推力は 265 秒にとどまる。さらに二酸化ケイ素がノズルスロートに堆積するため、**連続燃焼時間に上限がある。**性能は固体モーター並みであり、長い連続噴射はできない。

それでも、外部からの補給がまったくなくても月面と近直線ハロー軌道と地球低軌道の間を往復できる。**これがこの作品の自立の最低線である。**そして、より高性能な推進剤を求めて外へ出る動機でもある。

**冷ガススラスタの2つの選択肢は、この世代の両端にある。**窒素冷ガスは比推力 70 秒と低いが、窒素は敵のドロップで早く手に入る。ヘリウム冷ガスは 165 秒と大幅に高いが、ヘリウムは木星大気からしか大量には採れない。極低温推進剤の与圧のためにヘリウムを積んでいる機体は、それをそのまま冷ガスの推進剤にも使える。

### 6-2. 第2世代 — 極低温化学推進

水と炭素が要る。

| 推進剤 | 比推力 | 必要な元素 | 産地 |
|---|---|---|---|
| 液体酸素 / 液体水素 | 450 s | H, O。**タンクに Ti またはステンレス** | 月の水氷 |
| 液体酸素 / 液体メタン | 370 s | C, H, O | C はドロップ、小惑星、火星、タイタン |

液体酸素／液体水素は月の水だけで作れるが、水素の密度が低いため巨大なタンクが要り、蒸発損失があるため長期の航行に向かない。水素脆化に耐えるタンクが要るため、チタンか特定のステンレスを持っていることが前提になる。液体酸素／液体メタンは密度が高く貯蔵しやすいが、炭素が要る。

**この世代で近地球小惑星と火星に届く。**小惑星からは水と炭素と白金族と希土類が、火星からは炭素と窒素とアルゴンが得られる。**炭素と窒素の供給が敵のドロップから独立する**のが、この世代の最大の意味である。

そして炭素が手に入ることで、**炭素繊維複合材の熱防護材が作れるようになる。**大気制動が使えるようになり、火星・金星・地球の捕獲に要る Δv が大きく下がる。同じ推進系のまま届く範囲が広がるのは、この世代だけの性質である。

### 6-3. 第3世代 — 核熱推進

固体炉心の原子炉で水素を加熱して噴射する。比推力 900 秒、推力は化学推進に匹敵する。

- 燃料はウランまたはトリウム。月の KREEP 岩、または M型小惑星から得る。
- 作動流体は水素。核分裂の熱で加熱するだけなので、酸化剤を必要としない。**水さえあればどこでも補給できる。**
- 水素を扱うため、タンクにはチタンか特定のステンレスが要る。
- 炉心は重く、乾燥質量が大きい。小型の機体には向かない。
- 放射線遮蔽が要る。乗員のいる区画との間に遮蔽材を置く必要があり、機体の形状が制約を受ける（遮蔽の影の中に居住区を置く配置）。**背骨設計はこの制約を素直に表現できる。**

**この世代でケレスと木星系に届く。**ケレスは水が豊富で、核熱推進の補給地として最適である。

### 6-4. 第4世代 — 電気推進

原子炉または大型太陽電池の電力で推進剤を電離・加速する。

| 方式 | 比推力 | 推力 | 推進剤 |
|---|---|---|---|
| ホールスラスタ | 1600 s | 中 | Xe, Ar, Kr |
| イオンエンジン | 3000〜4000 s | 小 | Xe |
| 磁気プラズマ推進 | 5000 s | 小 | Ar, H |

- 推進剤は火星の大気（アルゴン 2%）から、あるいは希ガスの捕集から得る。
- 磁気回路に希土類が要る。磁気トルカと同じ資源の上に載る。
- **推力が極めて小さい。**加速度は 10⁻⁴ m/s² の程度であり、大きな Δv を得るのに数か月から数年かかる。戦闘には使えない。
- 電力が要る。太陽電池は太陽から遠ざかるほど無力になるため、外惑星では原子炉が前提になる。

電気推進は**戦闘用ではなく輸送用**である。ゆっくりでよい大量の物資を運ぶ無人ブースターに積む。これは「戦闘は化学推進、輸送は電気推進」という役割の分化を生み、機体設計の目的が明確に分かれる。

### 6-5. 第5世代 — 核融合推進

重水素とヘリウム3の反応を用いる。比推力 10⁴ 秒以上。

- 重水素は水から分離する。ヘリウム3は木星の大気から捕集する（月のレゴリスにも太陽風起源のヘリウム3が含まれるが、濃度が極めて低く、大量には得られない）。
- **重水素とヘリウム3の反応は中性子をほとんど出さない**（副反応の重水素同士の反応を除く）。荷電粒子が主生成物であるため、磁場で直接噴射方向へ導ける。これが高い比推力の理由である。
- ヘリウム3の同位体分離には極めて大きな電力が要る。原子炉が前提になる。
- 木星の大気を捕集し、その重力井戸から脱出するには 20 km/s 級の Δv が要る。**核融合推進なしにはヘリウム3を持ち帰れず、ヘリウム3なしには核融合推進が作れない。**この循環は、最初の一回だけ核熱推進と電気推進を組み合わせた片道の大型機で破る。

この作品はすでに中性子線ビームを敵への有効な攻撃手段として構想している。核融合の実現は、推進だけでなく武装の世代も変える。

## 7. 想定される進行経路

```
【出発点】月南極の基地。太陽電池と小さな氷採掘機を持つ。
   │
   ├─► 氷を採掘し電解 ──► 液体酸素/液体水素（タンクは電解で得たチタン）
   ├─► レゴリスを電解 ──► O, Si, Fe, Ti, Mg, Al ──► 太陽電池を増設
   └─► シラン合成 ──► 液体酸素/シラン（比推力 265 s、燃焼時間に上限）
   │
   │  【月面 ↔ 近直線ハロー軌道の往復が成立する】Δv 2.7 km/s
   │  ※月周辺には磁場がなく、姿勢制御はRCS推進剤を消費する
   ▼
低軌道での戦闘 ──► C, N, S, 白金族, 希土類 のドロップ
   │
   ├─► アンモニア合成 ──► ヒドラジン、四酸化二窒素（タンクはアルミ）
   ├─► 触媒床製造（白金族）──► ヒドラジン単推進剤スラスタが作れるようになる
   ├─► 磁気トルカ製造（希土類）──► 低軌道での姿勢制御が推進剤ゼロになる
   ├─► サバティエ反応 ──► メタン（高性能な極低温推進剤）
   ├─► 高分子合成 ──► ABS、HTPB（ハイブリッドと固体推進剤）

   │
   │  【地球低軌道と月の往復が自在になる】Δv 5〜7 km/s
   │  ※地球への帰還は大気制動により 3.2 → 0.7 km/s
   ▼
近地球小惑星への到達 ──► H₂O, C, 白金族, 希土類, Fe, Ni
   │
   │  【炭素・窒素・白金族・希土類の供給が敵のドロップから独立する】
   ▼
火星・金星への到達（大気制動により Δv 3.5〜3.6 km/s）──► C, N, Ar, 水氷, S
   │
   ├─► 大気捕集機 ──► アルゴン（電気推進の推進剤）
   └─► KREEP と M型小惑星 ──► U, Th ──► 核燃料精製 ──► 原子炉
   │
   │  【電力の制約が太陽から独立する】
   ▼
核熱推進の成立 ──► Δv 12〜16 km/s
   │
   ▼
ケレス・木星系への到達 ──► 大量の H₂O、カリストの拠点
   │
   ├─► イオ ──► S（高エネルギー密度電池）
   ├─► タイタン ──► CH₄, N₂（炭素と窒素が無尽蔵になる）
   ├─► 木星大気 ──► He（ヘリウム冷ガス、極低温推進剤の与圧）
   └─► 電気推進による大量輸送の成立
   │
   ▼
木星大気の捕集 ──► ³He（核熱＋電気推進の片道大型機で持ち帰る）
   │
   ▼
【核融合推進】Δv 100 km/s 以上
```

**各段階は、前の段階で得た資源がなければ始まらない。**しかし段階を飛ばすことはできる。近地球小惑星から白金族と鉄が十分に得られれば、火星を経由せずに核燃料の精製へ進める。経路は一本ではない。

## 8. 実装

### 8-1. データ構造

```ts
// src/game/economy/resource.ts
export interface ResourceDef {
  readonly id: string;
  readonly name: string;
  readonly symbol: string;        // 元素記号または化学式
  readonly density: number;       // kg/m³。貨物の容積計算に使う
  readonly storage: 'bulk' | 'cryogenic' | 'pressurized' | 'hazardous';
}
export const RESOURCES: readonly ResourceDef[];

// src/game/economy/resource-ledger.ts
export class ResourceLedger {
  amountOf(resourceId: string): number;         // kg
  add(resourceId: string, mass: number): void;
  take(resourceId: string, mass: number): boolean;
}
```

在庫は基地モジュールを持つ `Vessel` が保持する。輸送はプレイヤーが貨物区画に積んで運ぶ。

推進剤とタンク材料の適合性は、推進剤の側にタンク材料の要求として持つ。

```ts
// src/game/economy/propellant-compatibility.ts
export interface TankMaterialRequirement {
  readonly propellantId: string;
  readonly allowedMaterials: readonly string[];  // 資源 id。いずれか1つで足りる
}
export const TANK_MATERIALS: readonly TankMaterialRequirement[];
```

`producibility`（§8-2）は、タンクを持つ設計に対してこの表を引き、積む推進剤に適合する材料を在庫が満たすかどうかを要求として列挙する。

### 8-2. 生産可能性の判定

設計を生産できるかどうかは、次の純関数で判定する。**通貨は引数に含まれない。**生産の可否は資源・設備・電力だけで決まり、クレジットの残高はいかなる形でもこの判定に影響しない。

```ts
// src/game/economy/producibility.ts
export interface Requirement {
  readonly kind: 'resource' | 'facility' | 'power';
  readonly id: string;
  readonly needed: number;
  readonly available: number;
}
export function producibility(
  bp: VesselBlueprint,
  ledger: ResourceLedger,
  facilities: readonly string[],
  powerAvailable: number,
): readonly Requirement[];   // 空配列なら生産できる
```

不足している要求は、設計エディタが「何が足りないか」として表示する。さらに、その資源が**どの設備から作れるか**、その設備が**何を要するか**を `FACILITIES` から辿って表示する。プレイヤーは足りないものを起点に、必要な連鎖を遡って読める。

### 8-3. 市場 — クレジットの用途

クレジットは基地の市場での資源の売買にのみ用いる。

```ts
// src/game/economy/market.ts
export interface MarketListing {
  readonly resourceId: string;
  readonly buyPrice: number;      // クレジット/kg。プレイヤーが買う値段
  readonly sellPrice: number;     // クレジット/kg。プレイヤーが売る値段
  readonly stockPerCycle: number; // kg。1補充周期あたりに買える上限
}
export function marketOf(base: Base): readonly MarketListing[];
```

市場に並ぶのは、その基地の周辺で流通する資源に限る。**ヘリウム3、白金族、希土類、木星大気由来のヘリウムは、どの市場にも並ばない。**これらは自分で採るしかない。`stockPerCycle` の上限は、市場が進行の代替経路にならないための制約である。金で買えるのは、既に自分で採れる資源のやりくりだけである。

### 8-4. 産地の表現

産地は、`physics/solar-system.ts` に登録済みの天体に紐づける。

```ts
// src/game/economy/deposit.ts
export interface DepositDef {
  readonly bodyId: AttractorId;
  readonly resourceId: string;
  readonly abundance: number;      // 採掘機1基あたりの産出速度の係数
  readonly access: 'surface' | 'atmosphere' | 'regolith';
}
export const DEPOSITS: readonly DepositDef[];
```

`access` が `'atmosphere'` の産地は大気捕集機で採る。着陸を必要としないため、木星・金星・タイタンの大気成分は着陸の実装を待たずに採取できる。**これにより、月面着陸の実装が完了する前に資源進行の後半を成立させられる。**

敵のドロップは天体に紐づかないため、別に定める。

```ts
export interface EnemyDropDef {
  readonly enemyKind: EnemyKind;
  readonly drops: readonly { resourceId: string; massRange: [number, number] }[];
}
```

### 8-5. 大気制動と熱防護

大気制動は、既存の突入加熱と動圧の実装の上に載る。熱防護材は搭載要素として積み、その有無と量が加熱率と動圧の許容値を引き上げる。

```ts
// src/game/economy/thermal-protection.ts
export interface HeatShieldPart {
  readonly area: number;            // m²。防護する前面投影面積
  readonly ablativeMass: number;    // kg。消耗するアブレータの質量
  readonly maxHeatFlux: number;     // W/m²。これを超えると破損する
}
```

制動の1回ごとに、受けた総熱量に応じて `ablativeMass` が減る。使い切れば防護能力を失い、以後の突入では現在と同じ閾値に戻る。**熱防護材の補充には炭素が要る**ため、炭素の供給地から遠い運用では、大気制動を何回使えるかが計画の一部になる。

熱防護材を積んでいない機体が大気制動を試みた場合の挙動は、現在の再突入とまったく同じである。**新しい失敗の形は増えない。**

### 8-6. 設計エディタへの反映

設計エディタは、搭載要素のパレットに次を表示する。

- **生産できる要素** — 通常表示
- **資源が足りない要素** — 淡色表示。不足している資源と、その入手先を表示する
- **設備がない要素** — 淡色表示。必要な設備と、その建設に要るものを表示する
- **タンク材料が適合しない組み合わせ** — 推進剤を選んだ時点で、要求する材料と在庫を表示する

いずれも**選択して設計に含めることはできる**。生産のときにだけ拒否される。

### 8-7. 技術ツリーを持たない

研究点、前提技術の木、解禁の状態は実装しない。`UnlockManager` はステージの解禁のみを扱い、搭載要素の解禁には関与しない。`localStorage` に技術の状態を保存する必要もない。

保存すべきは、各基地の資源在庫と、建設済みの設備と、クレジットの残高だけである。これらはすでに基地の状態としてセーブに含まれる。

## 11. 技術的リスク

### 11-1. 設備の連鎖が詰まる

ある資源を得るのに必要な設備が、その資源自身を必要とする循環が生じると、進行が止まる。これは**到達可能性の閉包を求める問題であり、テストで機械的に検証できる。**

検証の実装は次の形をとる。

```ts
// tests/economy/resource-closure.test.ts
// 初期資源の集合から出発し、不動点に達するまで前方に閉じる
function reachableClosure(
  initial: ReadonlySet<string>,          // 資源 id
  facilities: readonly FacilityDef[],
  deposits: readonly DepositDef[],
  reachableBodies: (owned: ReadonlySet<string>) => ReadonlySet<AttractorId>,
): ReadonlySet<string> {
  const owned = new Set(initial);
  for (;;) {
    const before = owned.size;
    // 1. 今の資源で建てられる設備を全て建てる
    for (const f of facilities) {
      if (!f.buildCost.every((c) => owned.has(c.resourceId))) continue;
      if (!f.requiresFacility.every((id) => builtIds.has(id))) continue;
      if (!f.inputs.every((i) => owned.has(i.resourceId))) continue;
      builtIds.add(f.id);
      for (const o of f.outputs) owned.add(o.resourceId);
    }
    // 2. 今の推進剤で届く天体の産地を全て採る
    for (const d of deposits) {
      if (!reachableBodies(owned).has(d.bodyId)) continue;
      owned.add(d.resourceId);
    }
    if (owned.size === before) break;   // 不動点
  }
  return owned;
}
```

テストは、初期資源（月南極の基地が持つ太陽電池・氷採掘機と、その建設に要った金属）から始めてこの閉包を求め、**`RESOURCES` のすべての id が閉包に含まれることを確かめる。**含まれないものがあれば、その資源に至る経路が存在しないということであり、データの誤りである。

`reachableBodies` は、その時点で持っている推進剤の最良の比推力と、現実的な質量比（3〜6）から Δv を求め、§4-2 の表と突き合わせて届く天体を返す。**炭素を持っているかどうかで大気制動の可否が変わるため、この関数は所持資源に依存する。**閉包の反復のたびに再評価する。

### 11-2. 意図した循環と、それを破る質量比

木星大気のヘリウム3は、核融合推進なしには持ち帰れず、核融合推進はヘリウム3を必要とする（§6-5）。これは意図した循環であり、核熱推進と電気推進を組み合わせた片道の大型機で破る設計になっている。

**§11-1 の閉包の検証は、この経路を「破れる」と正しく判定しなければならない。**そのためには、核融合以外の推進で木星大気から脱出できる質量比が実際に存在することを、数値で確かめる必要がある。

```ts
// tests/economy/jupiter-escape.test.ts
// 木星大気の捕集点から脱出する 20 km/s が、核熱＋電気推進の
// 二段構成で出せる質量比を持つことを確かめる
const G0 = 9.80665;
const dv = (isp: number, massRatio: number) => isp * G0 * Math.log(massRatio);

// 第1段: 核熱推進（Isp 900 s）で大気圏から脱出速度へ
// 第2段: 電気推進（Isp 3000 s）で惑星間軌道へ
const stage1 = dv(900, 6);     // ≈ 15.8 km/s
const stage2 = dv(3000, 1.5);  // ≈ 11.9 km/s
assert(stage1 + stage2 >= 20_000);
```

テストは、この2段の合計 Δv が §4-2 の木星脱出 20 km/s を上回ることを、比推力と質量比から実際に計算して確かめる。質量比 6 と 1.5 はいずれも現実的な範囲に収まる。**この関係が成り立たなくなるほど比推力の表や Δv の表が変わった場合、テストが落ちることで循環が破れなくなったことが分かる。**

第1段が核熱推進でなければならないのは、木星の大気圏内から脱出速度まで加速するのに電気推進の推力（10⁻⁴ m/s²）ではまったく足りないためである。逆に第2段が電気推進でよいのは、重力圏を出た後は時間をかけられるためである。**この役割分担そのものが、テストの構造として表れている。**

### 11-3. 進行が長すぎる

月面から核融合までの道のりは長い。各段階で何が新しくできるようになるかが明確でないと、進行が作業に感じられる。段階ごとに「新しく届く場所」が増えることを、地図の上で見えるようにする必要がある。**大気制動の解禁（炭素の入手）は Δv の表そのものを書き換えるため、地図上の変化が最も大きい瞬間になる。**ここを見せ場として扱う。

### 11-4. 資源の種類が多すぎる

18種の元素と、そこから作られる推進剤・構造材・熱防護材を合わせると、在庫の一覧が長くなる。用途ごとにまとめて表示し、使わないものは折り畳む必要がある。**市場の画面も同じ問題を持つ**ため、在庫と市場は同じ分類でまとめる。

### 11-5. 電気推進の時間スケール

加速度が 10⁻⁴ m/s² の程度であるため、意味のある Δv を得るのに数か月かかる。この作品は時間加速を持つため成立するが、**時間加速の上限（131072倍）でも数分の実時間がかかる。**電気推進の機体は計画に任せて放置し、他の機体を操作している間に進む、という運用になる。これが成立するかは、複数機体の同時運用の使い勝手に依存する。

### 11-6. 磁気トルカの領域依存が分かりにくい

低軌道では姿勢制御が無料であり、月周辺では推進剤を消費する。**この差は、切り替わった瞬間には見えない。**月へ向かった機体の推進剤が思ったより速く減る、という形でしか現れない。磁気トルカが働いているかどうかを HUD に常時表示し、働かなくなった瞬間に通知を出す必要がある。
