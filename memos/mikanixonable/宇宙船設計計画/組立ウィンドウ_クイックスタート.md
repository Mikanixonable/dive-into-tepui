# 組立ウィンドウ クイックスタート

作成日 2026-08-20。第11版_1 の A群で入った組立の操作手順。**現時点の実装がそのまま何を受け付ける
か**を書く(設計の意図ではなく、押せるものと起きることを書く)。

> **先に読む制約**: 「確定」は既定の有人艦・軌道基地のどちらでも成功しない。原因と取りうる案は
> `第11版_実装中の決定事項.md` §1。**それが解けるまで、以下の操作は確定できない**(取消はできる)。
> また、取り付け・断面編集・部材生成のいずれも、**確定するまで機体の見た目は変わらない**(同 §3)。

## 開く

1. マップビュー([M])で基地を**右クリック**する。
2. 出たウィンドウの **「組み立てる」** を選ぶ。

開いた瞬間にゲームは**一時停止**する。世界が動かないのは、確定していない構造の下で時間を進め
ないため。基地の在庫だけを見たいなら、同じメニューの「基地の操作を開く」が別のウィンドウ。

## ウィンドウの読み方

上から順に:

| 段 | 中身 |
|---|---|
| タブ | 編集する対象 — 基地本体 / ドックの格納艦 / 新規船下書き |
| 操作 | 元に戻す・やり直す・**確定**・取消 |
| 下書き | 新規船下書き / 建造して格納(費用がラベルに出る) |
| 選択 | いま 3D で選んでいるノード・エッジと「選択を削除」 |
| 断面編集 | ノードを選んでいるときだけ出る |
| 部材棚 | 種別・長さ・半径(分離機構なら撃力)と「部材を掴む」 |
| 検証 | この対象の設計エラー |
| 部品棚 | 基地の倉庫にある部品。種別ごとにまとまっている |

カメラは対象に合わせて自動で寄る。タブを切り替えると寄り直す。左右ドラッグで回転、ホイールで
寄り引き —— 通常の追従カメラと同じ。

## 部品を付ける

1. 部品棚のボタンを**クリック**する → その部品を**掴んだ**状態になる(ゴーストが出る)。
2. カーソルを機体の上へ動かす。取り付けられる位置に近づくとゴーストがそこへ吸い付く。
3. もう一度**クリック**すると離す。**緑なら付き、赤なら付かずに捨てる**。

**ドラッグではなくクリック2回**(掴む → 離す)。掴んでいる間はカメラを回してよい。

すでに機体に付いている部品を**クリック**しても同じ状態になる(掴み上げ)。そのまま別の場所へ
離せば移動、赤いまま離せば倉庫へ戻る。

## 部材(構造)を伸ばす

1. 部材棚で種別(外皮 / トラス / 分離機構)・長さ・断面半径を決める。長さは 0.5 m 刻みに丸められる。
2. **「部材を掴む」** を押す。
3. 機体の**空いている接続口**へカーソルを寄せると、そこから部材が伸びた形のゴーストが出る。
4. クリックで確定。接続口の外向きに、指定した長さのノードが1つ生える。

**両端を既存の接続口に繋ぐことはできない**(閉じた構造は作れない)。部材は必ず空き口から新しい
ノードを生やす形になる。

## 断面を編集する

1. 3D で**ノード**をクリックして選ぶ。
2. 断面編集の段が出る。プリミティブが複数あるなら、まずどれを編集するか選ぶ。
3. 形状の種別・寸法・位相角を変える。数値欄は **Enter か欄外クリックで確定、Esc で破棄**。

**プリミティブの追加・削除はできない**(既存の1つの形と位相だけを編集する)。

## 消す

3D で**ノードかエッジ**をクリックして選び、「選択を削除」。部品は掴み上げて赤いまま離せば倉庫へ
戻る。

## 新しい船を作る

1. **「新規船下書き」** を押す。既定の有人艦の構成をコピーした下書きがタブに増える。
2. 下書きのタブで、上の手順どおりに編集する。
3. **「建造して格納」** —— ラベルに出ている資源を基地の帳簿から引き、実艦としてドックへ入る。
   倉庫から持ってきた部品はすでに作ってあるので二重には課金されない。

下書きだけは**ノード・エッジを 3D で選べない**(ワイヤーフレームを持たないため、`第11版_実装中の
決定事項.md` §4)。部品の取り付けはできる。

## 閉じる

- **確定** —— すべての対象が検証を通ったときだけ、まとめて実機へ書き戻す。1つでも通らなければ
  何も適用しない(基地とドックの艦が同じ接続口の認識で食い違わないため)。
- **取消** —— 何もせずに捨てる。実機には最初から触れていないので、戻す作業は無い。

どちらもゲームの一時停止を解く。セッション中は機体を発進させられない。

## つまずきやすいところ

- **ノードとエッジは既定では見えない**が、組立中は強制的に表示される。セッションを抜ければ
  描画設定どおりに戻る。
- **なぜ付かないかは画面に出ない**。ゴーストが赤いことしか分からない(同 §4)。
- クリックは**1フレームに1回**しか効かない。離した直後に同じ場所を掴み直すことはできない。
