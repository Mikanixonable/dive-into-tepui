# 船体設計システム — 実装計画

この文書は、プレイヤーが宇宙船の形状を設計し、保存し、生産できるようにするための計画である。

対象は以下の5つである。

1. 断面の定義と、その面積・断面二次モーメントの計算（§3、§5）
2. ノードとエッジからなる背骨と、そこから生成される外皮（§4、§6、§7）
3. 搭載要素の配置と内容積の割り当て（§8）
4. 設計の保存・検証・生産と、技術ツリーによる解禁（§9）
5. 設計エディタ（§10）

**他の巻との関係** — この巻は『推進系と推進剤』の巻で実装する `Vessel` への統合に依存する。艦艇と軌道基地が単一のエンティティ `Vessel` になっており、搭載要素の型と性能値が定義済みであることを前提とする。ただし §3 と §5（断面の幾何）は `src/physics/` に閉じた純関数のみであり、いかなる依存も持たない。この2節は他のすべてに先行して着手できる。

配管の敷設、タンクの与圧、分離機構による多段化、ペイロードの投入は『配管・多段・ペイロード』の巻の対象である。この文書では、エッジの種別として分離機構が存在することと、内容積に配管を収められることのみを扱い、その動作には踏み込まない。

## 1. 設計判断

### 1-1. 船体は背骨と断面で定義する

宇宙船の形状は、**ノードとエッジからなる背骨**と、**各ノードが持つ断面**で定義する。外皮は、エッジの両端にある2つの断面をつないだ立体（ロフト）として生成する。

エッジから外皮までの距離は定数ではなく、両端のノードの断面寸法によって決まる。したがって、細い部分と太い部分を持つ機体、先細りの機体、段ごとに直径の異なるロケットが、追加の機構なしに作れる。

### 1-2. 断面が分岐方向を決める

各ノードは、断面の表裏に向かう2つの軸方向の接続口と、断面形状ごとに決まる側面の接続口を持つ。側面の口の方向は断面が決め、各ノードが持つ回転位相ぶん回る。

- **多角形の断面** — 各辺の外向き法線の方向に口を持つ。三角形なら3方向、八角形なら8方向である。
- **円の断面** — プレイヤーが分岐数 n を 2・3・4・5・6 から選び、360度を n 等分した方向に口を持つ。分岐数2なら0度と180度、分岐数3なら0度と120度と240度である。
- **楕円の断面** — 長軸の正負2方向に口を持つ。

分岐の角度をプレイヤーが数値で指定する操作は存在しない。角度は断面形状と分岐数と回転位相から決まる。

### 1-3. 結合はすべて平面同士の突き合わせとする

エッジと断面の結合、側面分岐の結合、および断面を組み合わせて複合断面を作るときの結合は、いずれも平面同士の突き合わせとする。曲面同士を滑らかに融合させる処理も、立体同士の重なりを差し引く処理も行わない。

この判断により、外皮の体積・表面積・重心・慣性テンソルがすべて解析式で求まり、部分同士が重なることもない。数値積分も、等値面の三角形分割も不要である。実際のロケットも、段間部と側面ブースターの取り付けはフランジ結合であり、工学的にも自然である。

円の断面に側面の口を設ける場合のみ、その方向の円弧を弦で切り落として平面を作る。切り落としによる断面積と断面二次モーメントの減少は、弓形の解析式を差し引いて厳密に計算する。

### 1-4. 寸法は0.5メートル単位とする

エッジの長さ、および断面の外接円半径は、いずれも0.5メートル単位で指定する。連続値にすると、対称な機体や、断面の揃った段を組むことが困難になる。

### 1-5. 物理量は形状から導出する

質量・重心・慣性テンソル・断面積は定数として持たず、背骨と断面と搭載物から導出する。扁平な機体は実際に回りにくく、非対称な機体は実際に重心がずれる。

### 1-6. 設計と生産を分ける

プレイヤーは、資源を消費せずに設計を作り、名前を付けて保存し、読み込める。実機を得るには、保存した設計を指定して生産する。生産には時間がかかる仕組みを持つが、初期状態ではすべての設計の生産時間を0とする。

## 3. 断面

### 3-1. 定義

断面は、1つ以上の**基本断面**を面で貼り合わせた複合体である。

```ts
// src/game/vessel/cross-section.ts
export type PrimitiveShape =
  | { kind: 'circle';   radius: number; branchCount: 2 | 3 | 4 | 5 | 6 }
  | { kind: 'ellipse';  majorRadius: number; minorRadius: number }
  | { kind: 'polygon';  sides: 3 | 4 | 5 | 6 | 8; radius: number }
  | { kind: 'notched';  sides: 6 | 8; radius: number };  // 辺長が 1:2 で交互する切り欠き型

export interface SectionPrimitive {
  readonly id: string;
  readonly shape: PrimitiveShape;
  readonly phaseAngle: number;                      // この基本断面の回転位相 [rad]
  readonly attachment: PrimitiveAttachment | null;  // null は複合体の根
}

export interface PrimitiveAttachment {
  readonly parentId: string;            // 貼り付け先の基本断面
  readonly parentFaceIndex: number;     // 貼り付け先のどの辺に付けるか
  readonly childFaceIndex: number;      // 自分のどの辺を貼り付けるか
}

export interface CrossSection {
  readonly primitives: readonly SectionPrimitive[];
}
```

- 複合体は木構造である。各基本断面は、親の1つの辺に、自分の1つの辺を重ねて貼り付ける。
- 貼り付ける2つの辺は長さが等しくなければならない。等しくない場合は設計として不正とし、エディタが理由を表示する。
- 貼り合わせ面を共有するため、基本断面同士は重ならない。したがって複合断面の面積は基本断面の面積の和であり、断面二次モーメントは平行軸の定理で合成した和である。
- 円と楕円は辺を持たないため、複合体の根としてのみ使える。子として貼り付けることはできない。

例として、四角形断面の一辺に三角形断面を貼り付けると、五角形の家型の断面になる。四角形の対辺2つに三角形を貼り付ければ、六角形の紡錘型になる。八角形の複数の辺に四角形を貼り付ければ、突起を持つ断面になる。

### 3-2. 基本断面の形状

| 形状 | 寸法パラメータ | 側面の口の数 | 口の方向 |
|---|---|---|---|
| 円 | 半径 | 2・3・4・5・6 から選ぶ | 360度を分岐数で等分した方向 |
| 楕円 | 長半径・短半径 | 2 | 長軸の正負方向 |
| 正三角形 | 外接円半径 | 3 | 各辺の外向き法線 |
| 正方形 | 外接円半径 | 4 | 各辺の外向き法線 |
| 正五角形 | 外接円半径 | 5 | 各辺の外向き法線 |
| 正六角形 | 外接円半径 | 6 | 各辺の外向き法線 |
| 正八角形 | 外接円半径 | 8 | 各辺の外向き法線 |
| 切り欠き六角形 | 外接円半径 | 6 | 各辺の外向き法線 |
| 切り欠き八角形 | 外接円半径 | 8 | 各辺の外向き法線 |

**切り欠き型** — 正多角形の辺の長さがすべて等しいのに対し、切り欠き型は長い辺と短い辺が1対2の比で交互に並ぶ。

- **切り欠き八角形** — 正方形の4つの角を切り落とした形である。長さ2の辺が4つ（元の正方形の辺の残り）と、長さ1の辺が4つ（切り落とした角の断面）を持つ。長い辺の中点に大きな面を確保しつつ、角の張り出しを抑えられる。
- **切り欠き六角形** — 正三角形の3つの角を切り落とした形である。長さ2の辺が3つと、長さ1の辺が3つを持つ。

切り欠き型は、正多角形より広い平面を確保しながら外接円半径を抑えられるため、太陽電池パドルや放熱板のような広い取り付け面を要する部品を並べるのに適する。

## 4. 背骨

```ts
// src/game/vessel/skeleton.ts
export interface SkeletonNode {
  readonly id: string;
  readonly pos: Vec3;              // 船体ローカル座標 [m]。0.5 m 単位
  readonly section: CrossSection;
  readonly axis: Vec3;             // 断面の法線（背骨の進行方向）
  readonly phaseAngle: number;     // 断面全体の回転位相 [rad]
}

export type EdgeKind =
  | { kind: 'hull' }                                   // 外皮を作る。内側が内容積になる
  | { kind: 'strut'; radius: number }                  // 外皮を作らない構造材
  | { kind: 'decoupler'; separationImpulse: number };   // 外皮を作らず、切り離せる

export interface SkeletonEdge {
  readonly id: string;
  readonly a: string;
  readonly b: string;
  readonly portA: PortRef;
  readonly portB: PortRef;
  readonly length: number;         // 0.5 m 単位
  readonly kind: EdgeKind;
}

export type PortRef =
  | { kind: 'axial'; sign: 1 | -1 }
  | { kind: 'lateral'; primitiveId: string; faceIndex: number };

export interface VesselSkeleton {
  readonly nodes: readonly SkeletonNode[];
  readonly edges: readonly SkeletonEdge[];
}
```

背骨はグラフであり、閉路を含んでよい。三角形や梯子状に組めば扁平な機体になる。

側面の口の**大きさ**は、その辺の長さと、辺に沿った規定の幅で決まる。側面から分岐するエッジの相手側の断面は、この口に収まる大きさでなければならない。収まらない場合は設計として不正とし、エディタが理由を表示する。

`decoupler` エッジは、分離可能な境界を表す。この巻ではエッジの種別として存在し、外皮を作らないことのみを扱う。分離の動作は『配管・多段・ペイロード』の巻の対象である。

## 5. 断面の面積と断面二次モーメント

基本断面が多角形（正多角形・切り欠き型・複合体の構成要素）である場合、頂点列から以下で厳密に求める。頂点を反時計回りに `(x_i, y_i)`、`i` の次を `i+1` として、

```
cross_i = x_i·y_{i+1} − x_{i+1}·y_i
A   = (1/2)    · Σ cross_i
Cx  = (1/(6A)) · Σ (x_i + x_{i+1}) · cross_i
Cy  = (1/(6A)) · Σ (y_i + y_{i+1}) · cross_i
Ix  = (1/12)   · Σ (y_i² + y_i·y_{i+1} + y_{i+1}²) · cross_i
Iy  = (1/12)   · Σ (x_i² + x_i·x_{i+1} + x_{i+1}²) · cross_i
Ixy = (1/24)   · Σ (x_i·y_{i+1} + 2·x_i·y_i + 2·x_{i+1}·y_{i+1} + x_{i+1}·y_i) · cross_i
```

を求め、平行軸の定理で重心まわりに移す。この式は任意の単純多角形に対して厳密であり、形状ごとの個別の式を持つ必要がない。切り欠き型も、複合断面も、この1つの式で扱える。

**相乗モーメント `Ixy` は0とは限らない。** 複合断面が対称でない場合、断面の主軸は座標軸から回転する。慣性テンソルの計算では `Ixy` を必ず含める。正多角形と円だけであれば `Ixy` は常に0になるが、複合断面を導入する以上これは成り立たない。

円と楕円は解析式で求める。

```
円（半径 r）      A = πr²,   Ix = Iy = πr⁴/4,   Ixy = 0
楕円（半径 a, b）  A = πab,   Ix = πab³/4,        Iy = πa³b/4,   Ixy = 0
```

**円に側面の口を設ける場合** — その方向の円弧を弦で切り落とし、平面を作る。切り落とされる弓形の中心角を `θ`、半径を `r` として、

```
弓形の面積        A_seg = (r²/2)·(θ − sin θ)
弓形の重心距離     d_seg = (4r·sin³(θ/2)) / (3·(θ − sin θ))
弓形の断面二次モーメント は θ の閉形式で求まる
```

を円の値から差し引く。分岐数ぶんの弓形を、それぞれの方向で差し引く。切り落とし量は口の幅から決まる。

```
src/physics/section-moments.ts   (純関数)
    polygonArea(vertices) -> number
    polygonCentroid(vertices) -> { x, y }
    polygonSecondMoments(vertices) -> { ix, iy, ixy }          // 重心まわり
    circleSegmentMoments(radius, halfAngle) -> { area, centroidDist, ix, iy }
    sectionMoments(section) -> { area, centroid, ix, iy, ixy }  // 複合断面全体
    sectionOutline(section, sampleCount) -> readonly Vec2[]     // ロフト用の輪郭
```

検証は `tests/physics/section-moments.test.ts` に置く。正n角形の面積と断面二次モーメントが既知の閉形式と一致すること、辺数を増やすと円の値に収束すること、切り欠き八角形が「正方形から4つの直角三角形を引いた値」と一致すること、複合断面の面積が構成要素の和と一致すること、対称な複合断面の `Ixy` が0になり非対称なものは0でないことを固定する。

## 6. 外皮の生成と立体の物理量

### 6-1. 外皮の生成

`hull` エッジは、両端のノードの断面をつないだ立体を作る。

- 両断面の輪郭を、それぞれ**120点**に等分してサンプリングする。120は3・4・5・6・8のいずれでも割り切れるため、辺数の異なる断面同士でも頂点が一対一に対応する。円と楕円も同じ120点で表す。
- 対応する頂点同士を直線で結び、側面を四角形の帯として張る。
- 両断面の回転位相が異なる場合、頂点の対応は位相差を考慮して、対応する頂点間の距離の総和が最小になる割り当てを選ぶ。これにより外皮がねじれない。
- 複合断面の場合、輪郭は複合体全体の外周である。貼り合わせ面の内側は輪郭に含まれない。

側面の口から分岐するエッジは、口の平面の上に相手側の断面を置き、そこから同じ規則でロフトする。分岐部は平面同士の突き合わせであり、本体の外皮と交差しない。

### 6-2. 物理量

外皮は「断面が軸方向に線形に変化する一般化角錐台」の集まりである。

**エッジ1本の体積** — 長さ `h`、両端の断面積 `A₁` / `A₂`、中間断面の面積 `Am` として

```
V = (h/6)·(A₁ + 4·Am + A₂)
```

輪郭を線形補間するため中間断面は両端の輪郭の平均であり、`Am` はその平均輪郭の面積である。

**慣性テンソル** — 軸に沿った位置 `t ∈ [0, h]` における断面積 `A(t)`、断面二次モーメント `Ix(t)` / `Iy(t)` / `Ixy(t)`、断面重心 `C(t)` は、いずれも `t` の多項式である。したがって

```
I_axial      = ρ ∫ (Ix(t) + Iy(t)) dt
I_transverse = ρ ∫ (I(t) + A(t)·|C(t) − C_ref|²) dt
I_product    = ρ ∫ (Ixy(t) + A(t)·(...)) dt
```

はいずれも多項式の積分として閉形式で求まる。各エッジの慣性テンソルを平行軸の定理で船体重心まわりに移して合成する。

**表面積** — 側面の帯の面積の和に、露出した端面（他のエッジが接続していない断面）を加える。

**参照断面積** — 主軸3方向への投影面積のうち最大値。抗力係数 `bcInv = Cd·A/m` に用いる。

```
src/physics/hull-loft.ts   (純関数)
    loftVolume(sectionA, sectionB, length) -> number
    loftInertia(sectionA, sectionB, length, density) -> InertiaTensor
    loftCentroid(sectionA, sectionB, length) -> number
    loftSurfaceArea(sectionA, sectionB, length) -> number
    loftProjectedArea(sectionA, sectionB, length, axis) -> number
```

検証は `tests/physics/hull-loft.test.ts` に置く。円断面の等断面ロフトが円柱の解析値と一致すること、両端の断面積が等しい角錐台の体積が `A·h` になること、L字に組んだ骨格の慣性主軸が3値とも異なること（すなわちジャニベコフ効果が発生する形状であること）を固定する。

### 6-3. 質量特性の合成

```ts
// src/game/vessel/mass-properties.ts
export interface MassProperties {
  readonly dryMass: number;        // 構造 + 搭載要素の乾燥質量 [kg]
  readonly loadedMass: number;     // 推進剤と貨物を含む総質量 [kg]
  readonly centerOfMass: Vec3;     // 船体ローカル座標
  readonly inertia: InertiaTensor; // 重心まわり
  readonly referenceArea: number;  // 抗力の参照断面積 [m²]
}
export function deriveMassProperties(
  skeleton: VesselSkeleton,
  placements: readonly PartPlacement[],
  propellant: PropellantStore,
): MassProperties;
```

構造の質量は外皮の表面積と肉厚から求める。搭載要素はそれぞれの取り付け位置に質点として置く。推進剤はそれを収めるエッジの内容積の重心に置く。推進剤が減れば重心と慣性テンソルが変わるため、質量が一定量変化したときに再計算する。

## 7. 描画

```
src/render/hull/loft-mesh.ts
    buildLoftMesh(skeleton, lod) -> THREE.BufferGeometry
```

エッジごとに120分割のロフト帯を生成し、露出した端面を蓋で閉じ、全体を1つのジオメトリに結合する。生成は設計が変わったときに1度だけ行う。遠距離では分割数を下げた別のジオメトリを用いる。

`WebGPURenderer` は `Mesh` のジオメトリを最初の描画時にキャッシュするため、生成済みメッシュのジオメトリを差し替えてはならない。設計変更時は `Mesh` ごと作り直す。

外装の搭載要素は、取り付けたノードの接続口の位置と向きに置く。これらは個別のメッシュとして外皮のメッシュに子として付ける。

## 8. 搭載要素の配置と内容積

### 8-1. 配置

搭載要素は、背骨のノードに取り付ける**外装要素**と、エッジの内容積に収める**内装要素**に分かれる。

- **外装要素** — 武器、ドッキングポート、太陽電池パドル、放熱板、エンジン、RCSスラスタ。ノードの空いている接続口に取り付ける。接続口を1つ占有するため、そこからエッジを伸ばすことはできない。
- **内装要素** — 酸化剤タンク、還元剤タンク、球状イナートガスタンク、RCS推進剤タンク、バッテリー、コックピット、自動操縦装置、弾薬庫、配管、ペイロード倉庫、フライホイール、基地モジュール。`hull` エッジの内容積に収める。

```ts
// src/game/vessel/assembly.ts
export type PartPlacement =
  | { kind: 'external'; partId: string; nodeId: string; port: PortRef }
  | { kind: 'internal'; partId: string; edgeId: string };

export interface VesselAssembly {
  readonly skeleton: VesselSkeleton;
  readonly placements: readonly PartPlacement[];
}
```

### 8-2. 内容積の割り当て

`hull` エッジそれぞれの内容積に、プレイヤーが何を収めるかを指定する。そのエッジのロフト体積が上限である。1つのエッジに複数の内装要素を収めてよく、その体積の和が上限を超えないこと。

| 収容物 | 実効容積の係数 | 備考 |
|---|---|---|
| 極低温タンク（液体水素・液体酸素・液体メタン） | 0.85 | 断熱材のぶん減る |
| 常温貯蔵タンク（ヒドラジン・四酸化二窒素・過酸化水素） | 0.95 | |
| イナートガスタンク（球状） | 0.55 | 球をエッジの内容積に詰めるため、球以外の空間が死ぬ |
| RCS推進剤タンク | 0.95 | |
| ペイロード倉庫・弾薬庫 | 0.90 | 容積と最大積載質量の両方で制限される |
| コックピット | 0.80 | 与圧に必要な構造のぶん減る |
| バッテリー・自動操縦装置・フライホイール | 1.00 | |
| 配管 | 口径から決まる | エッジの長さと口径の断面積の積 |

固体モーターはタンクではなく、エッジそのものである。ケースが構造材を兼ねるため、固体モーターを割り当てたエッジは `hull` エッジ1本がモーター1基に対応する。

**イナートガスタンクが球状である理由** — 内圧に対して最も効率のよい圧力容器は球である。同じ耐圧なら球は円筒より薄い壁で済み、タンク自体の質量が小さい。一方、球は角柱状の内容積に詰めたときの充填率が悪い。この対立が実効容積の係数0.55として現れる。

## 9. 設計の保存・生産・技術ツリー

### 9-1. 設計データ

```ts
// src/game/vessel/blueprint.ts
export interface VesselBlueprint {
  readonly id: string;
  name: string;
  readonly skeleton: VesselSkeleton;
  readonly placements: readonly PartPlacement[];
  readonly feedNetwork: FeedNetwork;    // 配管の敷設
  readonly paint: PaintScheme;
  readonly stageOrder: readonly string[];
  readonly createdAt: number;
  readonly updatedAt: number;
}
export interface PaintScheme {
  primaryColor: string;
  secondaryColor: string;
  accentColor: string;
  metalness: number;
  roughness: number;
}
```

設計は `localStorage` の `tepui.blueprints` に保存する。保存・読み込み・複製・削除・改名ができる。既存のセーブデータの入出力と同じ方式でファイルへの書き出しと読み込みも行う。

`feedNetwork` と `stageOrder` は、この巻では空の値として保持するのみである。内容の解決は『配管・多段・ペイロード』の巻が担う。

### 9-2. 検証

設計の検証は独立した純関数とし、エディタと生産の両方が同じ関数を呼ぶ。

```ts
// src/game/vessel/blueprint-validation.ts
export interface BlueprintIssue {
  readonly severity: 'error' | 'warning';
  readonly targetId: string;      // ノード／エッジ／搭載要素の id
  readonly message: string;
}
export function validateBlueprint(bp: VesselBlueprint): readonly BlueprintIssue[];
```

この巻で検証する内容:

- 背骨が連結していること
- 複合断面の貼り合わせ面の長さが一致すること
- 側面の口から出るエッジの断面が口に収まること
- 1つの接続口に、エッジと外装要素が同時に割り当てられていないこと
- 内容積の割り当てがロフト体積を超えないこと
- コックピットまたは自動操縦装置を1つ以上持つこと
- 推力軸と重心のずれが規定内であること
- ノード数・総質量・最大寸法・複合断面の構成要素数が上限以内であること
- 技術ツリーで未解禁の要素を含まないこと

配管の連結、イナートガスの供給、弾薬庫の有無に関する検証は『配管・多段・ペイロード』の巻で追加する。

### 9-3. 生産

生産は、保存した設計を指定し、資源とクレジットを消費して実機を得る操作である。

```ts
export interface ProductionTask {
  readonly id: string;
  readonly blueprintId: string;
  readonly startedAt: number;      // simTime
  readonly finishAt: number;       // simTime
}
```

- 生産コストは、搭載要素ごとの単価と、外皮の表面積に比例する構造費の和とする。
- 生産時間は搭載要素の合計から求めるが、**初期状態では係数を0とし、すべての設計が即座に完成する**。時間のかかる生産は仕組みとして用意し、有効にするのは後の判断とする。
- 生産キューは基地モジュールを持つ機体が保持する。完成した機体はその基地の格納庫に配備される。

### 9-4. 技術ツリー

エンジンの型式、断面形状、推進剤、搭載要素は、技術ツリーの解禁によって使えるようになる。

```ts
// src/game/tech/tech-tree.ts
export interface TechNode {
  readonly id: string;
  readonly name: string;
  readonly description: string;
  readonly cost: number;                    // 研究点
  readonly requires: readonly string[];
  readonly unlocks: readonly string[];
}
export const TECH_TREE: readonly TechNode[];
```

- 研究点は敵の撃破とステージのクリアで得る。保持は `localStorage` の `tepui.tech` に置き、解禁済みの技術 id の集合と研究点の残高を保存する。
- 初期状態で解禁されているのは、円と正方形の断面、加圧式エンジン、四酸化二窒素／モノメチルヒドラジン、ヒドラジン単推進剤、固体モーター、窒素イナートガス、基本的な配管とタンクである。
- 解禁の対象は、断面形状（三角形・五角形・六角形・八角形・切り欠き六角形・切り欠き八角形・楕円）、円の分岐数の増加、複合断面、エンジンのサイクル、推進剤ペア、ヘリウムイナートガス、フライホイール、ジンバル機構、大口径の配管、大型の分離機構、ペイロード倉庫、ドッキングポートである。
- 未解禁の要素は設計エディタのパレットに表示するが、選択できず、解禁に必要な技術を表示する。

### 10-2. 骨格モード

左パネルの内容:

| 区画 | ウィジェット | 内容 |
|---|---|---|
| 選択中のノード | 一覧 | このノードの接続口。使用中／空きを表示し、空きをクリックすると新規ノードが生える |
| | `Slider` | 断面全体の回転位相（15度刻みのスナップあり） |
| 選択中のエッジ | `SegmentedControl<EdgeKind>` | 外皮／構造材／分離機構 |
| | `ValueInput` | 長さ（0.5 m 単位。増減ボタンは0.5 m刻み） |
| | `ValueInput` | 構造材の場合の半径、分離機構の場合の分離力積 |
| 全体 | `ToggleSwitch` | YZ平面のミラー編集 |
| | `Button` | 選択中のノード以下を削除 |

操作:

- **ノードの追加** — 選択中のノードの空いている接続口をクリックする。既定の長さのエッジと、同じ断面のノードが生える。生えた先が新しい選択対象になる。3Dビューポート上の接続口を直接クリックしても同じ操作になる。
- **ノードの移動** — エッジの長さを変えることで行う。ノードの座標を直接ドラッグする操作は持たない。位置は接続関係と長さから一意に決まる。
- **削除** — 選択中のノードとその先につながる部分をまとめて削除する。削除の前に、削除される範囲を3Dビューポート上で強調表示する。
- **ミラー編集** — 有効な間、YZ平面の片側で行った操作が反対側にも同時に適用される。
- **元に戻す／やり直す** — 設計データ全体のスナップショットを操作ごとに保持する。上限は50手とする。

### 10-3. 断面モード

選択中のノードの断面を編集する。複合断面を扱うため、骨格モードから分離した専用のモードとする。

左パネルの内容:

| 区画 | ウィジェット | 内容 |
|---|---|---|
| 複合体の構成 | ツリー表示 | 基本断面の木構造。行を選ぶとその基本断面を編集する |
| 選択中の基本断面 | `SegmentedControl<PrimitiveShape>` | 円／楕円／三角／四角／五角／六角／八角／切り欠き六角／切り欠き八角。未解禁の形状は選択できない |
| | `ValueInput` | 外接円半径（0.5 m 単位） |
| | `ValueInput` | 楕円の短半径（楕円選択時のみ） |
| | `SegmentedControl<2\|3\|4\|5\|6>` | 円の分岐数（円選択時のみ） |
| | `Slider` | この基本断面の回転位相 |
| 貼り付け | `Button` | 選択中の辺に新しい基本断面を貼り付ける |
| | 表示 | 貼り付け先の辺の長さと、貼り付ける断面の辺の長さ。一致しない場合は警告 |
| 断面の性能 | 表示 | 面積、内容積への寄与、断面二次モーメント、主軸の角度 |

中央のビューポートは、選択中のノードの断面を正面から見た2D表示に切り替わる。辺をクリックすると、その辺が「側面の口の候補」か「基本断面の貼り付け先」かを選べる。

### 10-4. 搭載モード

左パネルの内容:

| 区画 | ウィジェット | 内容 |
|---|---|---|
| 要素パレット | 種別ごとのアコーディオン | 外装要素と内装要素の一覧。未解禁のものは選択できず、必要な技術を表示する |
| 選択中の要素 | 表示 | 質量・性能値・コスト |
| 選択中のエッジの内容 | 一覧 | そのエッジに収めた内装要素。追加・削除ができる |
| | 表示 | ロフト体積、実効容積の合計、残容積、収容質量 |

操作:

- 要素パレットで外装要素を選び、3Dビューポート上のノードの空いている接続口をクリックすると装着する。装着できない口はクリックできず、理由をヒントで示す。
- ホバー中は、装着した場合の外観を半透明で表示し、右パネルの性能に差分を表示する。
- エッジをクリックすると、その内容積の割り当てを編集する。

### 10-5. 塗装モード

左パネルに、基本色・副色・アクセント色のカラー選択、金属感と粗さのスライダー、および既定の配色プリセットを置く。3Dビューポートに即座に反映する。

### 10-6. データの流れ

```
DesignEditorState (エディタの編集中データ、Undo/Redo のスタックを持つ)
    │  編集操作ごとに
    ▼
VesselBlueprint
    ├─► validateBlueprint()        → 左パネルと3Dビューポートの問題表示
    ├─► sectionMoments()           → 断面モードの性能表示
    ├─► deriveMassProperties()     → 右パネルの質量・重心・慣性
    ├─► deriveProductionCost()     → 右パネルのコスト
    └─► buildLoftMesh()            → 3Dビューポートの外皮表示
```

性能計算は編集操作のたびに実行する。計算はすべて解析式であり、ノードとエッジの数に対して線形であるため、毎操作の実行で問題にならない。外皮メッシュの生成のみ、編集が一定時間止まってから実行する。

## 13. 技術的リスク

1. **複合断面の輪郭抽出** — 複合断面の外周は、基本断面の輪郭から貼り合わせ面を除いて連結したものである。貼り合わせ面が完全に一致していることが前提であり、浮動小数点の誤差で隙間や重なりが生じると輪郭が破綻する。辺の長さの一致は設計の検証で保証し、輪郭の連結は頂点の同一性ではなく、貼り合わせの木構造をたどって構成する。
2. **断面をまたぐ頂点の対応** — 辺数の異なる断面や、回転位相の異なる断面をつなぐとき、頂点の対応を誤ると外皮がねじれる。120点への等分と、対応距離の総和を最小にする割り当てで解決するが、両端の位相差が大きい場合や、複合断面と単一断面をつなぐ場合の見た目は確認が必要である。
3. **円の弓形差し引き** — 円に複数の側面の口を設けたとき、隣接する弓形同士が重なる場合がある。分岐数が多く、口の幅が広いときに起きる。重なる設計は検証で拒否する。
4. **描画メッシュの生成コスト** — 背骨から生成するメッシュは実行時生成であり、`WebGPURenderer` はジオメトリを最初の描画時にキャッシュする。生成は設計変更時のみとし、既存メッシュのジオメトリを差し替えない運用を守る必要がある。
5. **設計の自由度と性能の破綻** — 断面寸法とエッジ長に上限を設けないと、極端に大きな機体が作れてしまう。ノード数・総質量・最大寸法・複合断面の構成要素数に上限を設け、検証で拒否する。
6. **保存形式の互換性** — 機体の表現が部品の配列から背骨とアセンブリの構造へ変わるため、旧形式の保存データは既定の設計への読み替え以上のことはできない。読み替え不能な保存データは明示的に拒否し、破損した機体を生成しないこと。
7. **UIの総量** — 設計エディタは4つのモードを持ち、配管と段のモードが加われば6つになる。既存のパネルへ統合できないかを追加のたびに確認し、置き場の規約に従うこと。
