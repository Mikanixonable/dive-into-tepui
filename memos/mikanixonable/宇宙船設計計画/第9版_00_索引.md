## 土台として存在するもの

機体は `Vessel` という単一の実体である。艦艇・軌道基地・通信衛星・コンテナ・敵艦に専用のクラスは無く、能力は積んでいる搭載要素から導く。

形はノードとエッジのツリーと、各ノードの断面で決まる。ツリーは閉じてよい。直径もエッジの長さも 0.5 メートル単位である。質量・重心・慣性テンソル・投影面積は定数ではなく、形状と搭載物から導かれる。慣性テンソルは慣性乗積を含み、姿勢積分はそれを一般の対称テンソルとして扱う。

断面と立体の幾何量はすべて解析式で求まる。結合を平面の突き合わせに限り、曲面を融合させず立体の重なりを差し引かないため、数値積分を要する箇所が1つも無い。

資源と設備の連鎖が定義され、その連鎖が詰まらないことが機械的に検査されている。設計データの型と19項目の検証がある。通信圏の判定があり、圏外の無人機は実際に計画の実行を止める。

## この作品の骨格をなす方針

| 方針 | 内容 |
|---|---|
| 実体は1つ | 艦艇・軌道基地・通信衛星・コンテナ・敵艦は、すべて `Vessel` である。能力は積んでいる部品から導く |
| 形状は自由、寸法は離散 | 形はノードとエッジのツリーと、各ノードの断面で決まる。**直径もエッジの長さも 0.5 メートル単位**である |
| 物理量は形状の帰結 | 質量・重心・慣性テンソル・投影面積・接触形状は定数として持たず、形状と搭載物から導出する |
| 結合は平面の突き合わせ | 曲面を融合させず、立体の重なりを差し引かない。すべての幾何量が解析式で求まる |
| 技術ツリーはない | 研究点も前提技術の木もない。使えるものは、手に入れた資源と、それを変換する設備の連鎖によって広がる |
| 通貨はない | 市場もない。すべては**資源・設備・電力**を消費する生産によって賄われる。生産設備そのものの生産にも資源が要る |
| 進行は物理的な事実で止まる | 作れないのは技術が未解禁だからではなく、材料か設備か電力が足りないからである |
| 高性能な計算機が存在しない | 機上で自力にできるのは、時刻で駆動する噴射シーケンスと姿勢の保持まで。自動でのドッキング、軌道の誤差修正、目標の追尾、計画の変更は、観測して判断する処理であり外部からの指令を要する |
| 自動操縦は通信を要する | 無人機は通信モジュールを積み、通信圏の内側にいなければ計画を実行できない。通信網は基地から順に伸び、孤立した中継点は働かない。通信衛星は無人の `Vessel` である |
| 戦域は基地の周りから広がる | 序盤は基地自身が敵を迎え撃つ。掃討したのち、月周回軌道・静止軌道・地球低軌道・L1 へと、Δv と通信圏の両方に従って外へ広がる |
| 設計は基地の戦闘ビューの中で行う | 全画面のワークベンチを持たない。ドックモジュールを持つ基地を操作対象にすると、その戦闘ビューの中で機体を実寸で見ながら組む。専用のビューもカメラも増えない |
| 指せる粒度は見えている粒度 | 外から見える搭載要素は個別に指せる。外から見えない内装要素は指せず、それを収めている外皮の区画として指す |

**最後の2つは同じ判断から出ている。**画面に見えているものと、触れるものを一致させる。見えないものを触れるようにも、触れるのに見えないようにもしない。

## 着手順

**F12・B6・F9 の3本を並行して始める。**互いに依存せず、それぞれが別の壁を崩す。詳細と理由は第3巻 §3 にある。

**F12（外皮メッシュの生成）が最も多くの後続を抱える。**機体が形のとおりに描かれない限り、組んだ形を確かめる手段が無い。B7 → B8 → B12 → B13 の連鎖と B17 の配線が、いずれもここで開く。

**B6（生産）は、設計データと資源の帳簿を初めて繋ぐ。**設計から実機へ至る経路がここで生まれ、それまで生産の可否に影響していなかった資源の連鎖が、初めて進行を止める側に回る。

**F9（姿勢制御系の分離）は、機体の系列で先へ進む唯一の道である。**F10 とその先の F13・B10・B16 は、いずれもここを通る。

**依存の無い部分だけを先に通してよい段階が4つある。**B1 の分離の物理、B11 の通信パネル、B17 の判定の純関数、F8 は、いずれも今すぐ着手できる。
