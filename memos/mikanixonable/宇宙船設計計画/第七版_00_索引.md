# 宇宙船設計計画 第七版 — 索引

宇宙船の設計・推進・多段化・基地・資源進行に関する実装計画を2巻に分けて置く。各巻はそれ単体で読んで実装に入れるように書いてある。実装費用が大きく当面の対象から外した機能は、別に1本まとめてある。

## 2巻に分けた基準

**第1巻は「機体がどう成り立っているか」まで**を扱う。この巻を通した時点で、機体は既定の設計として1つ与えられるものであり、それを編集する手段はまだない。慣性テンソルも接触形状も抗力も形状の帰結になり、推進系は4つに分かれ、推進剤ごとに Δv が変わる。

**第2巻は「プレイヤーがどう作るか」**を扱う。設計エディタ、生産、配管、多段、基地の運用、資源の連鎖はすべてこちらにある。

この境目に置いた理由は、第1巻が**最初に行うべき内容だけ**で構成されるようにするためである。第1巻の各項目は、第2巻の何かを作るために先に済ませておかなければならないか、他のすべてが立つ土台になっている。

## 着手順

第1巻の実装計画（§15）が F1 から F12 までの順序を定める。要点は3つである。

**F1・F3・F4 は依存がなく、並行して着手できる。**

**F1（断面の幾何）から着手する。**`src/physics/` に閉じた純関数とテストのみであり、ゲームには一切繋がない。計画全体で最大の未知は「複合断面と一般化角錐台の物理量が閉形式で求まるか」であり、ここが崩れると第1巻の §6〜§9 の設計思想ごと組み直しになる。失敗しても捨てる費用がゼロである段階で先に確かめる。

**F4（`Vessel` への統合）は早く通す。**`Ship` / `Player` / `Base` の統合を後回しにすると、以降のすべてが3クラスに対して同じ変更を繰り返すことになる。

第2巻のうち、資源と設備のデータ定義および生産可能性の判定は、純粋なデータと純関数であり第1巻に依存しない。早期に着手できる。

## 進行の仕組み

**技術ツリーは存在しない。**研究点も、前提技術の木も、解禁の状態も実装しない。使える推進剤・エンジン・構造材は、手に入れた資源と、それを変換する設備の連鎖によって広がる。設計は常に自由に作れ、保存でき、制約を受けるのは生産だけである。

生産に必要なのは**資源・設備・電力**であり、通貨は使わない。通貨は基地の市場での資源の売買にのみ用いる。

## 決まっている方針

実装に入る前に確定した判断を挙げる。

| 項目 | 決定 |
|---|---|
| 自機の3Dモデル | 事前生成アセットを廃し、背骨からのロフト生成に置き換える。`export-assets` から自機のベイクを外す。砲・RCS・放熱板などの外装は個別メッシュのまま残る |
| 敵艦 | 背骨を持たない。種別ごとに定めた質量特性を直接与える経路を使う。この経路は `Vessel` の恒久的な2つ目の入口である |
| 接触形状 | 背骨の各エッジに対応するカプセルの集合。外接球は広域の絞り込みと天体表面への到達判定に残す |
| 抗力係数 | 自由分子流域の 2.2 の定数とし、投影面積のみを姿勢と速度方向から求める。`bcInv` は姿勢に依存する値になる |
| 生産の対価 | 資源・設備・電力のみ。通貨は市場での資源売買に限る |
| スロットル | 加速度による4段指定を廃し、絞り率 0〜100% の連続値にする。`[1]`〜`[4]` はプリセット |
| 設計エディタのモード | 骨格・搭載・配管・塗装の4つ。断面は骨格モードに含め、段の一覧は右パネルの常設表示に置く |
| 配管 | 自動敷設を既定とし、手動の敷設はその上書きとする |
| 作業のブランチ | worktree を使って並行する |

## 実装に入る前に想定しておくこと

**再突入のバランスが変わる。**現在の抗力係数は、質量の仮定が実際の機体質量と食い違っており、本来より小さい値になっている。形状と実質量から導出すると抗力が増え、大気減衰と再突入のタイミングが変わる。これはステージの敗北条件に直結するため、第1巻 F7 の時点でステージ側の高度と時間の調整が要る。

**スロットル操作の手触りが変わる。**同じキーでも、機体設計によって出る加速度が変わる。

**保存形式に互換性がない。**機体の表現が変わるため、旧形式の保存データは既定の設計への読み替え以上のことはできない。読み替え不能な保存データは明示的に拒否する。
