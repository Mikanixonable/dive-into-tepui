# 艦艇（Vessel）のカスタマイズ・組み立て・生産機能の設計提案

## 1. 全体コンセプトと設計思想

### 「ハンガー・ワークベンチ (Hangar Workbench)」
* **自由度と直感性の両立**: 難解なノード接続や複雑すぎるパラメータ入力ではなく、「3Dモデルの部位（ハードポイント）をクリックして選択」「パーツを選ぶとホログラムで即座に装着プレビュー」「カラーパレットで塗装」という視覚的で直感的な操作感を実現。
* **スペックのリアルタイムフィードバック**: パーツを変更した瞬間に、**推力重量比 (TWR) / デルタV (Δv) / 機動角加速度 / 熱・電力収支 / 火力** がリアルタイムでレーダーチャートおよび数値比較インジケータ（+ / -）として変化。
* **「設計」と「生産」の分離**:
  1. **カスタム設計（Blueprint化）**: コストを気にせず自由なパーツ配置や色決めを行い、「設計図（ブループリント）」として保存。
  2. **生産（Production / Manufacturing）**: 保存した設計図をもとに、クレジットや資材を消費してドックに実機を生産・配備。

### (1) 追加・拡張するデータモデル（`src/game/dynamic/dynamic-entity/`）

#### ① `VesselBlueprint`（新規作成: `src/game/dynamic/dynamic-entity/blueprint.ts`）
プレイヤーがデザインした艦艇の「設計図」を表すシリアライズ可能なデータ構造。
```typescript
export interface PaintScheme {
  primaryColor: string;    // メイン装甲色 (HEX)
  secondaryColor: string;  // サブ装甲/フレーム色 (HEX)
  accentColor: string;     // 発光・アクセント色 (スラスター炎やコックピットガラス)
  metalness: number;       // 金属感 (0.0 〜 1.0)
  roughness: number;       // 粗さ/ツヤ (0.0 〜 1.0)
}

export interface HardpointBinding {
  socketId: string;        // 装着先ハードポイントID ('nose_gun', 'engine_main', 'wing_l', etc.)
  partId?: string;         // 倉庫内の既存パーツID、またはカタログのパーツ種別
}

export interface VesselBlueprint {
  id: string;
  name: string;            // 例: "Kestrel Mark-II", "Heavy Gunship"
  frameId: string;         // 使用する艦艇フレーム ('interceptor_v1', 'cruiser_v1' など)
  bindings: HardpointBinding[];
  paintScheme: PaintScheme;
}
```

#### ② `VesselFrame`（新規作成: `src/game/dynamic/dynamic-entity/vessel-frame.ts`）
艦艇の基礎スケルトン（骨格）を定義するマスターデータ。艦艇タイプごとに装着可能なスロット（ハードポイント）の座標や対応パーツ種別を持つ。
```typescript
export interface HardpointSocket {
  id: string;
  name: string;              // UI表示名 (例: "機首固定武装", "主推進器", "右舷ソーラー")
  allowedType: PartType;     // 装着可能な PartType ('weapon' | 'thruster' | 'solar_panel' など)
  localPosition: Vec3;       // 3Dモデル上の取り付け位置
  localRotation: Vec3;       // 向き
  size: 'S' | 'M' | 'L';     // スロットサイズ
}

export interface VesselFrame {
  id: string;
  name: string;              // 例: "インターセプター級軽フレーム"
  baseMass: number;          // 乾燥重量
  baseHp: number;            // フレーム基礎耐久
  sockets: HardpointSocket[];
}
```

#### ③ `Part` のビジュアル拡張（`src/game/dynamic/dynamic-entity/parts.ts`）
各パーツに 3Dメッシュ識別子（`meshAssetId`）とアタッチ用のオフセットを追加し、アセンブリ時にどの3Dモデルをどこに結合するかを紐付ける。

### (2) 3D描画・ビジュアル層の変更（`src/render/`）

#### ① `ModularVesselBuilder`（新規作成: `src/render/modular-vessel-builder.ts`）
`VesselBlueprint` と `VesselFrame` から、1つの完成された `THREE.Group`（3Dメッシュ）を動的に合成・構築するビルダー。
* フレームのベースメッシュに対し、各ソケットの位置に指定されたパーツのメッシュ（スラスター、武器、ソーラーパネルなど）を子オブジェクトとしてアタッチ。
* マテリアルの色や金属感 (`paintScheme`) を一括適用。
* 部品選択中・ホバー時には、そのソケットの 3D 位置にホログラム（半透明ワイヤーフレームやハイライト枠）を表示。

#### ② `VesselYard3DView`（新規作成: `src/render/vesselyard-viewport.ts`）
基地ビュー専用のインタラクティブな 3D キャンバス・スタジオ。
* 3Dターンテーブルカメラ（ドラッグで360°回転、ホイールでズームイン、部位クリックでフォーカス）。
* シーンライティング（スポットライト・リムライトを効かせ、暗闇のハンガーの中で艦艇が映える演出）。

### (3) ロジック・ステート層の拡張

#### ① `Vessel`（旧 `Ship`）/ `Player` クラスの更新（`src/game/dynamic/dynamic-entity/vessel.ts` または `ship.ts`）
* `recalculateSpecsFromBlueprint(bp: VesselBlueprint)` メソッドを追加。
* 単にパーツの `maxHp` や `weight` を合計するだけでなく、**総重量・推力重量比 (TWR)・慣性モーメント（旋回性能）・発電・放熱・DPS** を動的に再計算。

#### ② `BaseState` の拡張（`src/game/dynamic/dynamic-entity/base.ts`）
* `blueprints: VesselBlueprint[]` （基地に保存されている設計図リスト）
* `productionQueue: ProductionTask[]` （生産中の艦艇と完了までのタイマー）を追加。

### 直感的かつリッチにするための 4つのUI工夫

#### ① 3Dソケット直接クリックと「ホログラムプレビュー」
* 中央の 3D ビューポート上で、艦艇の未装着パーツ枠や各部位を直接クリックすると、カメラがその部位へスムーズにズームイン。
* 左パネルのパーツ一覧でパーツにカーソルを合わせる（ホバーする）だけで、3Dビュー上の艦艇に**半透明のホログラムメッシュ**として仮装着され、見た目の変化を確認。

#### ② カラー＆テクスチャ・ペイント工房 (Livery Studio)
* **直感的なカラーパレット**: 16進数入力だけでなく、洗練されたカラープリセット（例: 「ステラ・ブラック」「ネイビー・コマンド」「ミリタリー・オリーブ」「ソーラー・ゴールド」など）をワンタップで適用可能。
* **マテリアル質感スライダー**: メタリック（金属光沢）やラフネス（マット〜ツヤ）をスライダーで変更すると、3Dビューのライティングと反射がリアルタイムに変化し、質感を楽しめる。

#### ③ 差分（Diff）が見えるリアルタイム・スペックモニター
* パーツをホバー/選択した際、右パネルのスペック表示に**差分**が緑色（強化）や赤色（弱体化）でハイライト表示。
  * 例: `推力重量比: 2.1 G ➔ 2.8 G (+0.7 G)` `総重量: 1,200 kg (+150 kg)`
* 直感的な5角形レーダーチャート（機動力・耐久性・火力・航続距離・熱制御）により、専門的な物理数値に詳しくないプレイヤーでも「どんな性格の艦艇になったか」が一目でわかる。

#### ④ 「ワンタップ・プリセット」でシンプルさも維持
* カスタマイズの自由度が高すぎても迷わないよう、ワンタップで組み立てられる**「プリセット構成」**（例: 『高速一撃離脱仕様』『重装甲砲撃仕様』『長距離偵察仕様』）を用意。
* プリセットを選んでから「色だけ変える」「武器だけ変える」といったライトなカスタマイズも可能。

## 4. 段階的な実装ロードマップ

```
[Phase 1: データ・計算層] ➔ [Phase 2: 3Dアセンブリ・描画層] ➔ [Phase 3: 3panel UI構築] ➔ [Phase 4: 生産・配備機能]
```

1. **Phase 1: データ構造の拡張（`VesselBlueprint` & スペック動的計算）**
   * `VesselBlueprint` 型の定義と、Blueprint から Mass/Thrust/Torque/Thermal 等を計算する純粋関数・メソッドを作成。
   * セーブデータへの組み込み。
2. **Phase 2: 3Dモジュール合成とカラー適用（`ModularVesselBuilder`）**
   * パーツごとの3Dメッシュアタッチメントおよび `paintScheme`（カラー・マテリアル書き換え）を実装。
3. **Phase 3: BaseView UI の全面リニューアル**
   * 3面板スタイルの `BaseView` へ刷新。
   * 3D Viewport キャンバスの埋め込みとドラッグ回転・パーツホバープレビューの実装。
4. **Phase 4: 生産（Manufacturing）機能と配備**
   * 作成した Blueprint に基づく「新造・生産」アクションと、生産した艦艇を配備するロジックの接続。
