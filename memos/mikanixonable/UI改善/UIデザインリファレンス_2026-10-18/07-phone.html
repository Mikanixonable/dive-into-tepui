844×390 の横持ちスマホは、現行のレイアウトの前提(左右に幅 220〜260px のレールが立ち、全体ステータスが 2 行)がそのまま崩れる。 戦闘では左右レールだけで画面の 57% を覆い(--rail-w-left: 220px + --rail-w-right: 260px)、マップでは案内帯が物体一覧に重なり、軌道パネルの値は「…」で切れる(監査 10)。 そのうえ撮影画面には出ていない仮想パッド(#touch-ui。最初のタッチで現れる)が、レールの上にさらに重なる。 実際には、並進パッド(左下)・回転パッド(右下)・FIRE・ZOOM・推力段・制動/微動・ホールド・ワープ・ヘルプが、レールのパネルと同じ領域を取り合う。

方針は 3 つ。(1) 縦 390px では、常時出すものを「いまの判断に要る読み値だけ」に絞る(位置と速度・燃料・ターゲットまでの距離・弾薬)。 (2) それ以外の計器は、レールの代わりに「計器シート」へ逃がす(下から出る面。タブで 艦/軌道/ターゲット/敵 を切り替える)。 (3) 親指の届く下の両端を操作面に、中央は 1 本指ドラッグ(カメラ)のために空ける。 ブレークポイントは新設しない — MQ_COARSE_SHORT(coarse かつ高さ 500px 未満)を「スマホ横持ち」の判定として使う。 部品は 01 で定めた .ix-* をそのまま使い、密度だけを上げた(文字は 11px 未満にしていない)。 上部ツールバーの「現行/改修案/比較」は、現行の撮影がある戦闘・マップの 2 面だけが意味を持つ。シート・縦持ち・親指の図には現行が無いので、「現行」にすると空になる。

  3. タップ最小 44px。現行の .rail-toggle は 30px(--hud-rail-toggle-size)で、pointer: coarse でも広げていない — SPEC §6「タップターゲットは最小 44px」に反している。coarse-short ではレールごと無くなるので問題は消えるが、coarse の中間幅(タブレット)では別途 44px に直す必要がある。 src/game/hud/style/skeleton-style.ts(#hud .rail-toggle) ・ src/game/hud/style/layout-tokens.ts(--hud-rail-toggle-size) ・ SPEC UI-DESIGN §6

現行コードから拾った小さな問題(改修で一緒に直す)

どこ何が起きているか
touch-controls.ts の MQ_COARSE/MQ_SHORT/MQ_COMPACT 3 ブロック同じ grid-template-columns / left:6px; bottom:6px を 3 回書き、基底の calc(10px + var(--safe-l)) を捨てている。ノッチ端末でパッドがセーフエリアに食い込む。MQ_SHORT は coarse を問わないが、#touch-ui は初回タッチまで出ないので実害は無い。
buildRotationPad の並び下段が [→ ヨー][↑ ピッチ][← ヨー] の順で、矢印と位置が逆(→ が左)。意図(スティックの向き)かどうかを確かめて、そうでなければ [← ヨー][↑][→ ヨー] へ揃える。このページは現行の並びのまま描いた。
layout-tokens.ts と SPEC §5「ブレークポイント」SPEC は 700/1100px、コード(breakpoints.ts)は 760/1184px。844px は SPEC では「中間」、コードでも medium(760 以上)。スマホ横持ちは幅クラスでなく MQ_COARSE_SHORT で扱う方針なので、どちらでも結論は変わらないが、閾値の食い違いは別途 SPEC に合わせて直す。

G改修の手順(小さく入れられる順)

  1. パッドのセーフエリア対応と重複の整理(touch-controls.ts)。3 つの @media を MQ_COARSE 1 つにまとめ、座標を --safe-* から導く。ラベル「機首下げ/上げ」→「ピッチ」。見た目の変更はほぼ無く、実機で最初に効く。
  2. タップ寸法の是正(skeleton-style.ts / layout-tokens.ts)。.rail-toggle を coarse で 44px に。#hud-chase-reset と #hud-help-badge は既に 44px。
  3. 上部ストリップの 1 行化(top-bar.ts / skeleton-style.ts)。MQ_COARSE_SHORT で 2 行の全体ステータスを 1 行 44px に。ワープの « » をここへ移し、util 行を縮める。
  4. シートの導入(layout-tokens.ts / hud-root.ts / panel-shell.ts)。MQ_COARSE_SHORT でレール幅を 0 にして、同じパネルをシートのタブに入れる。まず「艦」「軌道」の 2 タブから。SPEC §5 に 1 文(レール=coarse-short ではシート)を足す。
  5. モードドック・推力段・常時小計器。推力段の SegmentedControl を touch-controls へ移し、制動・微動・ホールドを 1 つのドックにまとめる。小計器 2 枚を足す。
  6. マップの下部バー(display-timeline-panel.ts)。巨大パネルを 1 本の帯 + 取っ手に畳み、期間ピルを「時間」タブへ。物体一覧を「物体」タブへ。縦持ちは同じ部品を縦に並べ替えるだけ。
