MOLECULAR BUILDER

モジュールは原子、接続は結合。結合角が形に必然性を与え、組むたびに重心・推力線・トルク・Δv が図で更新される。ドッキングも分離も「結合を作る/切る」で統一。
パレットからドラッグ(またはクリックで構え)→ 光る結合手へ吸着 → 離して配置 結合の棒クリック=切断(分離)右クリック原子を撤去/構え解除 Space試験噴射Ctrl+Z/Y 戻す/進むShift押しながら連続配置 ホイール=拡大 / 背景ドラッグ=移動 / F全体表示

部品 = 原子

▾試してみる
  1. 左の RCS を右クリックで外し、空いた左の手へ「タンク S/L」をドラッグ。片側だけ重くなり、推力線が重心から外れて赤いトルクが出る。
  2. 試験噴射。機体が回り出す。「RCS 姿勢保持」を ON にして押し返せるか見る。
  3. 右にも同じタンクを足すと対称になりトルクが消える。Ctrl+Z で戻して別の足し方を試すと履歴の枝が分かれる。
  4. 「貨物と結合」: 機首のドックが貨物の結合手と結ばれる。結合の棒をクリックすれば切れる。
