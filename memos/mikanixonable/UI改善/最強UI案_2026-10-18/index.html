First steps最小の第一歩

  1. 会合計器のゴースト(02)を戦闘ビューへ。噴く前の相対軌道を CW 方程式で描くだけ。直感性の伸び幅が最大で、新しい画面を要しない。
  2. 未来を掴む時間軸(01)をマップビューへ。下端の帯をドラッグすると全物体がゴーストとして動く。既存の予測軌道計算を使い回せる。
  3. 注意点での自動停止(05)。Kerbal Alarm Clock 相当の機能で、時間加速の不満を最小の工数で消す。
  4. 警報の3階層と縁の光(06)。状況による再構成は後回しにし、規則だけを先に入れる。
  5. M キーの切替をズームへ置き換える(01)。ここまでの4つが揃えば準備が整う。04 の皮膚と 07 の建造は独立に進められる。
