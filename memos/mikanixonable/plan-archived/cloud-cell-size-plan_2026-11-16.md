# 雲の対流セル径場と一様見えの修復 — 要件定義・実装計画

2026-11-16 作成。対象ブランチ: `refactor/earth-weather-restructure`。
SPEC の正本は `DEVELOP/SPEC/RENDERING.md`「雲の描画」節。本計画が実装するのは**すでに仕様へ
書かれた振る舞い**であり、SPEC/ の変更は要らない（挙動の要求は既存記述で足りる）。

## 1. 背景と診断の結論

要求: 「雲の被覆率と同レベルの、描画系で参照するための情報として、対流セルの大きさという
概念を追加したい」。巻雲・積雲それぞれについて、被覆率＋対流セル径の 2 スカラー場と風向き
から、実際の気象の雲区分に従う多様な雲（大きさ・形・寿命・連鎖/単独生成・雲高・サブ配置）
を描きたい。

### 1.1 「一様に見える」の切り分け（調査済み）

被覆率のダイナミックレンジは健全。主因は描画応答側:

1. **ディザ飽和**: `cloud-shape-evaluator.ts` の `opaqueFraction` — 不透明度 >0.46 の柱は全て
   画素被覆 100% に張り付き、被覆率 0.46〜0.91 が見た目 1 値に潰れる（`cumulus-shape.ts` の
   帯 0.22–0.46）。
2. **飽和板に残る信号が「平らさ」だけ**: sparse 域の雲頂は被覆率 0.46–0.7 で 591–846 m
   （±130 m）しか動かず、アルベドは定数 0.8、法線は texel 勾配しか拾えない。細部ノイズも
   ±0.25 の深さで飽和板を破れない。
3. **巻雲の全面靄**: `hazeOnset` 0.38 が上層湿度基準 0.42 を下回り、ほぼ全球に τ≈0.03 級の
   白みが乗ってコントラストを洗い流す。
4. **全球 cap では対流粒が解像限界で消える**（48/24 km ノイズ vs ~25 km texel、Nyquist として
   正しい）— 被覆率を刻む項と塔を立てる項が両方ゼロになる。
5. **セル径が全球で一定** — 対流ノイズは 48/24 km 固定、細部オクターブ梯子も 32 km〜0.25 km
   固定。場依存なのは振幅と傾きだけで、どの空でも同じ粒の大きさ。

### 1.2 既存の部品（調査済み）

- 雲場の契約: 3 テクスチャ × RGBA = 12 ch 全使用（cloud: cumulus/cirrus/cirrusFlow×2、
  environment: land/convection/climateCloudiness/anvil、motion: surfaceWind×2/upperWind×2）。
  `BakedField` は MRT 任意出力数対応 → **セル径場は第 3 出力（RGBA）が置き場**。
- 対流ノイズは網目(y)/粒(x) の 2 成分で、湿度でブレンド済み（SPEC「少ない所=網目・多い所=
  粒」の一部実装）。層積雲デッキ・寒気噴出の fetch 依存被覆遷移・塔・金床・cirrusFlow も既存。
- 細部層は段ごとの寿命 τ∝λ^(2/3) を持つ（`cloud-detail-clock.ts`）— セル径で波長梯子を
  伸縮すれば寿命も自動で伸縮する。
- 風 → 形の経路は一部存在（巻雲の cirrusFlow 引き伸ばし最大 7 倍、積雲細部の streak
  最大 2 倍・fine のみ）。

## 2. 要件定義

- **R1**: 巻雲・積雲それぞれの「対流セルの大きさ」を、被覆率と同レベルの場として焼き、
  描画系が参照できるようにする。ユーザー決定: **セル径のみ**（型・組織化・伸び・年齢位相は
  場へ入れず、既存チャンネル＋セル径から描画側が導く）。
- **R2**: セル径は気象の診断から連続的に導く — 実際の雲区分（閉じた細胞・開いた細胞・
  雲列・平流積雲・孤立対流・かなとこ残滓・繊維状巻雲）の傾向に従うこと。緯度・海陸は
  直接の切替条件にせず、環境量を介して効く（SPEC 準拠）。
- **R3**: セル径は描画の細部尺度・粒の見た目・寿命・（風による）並びへ効かせる。
- **R4**: 診断で特定した一様見えの原因を同じ計画で修復する（ユーザー決定）。
- **R5**: 実写（観測）雲場の契約を壊さない — セル径場は中立の既定値を供給する。

## 3. 設計

### 3.1 場の契約（第 3 出力）

`cloud-field.ts` の MRT へ第 3 出力を追加。texel = RGBA HalfFloat:

| ch | 内容 | 値 |
|---|---|---|
| R | `cumulusCell` 積雲のセル径 | log2(径 [km]) |
| G | `cirrusCell` 巻雲の要素径（繊維・鱗のピッチ） | log2(径 [km]) |
| B,A | 予約（将来の組織化・伸び用。0 で焼く） | 0 |

- log2(km) を生値で焼く（HalfFloat なら正規化要らず、2 スロットの線形補間は幾何平均
  = 径として自然）。参照実装: `cloud-field-sample.ts` の pack/unpack、`observed-cloud-field.ts`
  の既定値供給、`cloud-field-sampler.ts` の `distinctTextureNode` 3 本目の結び。

### 3.2 セル径の導出

`condensation.ts`（または新設の `cell-size.ts`）で `WeatherSample` から log 域の加重混合で
連続的に導く。各「型」のプロトタイプ径に、既存の診断を門として掛ける:

| 型 | セル径 [km] | 門（既存診断） |
|---|---|---|
| 閉じた細胞（海洋性層積雲の板） | 40–100 | `stratocumulus`（condense 内部で計算済み） |
| 開いた細胞（寒気噴出・fetch 長） | 15–40 | `airMass.ocean`（fetch）— **WeatherSample に新規公開が必要** |
| 陸上の孤立対流（千切れ・鋭縁） | 2–8 | `landFraction` × `convectiveActivity` |
| 熱帯の集団（収束帯・平年高雲量） | 80–200 | `meanCloudiness` × 高い `surfaceHumidity` × 低活発度 |
| 前線帯に埋まった粒 | 20–60 | `band` |
| 既定（中緯度の海） | ~50 | 残余重み |
| 巻雲・繊維（ジェット下） | 1–5 | `cirrusFlow` の揃い度・`upperWind` 強さ |
| 巻雲・鱗（撹乱上層） | 1–7 | `convectiveActivity`・`landFraction`（既存の縮小項と整合） |
| 巻雲・金床残滓 | 30–150 | `anvil` |
| 巻雲・無撹乱の板 | 10–40 | 残余重み |

- 混合は log 域（`logCell = Σ w_i·log(s_i)/Σw_i`）で、重みは連続 → 径はどこでも跳ばない。
- `airMass.ocean` は `weatherAt` 内部では使われているが `WeatherSample` へ出ていない →
  `WeatherSample` に `oceanFetch`（0..1、海上滞在比）を追加する。
- 全径・門の定数は `CLOUD_TUNING` の調整値へ（cloud-lab のスライダーで動かせる）。
- 参照した気象学的な値域: 閉じた細胞 30–100 km・開いた細胞 10–40 km・雲列の横断
  ピッチ 2–20 km（Wood 2012 の中規模細胞対流レビュー、Agee らの雲列研究、
  Stevens 2020 の貿易風パターン整理に整合）。径は実測の概数であり、すべて
  `CLOUD_TUNING` 経由で調整できる。

### 3.3 描画側の消費

セル径は「場所で変わる細部の基本スケール」として使う:

1. **積雲細部（`cloud-detail.ts`）**: `DETAIL_WAVELENGTHS` 梯子全体に、texel 位置の
   `cumulusCell` 由来の倍率 `cellScale = cell_km / 基準径` を掛ける（基準径 ≈ 現在の等価
   スケール 24–48 km）。**寿命は段ごとの τ∝λ^(2/3) が自動追従する**ので大きいセルほど
   長生きになる（R3・SPEC「小さな粒ほど早く入れ替わる」）。
2. **粒の傾き（`grainOf`/tilt、`cloud-shape-evaluator.ts`）**: セル径を grain 傾きへ混入し、
   同じ画面密度でもセル径の違う空が違う質感で読めるようにする。
3. **巻雲（`CirrusDetailEvaluator`、同ファイル）**: 静的領域ノイズで選んでいたピッチ
   （`CIRRUS_CELL_PITCH_MIN/MAX`）を `cirrusCell` で駆動する。流れ方向の引き伸ばし
   （cirrusFlow・`CIRRUS_STRETCH_MAX`）は既存のまま — セル径は**横風方向のピッチ**に効く。
4. **積雲の場レベルの粒立ち（`condensation.ts`）**: `granularity` の効きをセル径で変調 —
   小さいセルの所ほど被覆率を深く千切り、大きいセル・板の所は滑らかに残す。これで焼かれた
   被覆率場にも「荒い空/滑らかな空」の違いが載り、全球 cap で見える質感に効く。

### 3.4 一様見えの修復（R4）

- **F1 飽和板の質感**: 二値化で覆いが飽和した域でも、柱の光学厚（cumulus 量→τ）を
  表面の明るさ・雲頂起伏へ効かせて、厚みの階調を残す（SPEC「雲の白さは厚みで変わる」）。
  具体的には `opaque-cloud-surface-renderer` のアルベド/法線評価へ場由来の τ 勾配を混ぜる。
  飽和帯の二値化そのものは積雲の不透明性の根拠なので、維持する。
- **F2 巻雲靄の全域化**: `hazeOnset` を上層湿度の基準より上へ引き上げるか、平年雲量
  （`climateCloudiness`）を門として乾燥帯では靄を消す。乾燥帯が晴れる SPEC に沿う。
- **F3 全球 cap の粒消失**は Nyquist として健全なので手を付けない（場の 100 km 級成分は
  湿度オクターブが担う）。**不採用**: 対流ノイズの座標系に場依存のスケールを掛けて焼き直す
  案 — 移流・2 位相リサイクルの同一性追跡が破綻し、費用も読めない。セル径で粒度の
  「効き」を変える方式（3.3-4）で代替する。

### 3.5 連鎖生成・寿命・雲高・サブ配置の扱い

- **連鎖生成 vs 単独生成**: 個体追跡はしない（texel 場の契約と両立しない）。fetch 勾配に
  沿って径が縮む場の形（開いた細胞が下流へ伝搬する見え）と、2 位相移流の位相リサイクルで
  生まれ変わる見えで表現する。
- **寿命**: 細部層の λ 連動（3.3-1）で径→寿命が導かれる。場レベルでは 18 h エポック混ぜ替えと
  20 h 移流リサイクルが既存。
- **雲高**: 既存の塔・層状・金床の機構のまま。必要ならセル径→雲頂 bias の相関は調整段で加える
  （今回は入れない — 効果が読めてから）。
- **サブ配置（texel 内の並び）**: 網目/粒の湿度ブレンドと細部層が担う現状のまま。

## 4. フェーズと検証

- **Phase A 契約**: `WeatherSample.oceanFetch` 公開、`CloudSample` + 第 3 出力、pack/unpack、
  `cloud-field-sampler` 3 本目、`observed-cloud-field` 中立値、契約コメント。
  検証: typecheck + test:render。
- **Phase B 導出**: セル径の加重混合と `CLOUD_TUNING` 調整値。weather-probe で径の
  緯度・海陸・前線分布を確認（閉じた細胞が亜熱帯西海岸沖に、開いた細胞が寒気噴出域に、
  小径が陸・集団が収束帯に出るか）。検証: typecheck + weather-probe 読み戻し。
- **Phase C 積雲側接続**: 細部梯子のセル径スケール、granularity 変調、grainOf 混入。
  検証: test:render + render-lab 前後比較（cloud-detail 系撮影は全段差が出る想定 — 封筒外は
  差分画像で説明可能にする）。
- **Phase D 巻雲側接続**: CirrusDetailEvaluator のピッチ駆動。検証: 同。
- **Phase E 一様見え修復**: F1・F2。検証: render-lab 前後比較 — `earth`/`leo` 系で板の
  階調が残るか、乾燥帯で靄が消えるかを撮影で確認。
- 全体: `npm run typecheck` / `test:render` / `check:boundaries`。雲場の変更なので
  cloud-lab での目視確認も推奨。

## 5. 不採用案・未確定

- **不採用: セル径以外の場チャンネル（型・組織化・伸び・年齢）** — ユーザー決定「セル径のみ」。
  B/A は予約として空けてある。
- **不採用: 対流ノイズへの場依存周波数ワープ** — 3.4-F3 に記載。移流同一性が壊れる。
- **不採用: 観測雲場への画像解析由来のセル径推定** — 中立定数で十分（R5）。
- **未確定**: セル径 → 雲頂の相関（小セル=低い雲）は 3.5 の調整段で扱う。雲列の風向きへの
  並び（streets）は既存 streak 機構へセル径を掛ける形で C で扱うが、横風ピッチと引き伸ばし
  の両立は実装段で見る。
- **保留**: 全球視点でセル径場そのものが 25 km texel で潰れる粒度（≤25 km セル）は、
  texel 内の平均径として焼かれる — 見えは細部層に委ねる。全球ビューの質感改善は主に
  Phase E が担う。
