03 / generated source

C. WeatherModel.weatherAt の中で値がどう変わるか

左から右が計算依存。下の細胞行だけは、上の湿度・風を入力にする。

WeatherSample を作る主経路

最終的に condense(weather) が読む値。

01
pressureFieldAt(direction)pressure / gradient / isobar / bend
02
balancedWind(...)局所気圧風 + atmosphericWind + RossbyWave → surfaceWind / upperWind
03
transport.advectedAt(...)移流後 surfaceHumidity / upperHumidity / convection
04
airMass.at / climate.slopewarmth / compression / terrainLift / front / rainband / lift
05
surfaceHumidity / upperHumidity平年雲量・上昇流・目・金床を加減算し 0..1 へ clamp
06
WeatherSamplecondense の入力として coverage・雲頂・薄い雲へ渡る

細胞の発生箇所

「画像へ後付け」ではなく、対流場の時点で作る。

01
CirculatingNoise.pairAt(direction)同じ gradientNoise から x=grain / y=network を返す
02
convectionSourceAt(direction)48 km と 24 km の2段を RG に焼く
03
WeatherTransport.advectedAt対流用の風で2位相移流し、時刻に応じて読む
04
condense(weather)湿度 0.45..0.70 で network → grain を混ぜ、granularity を coverage へ足す
CirculatingNoise.pairAt · condense

05 / rendering consumers

E. 3つの描画経路：同じ値をどう解釈するか

3行は同じ CloudRenderInput を読む並列経路。位置に実行順の意味はない。

OpaqueCloudSurfaceRenderer

不透明な雲頂。G-buffer の雲殻レイヤーへ書く。

IN
fieldSampler.sampleCloud(direction)CloudSample: RGBA basis + derived coverage / cloudTop / translucent
01
CloudShapeEvaluator.grainAt6 km gradientNoise。画面波長に応じて振幅 fade
02
opaqueFractioncoverage + grain × 0.25 をディザ帯へ変換
03
clearanceAt / cloudTopRadius雲頂の内外を判定。最初の交点を探す
OUT
marchedSurface → depthNode / normalNodeGBuffer.render の LIT_CLOUD_SHELL_LAYER
marchedSurface · GBuffer.render

CloudAtmosphereRenderer

大気積分へ球殻イベントとして挿入する。

IN
CloudFieldSampler.sampleCloud(up)交点方向の CloudSample
01
columnOpticalDepthOfcirrus は inSitu / convective、cumulus は liquid basis → τ
02
shellAirmassNode視線角で airmass を増幅。ただし接線付近は有限化
03
AtmosphereCloudLayers.build外殻から front-to-back のイベント列を作る
OUT
AtmosphereCloudLayers.composetransmittance / inscatter を大気結果へ合成
scatteredAt · build / compose

CloudShadowRenderer

受け手から太陽へ向かう光路の透過率を計算する。

IN
transmittance(worldPos, footprint)受け手位置 / 画面 footprint / sun direction
01
SHADOW_TAPS = 6光路を6区間へ分けて sampleOffset を作る
02
fieldAt(up) + grainAt雲頂より下を通った割合を opticalDepth へ加算
OUT
exp(-opticalDepth)地表ライティングへ渡す receiver transmittance
